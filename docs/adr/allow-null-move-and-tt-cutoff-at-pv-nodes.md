# null moveと置換表の打ち切りをPVノードでも行う

## ステータス

承認済み。決定日は2026年9月28日。

## コンテキスト

StockfishとYaneuraOuは、null move pruningと置換表の値による打ち切りを、最善応手列の候補を読むPVノードでは行わない。
minaseは、どちらもノードの種別を問わずに行う。
[棋力向上段階12](../plans/strength-stage12.md)は、これらの前提条件の欠落を2項目として測った。
1つ目は、null moveを試す条件に、非PVノードであることと、補正後の静的評価がβ以上であることを加える変更である。
この変更は、[発動率の診断](../measurements/strength-stage12-activation-diag.md)でnull moveを試すノードの37.00%を試さなくし、その内訳の大半は静的評価がβ未満であることだった。
STCは上限の3,000ペアで2,853有効ペア、得点率50.0%、LLR −2.807の判定保留となり、停止時点のLLRが負なので採らなかった（[測定記録](../measurements/strength-stage12-null-move-stc.md)）。
2つ目は、PVノードでは置換表の値で打ち切らず、記録手を順序付けにだけ使う変更である。
動機は、対局履歴や探索経路にある局面へ戻る手を引き分けとするので、探索値が経路に依存することだった。
しかし診断では、PVノードの打ち切りの大半は反復を検出しない静止探索で起きており、通常探索のPVノードで打ち切ったものは0.66%だった。
STCは1,346有効ペア、得点率49.1%の`H0`だった（[測定記録](../measurements/strength-stage12-pv-tt-cutoff-stc.md)）。
2項目はどちらも非PVノードに限る前提条件を加える主張なので、1つの決定として扱う。

## 決定

null move pruningは、ノードの種別と静的評価のβとの大小を条件にせずに試す。
置換表の値による即時打ち切りは、深さと種別の条件を満たせばPVノードでも行う。

## 検討した代案

null moveを非PVかつ補正後の静的評価がβ以上のノードに限る案は、上記のとおり判定保留でLLRが負だったので採らなかった。
PVノードで置換表の値による打ち切りをやめる案は、上記のとおりSTCで`H0`だったので採らなかった。

## 結果

null moveの適用条件は残り深さ3以上、直前がnull moveでない、βが詰み帯の外、手番側に王駒以外の駒がある、の4つのままである。
経路に依存する探索値が置換表を通じてPVへ入り得ることは、既知の近似として残る。
Stockfishのように、β打ち切りが予想されるノードの予測を持ったうえで条件を加える方式は、ノード種別の予測の土台を要するので未測定である。

# NNUEの学習では、どのパラメータ群にも重み減衰を掛けない

## ステータス

承認済み。決定日は2026年11月14日。

## コンテキスト

NNUEの学習器は、1つのAdamWの中でパラメータを線形の経路、第1層、出力部の3群に分け、群ごとに学習率と重み減衰を与える（[AdamWのADR](use-pytorch-adamw-with-bias-correction.md)）。
重み減衰は線形の経路が0、第1層と出力部が1×10⁻⁴であり、後者はFMの学習器がPyTorchのAdamWで使った値を引き継いだもので、NNUEで選んだ根拠の記録はなかった。

先行の学習器の調査（[学習レシピの調査](../research/nnue-training-recipes.md)）では、nnue-pytorch、tatara、tanuki-、およびvariant-nnue-pytorchが重み減衰0であり、Stockfishも入力を因子化する層にだけ4×10⁻⁵を掛けていた。
1×10⁻⁴を使う先行例は見つからなかった。
2026年11月14日にエンジンの開発者は、まだ直していない条件のうち先行例とずれているものを先行例に合わせると決めた。

## 決定

NNUEの学習器の`--weight-decay-ft`と`--weight-decay-head`の既定値を0とし、標準レシピは重み減衰の引数を指定しない。
重み減衰の引数そのものと、AdamWの分離した重み減衰の式は残す。

## 検討した代案

1×10⁻⁴を続ける案は、選んだ根拠の記録がなく、同じ値を使う先行例もないので採らない。
bulletの既定の0.01に合わせる案は、同じ値を使うと確かめた先行例がbulletだけなので採らない。

## 結果

重み減衰がないので、非線形の経路の大きさは、更新ごとの値の範囲の切り詰めだけで抑える。
重み減衰の計算の経路は、0でない値を明示して与えるテストで確かめ続ける。
PSTとFMの学習器の重み減衰は変わらない。

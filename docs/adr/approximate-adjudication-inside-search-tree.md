# 探索木の中では規則の裁定を近似し、厳密な裁定をルートと審判層に委ねる

## ステータス

承認済み。決定日は2026年8月22日。

## コンテキスト

中将棋では王手放置も自殺手も合法なので（RULES.md第8条）、探索の合法手に王の安全の確認は要らない。
一方、反復規則のR1からR3、駒枯れ（第22条）、E3の裸玉裁定、および詰み（第21条）の裁定は、対局履歴や局面全体の条件に依存する。
R1からR3の判定に要る履歴は対局管理層の内部にあり、探索へは対局開始から現局面までの局面キーの履歴だけを渡す。
主要なエンジンも、探索木の中では同一局面の2回目の出現を引き分けとする近似を許容している。
これらの方針は[探索部](../plans/search.md)の設計判断で定めた。

## 決定

探索木の中では、次の軽量なモデルだけで終局を扱う。
相手の最後の王駒を取る着手は、子局面で終局したものとして`MATE - (ply + 1)`を返す。
手番側に合法手がなければ、第23条により`-MATE + ply`を返す。
探索経路と対局履歴にある局面が再現したら、引き分けの値を返す。
駒枯れとE3は木の中で判定せず、駒割が実質的に代用する。
詰みの独立した判定は置かず、詰みは王駒を取る手の値として1手深く検出する。
厳密な裁定は、審判層が確定したルート合法手と、着手後の審判層の裁定に委ねる。

## 検討した代案

探索木の中で審判層と同じ裁定を行う案は採らなかった。
着手後の終局の裁定は審判層が行うので、探索の近似は実際の対局結果の正しさに影響しないからである。

## 結果

この近似には次の歪みがあり、いずれも許容する。
R1の4回目の出現の裁定は木の中で追わず、最初の再現の時点で引き分けとみなす。
R2とR3が禁止する着手は木の中で引き分け相当として扱い、禁止手しか残らない局面の第23条の負けを検出しない。
第22条の成り勝利の条件、死に駒の除外、および王駒側の1手の猶予と、E3の裁定の保留は、終局の値として表現しない。
E1を採用した規則では詰みの扱いが正確になり、標準規則では1手遅れの近似になる。
R2とR3で不合法となる手はルートの候補から除かれるので、探索が不合法な着手を返すことはない。
[探索部の反復負け回避](../plans/search-repetition.md)は、根での反復負けの回避と木の中の攻撃側の負けを起案しており、採用されればこの決定の一部を置き換える。

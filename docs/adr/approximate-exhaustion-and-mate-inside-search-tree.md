# 探索木の中では駒枯れ、裸玉、および詰みの裁定を近似し、厳密な裁定を審判層に委ねる

## ステータス

承認済み。決定日は2026年10月15日。

## コンテキスト

[探索木の中では規則の裁定を近似する決定](archive/approximate-adjudication-inside-search-tree.md)は、反復規則R1からR3、第22条の駒枯れ、E3の裸玉裁定、および第21条の詰みの裁定を、探索木の中では近似すると定めていた。
このうち反復の扱いは、[根の反復負け回避と探索木の中の周回の勝敗](avoid-r1-repetition-losses-at-the-root-and-score-cycles-by-attacker.md)と[R2とR3の禁止手の処理](skip-forbidden-repetition-moves-inside-the-tree.md)によって置き換えられた。
駒枯れ、裸玉、および詰みの扱いは変わっていないので、本ADRがその部分を引き継ぐ。
中将棋では王手放置も自殺手も合法なので（RULES.md第8条）、探索の合法手では王の安全を確認しなくてよい。
駒枯れ、裸玉、および詰みの裁定は、局面全体の条件と対局の履歴（駒枯れの1手の猶予）に依存する。

## 決定

探索木の中では、相手の最後の王駒を取る着手と合法手のない局面（第23条）だけを終局として扱い、それぞれ勝ちと負けの値を返す。
駒枯れ、E3の裸玉裁定、および詰みは木の中で判定せず、駒割による評価と、王駒を取る手を1手深く読むことで代用する。
厳密な裁定は、審判層が確定した根の合法手と、着手後の審判層の裁定に委ねる。

## 検討した代案

探索木の中で審判層と同じ裁定を行う案は採らなかった。
着手後の終局の裁定は審判層が行うので、探索の近似は実際の対局結果の正しさに影響しないからである。

## 結果

第22条の成り勝利の条件、死に駒の除外、および王駒側の1手の猶予と、E3の裁定の保留は、終局の値として表現しない。
木の中では王駒を取る手を読んで勝ちを判定するので、E1を採用した規則では詰みの扱いが正確になり、詰みで終局する標準規則では1手遅れの近似になる。
これらの厳密化は[棋力向上の段階計画](../plans/strength-stages.md)の段階11に残っている。
返す値の細目は、`crates/minase/src/search/alphabeta/negamax.rs`の`negamax`と`search_move`のdocコメントにある。

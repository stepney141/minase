# 探索木の中では規則の裁定を近似し、厳密な裁定をルートと審判層に委ねる

## ステータス

置き換え済み。決定日は2026年8月22日。[R1の反復負けは根の候補手の選別で避け、探索木の中の周回は攻撃側の負けとして読む](../avoid-r1-repetition-losses-at-the-root-and-score-cycles-by-attacker.md)、[R2とR3が禁じる着手を探索木の中で読まず、禁止手しかない局面を負けとする](../skip-forbidden-repetition-moves-inside-the-tree.md)、および[探索木の中では駒枯れ、裸玉、および詰みの裁定を近似し、厳密な裁定を審判層に委ねる](../approximate-exhaustion-and-mate-inside-search-tree.md)によって置き換えられた。

## コンテキスト

中将棋では王手放置も自殺手も合法なので（RULES.md第8条）、探索の合法手に王の安全の確認は要らない。
一方、反復規則のR1からR3、第22条の駒枯れ、E3の裸玉裁定、および第21条の詰みの裁定は、対局履歴や局面全体の条件に依存する。
R1からR3の判定に要る履歴は対局管理層の内部にあり、探索へは対局開始から現局面までの局面キーの履歴だけを渡す。
主要なエンジンも、探索木の中では同一局面の2回目の出現を引き分けとする近似を許容している（[反復の先行実装の調査](../../research/search-repetition-prior-art.md#比較)）。
これらの方針は[探索部](../../plans/archived/search.md)の設計判断で定めた。

## 決定

探索木の中では、相手の最後の王駒を取る着手、合法手のない局面（第23条）、および探索経路と対局履歴にある局面の再現だけを終局として扱い、それぞれ勝ち、負け、引き分けの値を返す。
駒枯れ、E3の裁定、および詰みは木の中で判定せず、駒割と、王駒を取る手を1手深く読むことで代用する。
厳密な裁定は、審判層が確定したルート合法手と、着手後の審判層の裁定に委ねる。

## 検討した代案

探索木の中で審判層と同じ裁定を行う案は採らなかった。
着手後の終局の裁定は審判層が行うので、探索の近似は実際の対局結果の正しさに影響しないからである。

## 結果

この近似には次の歪みがあり、いずれも許容する。
R1の4回目の出現の裁定は木の中で追わず、最初の再現の時点で引き分けとみなす。
R2とR3が禁止する着手は木の中で引き分け相当として扱い、禁止手しか残らない局面の第23条の負けを検出しない。
第22条の成り勝利の条件、死に駒の除外、および王駒側の1手の猶予と、E3の裁定の保留は、終局の値として表現しない。
木の中では王駒を取る手を読んで勝ちを判定するので、E1を採用した規則では詰みの扱いが正確になり、詰みで終局する標準規則では1手遅れの近似になる。
R2とR3で不合法となる手はルートの候補から除かれるので、探索が不合法な着手を返すことはない。
返す値の細目は、`crates/minase/src/search/alphabeta/negamax.rs`の`negamax`と`search_move`のdocコメントにある。
[探索部の反復負け回避](../../plans/archived/search-repetition.md)は、根での反復負けの回避と木の中の攻撃側の負けを起案しており、採用されればこの決定の一部を置き換える。

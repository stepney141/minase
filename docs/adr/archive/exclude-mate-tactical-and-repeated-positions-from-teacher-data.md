# 詰み帯、捕獲または成りの最善手、および対局内の再出現の局面を教師データに記録しない

## ステータス

置き換え済み。[詰み帯、捕獲または成りの最善手、および対局内の再出現の局面を、除外の理由を付けて教師データに記録する](record-excluded-positions-with-a-reason.md)によって置き換えられた。

## コンテキスト

静的評価は、探索せずに局面だけから値を返し、その絶対値は28,999以下と定められている。
教師データの探索値には、静的評価が見ない情報が入り込む局面がある。
詰み帯の探索値は詰みまでの手数を表す目盛りであり、駒得の目盛りではない。
詰み帯の下限は29,000より大きく、29,000以上で詰み帯より小さい値は探索値にも静的評価にも現れない。
最善手が捕獲または成りの局面では、探索値が次の手で得る駒得や成りの利益を含むので、局面だけを見る静的評価との差が大きい。
探索は、対局で既に現れた局面や探索経路上の局面へ戻る手順を引き分けとして読むので、探索値は履歴にも依存する。
同じ対局で2回目以降に現れた局面では履歴の影響が最も強く、同じ盤面に異なる教師値が付き得る。
[評価関数の設計書](../plans/archived/evaluation.md)は、静的評価に対局履歴を入力しないことを前提にした。

## 決定

生成器は、探索値の絶対値が29,000以上の局面、合法な最善手が捕獲または成りである局面、および現局面の探索キーが同じ対局の過去に現れている局面を記録しない。
除外した局面は、この順に判定して最初に該当した理由だけで数え、理由ごとの件数を生成統計に出す（閾値は`MATE_BAND_START`のdocコメントに、件数の欄は`Statistics`のdocコメントにある）。

## 検討した代案

捕獲や成りの局面の代わりに、静止探索の末端の局面（捕獲の応酬が落ち着いた局面）を記録する案は、探索の着手列をたどって局面を作り直す費用がかかるので採らなかった。
対局履歴を評価関数の入力に加える案は、静的評価には過剰であり、局面だけを見る近似を保つために採らなかった。

## 結果

最初の出現だけを残しても、残った局面の探索値から履歴の影響が消えるわけではなく、この処置は影響の軽減にとどまる。
保存済みの局面を深く探索し直した付け直しファイルで探索値を差し替えた記録に対しては、学習器が新しい探索値と最善手で同じ除外を適用し直す。
捕獲局面を学習に加える方式は、後に[静止探索の出力を学ぶPSTの学習](../plans/archived/qsearch-output-training.md)で対局により検証され、不採用になった（[静止探索の出力を回帰する学習と、捕獲局面を加える学習を採らない](do-not-regress-quiescence-search-outputs.md)）。

# AlphaZero型探索の自己対局には、重みの移動平均ではなく平均でない重みのネットを使う

## ステータス

承認済み。決定日は2026年10月30日。

## コンテキスト

利用者は2026年10月30日に、重みの移動平均（EMA）を学習器に入れ、対局で確かめてから使うと決めた（[強化学習の実行の設計書](../plans/alphazero-rl.md)の「学習が動いてから決める技法」の節）。
学習器は、KataGoの既定に倣って50万標本ごとに1/8の割合で平均を更新し、サイクルをまたいで持ち越し、平均の重みのネットも書き出す。
KataGoは平均のネットで自己対局を行い、dlshogiは任意の設定で平均を使い、Gumbel dlshogiは使わない。

## 決定

自己対局と進捗測定には、平均でない重みのネットを使う。
サイクル25で、平均のネットを候補、平均でないネットを基準とした1手800シミュレーションのGSPRTは、433ペアで`H0`となった（LLR −2.967、平均のネットの得点率0.471、[記録](../measurements/alphazero-rl/alphazero-rl-ema-c0025.md)）。
学習器は平均の計算と書き出しを続けるので、学習の速さが落ちた後に同じ比較をやり直せる。

## 検討した代案

KataGoと同じく平均のネットで自己対局を行う案は、比較で強いと言えなかったので採らなかった。
同じサイクル25の最新の検証集合でも、平均のネットのほうが方策と価値の損失が大きく、学習が速く進む間は平均が現在の重みより遅れていた。

## 結果

自己対局の起動は`--selfplay-weights raw`のままとする。
伸びが止まった場合など、学習の速さが落ちた後には、平均のネットを改めて同じ方法で比べることができる。

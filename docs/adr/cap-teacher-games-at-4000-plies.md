# 教師データの自己対局の手数上限を4,000手にする

## ステータス

承認済み。決定日は2026年9月14日。

## コンテキスト

教師データの生成器は、手数上限に達した対局の勝敗を定められないので、その対局の全局面を破棄する。
世代1までの上限は600手であり、[棋力向上段階7](../plans/archived/strength-stage7.md)の起案時の見積もりでは、破棄した対局が探索の約2割を無駄にしていた。
一方、反復規則R1で終わらない長い対局は探索を消費し続けるので、上限を上げるほど無駄が減るとは限らない。
[手数上限の試行生成](../measurements/strength-stage7-plycap-trial.md)は、上限4,096手で500局を生成し、100手から4,000手までの100手刻みの40候補について、探索した局面1つあたりの記録局面数を同じ着手列から計算した。
この比は4,000手で0.706222と40候補中で最大であり、600手の0.613229より15.164%高かった。
600手では87局を破棄してその探索が全体の24.522%を占め、4,000手では破棄が12局、探索の16.596%だった。

## 決定

生成器の手数上限の既定値を4,000手とする（詳細は`DEFAULT_MAX_PLY`のdocコメントにある）。

## 検討した代案

上限に達した対局を引き分けとして記録する案は、勝敗の定まらない対局に誤った結果を与え、教師値の対局結果の成分を歪めるので採らなかった。
探索値が一定以上の局面が続いた対局を打ち切る裁定は、対局ハーネスの[早期投了の導入判定](../plans/match-early-resignation.md)が待機中であり、生成器だけに別の規則を持ち込む理由がないので採らなかった。

## 結果

この上限は生成の効率だけを変え、棋力への効果は世代2の採否測定に含めて単独では測っていない。
最大値は事前に定めた候補範囲の上端にあり、4,096手を超える対局の分布は試行から分からない。
比は同じ500局の着手列から求めた推定であり、新しい上限で生成した実時間の比ではない。
以後の世代3とNNUEの教師データも、この上限で生成された。

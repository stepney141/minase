# `try_make_move`は全合法手との照合で検査する

## ステータス

承認済み。決定日は2026年8月22日（[ROADMAP.md](../ROADMAP.md)へ記録した日）。

## コンテキスト

`Position::try_make_move`は、外部から受け取った着手が合法かを検査してから局面へ適用する入口であり、プロトコル層と審判層が使う。
現在の実装は、その局面の合法手をすべて生成し、受け取った着手がその中に含まれるかで判定する（`crates/minase-core/src/movegen/checked.rs`）。
この方式は着手1つの検査に全合法手の生成を要するので、着手の種類ごとに直接検査する方式より遅い。

## 決定

全合法手と照合する方式を維持する。
性能の改善は、この検査が実際の処理時間で問題になることを実測で示してから判断する。

## 検討した代案

着手の種類ごとに合法性を直接検査する方式は、合法手生成と別の規則の実装をもう1つ持つことになり、両者の食い違いが新たな不具合の源になる。
実測で必要性が示されていない段階では、この保守の手間と不具合の危険を引き受ける理由がないので採らなかった。

## 結果

`try_make_move`の合法性の判定は、定義上、合法手生成器の判定と一致する。
検査が遅いことは把握したうえで、現行の方式を維持している。

# NNUEの線形の経路の序中盤の列を、学習後に対局結果へのロジスティック回帰で補正する

## ステータス

提案。補正ネットの採用と、LTCの時間切れ1件の扱いについて、エンジンの開発者の判断を待っている。

## コンテキスト

minaseのNNUEは探索値だけを教師として学び、対局結果を教師値に使わない（[ADR](train-the-nnue-on-search-value-teachers-without-lookahead.md)）。
そのネットで指すと、20〜99手目の奔王は85.8%の手数で自陣の最下段から2段以内にいるなど、人間の上位者、HaChu、およびゼロから学んだAlphaZero型のネットがそろって示さない配置が複数の駒に現れた（[集計](../measurements/adhoc/piece-placement-census.md)）。
保存済みの対局では、評価値と駒の枚数の差で条件付けても、配置が対局結果を予測した（[回帰の記録](../measurements/adhoc/nnue-placement-outcome-regression.md)）。
2026年11月3日にエンジンの開発者は、この偏りを減らしつつ強くする方法の検討を求め、採用の条件を棋力の向上と配置の偏りの減少の両方と決めた。

[設計書](../plans/archived/nnue-outcome-regression.md)では、既存の教師と現行のネットから補正を求めた。
判定の対局の予測の損失は0.0071（95%区間0.0052〜0.0088）下がった（[回帰の記録](../measurements/nnue-outcome-regression/nnue-outcome-regression-fit.md)）。
配置の距離は0.4602から0.4332へ下がり、差の95%区間は−0.0324〜−0.0218だった（[配置の記録](../measurements/nnue-outcome-regression/nnue-outcome-regression-placement-stc.md)）。
段階ゲートは[STC](../measurements/nnue-outcome-regression/nnue-outcome-regression-stc.md)が117ペア、[LTC](../measurements/nnue-outcome-regression/nnue-outcome-regression-ltc.md)が122ペアでともに`H1`となった。

## 決定

学習済みのネットの第1層と出力部を固定し、線形の経路の序中盤の列だけを、教師の対局結果へのロジスティック回帰（Texel tuningと同種）で補正する。
補正は成っていない21駒種の段7区分と中央からの筋6区分の和であり、パラメータは273個である。
`minase-trainer nnue fit-linear`がこの計算を行い、式と局面の選び方は`crates/minase-trainer/src/nnue/fit_linear/mod.rs`のdocコメントにある。
補正は基点のネットに対して求めたものなので、ネットを学び直したら求め直す。

LTCの時間切れ1件は、機械の一時的な停止によるものと判断する。
エンジンは残り時間内に探索を終えており、停止は候補と基準の両方に起きていて、該当ペアを除いたLLRは3.0149で判定境界2.9444を超えるので、測定をやり直さない。

## 検討した代案

ネット全体をλ<1で学ぶ案は、今回は採らなかった。
非線形部分が対局を識別して結果を記憶するおそれがあり（[教訓](../lessons/game-constant-target-memorization.md)）、予測は混合の比に応じた分しか動かない。
この案はNNUEでは対局で測っていないので、棄却ではなく未検証である。

第1層を固定して出力重みだけを回帰する案は、保存済みの対局で損失の減少幅が0.00181にとどまり、段と筋の補正の0.00390より小さかった。
両方を入れても、段と筋の補正からの改善は確かめられなかった。

全升を自由にする案は、パラメータが約6,800個に増え、出現する局面の少ない升に雑音が乗りやすいので採らなかった。

両方の列に同じ補正を足す案は、確かめていない終盤にまで影響が及ぶので採らなかった。
回帰の対象は手数60〜159の局面である。

自駒と相手駒を別のパラメータにする案は、自由度が2倍になり、手番による偏りを拾いやすいので採らなかった。

全局面に共通の勝率尺度だけを使う案は、手番の有利さを配置の補正が肩代わりするおそれがあるので採らなかった。
手数帯ごとの勝率尺度と手番の切片を補正なしで先に求めて固定し、ネットへは書き出さない。

現行のネットで新しい対局を生成して回帰する案は、約17時間の生成を要するので、既存のデータで信号を確かめることを優先した。
AlphaZero型のネットの局面を使う案は、c0032がαβ探索に2勝192敗で局面の質が確かでないので採らなかった。

特定の配置の行に手で罰則を足す案は、見えている癖しか直せず、係数の根拠もないので採らなかった。

配置の距離の判定に減少幅の閾値を足す案は採らなかった。
学び直しただけのネットにも0.01程度の差があるが、検出力の計算に使った0.03は採用に必要な最小の改善幅ではなく、0.01のような閾値にも裏付けがない。
判定は差の95%区間の上限が0未満であることのままとし、大きさと駒種ごとの内訳を記録に添える。

## 結果

推論の費用は変わらない。
書き換えるのは線形の区画の序中盤の列と検査和だけであり、非線形部分と探索用駒価値は変わらない。

補正は配置だけでなく駒種の価値も動かす。
回帰の式に枚数の差の項がないので、駒1枚あたりの平均の補正がそのまま駒の評価になり、竪行は平均+262 cp、醉象は平均−211 cpである。
探索用駒価値は変えていないので、静的交換評価や枝刈りの余裕値が使う駒価値と、評価関数の駒の価値の差が以前より大きい。

配置の距離の減少は全駒種の改善を意味しない。
奔王、龍馬、竪行、鳳凰、および飛車の距離は大きく減ったが、仲人、銀将、王将、および金将の距離は増えた。
探索が補正を追って新しい癖を作っている可能性がある。

棋力の差は補正前のネットとの自己対局で測ったものであり、人間やHaChuに対する差は測っていない。

この方式では、学習の後に補正の工程が1つ増える。
学び直したネットに`fit-linear`をかけて補正の大きさとDを見れば、教師やλを変えたときに偏りがどれだけ残るかを測れるので、後付けの補正が要らなくなる学習の探索に使える。

# late move pruningは静かな手だけを数え、履歴の条件を付けない

## ステータス

承認済み。決定日は2026年10月4日。

## コンテキスト

late move pruningは、浅いノードで順序付けの後方にある静かな手を読まずに済ませる手法である。
[棋力向上段階4](../plans/strength-stage4.md)の方式は、捕獲手も含めた手番号が深さ1、2、3で12、23、13に達した後の静かな手を切り、STCが114有効ペアでLLR −2.947の`H0`だった（[測定記録](../measurements/strength-stage4-lmp-stc.md)）。
[棋力向上段階8](../plans/strength-stage8.md)は、履歴値の低い手だけを切るhistory pruningを診断したが、21組の候補のどれも失う割合が10%以下にならなかった（[診断](../measurements/strength-stage8-pruning-bench.md)）。
[不採用だった探索部の改良の再調整](../plans/search-revival-spsa.md)は、元の実装を[診断](../measurements/search-revival-lmp-diag.md)した。
残り深さ1では、手を切るまでに探索した手が平均で捕獲手8.1手、静かな手4.5手であり、上限の枠の約3分の2を捕獲手が占めた。
残り深さ1で手を切ったノードの約36%は、静かな手を1手も探索しないうちに切り始めており、killer手もノードあたり平均0.56手が切られていた。
中将棋はチェスや本将棋より捕獲手が多いので、捕獲手を数えると静かな手の枠が捕獲手で埋まる。
2026年10月2日に利用者が定義の変更を決め、改めた定義で戻した版を既存の係数とまとめてSPSAで調整して採用した（[採用のADR](adopt-revived-search-items-as-a-bundle.md)）。

## 決定

置換表の手、捕獲手、成る手、およびkiller手のいずれでもない静かな手を数え、その数が上限に達した後の静かな手を展開しない。
枝刈りで展開しなかった手も数え、ある手を展開するかは、その手より前に数えた数で決める。
killer手は枝刈りの対象から外す。
上限は残り深さについて単調な`(基数 + 傾き × 残り深さ²) / 100`とする。
適用するノードは、残り深さ3以下、零窓、詰み帯の外、手番側の王駒に相手の利きが届かないノードである。
履歴値を枝刈りの条件にしない。

## 検討した代案

捕獲手も数える手番号で切る段階4の方式は、上記のとおり静かな手の枠が捕獲手で埋まり、STCで`H0`だったので採らなかった。
StockfishとYaneuraOuは捕獲手と置換表の手も数え、killer手も切るが、同じ理由で採らなかった。
深さごとに独立した3つの上限は、単調でない値が選ばれ得るので、深さの単調な式に改めた。
履歴値の低い手だけを切るhistory pruningは、上記の診断で適格な候補がなかったので見送った。

## 結果

基数と傾きは`crates/minase/src/search/alphabeta/params.rs`の`LmpBase`と`LmpSlope`である。
StockfishとYaneuraOuの上限式にあるimprovingの項は、improvingを別の項目として戻したので含めていない。
全深さへ適用を広げる変更は、未測定の候補として残る。

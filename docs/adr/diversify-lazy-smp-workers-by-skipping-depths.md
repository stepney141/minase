# 補助ワーカーは深さを飛ばし、最も深い反復を完了したワーカーの結果を採る

## ステータス

承認済み。決定日は2026年8月23日。

## コンテキスト

[Lazy SMP](../plans/archived/lazy-smp.md)は、複数の探索ワーカーがそれぞれ独立に反復深化を行い、置換表だけを共有する並列化方式である。
初版では、補助ワーカーが主ワーカーと同じ深さの列を探索し、ルート合法手の並びをワーカー番号の分だけ回転させていた。
初版の`Threads=2`は、固定深さ6のbenchで経過時間を1.4%しか縮めなかった（[測定記録](../measurements/lazy-smp/lazy-smp-v1-diversification-bench.md)）。
時間制御の自己対局でも、有効81ペアの時点でEloはおよそ+2、95%信頼区間はおよそ±45であり、測定を止めた（[測定記録](../measurements/lazy-smp/lazy-smp-threads2-tc.md)）。
指し手順序付けは置換表の記録手を先頭へ入れ替えるので、主ワーカーが根の記録を書いた後は、補助ワーカーも回転した並びを捨てて主ワーカーと同じ手から読んでいた。
初版の補助ワーカーは、主ワーカーが置換表に残した記録を使って探索を速く進めていたが、最終結果には主ワーカーの結果だけを採るので、補助ワーカーの探索の成果は使われずに捨てられていた。
診断で深さ5の経過時間を縮めたのは、補助ワーカーが同じ深さを主ワーカーより先に探索する構成であり、深さ1、3、5を探索して上限で止める深さスキップは18%、上限を置かないストライドは16〜17%縮めた。
深さ6でも経過時間を縮めたのは深さスキップだけであり、ストライドは5〜7%延ばした。
補助ワーカーが1つ深い反復にいる構成では、主ワーカーは利益を得ず、メモリと置換表の競合だけが残って経過時間が延びた。

## 決定

補助ワーカーk（k=1、…、Threads−1）は、周期`p = 2 + ((k - 1) % 4)`の深さスキップで反復深化を行い、ルート合法手の回転、時刻、および乱数を多様化に使わない。
停止時には、最も深い反復を完了したワーカーの最善手、評価値、深さ、および主変化を、同じ反復の組として採用する。
同じ深さなら、ワーカー番号が小さいもの（主ワーカーは0）を優先する。

## 検討した代案

ルート合法手の回転は、置換表の記録手の先頭入れ替えに打ち消されるので採らなかった。
補助ワーカーを常に1つ深い反復に置く案は、固定深さの経過時間が13〜25%延びたので採らなかった。
ワーカー番号をそのまま周期にする案は、ワーカーが多いと深さ1しか探索しない補助ワーカーが生じるので採らず、周期を4種類で循環させた。
主ワーカーの結果だけを採る初版の方式は、補助ワーカーが得た利益を捨てるので採らなかった。

## 結果

第2版はbenchのゲートを深さ5で26.5%、深さ6で17.9%の短縮で通過した（[測定記録](../measurements/lazy-smp/lazy-smp-v2-bench-gate.md)）。
時間制御のGSPRTは上限500ペアでLLRが2.615の判定保留であったが、固定局数のEloは+62.1、95%信頼区間は［+41.5, +83.0］であった（[測定記録](../measurements/lazy-smp/lazy-smp-v2-threads2-tc.md)）。
設計書は500ペアの判定保留を不採用と定めていたが、この規定から逸脱することを明記して採用した。
現行の[棋力測定の手引き](../guides/sprt.md)は信頼区間を採用の根拠に読み替えることを禁じており、この採用はその規則より前の判断である。
後に[秒読みつき時計での持ち時間と秒読みの活用](../plans/byoyomi-time-usage.md)が、同じ深さのワーカーの間で途中結果の有無を比べる基準を加えた。
`Threads=4`対`Threads=2`の測定は行っていない。
測定は評価関数v0の時期に行ったので、多様化の方式を変える提案には再測定が要る。
探索する深さの列の詳細は`crates/minase/src/search/alphabeta/deepening.rs`の`auxiliary_depths`のdocコメントに、結果の選択は`team.rs`の`select_worker_outcome`のdocコメントにある。

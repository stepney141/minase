# NNUEの線形の経路を、学習の後に対局結果で補正しない

## ステータス

承認済み。決定日は2026年11月7日。[NNUEの線形の経路の序中盤の列を、学習後に対局結果へのロジスティック回帰で補正する](archive/correct-the-nnue-linear-path-by-regressing-on-game-outcomes.md)を置き換える。

## コンテキスト

[以前の決定](archive/correct-the-nnue-linear-path-by-regressing-on-game-outcomes.md)は、世代反復の各世代で、学習したネットの第1層と出力部を固定し、線形の経路（駒と升ごとの点数の表）の序中盤の列を対局結果へのロジスティック回帰（Texel tuningと同種、`minase-trainer nnue fit-linear`）で補正すると定めていた。
[中断した世代反復](../plans/archived/nnue-generation-reset.md)の第1世代の教師では、補正したネットが補正しないネットに対してSTCで`H1`（得点率92.1%）だった。

[標準レシピv1の設計書](../plans/nnue-standard-recipe.md)は、同じ系列の第2世代の教師で、補正の前のネットを候補、補正の後のネットを対照としてSTCで比べた（[測定記録](../measurements/nnue-standard-recipe/nnue-standard-recipe-fit-stc.md)）。
補正の前のネットは、376ペアで`H1`（得点率57.1%）となった。
補正の後は、仲人を盤から取り除くと駒を失った側の評価がかえって上がる割合が0.2%から55.9%へ増えていた。
2026年11月14日にエンジンの開発者は、学習の後に線形の経路を補正する先行例がないことを確かめ、先行の複数のエンジンに共通する方法に合わせると決めた（[学習レシピの調査](../research/nnue-training-recipes.md)）。

## 決定

NNUEの世代反復では、学習したネットをそのまま次の世代の教師の生成に使い、線形の経路を学習の後に補正しない。
`nnue fit-linear`は、教師や`--lambda`を変えたときに残る偏りを調べる診断としてだけ残す。

## 検討した代案

補正を続ける案は、第2世代の教師で補正しないネットより弱かったので採らない。
第1世代の教師では補正したネットのほうが強かったので、第1世代だけ補正する案も考えたが、学習後に線形の経路を補正する先行例が見つからず、先行例に合わせる方針に反するので採らない。
第1世代と第2世代で優劣が逆になった原因は調べていない。

## 結果

連続生成スクリプトは、補正の有無を`--fit`で選べるが、標準レシピv1では`--fit no`を指定し、学習の出力`train/nnue.bin`をコミットして次の世代の初期値にする。
補正を行わないので、対局結果は教師の勝率尺度の推定を除いて学習に入らない。
この条件で世代を重ねて強くなるかは、[世代反復の設計書](../plans/nnue-generation-iteration.md)の世代の判定で確かめる。

# 静止探索の出力を回帰する学習と、捕獲局面を加える学習を採らない

## ステータス

承認済み。決定日は2026年9月30日。

## コンテキスト

教師データは、最善手が捕獲でも成りでもない静かな局面だけを記録し、その静的評価を教師値へ近づける。
[探索局面を用いた評価関数の学習](../plans/archived/search-aware-evaluation.md)では、静止探索の途中の局面をそのまま学んだ候補が、通常の局面を高く見積もるようになって不採用になった（[探索中に静的評価を呼んだ局面を学習の局面に混ぜない](do-not-train-on-search-tree-positions.md)）。
[静止探索の出力を学ぶPSTの学習](../plans/archived/qsearch-output-training.md)は、入力の局面と学習目標を分けて調べた。
対照Rは静かな局面の静的評価を教師値へ近づけ、候補Qは同じ局面から静止探索した値を同じ教師値へ近づけ、損失の勾配を値を決めた末端の局面へ渡した。
候補QcはQと同じ学習目標に捕獲局面を加え、3者は着手時の採用版S0を初期値に、同じ教師と更新回数で独立に学習した。
[Q対RのSTC](../measurements/qsearch-output-q-vs-r-stc.md)は640有効ペア、ペンタノミアル度数[150, 26, 326, 22, 116]、LLR −2.986で`H0`となった。
[Qc対QのSTC](../measurements/qsearch-output-qc-vs-q-stc.md)は上限3,000ペアに達し、2,816有効ペアでLLR −1.166と負だった。

## 決定

評価関数の学習目標を静止探索の出力にする方式と、教師データに捕獲局面を加える方式を採らない。

## 検討した代案

候補Qは`H0`、候補Qcは上限到達時のLLRが負となり、事前の規則によりどちらもS0との採否測定へ進めなかったので採らなかった。
固定した重みで末端を1回だけ置き換える近似は、重みの変化による読み筋の変化を無視するので候補にしなかった。

## 結果

学習と診断のコードはブランチ`qsearch-output-training`、`qsearch-output-r`、`qsearch-output-q`、`qsearch-output-qc`に残り、masterには入っていない。
新しい世代のデータで学んだ対照RがS0より強いかは測っていない。
末端の取り出しの費用は事前の基準を大きく下回ったので、費用は不採用の理由ではない。
結論はPSTという関係を表せないモデルでの結果であり、NNUEの下で同じ学習目標を再提案するには測り直す必要がある。

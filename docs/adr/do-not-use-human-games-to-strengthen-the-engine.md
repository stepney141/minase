# 強くする手段に人間の棋譜を使わない

## ステータス

承認済み。決定日は2026年10月25日。

## コンテキスト

lishogiのBotの対局で、minaseの麒麟は、成る前に盤上にいた手数の59%で持ち主から見て右端の2筋にいた。
この割合は人間の上位者の0.3%と大きく異なる（[分析の記録](../measurements/adhoc/kirin-right-edge-bias.md)）。
この偏りを受けた[強豪エンジンの教師生成の調査](../research/teacher-generation-strong-engines.md)は、自己対局の局面の偏りへの対策のうち、外部の強いエンジンを要しないものとして、人間の棋譜の局面を自己対局の開始局面にする方法を第1の候補に挙げた。
AobaZeroは人間の棋譜に似た局面を開始局面にして+20 Eloを得ており、minaseの手元にはlishogiの人間同士の棋譜が約2万3千局ある。
minaseには、人間の棋譜から開始局面の一覧を作るサブコマンド`minase data lishogi openings`と、人間の対局結果を教師データにするサブコマンド`minase data lishogi games`もある。
前者は、[棋力向上段階9](../plans/archived/strength-stage9.md)の診断で、実戦の局面から始めた自己対局を2,000局生成するのに使われたが、その教師データは採用されていない（[診断Cの記録](../measurements/strength-stage9/strength-stage9-human-start-signal.md)）。

## 決定

エンジンの開発者は、minaseを強くする手段に人間の棋譜を使わないと決めた。
対象は、教師データの局面、自己対局の開始局面、教師値、および学習の補助信号である。
人間の知識を使わずに強くすることを目指すためである。
外部の評価器が要る場合は、人間の知識を使わずに作る[AlphaZero型の計画](../plans/alphazero.md)の成果を使う。

## 検討した代案

人間の棋譜の局面を自己対局の開始局面にする案は、先例に効果の記録があるが、人間の棋譜に依存するので採らない。
人間の対局結果を教師にする案も、同じ理由で採らない。

## 結果

自己対局の局面を多様にする手段は、自己生成の範囲で行う方法（範囲を絞ったランダム化、静的評価と探索値が食い違う局面の採取など）と、自前で作る評価器を使う方法に限られる。
教師生成の見直しは、AlphaZero型の計画の後に、そのネットの評価値でNNUEの教師データを付け直す形で起案する。
人間の棋譜を偏りの診断の基準に使うことは、エンジンを強くする手段ではないので、この決定の対象に含めない。
[NNUEの線形経路の初期化の計画](../plans/nnue-material-linear-init.md)の麒麟の診断が、これに当たる。
既存の`minase data lishogi openings`と`minase data lishogi games`は、強くするための学習には使わない。

# NNUEの教師の生成では、王手の局面を除き、評価値が傾いた開始局面を捨て、大差が続いた対局を評価値で裁定する

## ステータス

承認済み。決定日は2026年11月14日。

## コンテキスト

NNUEの教師の生成器`minase data selfplay generate`は、初期局面から一様ランダムな合法手を8〜16手指した局面から自己対局を始め、毎手を2万ノードで探索して教師の探索値を記録する。
学習に使わない局面には除外の理由を付け、詰みの帯、戦術的な局面、反復の局面の順に判定していた（[ADR](record-excluded-positions-with-a-reason.md)）。

強豪エンジンの教師生成の調査（[自己生成で育てたチェスエンジンと変種](../research/teacher-generation-strong-engines/zero-chess-and-variants.md)）では、先行のエンジンに共通する処理が3つあった。
Zevra 2、Sapling、Viridithas、Akimbo、およびFairy-Stockfishは、王手のかかった局面を教師から除く。
Astra、Viridithas、PlentyChess、およびIntegralは、探索した評価値で開始局面を選別し、閾値は300〜1,000 cpである。
Sapling（2,500 cpが5手）、Viridithas（2,500 cpが4手）、Integral（2,500 cpが5手）、およびFairy-Stockfish（3,000 cpが4手）は、大差が続いた対局を優勢な側の勝ちとして打ち切る。
以前は、学習後の線形の経路の補正に対局結果を使っていたので、評価値で決めた裁定の結果を評価関数の補正へ戻すと循環が生じることを理由に裁定を見送っていたが、[補正を行わない決定](do-not-correct-the-nnue-linear-path-after-training.md)でこの理由はなくなった。
2026年11月14日にエンジンの開発者は、3つの処理を採ると決めた。

先行例の閾値は歩兵を100 cpとするチェスのエンジンの値なので、評価値を勝率へ換算する尺度の比で直した。
先行例の尺度をbulletの例が使う1ロジットあたり400 cpと仮定し、minaseの尺度には中断した世代反復の勝率尺度679.03 cpを使うと、開始局面の選別の1,000 cpは約1,700 cp、裁定の2,500 cpは約4,250 cpになる。
先行例の尺度の仮定と、新しい系列の勝率尺度で換算し直さないことは、[標準レシピv1の設計書](../plans/nnue-standard-recipe.md)が置いた仮定である。

## 決定

教師の生成器は、次の3つの処理を引数のない固定の規則として行う。

- 手番の側が王手（[競技規則](../rules/chu-shogi.md)第8条）を受けている局面を、詰みの帯の次に判定して除外する。
- ランダムな手で作った開始局面を教師と同じノード数で探索し、探索値の絶対値が1,700 cpを超えたら捨てて作り直す。`--openings`で開始局面を与えた生成には適用しない。
- 先手から見た探索値の絶対値が4,250 cp以上で詰みを示す帯より小さく、同じ側の優勢を示す局面が5手続いたら、その手を指さずに優勢な側の勝ちとして対局を終える。

裁定で終えた対局は、教師データの形式MNSDの版3で終局理由13として保存し、学習器はほかの対局と同じ勝敗として読む。
判定の順序、乱数、および集計の仕様は`crates/minase/src/bin/minase/selfplay_gen/play.rs`と`crates/minase/src/training/records.rs`のdocコメントにある。

## 検討した代案

王手の局面を教師に含め続ける案は、先行例に合わせる方針で採らない。
開始局面の閾値を最も厳しい300 cp相当（約510 cp）にする案は、先行例の閾値が割れている中で今の教師からの変化が最も大きい値を選ぶことになるので採らない。
裁定を行わない案は、循環の理由がなくなったので採らない。
引き分けの裁定は、先行例の条件がチェスの50手規則や手数に結びついていて中将棋へ移す根拠がないので加えない。
閾値を引数で選べるようにする案は、新しい系列の生成がすべて同じ規則を使い、連続生成スクリプトと、生成機で動く作業用のスクリプトへの受け渡しが増えるだけなので採らない。

## 結果

開始局面を捨てた数と裁定で終えた対局の数は、生成の集計に記録される。
裁定で打ち切った対局は終局まで指さないので、1本あたりの時間と記録局面数が変わり、最初の世代の生成で測り直す。
同じシードから同じ教師ファイルを作る性質と、途中で止めて再開できる性質は変わらない。
MNSDの版2の教師ファイルは読めなくなった。

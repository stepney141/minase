# 線形の評価の2組の重みを盤上総駒数で補間する

## ステータス

承認済み。決定日は2026年9月8日。

## コンテキスト

駒の種類と升ごとの点数を足す線形の評価は、同じ駒状態と升に常に同じ値を与えるので、駒が減って走り駒の活動範囲や成りやすさが変わることを表せない。
[PSTの序中盤と終盤の補間](../plans/archived/tapered-pst.md)は、序中盤用と終盤用の2組の重みを局面の進行度で混ぜる方式を自己対局で検証した。
進行度の候補には、盤上総駒数、手数、閾値で表を一斉に切り替える方式、および駒種別の重みで駒数を数える方式があった。
中将棋には駒打ちがないので、盤上総駒数は捕獲でだけ減り、成りでは変わらない。
王駒2枚は常に盤上に残り、初期配置は92枚である。
2組の重みを補間する候補は、開始版に対して[STC](../measurements/tapered-pst/pst-tapered-adoption-stc.md)と[LTC](../measurements/tapered-pst/pst-tapered-adoption-ltc.md)の両方で`H1`となった。
LTCは187有効ペア、ペンタノミアル度数[21, 2, 84, 0, 80]、LLR +2.970で、異常は0件だった。

## 決定

王駒を含む盤上総駒数Nから補間係数q = min(90, max(0, N − 2))を求め、序中盤用の和にq、終盤用の和に90 − qを掛けて足し、最後に1回だけ整数で割る（詳細は`pst::phase`と`Network::evaluate_accumulator`のdocコメントにある）。

## 検討した代案

手数で進行度を測る案は、同じ盤面でも到達した手数で評価が変わり、置換表で共有する局面の評価と矛盾するので採らなかった。
閾値で表を一斉に切り替える案は、境界で評価値が飛ぶので採らなかった。
駒種別の重みで進行度を数える案は、重みの調整が別に要るので最初の比較から外した。
3組以上の表や、駒数で出力の重みを切り替える案は、[棋力向上段階7](../plans/archived/strength-stage7.md)が見送った。
[端点の識別性の診断](../measurements/tapered-pst/pst-tapered-identifiability.md)では、2組の重みすらデータから別々に決められない特徴があり、表を増やしても分離できない特徴が増えるだけだからである。

## 結果

補間係数は盤上の密度の近似であり、王の危険度や終局までの距離を表さない。
補間係数が小さい局面だけに現れる特徴の終盤側の重みは、少数の局面で決まりやすい。
探索用駒価値は補間せず1組の固定値を使うので、評価関数が端点ごとに学ぶ駒の価値とは離れ得る（[探索用駒価値は学習PSTから導いた値に固定する](derive-search-piece-values-from-the-learned-pst.md)）。
NNUEの線形の経路も同じ式で補間しており、その経路を設けて駒数による出力の不連続を避けた判断は、[NNUEの出力を、探索用駒価値で初期化した線形の経路と隠れ層のない直接内積の和にする](compose-the-nnue-of-a-piece-value-initialized-linear-path-and-a-direct-screlu-head.md)が扱う。

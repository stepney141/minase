# 経由升で取った歩兵と仲人の足は、取られる前の利きで判定する

## ステータス

承認済み。決定日は2026年7月30日。

## コンテキスト

獅子が2段階移動の第1段階で相手の駒を取り、第2段階で距離2の相手獅子を取る着手は、取られる獅子に足があれば原則として不合法である（RULES.md第14条第2項）。
足の判定は、獅子を取った段階の直後の仮想盤面で、取られた側の駒が獅子のいた升へ利くかで行う（第13条第4項）。
ところが第16条第8項から第10項は、相手獅子の唯一の足が歩兵または仲人であり、獅子がそれを第1段階で取る場合に、足が消滅したとは扱わないと定める。
着手後の盤面にはその歩兵または仲人が残っていないので、仮想盤面の利きだけでは条文どおりの結果にならない。
この調整の方式は[合法手生成とmake/unmakeの設計](../plans/movegen.md)の6.3節で決めた。

## 決定

足の判定は、獅子を取った段階の直後の仮想盤面の利きに、経由升で取った歩兵または仲人が取られる前の升から獅子のいた升へ利いていたかどうかを論理和で加えて行う。この付け喰いでは獅子を第2段階で取るので、獅子のいた升は着手の到達升と一致する。
規則コードL3を採用した場合は、この項を加えず仮想盤面の利きだけで判定する。
判定の細目は`lion_has_foot_after_capture`のdocコメントにある。

## 検討した代案

取った歩兵または仲人の占有を仮想盤面へ戻してから利きを調べる案は採らなかった。
占有を戻すと、その駒の除去によって通るはずの背後の走り駒の利きを遮ってしまう。
その結果、走り駒が本当の足である局面で足がないと判定し、第14条第2項が禁じる距離2の捕獲を合法と誤る。

## 結果

歩兵と仲人の利きは1升の固定利きなので、論理和の項は占有に依存せず、仮想盤面を2通り作る必要がない。
走り駒の裏足と、取られた歩兵または仲人の足が、1回の判定の中で両立する。
典拠の日本中将棋連盟「中将棋対局規定　補足編」が挙げる事例は仲人だけであり、歩兵への拡張はRULES.mdの敷衍に従っている。

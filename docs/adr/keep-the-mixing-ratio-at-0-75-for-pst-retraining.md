# PST全体を学び直すときは、教師の混合比を0.75に保つ

## ステータス

承認済み。決定日は2026年9月26日。

## コンテキスト

教師値は、探索値を教師用Kで勝率へ換算した値と対局結果を、混合比λで混ぜたものである。
[評価関数の設計書](../plans/evaluation.md)は、浅い探索値を主にして対局結果で補う配分としてλ=0.75を初期値にし、自己対局の教師の分類はこの値を来歴ファイルに持つ。
対局結果は着手列の偶然に強く依存するので、その雑音が学習の目標を乱している可能性があった。
[教師の混合比λ=1.0](../plans/teacher-mixing-ratio.md)は、採用中のPSTを初期値に、λ=1.0の先読み教師で既存の11ファイルから学び直した候補を測った。
λ=0.75で同じ追加学習をした対照は置かなかったので、比べたのはλ=1.0での再学習の工程全体である。
候補は学習後の診断を通過したが、[STC](../measurements/teacher-mixing-ratio-100-stc.md)は123有効ペア、ペンタノミアル度数[59, 3, 54, 1, 6]、LLR −2.956で`H0`となり、候補の得点率は28.0%だった。

## 決定

PSTの学習では、自己対局の教師の分類のλを来歴ファイルの0.75のまま使う。

## 検討した代案

λ=1.0は、STCで`H0`となったので採らなかった。
λ=0.25と0.5は、エンジンの開発者が測る値を1つに絞ったので測っていない。
λ=0、すなわち対局結果だけの教師は、目標の分散が大きく、段階9の診断でも対局結果が持ち込む情報を検出できなかったので候補にしなかった。
学習の途中でλを変える方式は、固定の比率の結果が分かるまで検討しないことにした。

## 結果

負け越しが大きかったので重みの入出力、符号、および埋め込みの不具合を点検したが、見つからなかった。
この結果はPST全体を学び直す条件に限られ、PSTを凍結した補正やNNUEの教師の混合比を決めるものではない。
NNUEがλ=1.0を採った判断は、[NNUEは探索値だけの先読み教師と二値交差エントロピーで学ぶ](train-the-nnue-on-search-value-lookahead-teachers.md)が扱う。

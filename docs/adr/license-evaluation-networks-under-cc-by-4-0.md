# 評価ネットの重みをCC BY 4.0で配布する

## ステータス

承認済み。決定日は2026年11月25日。

## コンテキスト

minaseの評価ネットは、Hugging Face Hubのモデルリポジトリ[stepney141/minase-nets](https://huggingface.co/stepney141/minase-nets)で公開している（[配置のADR](host-evaluation-networks-on-hugging-face-hub-and-name-them-by-structure.md)）。
このリポジトリには、αβ探索が使うNNUEの重みのファイル（`.nnue`）と、AlphaZero型のPV-MCTSが使うONNXのファイル（`.onnx`）を置く。
これまでモデルカード（モデルリポジトリの`README.md`）にはライセンスの記載がなく、利用者は、重みを再配布してよいか、自分のエンジンに組み込んだり学習の初期値にしたりしてよいかを判断できなかった。
ネットはコードのリポジトリの外にあるので、ライブラリをMIT、エンジンをGPL-3.0-or-laterとした[ライセンスのADR](license-library-under-mit-and-engine-under-gpl.md)の効力は及ばない。

エンジンの開発者は、重みを使う側に課す条件をできるだけ少なくし、そのうえで出典を表示してもらうことを望んだ。
重みは、実行されるプログラムではなく、学習で得た数値の並びであり、データに近い。
Creative Commonsは、[FAQ](https://creativecommons.org/faq/#can-i-apply-a-creative-commons-license-to-software)で、CCライセンスをソフトウェアに使うことを勧めていない。一方で、データベースを含むソフトウェア以外の著作物には使えるとしている。
そのため、重みにはCCライセンスを適用できる。

重みの学習に使った教師データは、どの世代もminase自身が対局で生成した局面と探索値であり、第三者の棋譜を含まない（たとえば[第3世代の学習の記録](../measurements/nnue-generation-iteration/nnue-generation-iteration-gen3-training.md)）。
したがって、教師データの出自から重みのライセンスに制約は生じない。

## 決定

Hugging Face Hubのモデルリポジトリにあるファイルは、過去のリビジョンにあるものも含めて、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)で配布する。
モデルカードのメタデータに`license: cc-by-4.0`と書き、本文の「License」の節に出典の表示例を示す。

## 検討した代案

CC0 1.0は、出典を表示する義務がなく、課される条件が最も少ない。
しかし、出典を表示してもらいたいというエンジンの開発者の判断で採らなかった。

MITライセンスは、重みの公開に使われている先例がある。
しかし、条文がソフトウェアを前提としており、著作権の表示と許諾の文を複製物に含めることを求めるので、重みのファイル単体には当てはめにくい。
これに対し、CC BY 4.0では、出典の表示は媒体と状況に応じた合理的な方法で行えばよいので、MITライセンスは採らなかった。

エンジンと同じGPL-3.0-or-later、または継承（SA）を付けたCCライセンスは、重みを組み込んだ側の配布物にも同じライセンスを求める。
非営利（NC）または改変禁止（ND）を付けたCCライセンスは、利用の範囲を狭める。
いずれも条件をできるだけ少なくする目的に反するので採らなかった。

## 結果

ネットを再配布する者や、ネットを改変して配布する者は、出典とライセンスを表示する。
CC BY 4.0の条件はネットを他者へ共有するときに課されるので、ネットを読み込んで対局させるだけなら表示は要らない。
なお、日本の著作権法で、学習によって得た重みが著作物に当たるかどうかは定まっていない。
著作物に当たらない場合は、この表示の義務も生じないが、その場合でもライセンスの明記は、自由に使ってよいというエンジンの開発者の意思を示す。

Free Software Foundation（FSF）は、[ライセンス一覧](https://www.gnu.org/licenses/license-list.html#ccby)で、CC BY 4.0がGNU GPLのすべての版と両立すると判断している。
そのため、ネットをGPL-3.0-or-laterのエンジンと一緒に配布できる。

`crates/minase/nets/`にあるPSTなどの重みは、コードのリポジトリのうちエンジンのcrateのディレクトリに含まれるので、この決定の対象外であり、GPL-3.0-or-laterのままである。
新しいネットを公開するときは、モデルカードの「License」の節を書き直さず、同じ条件で配布する。

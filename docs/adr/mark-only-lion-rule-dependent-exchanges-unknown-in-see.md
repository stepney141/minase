# SEEは獅子規則に依存する交換段階だけを判定不能とする

## ステータス

承認済み。決定日は2026年9月5日。

## コンテキスト

静的交換評価（SEE）は、ある升での駒の取り合いを実際には読まず、取る駒と取り返される駒の価値の列から損得を見積もる手法である。
[棋力向上段階3](../plans/archived/strength-stage3.md)は、SEEで損と見積もった捕獲手を静止探索で展開しないことにした。
中将棋には、獅子の2段階移動、先獅子、および付け喰いという捕獲の規則があり（RULES.md第12条から第16条）、獅子が絡む取り合いは駒価値の列だけでは解けない。
ただし、規則が捕獲の可否を変えるのは、獅子が獅子を取る場合と、麒麟が獅子を取って成った直後の取り返しだけである。
非獅子が獅子を取る手と獅子が非獅子を取る手は常に合法であり（第14条第5項）、先獅子は到達升での取り合いには働かない。
設計書の記録では、獅子が絡む捕獲をすべて判定不能とすると、benchの深さ3で捕獲手の約70%が判定不能になった。
規則に依存する段階だけを判定不能としたSEEは、[STC](../measurements/strength-stage3-see-stc.md)と[LTC](../measurements/strength-stage3-see-ltc.md)でともに`H1`となった。

## 決定

SEEは、経由升を持つ着手（居喰いと付け喰いを含む）、麒麟が獅子を取って成る着手、および交換列の途中で到達升の獅子を獅子または成れる麒麟が取り返し得る段階だけを判定不能とし、判定不能の捕獲手は枝刈りしない。
それ以外の捕獲は、獅子、角鷹、および飛鷲が関わる場合も、捕獲が1回の通常の交換として計算する。

## 検討した代案

獅子が絡む捕獲をすべて判定不能とする案は、SEEを適用できる捕獲手が3割に満たなくなるので採らなかった。

## 結果

判定は`crates/minase/src/search/alphabeta/see.rs`にあり、判定不能の範囲の詳細は`see_prunes`のdocコメントにある。
静止探索と通常探索のSEE pruningが同じ判定を使い、2026年10月10日からは手選択器のkiller手の前置き（[ADR](try-killers-before-a-losing-first-capture.md)）も同じ判定を使う。
2段階移動で2枚目を取れる可能性は見積りに含めないので、獅子、角鷹、および飛鷲が取り返す側の得は過小に見積もられる。
約70%という比率には独立した測定記録がないので、判定不能の範囲を広げる提案では測り直す必要がある。

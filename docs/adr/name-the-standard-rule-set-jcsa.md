# 標準規則の千日手をR1に置き換えた規則セットをJCSAと名づける

## ステータス

承認済み。決定日は2026年11月12日。

## コンテキスト

minaseは、規則コード列`L0,P0,R1,E0`を表す規則セット名として`engine-default`を持ち、`minase-core`は同じ規則を定数`Rules::ENGINE_DEFAULT`と、規則を明示せずに対局を作る`Game::with_default_rules()`で提供していた。
この名前は、起動引数やオプションの既定値という意味を含んでいる。
しかし、[規則セットの指定を必須にする決定](require-the-rule-set-through-the-protocol-and-keep-no-default.md)によって、エンジンは規則セットの既定値を持たなくなった。
既定値のないエンジンに「エンジンの既定」という名前の規則セットが残ると、名前が実態を表さない。

この規則セットは、日本中将棋連盟（Japan Chu Shogi Association）の競技規則に基づく標準規則のうち、千日手だけを規則コードR1に置き換えたものである。
連盟式の千日手（規則コードR0）は、条文にない解釈を補わなければ裁定できないので実装していない（[ADR](do-not-implement-r0-repetition.md)）。

## 決定

規則セット名`engine-default`を`JCSA`へ改名し、旧名の別名は置かない。
`minase-core`の定数は`Rules::JCSA`へ改名し、`Game::with_default_rules()`は削除して、呼び出し元は`Game::new(Rules::JCSA)`と書く。
名前の照合は大文字と小文字を区別せず、正準の表記は`JCSA`とする。
名前の定義は[規則書](../rules/chu-shogi.md)の第33条第5項にあり、同項は、この規則セットが千日手の扱いに限り連盟の規則と異なることを明記する。

## 検討した代案

旧名`engine-default`も受理し続ける案は採らなかった。
同じ規則セットに2つの名前が残り、記録や設定を名前で突き合わせるときに表記が割れるからである。

名前を置かず、コード列`L0,P0,R1,E0`だけで指定させる案は採らなかった。
最もよく使う規則セットであり、手で入力する設定や文書の中で、4つのコードを毎回並べるより名前のほうが誤りにくい。

連盟の規則と完全には一致しないことを名前に含める案（たとえば`JCSA-R1`）は採らなかった。
MinaseはR0を選択可能な規則コードとして提供しないので、連盟の規則に基づく規則セットは1つしかなく、区別する相手がない。
違いは規則書の条文に書く。

## 結果

規則セット名を保存している記録は、改名の後は読み込めない。
対局ハーネスと係数調整`minase spsa`の実行条件`manifest.json`は、利用者が入力した規則の原文を保存し、再開のときに解析し直すので、原文が`engine-default`の実行は改名の後のハーネスで再開できない。
教師データの形式MNSDのヘッダも規則セットを文字列で保存するが、現行の生成器はコード列を書くので、生成器が書いたファイルは改名の影響を受けない。
集計の条件に名前を使っていた`scripts/resign_diagnosis.py`は、正準のコード列の欄で選ぶ形に改めたので、改名の前後どちらの記録も同じ条件で選べる。

改名より前のコミットのバイナリは`JCSA`を受理しないので、改名の前後をまたぐ対局の測定では、名前ではなくコード列で規則を指定する。
測定記録、完了済みの設計書、監査報告、および変更履歴に現れる`engine-default`は、過去の事実の記録なので書き換えていない。

# 王手延長を実装しない

## ステータス

承認済み。決定日は2026年8月22日。

## コンテキスト

王手延長（check extension）は、王手を受けたノードで残り深さを延ばし、王手の応酬を浅い読みで打ち切らないようにする手法である。
チェスでは王手を受けた側の応手が少なく、王手の放置は合法手にならないので、王手を受けたことが延長の条件として明確に定まる。
中将棋では、醉象が成った太子も王駒になるので王駒が複数あり得るうえ、王手放置も合法である（RULES.md第8条と第20条）。
さらに、獅子、角鷹、および飛鷲の2段階移動を含めて王駒への利きを判定する費用が高い。
[探索部](../plans/archived/search.md)は、これらの理由から延長条件の設計と検証に見合う利益が見込めず、完了基準は他の改良で満たせるとして、設計の段階で王手延長を見送った。
同じ設計書は、王手延長を実装するなら、どの王駒への捕獲脅威を対象とするか、規則コードE1の有無で扱いを変えるかという延長条件を、試験の設計の時点で確定する必要があるとした。
後の[棋力向上段階8](../plans/archived/strength-stage8.md)の[起案時の発動率診断](../measurements/strength-stage8-activation-diag.md)では、手番側の王駒に相手の利きが届くノードは1.9%であり、段階計画が見送りの基準とする発動率5%にも届かなかった。

## 決定

王手延長を実装しない。

## 検討した代案

チェスと同じく、王駒に相手の利きが届くノードで残り深さを延ばす案は、複数の王駒と王手放置の合法性を扱う延長条件の設計と検証に見合う利益が見込めないので採らなかった。

## 結果

探索は、王駒に利きが届くノードでも残り深さを延ばさない。
王駒に利きが届くノードで浅いノードの前向き枝刈りを控える規則は、延長とは別の決定であり、[浅いノードの前向き枝刈りは王駒に利きが届くノードでは行わない](skip-static-eval-pruning-when-a-royal-is-attacked.md)が扱う。
王手延長を再び提案する場合は、複数の王駒と王手放置の合法性を扱う延長条件を先に設計し、現行の構成で発動率を測り直す必要がある。

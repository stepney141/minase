# 評価関数に王と2駒の組の表（KPP）を使わない

## ステータス

承認済み。決定日は2026年8月26日。

## コンテキスト

[評価関数の設計書](../plans/archived/evaluation.md)の設計判断第1によれば、本将棋ではBonanza以降、自玉の升と他の2駒の升と種類の3つ組ごとに点数を持つ表（KPP）が学習評価関数の標準になった。
同書は、手書きの駒得評価v0を学習評価関数へ置き換えるにあたり、この方式を中将棋へ移せるかを見積もった。
中将棋には持ち駒がないので、駒の特徴は盤上の駒だけで定まるが、それでも144升、47通りの駒状態（駒種と現在の成り可否の組）、および2陣営の組で13,536個になる。
その対の数は約9,200万であり、自玉の升144を掛けた素のKPPは百億を超え、学習に要するデータも記憶域も桁違いに大きい。
さらに、醉象が成ると太子が生じ、王駒が王将と太子の2枚になり得るので、Kの基準が一意に定まらない。
2駒の種類と相対位置の組に縮めた表（相対PP）なら大きさは数百万まで減るが、各項を独立に足すだけなので、第3の駒があるときだけ効く関係を表せない。

## 決定

評価関数に、KPPと、それを相対位置で縮めた相対PPの表を主方式として使わない。

## 検討した代案

KPPを採る案は、表の大きさと王駒2枚の問題により採らなかった。
相対PPを主方式にする案は、隠れ層を持つネットより表現できる関係が狭いので採らなかった。

## 結果

2駒の関係は、後にFactorization Machineの補正として低ランクで表され、現在はNNUEの非線形の経路が担う。
相対PPを主方式ではなく線形評価への補正として加える案は、[近傍の2駒の相対位置の表による評価の補正を実装しない](skip-relative-piece-pair-correction.md)が扱う。
王の位置による条件付けは、表ではなくNNUEの入力特徴集合の選択として扱われる。

# 根の2手目以降を前回反復の部分木ノード数で並べる

## ステータス

承認済み。決定日は2026年10月10日。

## コンテキスト

根では、先頭に置換表の記録手を置き、2手目以降を零窓で読み、値が窓に入れば全窓で読み直す。
最善手が交替する反復で新しい最善手を早く見つけられれば、αが早く上がり、残りの零窓探索のノード数が減る。
[手の順序付けの改善](../plans/move-ordering.md)の[根の診断](../measurements/move-ordering-root-diag.md)では、最善手が交替した反復のノード数が全反復のノード数に占める割合が、STCで53.6%、LTCで53.8%だった。
新しい最善手の順位の平均は、通常の順序付けのキーではSTCで24.8、前回反復の各手の部分木ノード数の降順に並べると18.7だった。
ただし反復ごとに数えると、部分木ノード数で並べた方が後になる反復がやや多く、改善は大きく前へ動く少数の反復に偏っていた。
この候補を含む7候補の構成は、STCとLTCの`H1`で一括して採用した（[STC](../measurements/move-ordering-all-stc.md)、[LTC](../measurements/move-ordering-all-ltc.md)）。

## 決定

根の先頭の手は変えず、2手目以降を前回の完了反復で各手が使った部分木ノード数の降順に安定整列する。
部分木ノード数には、aspiration windowsの読み直しを含めて累積した値を使う。

## 検討した代案

前回反復の評価値で並べる案は、零窓で得た値が上界か下界にすぎず正確な評価値ではないので採らなかった。
部分木ノード数は前回反復で実際に払った探索量であり、値の種類を区別せずに使える。

## 結果

前回反復の記録がない深さ1では、通常の順序付けのキーで並べる。
採用は7候補の一括の判定によるので、この候補単独の寄与は測っていない。
改善は少数の反復に偏るので、この整列を見直す場合は、反復ごとの勝ち負けの件数ではなく順位やノード数の合計で比べる必要がある。

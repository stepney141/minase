# 駒除去差分の符号を保たせる片側絶対値の補助損失を学習に加える

## ステータス

承認済み。決定日は2026年9月14日。

## コンテキスト

駒除去差分とは、局面から王駒以外の駒を1枚除いたときの評価値の変化である。
自駒を除けば手番側の評価は下がり、相手駒を除けば上がるべきだが、教師値に対する二値交差エントロピーは勝率が飽和する大差の局面で評価値の誤差に鈍く、この符号を保証しない（[検証損失の近さは駒価値の正しさを保証しない](../lessons/validation-loss-hides-material-distortion.md)）。
[棋力向上段階7](../plans/strength-stage7.md)の世代2の再学習では、量子化の保存範囲の超過と、駒除去差分の符号の反転が生じた。
符号が反転した候補は、学習後の診断で採否測定へ出さない規則だった。
[二乗型の追加損失の予備比較](../measurements/strength-stage7-removal-pilot.md)では、正の係数のいずれも符号反転0件を満たさなかった。
[片側絶対値型の予備比較](../measurements/strength-stage7-removal-absolute.md)では、係数0、1、10、100、1000を訓練集合の中で比べ、符号反転0件と量子化の保存範囲に収まることを満たす中で交差エントロピーが最小の1000が選ばれた。

## 決定

学習の損失に、各局面の王駒以外のすべての駒を1枚ずつ除いた差分が参照と同じ符号を余裕を持って保つことを求める片側絶対値型の補助損失を、係数1000で加える。
除去後の補間係数は除去後の盤上総駒数で計算し直し、検証損失と最良エポックの選択には補助損失を含めない（詳細は`minase-trainer`の`pst::removal`のdocコメントにある）。

## 検討した代案

二乗型の追加損失は、予備比較で符号反転0件を達成できなかったので採らなかった。
学習後の診断で符号の反転を見つけたら別のエポックや係数へ差し替える運用は、既知の診断局面へ係数を合わせることになるので採らなかった。

## 結果

係数1000は段階7の学習率0.03と訓練集合の下で選んだ値であり、有限の係数は量子化後の符号の維持を保証しない。
参照は、段階7では初期値の重みの整数評価だったが、後の計画で駒得評価v0の駒価値に改められた。
現在のNNUEと同時学習の学習器は常にv0の駒価値を参照にし、PSTの学習器は引数`--removal-reference`でv0と初期値の重みのどちらかを明示させる（参照表は`pst::removal::v0_piece_values`のdocコメントにある）。
補助損失は王駒の升を対象から除くので、王の位置で条件付けた入力特徴集合でも同じ式で計算できる。
[NNUEの隠れ層と位相補間の出力](../plans/nnue-hidden-layer.md)は、この補助損失を外す候補を起案している。

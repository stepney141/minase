# 詰み帯、捕獲または成りの最善手、および対局内の再出現の局面を、除外の理由を付けて教師データに記録する

## ステータス

承認済み。決定日は2026年10月14日。

## コンテキスト

[除外した局面を教師データに記録しない決定](exclude-mate-tactical-and-repeated-positions-from-teacher-data.md)は、詰み帯の局面、合法な最善手が捕獲または成りの局面、および同じ対局で再出現した局面を、局面だけを見る静的評価の学習から除くために、生成器が記録しないと定めた。
同様に、生成器は乱数で指した序盤と、乱数の注入（探索の代わりに乱数で選んだ合法手を指すこと）の手番の局面、記録を始める前に探索した局面、および終局の局面も書いていなかった。
[教師データを対局単位の連鎖で記録する決定](record-teacher-data-as-chained-games.md)では、読み手が開始局面から手順を再生して局面を復元するので、途中の局面を捨てると手順が途切れる。
また、AlphaZero型探索の教師あり学習は、戦術的な局面での正しい手こそが方策の教師に必要なので、これらの局面を除外しないと定めている（[AlphaZero型探索の設計書](../plans/alphazero.md)）。

## 決定

生成器と実戦棋譜の取り込みは、保存する対局の開始局面から終局の局面まで、すべての局面を記録する。
これまで捨てていた3種類の局面には、従来と同じ優先順位（詰みの帯、戦術的な局面、反復の局面）で最初に該当した理由を除外の理由として付け、探索値はそのまま持たせる。
探索しなかった局面と、記録を始める前に探索した局面には、価値がない印を付ける。
NNUEとPSTの学習器は、除外の理由がなく価値を持つ局面だけを読むので、静的評価の学習から3種類の局面を除く判断は変わらない。
手数の上限で終局しなかった対局は、従来どおり書かない。

## 検討した代案

従来どおり捨てる案は、手順が途切れて局面を復元できず、戦術的な局面の正しい手を方策の教師にも使えないので採らなかった。
除外の理由を持たずに全局面を書き、学習器が理由を判定し直す案は、最善手が捕獲か成りかの判定と再出現の判定を読み手が繰り返すことになり、探索値の絶対値以外は生成時の探索結果がなければ判定できないので採らなかった。

## 結果

自己対局の生成器と実戦棋譜の取り込みが書く、除外の理由がなく価値を持つ局面の列は、版1の生成器が書いていたレコードの列と順序まで一致した（[照合の記録](../measurements/unified-teacher-format-equivalence.md)）。
自己対局の生成器は、保存した対局について除外の理由ごとの局面数を要約に出し、`minase data selfplay inspect`はファイルに含まれる除外の理由ごとの局面数を数える。
3種類の局面を静的評価の学習から除く理由と、その処置が履歴の影響を軽減するにとどまることは、置き換えた決定と同じである。

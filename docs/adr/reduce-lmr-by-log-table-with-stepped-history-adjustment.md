# LMRの減深量は対数表に3段階のhistory補正を加えて求める

## ステータス

承認済み。決定日は2026年9月7日。

## コンテキスト

LMR（late move reductions）は、順序付けの後方にある静かな手を浅く読み、αを上回ったときだけ本来の深さで読み直す手法である。
[棋力向上段階5](../plans/strength-stage5.md)の前のLMRは、残り深さ3以上で4手目以降の静かな手を一律に1だけ浅く読んでいた。
中将棋は1局面の合法手が100手を超えるので、後方の手をより大きく減深する余地がある。
段階5は、減深量を残り深さと手番号の対数の積から求め、history値で増減する式に改めた。
[診断bench](../measurements/strength-stage5-lmr-bench.md)は、減深によって失う良い結果の割合が当時の規則を超えない係数の組のうち、減深量の平均が最大の組を選んだ。
選んだ組では、失う割合は全体で27.9%、減深量の平均は1.557だった。
同じ標本に当時の規則を当てはめると、失う割合は35.5%、減深量の平均は0.999だった。
この式は[STC](../measurements/strength-stage5-lmr-stc.md)と[LTC](../measurements/strength-stage5-lmr-ltc.md)でともに`H1`となった。
係数の値は、その後のSPSAの調整セッションで変わったが、式と増減の規則は変わっていない。

## 決定

LMRの減深量は、残り深さ`d`と手番号`m`から`floor(ln(d)·ln(m)/c)`を前計算した表の値に、history値が閾値`+H`以上なら−1、`−H`以下なら+1の補正を加え、0以上`min(3, d − 2)`以下に切り詰めて求める。
この切り詰めにより減深後の深さは1以上に保たれ、静止探索へは落ちない。
対象は、置換表の記録手、捕獲手、およびkiller手を除く非捕獲手であり、成る非捕獲手も含む。

## 検討した代案

history値に比例して減深量を連続的に増減する案（`r −= history / K`）は、比例係数と切り詰めの2つの自由度を持ち込み、それぞれを1つに絞る診断が要るので採らなかった。
減深量の上限を3より大きくする案は、標準時間制御の到達深さで減深後の深さが1になる頻度が増え、誤った読み直しが増えるので採らなかった。
失う良い結果の割合に10%以下という絶対基準を課す案は、[試行診断](../measurements/strength-stage5-lmr-trial-bench.md)で当時の規則自体が良い結果の31.5%を失っていて基準を満たさなかったので採らなかった。

## 結果

式の詳細は`crates/minase/src/search/alphabeta/pruning.rs`の`lmr_reduction`と`lmr_table`のdocコメントにあり、除数`c`と閾値`H`の現行値は`params.rs`の`LmrDivisor`と`LmrHistoryThreshold`にある。
根ではLMRを行わない。
上限3と3段階の補正は、STCの到達深さが5〜6だった時期の判断なので、到達深さが大きく変わった場合は見直す余地がある。

# PSTの学習に浅い探索の手の順位の損失を加えない

## ステータス

承認済み。決定日は2026年10月1日。

## コンテキスト

[浅い探索の手の順位を学ぶ損失](../plans/rank-loss-training.md)は、深い探索が安定して支持する手を浅い探索でも上位に評価させる順位の損失を、PSTの学習に加えた。
この損失は、[一次資料の調査](../research/evaluation-learning-primary-sources-2026-09.md)が扱うBonanzaのMinimax Tree Optimization（MMTO）の原理を、人間の棋譜の手から深い探索の手へ置き換えたものである。
浅い探索には、根の各候補手を指した子局面から静止探索を行う深さ1の探索を使った。
教師には、候補手の子局面を1,000,000ノードと10,000,000ノードの2予算で探索し、両方で同じ手を判定の差117.7センチポーン以上で支持した手の組だけを使った（[較正の記録](../measurements/rank-loss-teacher-calibration.md)）。
順位だけでは評価の尺度が決まらないので、静的値の回帰に順位の損失を重みβで加え、β=0の対照Cと比べた。
[学習](../measurements/rank-loss-training.md)では、検証の組の正答率がCの0.33から0.48〜0.51へ上がった一方、静的評価と教師値の平均絶対誤差がCの1.18〜1.28倍に悪化し、3通りのβがすべて事前に定めた上限の1.05倍を超えた。
エンジンの開発者の判断で、誤差の上限だけを外して選ばれるβ=1.0をCと対局させたところ、[STC](../measurements/rank-loss-vs-control-stc.md)は213有効ペアの得点率38.5%（約−81 Elo）で`H0`となった。

## 決定

PSTの学習に、浅い探索の手の順位の損失を加えない。

## 検討した代案

β=1.0の候補を採用の手順に進める案は、対照に対するSTCで`H0`となったので採らなかった。
β=0.1とβ=0.3の候補は、平均絶対誤差の上限を超えており、対局では測らなかった。

## 結果

この結論は、駒どうしの関係を表せない線形のPSTについてのものであり、関係を表せるモデルで同じ損失を使う方式を否定しない。
既定の評価関数は2026年10月12日にNNUEへ置き換わったので、NNUEの学習に順位の損失を加える提案は、NNUEで測り直してから判断する。
採用中の評価関数S0との対局は行っておらず、S0に対する強弱は結論していない。

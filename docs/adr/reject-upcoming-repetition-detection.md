# 反復の先読み（upcoming repetition detection）を採らない

## ステータス

承認済み。決定日は2026年9月28日。

## コンテキスト

反復の先読みは、可逆な1手で既出局面へ戻れる局面では引き分けが保証されるとみなし、探索窓の下限αを引き分けの値まで上げる手法である。
Stockfishなどのチェスのエンジンが採用しており、YaneuraOuは将棋で強くならないとして使っていない（[未導入の棋力向上手法の調査](../research/unplanned-strength-techniques-survey.md)）。
[棋力向上段階12](../plans/archived/strength-stage12.md)は、項目を選ぶ段階で、この手法の前提がminaseの反復規則で成り立つかを調べた。
minaseで対局を始めるには、反復規則としてR1、R2、R3のいずれか1つを明示する（[RULES.md](../rules/RULES.md)第31条）。
R2とR3では、既出局面を再現する着手が禁じ手になる。
R1では、同一局面の4回目の出現で裁定し、反復の区間で攻撃的着手だけを続けた対局者が一方だけなら、その側の負けになる。
いずれの規則でも、既出局面へ戻れることは引き分けを保証しない。

## 決定

反復の先読みを探索に入れない。

## 検討した代案

チェスと同じく、既出局面へ戻れる局面でαを引き分けの値まで上げる案は、上記のとおり前提が成り立たず、誤った下限で枝を切り得るので採らなかった。

## 結果

反復の裁定を探索に反映する作業は、起案中の[探索部の反復負け回避](../plans/archived/search-repetition.md)が扱う。
将来、既出局面への復帰が引き分けを保証する反復規則を加える場合は、その規則に限って改めて検討できる。

# NNUEの教師生成に使う機械は、vast.aiの中断可能インスタンスを、その時点の最低入札額で借りる

## ステータス

承認済み。決定日は2026年11月14日。

## コンテキスト

NNUEの教師は、作業機の制御スクリプト`scripts/vast/teacher_generation.py`が、計算機を時間単位で借りられる市場vast.aiで借りた生成機に生成させる。
制御スクリプトは、生成機が止められても回収済みの塊から別の機械で続きを生成できる（[ADR](generate-teacher-files-on-one-rented-machine-and-continue-from-collected-chunks-on-another.md)）。
vast.aiの借り方には、入札で安く借りる代わりにいつでも止められる中断可能インスタンスと、表示の時間単価で借りて止められないオンデマンドがある。
中断可能インスタンスは時間単価が安いが、止められるたびに移行の時間と確定していなかった対局を失う。

[2つの借り方の比較](../measurements/interruptible-teacher-generation/interruptible-teacher-generation-trial.md)では、2026年11月14日の07:36から10:24（UTC）まで、中断可能インスタンスを最低入札額で借りて教師ファイル6本を生成した。
受け入れの検査に通った記録局面1億あたりの総費用は15.92米ドルで、2回止められ、1世代37本の換算は約17.2時間であった。
設計書は2つの借り方で同じ10本ずつを生成すると定めていたが、エンジンの開発者が20本を生成しなくても比べられると判断したので、オンデマンドの費用は、止められずに生成した区間の実測から時間単価の関数として求めた。
その費用は、時間単価をp米ドル/時として記録局面1億あたり約13.39p米ドルであり、中断可能インスタンスと等しくなるのはpが約1.19米ドルのときである。
試行の前後に出ていた、機種の条件を満たし借りた後の検査を通る見込みのあるEPYC 7B13機のオンデマンドの出品は、1時間1.601〜2.002米ドルであった。

## 決定

教師生成に使う機械は、中断可能インスタンスとして借りる。
入札額は、借りる時点の出品の最低入札額を0.0001米ドル単位で切り上げた値とし、借りている間は変えない。
この決定は、2026年11月14日の約2.8時間の観測に基づく暫定のものである。

## 検討した代案

オンデマンドを標準にする案は採らなかった。
試行の前後に出ていたオンデマンドの7B13機の時間単価で求めた記録局面1億あたりの費用は約21.4〜26.8米ドルであり、中断可能インスタンスの約1.3〜1.7倍だったからである。
朝に出ていた1時間1.055米ドルの英国の7B13機なら約14.1米ドルで、中断可能インスタンスより約11%安くなるが、この出品は試行の前になくなっていた。

借りる時点で両方の借り方の出品を比べ、安く見込まれる方を選ぶ案は採らなかった。
中断可能インスタンスの実効の費用は中断の頻度で決まり、今回の観測では中断が最初の約24分に2回起きた後に2時間24分起きなかったので、1回の観測から頻度を推定して比べる根拠がないからである。

止められるたびに入札額を上げる案は採らなかった。
今回の試行では、同じ出品の最低入札額が10分ほどで0.7467米ドルから0.88米ドルに上がっており、入札額を上げると費用の見込みが借りている途中で変わり、一定の入札額での中断の頻度も測れなくなるからである。

## 結果

1世代37本の教師ファイルは、今回の観測の条件なら約17.2時間、約16.5米ドルで生成できる見込みである。
条件を満たすオンデマンドの出品が1時間約1.19米ドルを下回る時間帯が続く場合や、中断の頻度が今回より高く1世代の生成が24時間を超える場合は、この決定を見直す。
生成機が止められるたびに、移行に約4〜13分かかり、1,000局前後の対局を失う。

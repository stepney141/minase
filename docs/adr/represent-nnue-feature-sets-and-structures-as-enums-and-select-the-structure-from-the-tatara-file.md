# NNUEの入力特徴集合と構造を列挙型で表し、tataraの形式の重みのファイルの構造記述から構造を選ぶ

## ステータス

承認済み。決定日は2026年11月19日。[NNUEを入力特徴集合と出力部の型引数で組み立て、型の合わないネットのファイルは読み込みで拒否する](archive/parameterize-the-nnue-by-types-and-reject-mismatched-network-files-on-load.md)を置き換える。

## コンテキスト

入力特徴集合は、局面と視点から第1層のどの行を発火させるかを定める規則であり、構造は、両視点の第1層の出力から評価値を計算する後段の形である。
[以前の決定](archive/parameterize-the-nnue-by-types-and-reject-mismatched-network-files-on-load.md)は、NNUEを`FeatureSet`トレイトと`Head`トレイトの型引数で総称化し、探索は型の別名で具体化した1組だけを使うとした。
重みのファイルはminase独自のMNUEの形式で、ファイルのヘッダの構造記述の文字列を、型から組み立てた文字列と照合していた。

エンジンの開発者は2026年11月15日に、自玉の升ごとに別の重みを引くHalfKP_vmを、王の位置を使わないA型と同じコミットのエンジンと学習器で扱えるようにすると決めた。
探索が使う型を型の別名で1つに固定する方式では、A型とHalfKP_vmを同じコミットで扱えない。
同じ日に開発者は、NNUEの抽象化、学習器の構成、重みの形式、および量子化を、将棋のNNUEの学習器tataraに倣うと決めた（[調査メモ](../research/tatara-nnue-transfer.md)）。
tataraは、公開する入力特徴集合を列挙型`FeatureSet`で表し、次元や特徴のハッシュなどを1つの仕様の値`FeatureSetSpec`から引く。
構造は列挙型`ArchKind`（LayerStackとSimple）で表し、重みのファイルの先頭に版の番号、ネットのハッシュ、および構造記述の文字列を置く。
決定は[tatara化とHalfKP_vmの設計書](../plans/archived/nnue-tatara-framework-and-halfkp-vm.md)で下した。

## 決定

入力特徴集合を列挙型`FeatureSet`（A型と`HalfKpVm`）で表し、次元、区分の数、1視点の発火数の上限、特徴のハッシュ、構造記述での名前、鏡映の扱い、および特徴分解の有無を、`FeatureSet::spec`だけが作る仕様の値から引く。
エンジン、学習器のデータの読み込み、学習、チェックポイント、および書き出しは、同じ仕様の値を参照する。
重みのファイルはtataraのLayerStackとSimpleの形式とし、エンジンは先頭の版の番号で構造を選び、構造記述の文字列を仕様から組み立て直した文字列とバイト単位で照合してから復号する。
対応する組はA型とLayerStack、HalfKP_vmとSimpleの2つだけとする。
MNUEは廃止し、読み分ける経路も変換の命令も作らない。

## 検討した代案

いまの型引数と型の別名を残し、構造を選ぶたびにコミットを分ける案は、A型とHalfKP_vmを同じコミットで扱う目的に反するので採らなかった。
MNUEの版を上げて新しい構造を表す案は、tataraの形式から外れ、`MN`で始まる独自の形式を増やさない方針（2026年10月13日）にも反するので採らなかった。
ファイルの長さから構造を推し量る案は、取り違えを見逃すので採らなかった。
tataraのSimpleの形式は将棋エンジンやねうら王の形式と互換ではなく、tataraもSimpleをやねうら王の形式で書き出さないので、やねうら王との互換は目標にしなかった。

## 結果

読み込みは、対応していない入力特徴集合と構造の組、構造記述の不一致、ハッシュの不一致、途中で切れたファイル、末尾の余りのバイト、値域の違反、および正でない`fv_scale`（整数の出力を評価値へ換算する除数）を、原因ごとのエラーで拒否する。
並びと拒否の条件は`crates/minase/src/eval/nnue/network/`のdocコメントに、仕様の値は`crates/minase/src/eval/nnue/input/`のdocコメントにある。
ファイルにはチェックサムがなく、ネットの取り違えと破損は、ファイル全体のSHA-256で識別する方式（[ADR](identify-nnue-networks-by-the-sha256-of-the-whole-file.md)）で見つける。
本決定の後のコミットはMNUEの形式のネットを読めないので、本決定より前のネットを動かすには、本決定より前のコミットを使う。
入力特徴集合を足すときは、`FeatureSet`の列挙子、仕様の値、番号付けの`Indexer`、および対応する構造の組を足す。

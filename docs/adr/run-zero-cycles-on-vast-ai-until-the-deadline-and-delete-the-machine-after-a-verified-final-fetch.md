# AlphaZero型探索の実行器はvast.aiの機械にも対応して残高を照会せずに終了期限でサイクルを始め、起動スクリプトは最後の受け取りを照合してから機械を削除する

## ステータス

承認済み。決定日は2026年11月10日。

## コンテキスト

実行器`minase_zero run-cycles`は、Colabの機械に固定されていた。
接続は`colab ssh`を中継に使うSSHで、作業場所は`/content`の下、次のサイクルを始めるかは終了期限と`colab usage`のCUの残高で決めていた。
[2回目の実行の設計書](../plans/alphazero-rl-2.md)は使う機械を1サイクルの料金で選ぶので、vast.aiで借りる複数GPUの機械も候補にする必要がある。
vast.aiの口座の照会は、2要素認証のログインがほぼ毎日切れてHTTP 401を返し得る（[SPSAの手引き](../guides/spsa.md)の8節）。
vast.aiのコンテナでは、表示されるCPUの数がcgroupの割当てより多いことがある。
vast.aiの料金は、稼働中の時間単価のほかに、停止から削除までのディスクの保管料と貸し手ごとの転送料がかかる。
また、サイクルの記録は完了したサイクルにしか書かれないので、途中で失われた機械の費用は残らない。
SPSAでは、費用を、期限での自己停止と、取得を終えた機械の削除で抑えている（[SPSAの費用のADR](limit-rented-spsa-costs-by-self-stop-deadlines-and-deletion-after-the-last-game.md)）。
方式はClaudeが提案し、[複数GPU化の設計書](../plans/archived/alphazero-multi-gpu.md)の承認で決まった。

## 決定

実行器は必須の引数`--machine colab|vast`で接続、作業場所、および次のサイクルを始める判定を分ける。
vast.aiでは、インスタンスの番号を受け取って起動時に1回だけ接続先を照会し、作業場所を`/workspace`の下とし、残高を照会せず、現在の時刻に1サイクルの見込みを足した時刻が終了期限以前のときにサイクルを始める。
GPUの枚数と、cpusetとcgroupの割当てから求めた使えるCPUの数は、最初のサイクルの前に借りた機械で調べ、生成器のスレッドの総数か、学習器の再生のスレッド数の合計が、使えるCPUの数を超えれば工程を起動しない。
起動スクリプト（`docs/measurements/alphazero-multi-gpu/launch-vast.py`）は、インスタンスの作成時に自己停止を予約し、自己停止の時刻と貸出期限の早いほうを終了期限として作業機の側でも見張る。
実行器が終わったら、NASにないファイルを受け取って検査和を照合してから機械を削除し、すべての出来事とインスタンスの情報の全体を`vast-instances.jsonl`に追記する。

## 検討した代案

実行器が機械を借りて止める案は採らなかった。
借りることと止めることは起動スクリプトの役目であり、実行器の失敗で機械が残る経路を増やさないためである。

vast.aiでも残高を照会して次のサイクルを決める案は採らなかった。
2要素認証の切れで、学習と関係のない理由で長い学習が止まるからである。

最後の受け取りに失敗しても機械を削除する案は採らなかった。
接続が切れただけでは機械とその上のファイルが失われたとは限らず、自己停止の時刻までは受け取り直せるからである。

料金の欄を名前で選んで記録する案は採らなかった。
vast.aiの応答の欄の名前と意味を推測することになるので、作成の直後と削除の直前のインスタンスの情報を丸ごと残し、料金は後から求める。

## 結果

Colabの接続、残高の判定、および作業場所は変わらない。
vast.aiの機械を借りる前に、そのときの出品の料金を示して利用者の承認を得る運用は、[2回目の実行の設計書](../plans/alphazero-rl-2.md)の費用の規則に従う。
最後の受け取りか照合に失敗した機械と、削除が失敗した機械は残り、起動スクリプトは異常で終わって利用者に報告する。
削除が失敗したときは、機械にSSHで入り、そのコンテナだけを操作できる鍵で停止を要求する。
SSHが使えない機械と、導入に失敗した機械は削除する。
作業機からvast.aiの機械への転送は、測った2台で毎秒約5.5 MBと約24 MBであり、リプレイバッファの上限の約29 GBを新しい機械へ送るには約20〜90分かかる（[vast.aiの測定](../measurements/alphazero-multi-gpu/alphazero-multi-gpu-vast.md)）。
手順は[借りる機械の操作の手引き](../guides/alphazero-machines.md)の7節にある。

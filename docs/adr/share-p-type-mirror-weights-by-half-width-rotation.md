# P型のNNUEは左右鏡映の対で第1層の重みを半幅だけ回して共有する

## ステータス

承認済み。決定日は2026年10月12日。

## コンテキスト

置き換え前のPSTは、左右鏡映した升の組で重みを共有し、盤面全体を左右反転した局面に同じ評価を返していた。
一方、FMは学習時に局面を確率的に鏡映するデータ拡張で鏡映を扱い、埋め込みを共有していなかったので、評価の厳密な鏡映不変性を持たなかった（[アーキテクチャの考察](../research/nnue-architecture-discussion.md)）。
[NNUEによるPST＋FMの完全代替](../plans/nnue-replacement.md)は、NNUEでも盤面全体の左右鏡映に対して評価を厳密に不変にすることにした。
P型は王の位置で条件付けない入力特徴集合であり、HalfKP-hm-b8は自玉の位置で条件付ける入力特徴集合である。
HalfKP-hm-b8は、基準の王駒が盤の左半分にあれば盤面全体を鏡映してから番号を付ける正規化で不変性を得られるが、P型には正規化に使える基準の駒がない。

## 決定

P型の第1層では、ある特徴とその鏡映の特徴が、幅Hの重みの行を半幅H/2だけ回した位置で共有し、第1層のバイアスと出力重みもユニットjとj+H/2で共有する。
こうすると、局面を鏡映すると累算値の成分jとj+H/2が入れ替わるだけになり、出力の内積は変わらない。
線形の経路はどの入力特徴集合でもPSTと同じく鏡映の対で重みを共有し、共有の条件は重みファイルの復号時に検査する（詳細は`Mirror`と`Network::decode`のdocコメントにある）。

## 検討した代案

FMと同じく学習時のデータ拡張で鏡映を扱う案は、評価の厳密な不変性を保証しないので採らなかった。
学習器で全13,680行を別々に持ち、更新のたびに鏡映の対を平均して対称化する案は、共有したパラメータの勾配（両方の鏡映からの和）と同値にならないので採らなかった。

## 結果

学習器は、P型の第1層と線形の経路を、鏡映の対の片方6,840行に空升を表す埋め草1行を加えた6,841行の正準行で持ち、0から数えた筋の番号が6以上の特徴は対の正準行を回して読む。
バイアスと出力重みは半幅を自由なパラメータとし、更新のたびに全幅へ展開する。
HalfKP-hm-b8の不変性は、両陣営が基準の王駒を一意に持つ局面に限られるので、鏡映の一致の検査もその局面に限る。
出力部に隠れ層を加える場合は、隠れ層の重みにも同じ半幅の共有を課さなければP型の不変性が崩れる。

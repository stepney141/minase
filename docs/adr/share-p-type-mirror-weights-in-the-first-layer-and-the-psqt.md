# A型のNNUEは左右鏡映の対で、第1層の重みを半幅だけ回して共有し、PSQTを同じ値にする

## ステータス

承認済み。決定日は2026年11月19日。[A型のNNUEは左右鏡映の対で第1層の重みを半幅だけ回して共有する](archive/share-p-type-mirror-weights-by-half-width-rotation.md)を置き換える。

## コンテキスト

A型は王の位置を使わないので、自玉の位置に応じて盤を鏡映してから番号を付ける正規化では、左右鏡映で評価値が変わらないことを保証できない。
[以前の決定](archive/share-p-type-mirror-weights-by-half-width-rotation.md)は、特徴fとその鏡映Mfの第1層の行を半幅H/2だけ回した位置で共有し、第1層のバイアスと出力重みもユニットjとj＋H/2で共有した。
以前の出力部は第1層の各視点を4分割して要素積を取っていたので、隠れ層を足すときは隠れ層の重みにも同じ半幅の共有を課す必要があった。

A型はtataraのLayerStackへ載せ替えた（[構造のADR](compose-p-as-a-tatara-layerstack-with-a-psqt-and-halfkp-vm-as-a-simple-network.md)）。
tataraの要素積は、第1層の出力の成分jとj＋H/2の切り詰めた値を掛けるので、2つの成分が入れ替わっても積は変わらない。
tataraには王の位置を使わない入力がなく、鏡映を扱う入力はすべて王の位置で鏡映を正規化するので、A型の鏡映の共有に先例はない。

## 決定

A型の第1層は、以前の決定と同じく、W[Mf, j]＝W[f, (j＋H/2) mod H]、b[j]＝b[(j＋H/2) mod H]の関係で行を共有する。
PSQTには別にQ[Mf]＝Q[f]を課す。
後段（L1、L2、出力）には共有を課さない。
学習では鏡映の対の片側だけを自由なパラメータとして持ち、相手側の勾配を回して足し、書き出しでは全行に展開する。
エンジンは、読み込んだ整数について、第1層の全ての鏡映の対が半幅回した関係にあること、第1層のバイアスの前半と後半が一致すること、およびPSQTの対が一致することを確かめ、外れていれば拒否する。

## 検討した代案

以前の決定のように後段にも半幅の共有を課す案は、tataraの要素積の下では要素積の出力そのものが鏡映で変わらず、後段に不要な制約を課すだけなので採らなかった。
A型にも王の位置で鏡映を正規化する案は、A型には正規化の基準にできる駒がないので採らなかった。
学習時のデータ拡張で鏡映を扱う案と、全行を別々に持って更新のたびに平均する案は、以前の決定と同じ理由（評価の厳密な不変性を保証しない、共有したパラメータの勾配と同値にならない）で採らなかった。

## 結果

鏡映の下では累算値の成分jとj＋H/2が入れ替わるだけで、要素積、後段の入力、評価値は変わらない。
v0の位置評価は左右鏡映で対称なので、この制約の下でもv0を正確に表せる。
学習器は、第1層とPSQTを、鏡映の対の片方6,840行に、常に0の埋め草1行を加えた6,841行の正準行（対を代表する行）で持ち、0から数えた筋の番号が6以上の特徴は対の正準行を参照する（第1層は半幅回して読み、PSQTはそのまま読む）。
共有の条件と検査は`crates/minase-trainer/src/nnue/layerstack/`と`crates/minase/src/eval/nnue/network/layer_stack.rs`のdocコメントにある。
HalfKP_vmは基準の王駒の筋で盤を鏡映して番号を付けるので、この共有を使わない。

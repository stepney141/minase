# AlphaZero型探索の自己対局の開始局面として、歩兵と仲人を動かさず、1〜3段目の駒を段の中で並べ替え、2枚の角行を偶奇の異なるマスに置き、後手を点対称に置いた初期配置を選べるようにする

## ステータス

承認済み。決定日は2026年11月10日。

## コンテキスト

出村と金子は、将棋のGumbel AlphaZeroの学習で、初期配置の駒を並べ替えた局面（Shogi816K）から自己対局を始めて事前学習し、初期局面から両者が1手ずつ乱択で指した局面で微調整する組合せが、開始局面を多様にしない学習より強くなったと報告した（Y. Demura and T. Kaneko, "Initial state diversification for efficient AlphaZero-style training", ICGA Journal 46(2), 40–66, 2024）。
本書の段は、各側の最も奥の段を1段目として数える。
Shogi816Kは、歩を動かさず、飛車と角を自陣の2段目の9マス、残りの駒を1段目の中で並べ替え、後手を先手と点対称に置き、乱択の手順を加えずに対局を始める（3.2節）。
minaseの強化学習の1回目は、初期局面から8〜16手を乱択で指した局面から自己対局を始めた。
[2回目の実行の設計書](../plans/alphazero-rl-2.md)は、学習の前半の事前学習の期間の開始局面に、Shogi816Kの方式を中将棋へ移した局面を使う。
中将棋の初期配置（[競技規則](../rules/chu-shogi.md)の第5条）は、先手から見て1段目に12枚、2段目に角行2枚を含む8枚と4つの空きマス、3段目に12枚、4段目に歩兵12枚、5段目に仲人2枚を置く。
人間の棋譜を使わずにプログラムで作る局面なら、標準以外の開始局面も使うことは、2026年11月9日に利用者が決めた（[自己対局の分布の提案](../proposals/alphazero-selfplay-distribution.md)の「起案の前に決めたこと」）。

## 決定

自己対局の生成器`minase data zero-selfplay`に、開始局面の種類（`shuffled-setup`か`random-opening`）を選ぶ必須の引数`--start-position`を置く。
`random-opening`では、今までどおり初期局面から8〜16手を乱択で指してから対局を始める。
`shuffled-setup`では、次の手順で組み替えた局面から、乱択の手順を加えずに対局を始める。
先手の1〜3段目の駒を、それぞれの段の12マスの中で並べ替える。2段目は8枚の駒と4つの空きマスを合わせて並べ替え、2枚の角行は筋と段の和の偶奇が異なる2マスに置く。歩兵と仲人は動かさず、後手は先手を盤の中心で180度回して置く。
並べ替えは対局のシードから作る乱数で、許される配置の全体（先手の配置で約3.0×10²⁰通り）からほぼ一様に選ぶ。
局面は第5条の初期配置だけを置き換えたものであり、先手番、手数0、獅子を取った直後の制限なし、成りの保留なしとし、反復の数え方では最初の出現として扱う。
対局の記録には、組み替えた局面を開始局面として、手数0で書く。

## 検討した代案

段をまたいで並べ替える案は採らなかった。
強い駒が3段目に、玉将と弱い駒が1段目に並ぶ標準の構造を残し、論文の制約（飛車と角は2段目、残りは1段目）に近づけるためである。

2段目の空きマスの位置を固定する案は採らなかった。
論文は9×9の将棋で飛車と角を2段目の9マスのどこにでも置くので、12×12の中将棋でも2段目の12マスのどこにでも置く。

後手を先手と線対称に置く案は採らなかった。
論文は点対称に置いており、中将棋の標準の初期配置も点対称である。

角行の偶奇を縛らない案は採らなかった。
角行は斜めにしか動かないので、2枚を偶奇の等しいマスに置くと、どちらの角行ももう一方の偶奇のマスに届かない。
この制約はChess960が2枚のビショップを異なる色のマスに置く規則に倣ったものであり、中将棋の標準の初期配置でも2枚の角行は偶奇の異なるマスにある。
龍馬と鳳凰は1マスの縦横の動きで偶奇を変えられ、麒麟は各側1枚なので、偶奇を縛らない。

組み替えた局面からさらに乱択の手順を指す案は採らなかった。
論文のShogi816Kは乱択の手順を加えておらず、組み替えた局面でも、3段目と4段目の駒に遮られて、どの駒も初手で相手の駒に届かない。

## 結果

組み替えた局面の対局は、教師データの形式MNSD（[ファイル形式の手引き](../guides/file-formats.md)）を変えずに、その開始局面の欄で表せる。
MNSDの由来の欄は、8〜16手の乱択と同じく乱数開始の自己対局とし、開始局面の種類は生成条件`config.json`、集計`summary.json`、および実行器がサイクルごとに追記する記録に残す。
組み替えた局面の先手の有利さの偏りは、2回目の実行の設計書のフェーズ1で、学習を始める前にαβ探索で確かめる。
実装は、`crates/minase-core/src/position/setup.rs`の`Position::shuffled_initial`と、`crates/minase/src/bin/minase/zero_selfplay/game.rs`にある。

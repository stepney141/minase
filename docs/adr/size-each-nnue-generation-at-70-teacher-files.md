# NNUEの世代反復の1世代の教師を、局面数ではなく教師ファイルの本数で定め、70本とする

## ステータス

承認済み。決定日は2026年11月14日。

## コンテキスト

NNUEの教師は、1ファイル7,500局を生成する教師ファイル（本）を単位に作る。
[中断した世代反復](../plans/archived/nnue-generation-reset.md)は、1世代の量を局面数の目標で定め、第2世代は37本だった。
同じ系列の第2世代の教師での比較では、37本の全量（約27.6万局）がその半分に対してSTCで`H1`（約+94 Elo）、4分の1に対して`H1`（約+239 Elo）であり（[教師の量](../measurements/nnue-generation-reset/nnue-generation-reset-gen2-volume.md)）、局面数をそろえて対局数だけを2倍にした教師も`H1`（約+46 Elo）だった（[対局数と局面数](../measurements/nnue-generation-reset/nnue-generation-reset-gen2-diversity.md)）。
教師の価値は対局数で決まり、37本はまだ頭打ちではなかった。
中将棋は1局が長く、中断した系列の1局は約366局面で、チェスのエンジンSaplingの約138局面の約2.7倍である（[学習レシピの調査](../research/nnue-training-recipes.md)）。
2026年11月14日にエンジンの開発者は、中将棋は分岐と手数が多いので規模を増やすべきだとして、1世代を70本と決めた。

## 決定

NNUEの世代反復の1世代の量は教師ファイルの本数で定め、標準レシピv1は1世代に新しい教師を70本（保存される対局で約52万局）生成する。

## 検討した代案

局面数で定める方式は、対局が長くなっただけで目標に達し、教師の価値の主因である対局数が世代ごとにそろわないので採らない。
37本のままにする案は、頭打ちでないと分かっている規模にとどまるので採らない。
70本が37本よりどれだけ強いかは測っていない。

## 結果

連続生成スクリプトは`--books-per-generation`で1世代の本数を受け取り、標準レシピv1では70を指定する。
1世代の生成機の費用と時間は、[世代反復の設計書](../plans/nnue-generation-iteration.md)が見積もる。

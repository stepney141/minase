# 発動率の低い探索手法を実装しない

## ステータス

承認済み。決定日は2026年9月21日。

## コンテキスト

棋力向上の段階計画では、探索の改良を実装する前に、採否測定の条件でその改良が働くノードや手の割合（発動率）を診断し、5%未満なら見送る。
発動しない改良は自己対局で効果を検出できず、測定の時間だけを費やすからである。
王手延長（check extension）は、[探索部](../plans/search.md)で設計の段階から見送った。
中将棋では王駒が複数あり得ること、王手放置が合法であること、および獅子、角鷹、飛鷲の2段階移動を含む利き判定の費用が高いことから、延長条件の設計と検証に見合う利益が見込めなかったからである。
[棋力向上段階8](../plans/strength-stage8.md)の[起案時の発動率診断](../measurements/strength-stage8-activation-diag.md)でも、手番側の王駒に相手の利きが届くノードは1.9%だった。
同じ診断で、ProbCutの対象になり得る残り深さ5以上の非PVノードは0.4%であり、LTCの到達深さに相当する深さ8で測り直しても1.47%だった（[測定記録](../measurements/strength-stage8-probcut-diag.md)）。
mate distance pruningは、[棋力向上段階6](../plans/strength-stage6.md)の[置換表の対局再生診断](../measurements/strength-stage6-tt-replay.md)で、打ち切られる通常探索のノードがSTC相当で1.08%、LTC相当で1.65%だった。
獅子の2段階の非捕獲移動を浅く読む案は、着手の正準表現がじっと以外を直接の跳びと同一視するので、手の側から区別できなかった。
獅子の非捕獲手全体（検査する非捕獲手の13.5%）を対象にする根拠もなかった。

## 決定

王手延長、ProbCut、mate distance pruning、および獅子の2段階の非捕獲移動の減深を実装しない。
これらは判定の規則と再開の条件の形が同じなので、1つの決定として扱う。

## 検討した代案

発動率の基準に届かない手法を採否測定にかける案は、効果を検出できない測定に時間を費やすので採らなかった。

## 結果

ProbCutは深さ6から深さ8で対象ノードが約2倍に増えたので、到達深さがさらに伸びた段階で測り直す価値がある。
mate distance pruningの発動は詰みの値が探索経路上にある場合に限られるので、[詰み探索](../plans/mate-search.md)の導入などで詰みの値の出方が変われば測り直す。
王手延長を再び提案する場合は、複数の王駒と王手放置の合法性を扱う延長条件を先に設計する必要がある。

# 発動率の低い探索手法を実装しない

## ステータス

承認済み。決定日は2026年9月21日。

## コンテキスト

棋力向上の段階計画では、探索の改良を実装する前に、採否測定の条件でその改良が働くノードや手の割合（発動率）を診断し、5%未満なら見送る。
発動しない改良は自己対局で効果を検出できず、測定の時間だけを費やすからである。
ProbCutは、浅い探索の値が予想される境界を十分に超えるノードを、本来の深さで読まずに打ち切る手法である。
[棋力向上段階8](../plans/strength-stage8.md)の[起案時の発動率診断](../measurements/strength-stage8-activation-diag.md)では、ProbCutの対象になり得る残り深さ5以上の非PVノードが、benchの深さ6で0.4%だった。
段階8の最終構成で測り直した[診断](../measurements/strength-stage8-probcut-diag.md)では、対象になり得るノードは深さ6で0.74%、LTCの到達深さに相当する深さ8で1.47%だった。
mate distance pruningは、詰みまでの手数から窓を狭め、窓が空になったノードを打ち切る手法である。
2026年9月12日に完了した[棋力向上段階6](../plans/strength-stage6.md)の[置換表の対局再生診断](../measurements/strength-stage6-tt-replay.md)では、打ち切られる通常探索のノードがSTC相当で1.08%、LTC相当で1.65%だった。

## 決定

ProbCutとmate distance pruningを実装しない。
どちらも採否測定の条件での発動率が基準の5%に届かないという同じ理由で見送るので、1つの決定として扱う。

## 検討した代案

発動率の基準に届かない手法を採否測定にかける案は、効果を検出できない測定に時間を費やすので採らなかった。

## 結果

ProbCutは、同じ最終構成の診断で深さ6から深さ8の間に対象ノードが約2倍に増えたので、到達深さがさらに伸びた段階で測り直す価値がある。
mate distance pruningの発動は詰みの値が探索経路上にある場合に限られるので、[詰み探索](../plans/mate-search.md)の導入などで詰みの値の出方が変われば測り直す。
同じ段階8で見送った王手延長と獅子の2段階の非捕獲移動の減深は、発動率以外の理由によるので、[王手延長を実装しない](omit-check-extension.md)と[獅子の2段階の非捕獲移動だけを浅く読む減深を実装しない](omit-lion-two-step-quiet-move-reduction.md)が扱う。

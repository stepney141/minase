# 近傍の2駒の相対位置の表による評価の補正を実装しない

## ステータス

承認済み。決定日は2026年9月26日。

## コンテキスト

線形の評価は、局面段階を固定すると各駒を独立に採点するので、近くにいる駒の組の形に依存する価値を表せない。
[相対2駒評価の設計書](../plans/archived/relative-pair-eval.md)は、2枚の駒の種類と相対変位の組ごとに点数を持ち、同じ形には盤のどこでも同じ点数を与える補正項を、PSTを固定したまま加える計画だった。
着手の根拠は、診断を通過した教師と正常な学習器を使っても、近傍の駒の配置に依存する誤りが残ることとした。
フェーズ0では、根（探索を始める局面）の内容を見る前に判定の規則を[準備記録](../measurements/relative-pair-eval/relative-pair-prep.md)へ固定した。
標本は、前段の探索局面の学習計画の最終診断で教師の判定が安定し、採用版の選択の損失が大きかった6つの根である。
各根は、読み筋の駒の損得から、採用版の読みの深さの内側で駒の損得が決まる型、その先で決まる型、および駒の損得のない型に分けた。
後の2型のうち局所的な配置と判定される根が3以上なら着手する規則だった。
6つの根はすべて読みの深さの内側で駒の損得が決まる型であり、局所的な配置と判定される根は0だった。

## 決定

近傍の2駒の相対位置の表による補正項を、必要性の根拠がないとして実装しない。

## 検討した代案

判定の規則を満たさないまま補正項を実装して対局で測る案は、着手の根拠を事前に固定した計画の規則に反するので採らなかった。

## 結果

6つの根の大きな着手の誤りは、100,000ノードの探索が名目上の深さの内側にある駒の損得を見落とした型であり、静的評価よりも探索の枝刈りや深さの削減に関係する可能性を示す。
この結論は、PSTを評価関数としていた時期の6つの根の標本と規則の下で根拠がなかったことに限られ、関係を表す評価方式全般を否定しない。
別の計画で近くの2駒を採点する局所2駒表を実装して測った結果は、[PSTに手作りの局所2駒表の補正項を加えない](reject-local-two-piece-correction-for-pst.md)が扱う。
2駒の関係は、現在はNNUEの非線形の経路が表すので、相対位置の表を再提案するには、NNUEの下で残る誤りの型を同じ手順で診断し直す必要がある。

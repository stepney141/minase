# 持ち時間を後半の手のために温存せず、序盤から分担して使う

## ステータス

承認済み。決定日は2026年9月18日。

## コンテキスト

lishogiと対局ハーネスの時計は、持ち時間が残る間は思考時間の全額を持ち時間から引き、持ち時間が尽きた手から秒読みを与え、使わなかった秒読みを持ち越さない（[持ち時間の効率的な使用](../plans/archived/time-management-efficiency.md)）。
minaseの予算式は、秒読みの分担を毎手の土台とし、持ち時間の分担を序盤から上乗せする。
[現行の診断](../measurements/time-management-efficiency/time-management-efficiency-diag.md)では、5分と秒読み10秒の自己対局で、持ち時間は先手が37手目、後手が36手目に尽きた。
issue #7を受けて、持ち時間が秒読みを十分に上回る間は予算から秒読みの項を外し、残り時間が秒読みに近づいてから秒読みの予算へ移る温存の方式が代案に挙がった。
既存エンジンの調査では、対局全体で持ち時間を温存するエンジンは調べた7本に1本もなく、対数の価値モデルから配分を導くKataGoはminaseより速い消費を最適としていた（[秒読みつき時間制御における既存エンジンの持ち時間配分](../research/time-management-byoyomi-survey.md)）。

## 決定

持ち時間は、YaneuraOuと同じく序盤から残り手数の見積りで分担して使い、後半の手のために温存しない（[同じ調査](../research/time-management-byoyomi-survey.md)）。
持ち時間が序盤で尽きること自体は、この配分の帰結として受け入れる。
最初の数手の長考は、温存ではなく[秒読みの項にだけ掛ける序盤の係数](scale-only-the-byoyomi-term-in-the-opening.md)で抑える。

## 検討した代案

温存の方式は、序盤の消費を直接減らして重要な局面へ持ち時間を残せる一方、序盤の到達深さが下がる。
1手の価値を思考時間の対数とする連続近似のモデルでは、温存が有利になる条件、すなわち局面の難しさに応じた延長が価値を生むことが示されなかった。
このため、エンジンの開発者は温存を採らないと決めた。

## 結果

温存との棋力の優劣は測定していない。
持ち時間優先の時計では持ち時間が尽きるまで秒読みを使えないので、持ち時間の大半は、秒読みがあれば賄えた分の思考時間に使われる。
秒読みつきの時計で持ち時間を局面の難しさで配分する方式は、後に[秒読みつき時計での持ち時間と秒読みの活用](../plans/byoyomi-time-usage.md)が段階Bとして測ったが、どの候補も秒読み期の締切と途中結果の採用を加えた同書の段階Aの構成を上回らず、不採用となった。
温存を再提案する場合は、秒読みつきの時計で棋力を測る必要がある。

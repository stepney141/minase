# NNUEは探索値だけの先読み教師と二値交差エントロピーで学ぶ

## ステータス

承認済み。決定日は2026年10月12日。

## コンテキスト

教師値は、教師局面の探索値を教師用の尺度Kで勝率に換算した値と、その対局の結果を、混合比λで混ぜたものである。
先読み教師は、各局面の探索値に、同じ対局でその後n手までの探索値を、手数が離れるほど小さい重み（減衰率γ）で混ぜた教師値である。
対局結果は同じ対局のすべての局面で同じ値を取るので、駒の組を表せるモデルは結果の成分を対局の記憶として学び、検証損失が初回から悪化した（[教訓](../lessons/game-constant-target-memorization.md)）。
PSTを凍結してFMの補正を学んだ[候補Fa](../plans/fm-quarter-current-pst.md)は、探索値だけ（λ=1.0）の先読み教師で採用された。
一方、PST全体をλ=1.0で学び直した候補は、[共適応の検証](../plans/eval-search-coadaptation.md)で約150 Elo負けたので、λ=1.0の支持は条件付きだった。
[NNUEによるPST＋FMの完全代替](../plans/nnue-replacement.md)は、隠れ層に相当する非線形の経路を持つNNUEの教師を決める必要があった。

## 決定

NNUEの学習は、探索値だけを使う混合比λ=1.0の先読み教師を減衰率γ=0.9と手数n=40で作り、ネット全体の出力に対する二値交差エントロピーで学び、検証局面は対局単位で20分の1を分ける。
教師値の組み立ての詳細は`data::build_targets_from_arrays`と`minase-trainer nnue train`の引数`--lambda-override`のdocコメントにある。

## 検討した代案

対局結果を混ぜる教師（λ<1）は、非線形の経路が対局結果を対局の記憶として学ぶ危険があり、先読み教師が将来の情報を既に含むので採らなかった。
線形の経路と非線形の経路で教師を分ける案は、同じ合計出力の一部を別の教師へ引くと、両方が共通に表せる方向で寄与が相殺するので採らなかった（[PSTとFMの同時学習](../plans/pst-fm-joint-training.md)と同じ判断）。
tataraの勝率モデル損失は、既定のオフセットと尺度がチェスの評価値の分布向けであり、中将棋での値を推定する根拠がないので採らなかった（[学習器の速度の調査](../research/nnue-trainer-speed.md)）。
やねうら王の公式手順のように教師局面を静止探索の末端へ置き換える案は採らなかった（[教師生成の先行事例](../research/teacher-generation-prior-art.md)）。
元の局面と末端の深い探索値は静かな局面でも平均185.8センチポーン異なり（[記録](../measurements/qsearch-output-leaf-sample.md)）、元の教師値を末端へ移す近似の根拠がないからである。

## 結果

教師用のKを教師の分類ごとに推定する規則と、出力のKを基準の重みファイルの値に固定する規則は、[教師データを来歴ファイルで分類する](classify-teacher-data-by-provenance-files.md)と[学習する評価関数の出力Kを固定する](fix-the-output-k-of-trained-weights.md)が扱う。
`minase-trainer nnue train`の`--lambda-override`の既定値は1.0であり、PST、FM、および同時学習の学習器が来歴のλを使うのとは既定が異なる。
初代のネットは、検証損失がどちらの入力特徴集合でもエポック1で最良になり、その後は訓練損失だけが下がった（[学習の記録](../measurements/nnue-replacement-training.md)）。
この頭打ちは[学習率スケジュール](../plans/nnue-lr-schedule.md)の計画が扱う。
λ=1.0の支持は条件付きなので、教師の混合比を変える提案は、NNUEの候補を対局で測って決める必要がある。

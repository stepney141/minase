# NNUEは先読みを使わない探索値だけの教師で、勝率の差の2乗を損失として学ぶ

## ステータス

承認済み。決定日は2026年11月14日。[NNUEは先読みを使わない探索値だけの教師と二値交差エントロピーで学ぶ](archive/train-the-nnue-on-search-value-teachers-without-lookahead.md)を置き換える。

## コンテキスト

[以前の決定](archive/train-the-nnue-on-search-value-teachers-without-lookahead.md)は、NNUEをλ=1.0（教師値に対局結果を混ぜない）とし、各局面の素の探索値を勝率へ換算した教師で、二値交差エントロピーを損失として学ぶと定めていた。
先読み教師を外したネットはSTCとLTCで`H1`であり、対局結果を混ぜる教師は非線形の経路が結果を対局の記憶として学ぶ危険があった（[教訓](../lessons/game-constant-target-memorization.md)）。

先行の学習器の調査（[学習レシピの調査](../research/nnue-training-recipes.md)）では、bullet、tatara、およびvariant-nnue-pytorchがネットの勝率と教師の勝率の差の2乗を、nnue-pytorch（2.5乗）、Stockfish（2.434乗）、およびtanuki-（2.75乗）が勝率の差のべき乗を損失にしていた。
二値交差エントロピーを使うのは、調べた範囲ではやねうら王の旧学習器であり、tanuki-の作者の比較では交差エントロピー型が二乗誤差型に−56.52 ±19.45 Eloだった（[tatara調査](../research/tatara-nnue-transfer.md)）。
2026年11月14日にエンジンの開発者は、先行する複数のエンジンに共通する形に合わせると決め、指数は根拠がないので基本の形の2にすると決めた。

## 決定

NNUEの学習は、λ=1.0とし、各局面の素の探索値を教師の勝率尺度で勝率qに換算した教師を使い、先読み教師を指定しない。
損失は、ネットの出力のロジットzから求めた勝率p = 1/(1+e^(−z))と教師の勝率qの差の2乗 (p−q)² の、ミニバッチの平均とする。
指数は2に固定し、引数にしない。
教師の勝率尺度を対局結果から推定する計算は、二値交差エントロピーのままとする。

## 検討した代案

二値交差エントロピーを続ける案は、現行の主な学習器が使っておらず、上の比較で二乗誤差型に負けていたので採らない。
指数を2.5前後にする案は、nnue-pytorchの文書が2.6で学習の結果が良かったと書くだけで比較の記録がなく、Stockfishの2.434はほかの5つの係数と組で調整された値であり、どれも各エンジンが自分の教師で決めた値なので採らない。
先読み教師と対局結果を混ぜる教師（λ<1）は、以前の決定と同じ理由で採らない。

## 結果

ロジットに対する勾配は2(p−q)·p(1−p)となり、勝率が0か1に近い大差の局面では小さくなる。
minaseの教師は探索値2,000 cp以上の局面が36%を占めるので（[記録](../measurements/nnue-early-best-epoch/nnue-teacher-decided-positions.md)）、交差エントロピーからの変化は先行例より大きく出る可能性がある。
検証損失も同じ式で測るので、変更の前後で検証損失の値は比べられない。
変更はGPUの更新と検証のカーネル、およびCPUの参照計算の両方に及び、両者の一致は等価性の検査で確かめている。
PSTとFMの学習器の損失、`nnue fit-linear`の目的関数、および教師の勝率尺度の較正は変わらない。

# NNUEの世代反復では、学習したネットをgitの外に置いてそのまま次の世代の教師の生成に使い、学習の後に補正しない

## ステータス

提案。[NNUEの世代反復では、線形の経路を学習の後に対局結果で補正せず、学習したネットをgitの外に置いてそのまま次の世代に使う](use-each-trained-nnue-uncorrected-and-outside-git-for-the-next-generation.md)を置き換える案である。[tatara化とHalfKP_vmの設計書](../plans/nnue-tatara-framework-and-halfkp-vm.md)で載せ替えたP型が、載せ替えの確認のSTCで前のP型に約64 Elo負けたので、その原因の切り分けの結果を見てP型の扱いを決めるまで、決定しない。

## コンテキスト

[以前の決定](use-each-trained-nnue-uncorrected-and-outside-git-for-the-next-generation.md)は、世代反復で学習したネットをそのまま次の世代に使い、線形の経路を学習の後に対局結果で補正しないとした。
補正の命令`nnue fit-linear`は、教師や`--lambda`（探索値と対局結果を混ぜる比率λ）を変えたときに残る偏りを調べる診断としてだけ残していた。
補正を続ける案を退けた理由は、第2世代の教師で学んだネットで補正したネットが補正しないネットより弱かったこと、および学習後に線形の経路を補正する先行例が見つからなかったことである。

P型はtataraのLayerStackへ載せ替え、補間つきの線形の経路は区分1つのPSQTに替わった（[構造のADR](compose-p-as-a-tatara-layerstack-with-a-psqt-and-halfkp-vm-as-a-simple-network.md)）。
補正は、序中盤と終盤の2列を持つ線形の経路のうち序中盤の列だけを書き換えるので、補間のないPSQTには同じ意味で移せない。
学習器は前の世代のネットを`--base`で受け取らなくなった（[学習器の構成のADR](split-the-nnue-trainer-into-a-shared-loop-and-structure-backends.md)）。

## 決定

世代反復では、学習したネットをそのまま次の世代の教師の生成に使い、学習の後に補正しない。
重みは世代ごとに初期化し、前の世代のネットを学習の初期値にしない。
世代のネットはgitにコミットせず、ファイル全体のSHA-256を世代の実行記録に書いて固定する。
`nnue fit-linear`は削除する。

## 検討した代案

`nnue fit-linear`を診断として残す案は、PSQTに同じ意味で移せず、使わないコードを残さない方針に反するので採らなかった。
PSQTに合わせた補正を新しく作る案は、以前の決定が補正を退けた理由（補正したネットが弱かった、先行例がない）がそのまま当てはまるので採らなかった。

## 結果

連続生成スクリプトは補正の段を持たず、学習の出力`train/nnue.bin`を次の世代の教師の生成に使う。
世代のネットは手元の機械へ回収し、SHA-256の16進数をファイル名にしてNASに置く。
補正を行わないので、対局結果は、λ＜1の教師の混合と教師の勝率尺度の推定を除いて学習に入らない。

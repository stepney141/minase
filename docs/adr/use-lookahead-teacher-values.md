# 教師の探索値を同じ対局の将来の探索値の幾何加重平均に置き換える

## ステータス

承認済み。決定日は2026年9月23日。

## コンテキスト

教師値の主成分は、記録した局面そのものを約10万ノードで探索した値であり、駒を取らない手が7手から9手続く攻めの準備を数値に含まない。
[棋力向上段階9](../plans/archived/strength-stage9.md)の診断では、深い探索の付け直しや人間の棋譜など、教師の盲点を埋める3つの追加案のどれも採用の根拠を得られなかった。
[先読み教師値](../plans/archived/lookahead-teacher.md)は、探索を深くする代わりに、対局が実際に進んだ先の探索値を使う仮説を立てた。
攻めの準備が整った局面ではその後の十数手で探索値が下がるので、将来の値を混ぜた教師はその局面を低く評価する、という仮説である。
この形はKnightCapのTD(λ)の目標値に着想を得ており、追加の探索を要せず、既存の教師データの対局番号と手数だけから計算できる（[先読み教師値の設計書](../plans/archived/lookahead-teacher.md)の参考資料）。
学習PSTを先読み教師で学び直した候補は、段階開始版に対する[STC](../measurements/lookahead-teacher-pst-stc.md)で325有効ペア、ペンタノミアル度数[44, 10, 166, 14, 91]、LLR 2.958の`H1`となった。
[LTC](../measurements/lookahead-teacher-pst-ltc.md)は104有効ペア、LLR +1.06の判定保留の時点でエンジンの開発者の指示により中止され、採用はLTCの`H1`を待たずに決められた。

## 決定

局面tの教師の探索値を、同じ対局のt+1手からt+40手までに記録された局面の探索値の加重平均に置き換える。
平均は、各探索値を局面tの手番側の視点へそろえ、手数の差kに0.9のk−1乗の重みを付けて正規化したものであり、窓の中に記録がなければ元の探索値を使う。
先読みの減衰率γと窓の手数nは教師の分類の属性とし、教師用Kを分類ごとに推定し直す（詳細は`compute_lookahead`のdocコメントにある）。

## 検討した代案

将来の探索値の最小値を使う案は、探索値の揺れで低い側へ系統的に偏り、両陣営で同じ偏りが生じると1つの局面に矛盾する目標を与えるので採らなかった。
[先読み教師値の設計書](../plans/archived/lookahead-teacher.md)の参考資料にあるKnightCapと同じγ=0.7は、12手先の重みが0.59%しかなく、敗局で観察された約12手から16手後の急落を教師値に反映できないので採らなかった。
先読みと、深い探索で探索値を付け直した付け直しファイルを併用する案は、将来の値の探索条件が混在して教師の分類をγとnだけでは表せないので採らず、学習器は併用を拒否する。
記録された探索値を先読み値で書き戻す案は、教師データのMNSD形式では探索値の欄が16ビット整数なので採らず、先読み値は学習器の中で実数の配列として持つ。

## 結果

先読み教師は、実際に指された着手列と生成時の除外条件に依存する教師であり、不偏な推定ではない。
採用は[SPRTの手引き](../guides/sprt.md)が定める手順から外れて決められたので、LTCで改善を示した証拠はない。
採用した重みと[SPSAの結果の適用](../plans/archived/spsa.md)の係数の組合せは、測られていない。
NNUEの教師も同じγとnを使い、その判断は[NNUEは探索値だけの先読み教師と二値交差エントロピーで学ぶ](archive/train-the-nnue-on-search-value-lookahead-teachers.md)が扱う。

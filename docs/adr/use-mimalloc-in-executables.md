# 実行ファイルでmimallocを使う

## ステータス

承認済み。決定日は2026年8月22日。

## コンテキスト

探索部の実装中に、メモリ割当の速度が探索速度に影響するかが論点になった。
mimallocは、Microsoftが開発した汎用のメモリアロケータであり、Rustでは`#[global_allocator]`で標準のアロケータと置き換えられる。
Vecの巻き上げとは、合法手生成器が駒ごとに確保していた`Vec`を関数の先頭で1回だけ確保して使い回す改善である。
2026年8月22日に、benchの実行時間を、標準のアロケータ、mimalloc、Vecの巻き上げ、およびその併用の4つのバイナリで比べた（[測定記録](../measurements/bench-mimalloc-vec-hoist.md)）。
静止探索を含むdepth=3では、mimallocが約6%、Vecの巻き上げが約14%、併用が約16%速かった。

## 決定

mimallocを、実行ファイル`minase`の側でグローバルアロケータとして宣言する。
ライブラリ`minase-core`はアロケータを宣言しない。

## 検討した代案

ライブラリ側でアロケータを宣言する案は、ライブラリの利用者にアロケータの選択を強制するので採らなかった。

## 結果

宣言は`crates/minase/src/bin/minase/main.rs`にあり、依存は`crates/minase/Cargo.toml`にある。
ライブラリを使う側のプログラムは、アロケータを自由に選べる。

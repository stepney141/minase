# 学習器のAdamWはPyTorchと同じバイアス補正つきの式にする

## ステータス

承認済み。決定日は2026年10月12日。

## コンテキスト

minaseの評価関数の学習器は、PythonとPyTorchの`torch.optim.AdamW`で学んできた。
NNUEの学習率と重み減衰（線形の経路は学習率0.03と重み減衰0、第1層と出力部は学習率10⁻³と重み減衰10⁻⁴）は、PSTとFMの学習器がPyTorchのAdamWで使った値を引き継いだものである。
[Rust製NNUE学習器](../plans/archived/nnue-trainer-rust.md)は、これをRustで書き直すにあたり、最適化器の更新式を決める必要があった。
tataraとbulletのAdamWはモーメントのバイアス補正を持たず、PyTorchとは更新式が異なる（[学習器の速度の調査](../research/nnue-trainer-speed.md)）。

## 決定

学習器のAdamWを、PyTorchの`torch.optim.AdamW`と同じく、バイアス補正つきの1次と2次のモーメント、分離した重み減衰、β₁=0.9、β₂=0.999、ε=10⁻⁸の式にする。
バイアス補正の係数は更新回数から倍精度で求め、更新回数はチェックポイントに保存して再開後も続けて数える（詳細は`nn::AdamCoefficients::update`のdocコメントにある）。

## 検討した代案

tataraやbulletと同じバイアス補正のない式にする案は、同じ係数の意味が変わり、PyTorchのAdamWで使った学習率と重み減衰をそのまま使えなくなるので採らなかった。

## 結果

NNUE、PST、FM、および同時学習の学習器は、同じAdamWの部品を使う。
Pythonの学習器は2026年10月13日に撤去したので、以後はPyTorchとの一致を保守の条件にしないが、現行の係数の値はこの式を前提にしている。
更新式を変える場合は、係数を選び直したうえで学習した候補を対局で測る必要がある。
重み減衰0のAdamWは重み減衰を持たないAdamと同じ式なので、PSTの学習器も同じ部品で書ける。

# 王駒がすべて狙われた局面でも静止探索でstand-patを使う

## ステータス

承認済み。決定日は2026年9月29日。

## コンテキスト

stand-patは、静止探索で何も指さずに現局面の評価値を採る選択肢であり、探索値の下限として使う。
これは「現局面の評価値を下回らない手がある」とみなす楽観的な近似であり、両取りのように避けられない脅威を無視する。
2026年9月28日の[探索部の不具合監査](../audits/search-bugs-2026-09-28.md)は、手番側の王駒がすべて相手の利きにある局面でもstand-patを使うことを指摘した。
監査の再現例では、深さ1が詰みを見落とし、深さ2で見つけた。
チェスのエンジンが王手中のstand-patを禁じるのは、応手が少なく評価値を保てる手がないことが多いからであり、王手放置が合法かどうかとは関係がない。
中将棋は王手放置が合法であり（RULES.md第8条）、王手を受けても逃げ方が多い。
[探索部の不具合修正](../plans/search-bug-fixes.md)は当初、王駒がすべて狙われた静止探索の局面でstand-patを使わず全合法手を読む修正を含めていた。
この修正を含む3件の組の[非劣性のSTC](../measurements/search-bug-fixes-noninferiority-stc.md)は不合格となった。
診断のSTCでは、修正の親コミットの得点率が67.0%、LLRが2.963で`H1`となり、修正は約120 Elo弱かった（[測定記録](../measurements/search-bug-fixes-qsearch-evasion-diag-stc.md)）。
benchの深さ9では、この修正によって総ノード数が83.3%、所要時間が39%増えた（[測定記録](../measurements/search-bug-fixes-bench.md)）。

## 決定

静止探索は、手番側の王駒がすべて相手の利きにある局面でもstand-patを下限として使い、王手中の特例を置かない。
この挙動を不具合ではなく静止探索の近似の限界として扱う。

## 検討した代案

王駒がすべて狙われた局面で全合法手を読む案は、約120 Elo弱かったので採らなかった。
この挙動を不具合として非劣性の判定で直す案も採らなかった。
王駒が詰んでいる局面での誤りは、stand-patが避けられない脅威すべてについて犯す誤りの一例であり、手法の契約に反してはいないからである。

## 結果

静止探索は、王駒が詰んでいる局面を評価値どおりに見誤ることがあり、その発見は1段深い通常探索に委ねる。
実装は`crates/minase/src/search/alphabeta/quiesce.rs`の`quiesce`にある。
測定はNNUE採用前の評価関数と、当時の静止探索の構成で行った。
この挙動を変える提案は探索の改良として扱い、現行の構成での再測定と、+10 Eloの向上を要求する通常の段階ゲートを経る。

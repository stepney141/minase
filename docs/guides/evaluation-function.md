# 評価関数と学習の目的関数

本書は、minaseが現在採用している評価関数の計算式と、その重みを学習したときの目的関数を数式で説明する。
評価関数とは、局面を受け取り、手番側から見た有利さを1つの整数で返す関数であり、探索は読みの末端でこの値を比べて着手を選ぶ。
値の単位はセンチポーン（以下cp）であり、成っていない歩兵1枚をおよそ100とする目盛りである。
ただし学習した評価では、駒の寄与は位置や他の駒との関係で変わるので、どの局面でも歩兵1枚が100 cpに当たるわけではない。
本書は現行の式と現行の重みの作り方だけを記し、方式を選んだ経緯と比較実験は、各節で示す設計書と測定記録に任せる。

## 全体の構成

現行の評価関数は、駒の種類と升ごとの点数を足し合わせる線形の評価表（PST、piece-square table）と、2駒の組の関係を補う補正項（FM、Factorization Machine）の和である。
PSTは序中盤用と終盤用の2組の表を持ち、盤上の総駒数に応じた比率で混ぜて使う。
FMは、各特徴に長さ32のベクトルを持たせ、局面に現れた特徴の全ての対についてベクトルの重み付き内積を足すことで、2駒の位置関係を少ないパラメータで表す。
重みは、自己対局で現れた局面に付けた勝率の教師値を予測するように学習し、整数へ量子化して重みファイル `crates/minase/nets/pst.bin` に保存する。
Rustの実装は `crates/minase/src/eval/pst/` にあり、学習器はPythonで `tools/train/` にある。

局面 $`p`$ に対する最終的な評価値 $`E(p)`$ は、次の式で計算する。

```math
E(p) = \operatorname{clip}\bigl(E_{\mathrm{PST}}(p) + E_{\mathrm{FM}}(p)\bigr),
\qquad
\operatorname{clip}(y) = \max\bigl(-28999,\ \min(28999,\ y)\bigr).
```

$`E_{\mathrm{PST}}`$ はそれ自体も同じ範囲へ切り詰めた整数であり、FMの補正を足した後にもう一度切り詰める。
したがって、PSTとFMの丸める前の値を合計してから1回だけ整数化する計算とは、丸めと切り詰めの位置が異なる。
探索は詰みを30,000から手数を引いた値で表し、29,744（30,000から最大手数256を引いた値）以上を詰みの値として扱うので、上限28,999の静的評価が詰みの値と取り違えられることはない。
以下では、入力特徴、PST、FMの順に式を定め、その後で学習の目的関数を説明する。

## 入力特徴

評価関数の入力は、局面で成り立つ特徴の集合である。
特徴は全部で13,680個あり、局面ごとに高々145個が成り立つ。
内訳は、盤上の駒を表す13,536個と、先獅子の対象升を表す144個である。

盤上の駒の特徴は、「手番側の駒か相手の駒か」の2通り、駒状態の47通り、升の144通りの組で番号を付ける。
駒状態は駒種と現在の成り可否の組であり、29駒種のそれぞれに「成れない」状態を、成れる18駒種に「成れる」状態を割り付けて47通りとする。
たとえば、初期配置の金将は飛車へ成れるが、歩兵が成った金将はもう成れないので、動きが同じでも別の駒状態になる。
47通りのうち自己対局で実際に現れるのは37通りであり、残りの枠は特徴の番号を固定するために置いた未使用の枠である。
先獅子の特徴は、獅子以外の駒が獅子を取った直後にだけ1つ成り立ち、その捕獲が起きた升を表す（RULES.md第15条）。
直後の1手で相手が獅子を取り返せるかどうかが変わるので、同じ駒配置でも評価を変えられるように入力へ含める。

特徴は常に手番側の視点で符号化する。
筋を $`f`$、段を $`r`$（ともに0から11）とし、駒が手番側のものなら $`c = 0`$、相手のものなら $`c = 1`$、駒状態の番号を $`d`$（0から46）とすると、特徴の番号は次の式で決まる。

```math
r_{\mathrm{rel}} =
\begin{cases}
r, & \text{先手番の局面},\\
11 - r, & \text{後手番の局面},
\end{cases}
\qquad
i = (47c + d) \cdot 144 + 12\, r_{\mathrm{rel}} + f.
```

先獅子の特徴の番号は、同じ段の反転を施して $`13536 + 12\, r_{\mathrm{rel}} + f`$ とする。
後手番の局面では盤を段の方向に反転して陣営を入れ替えるので、後手番の局面も先手番の局面と同じ規則で番号へ写る。
駒の動きは前後には非対称で左右には対称なので、視点の変換では段だけを反転し、筋は反転しない。
この符号化により、評価値は符号を反転せずにそのまま手番側から見た値になり、先手と後手で同じ重みを共有できる。
一方で、同じ駒配置の評価が手番を替えるとちょうど符号反転するという制約は課していないので、手番を持つこと自体の価値も学習できる。

以下では、局面 $`p`$ で成り立つ特徴の番号の集合を $`\mathcal{A}(p)`$ と書き、特徴 $`i`$ が成り立つことを $`x_i = 1`$、成り立たないことを $`x_i = 0`$ と書く。
符号化の実装は `crates/minase/src/eval/pst/features.rs` にあり、学習器の `tools/train/src/minase_train/data/features.py` と同じ番号を使う。

## PSTの補間

PSTは、特徴 $`i`$ ごとに序中盤用の重み $`w_i^{\mathrm{mg}}`$ と終盤用の重み $`w_i^{\mathrm{eg}}`$ をcp単位で持つ。
PSTの重み自体が駒の価値と位置の寄与をまとめて表しており、駒得の表を別に足すことはしない。
局面で成り立つ特徴の重みの和を、端点ごとに次のように置く。

```math
S_{\mathrm{mg}}(p) = \sum_{i \in \mathcal{A}(p)} w_i^{\mathrm{mg}},
\qquad
S_{\mathrm{eg}}(p) = \sum_{i \in \mathcal{A}(p)} w_i^{\mathrm{eg}}.
```

2つの和は、王駒を含む盤上の総駒数 $`N(p)`$ から求める補間係数 $`\phi(p)`$ で混ぜる。
先獅子の特徴は駒数に含めない。

```math
q(p) = \min\bigl(90,\ \max(0,\ N(p) - 2)\bigr),
\qquad
\phi(p) = \frac{q(p)}{90}.
```

初期配置の92枚では $`\phi = 1`$ となって序中盤用の表だけを使い、王駒2枚だけが残った局面では $`\phi = 0`$ となって終盤用の表だけを使う。
その間は総駒数について線形に混ぜ、駒を取ると係数が変わるが、成りだけでは変わらない。
実数で書いたPSTの評価は次のとおりである。

```math
P(p) = \phi(p)\, S_{\mathrm{mg}}(p) + \bigl(1 - \phi(p)\bigr)\, S_{\mathrm{eg}}(p).
```

重みファイルには、各重みを8倍して最も近い整数へ丸めた16ビット整数 $`W_i = \operatorname{round}(8 w_i)`$ を保存し、ちょうど中間の値は偶数の側へ丸める。
すなわち重みの単位は1/8 cpであり、1特徴あたりの丸め誤差は1/16 cp以下である。
16ビット整数に収まるように、学習中の重みは各更新の後で $`[-4096,\ 4095.875]`$ cpへ切り詰める。
Rustの実装は、整数の重み和を補間してから最後に1回だけ整数除算する。

```math
E_{\mathrm{PST}}(p) = \operatorname{clip}\left( \operatorname{trunc}\left( \frac{ q(p) \sum_{i \in \mathcal{A}(p)} W_i^{\mathrm{mg}} + \bigl(90 - q(p)\bigr) \sum_{i \in \mathcal{A}(p)} W_i^{\mathrm{eg}} }{720} \right) \right).
```

ここで $`\operatorname{trunc}`$ は0の方向への切り捨てであり、負の値でも床関数とは異なり0の側へ丸める。
除数720は、補間の分母90と量子化の倍率8の積である。
探索中は、着手で変わった特徴の重みだけを足し引きして2つの和を差分更新し、評価のたびに144升を走査し直すことはしない（`crates/minase/src/eval/pst/accumulator.rs`）。

学習器は、左右の鏡映で重なる2つの特徴に同じ重みを持たせる。
筋 $`f`$ の特徴を、陣営、駒状態、段を保ったまま筋 $`\min(f, 11 - f)`$ の特徴と同一視するので、学習する重みは6,840特徴の2端点分である。
保存時には13,680特徴へ展開するので、Rust側の評価は鏡映の共有を意識しない。
補間の設計は[PSTの序中盤と終盤の補間](../plans/tapered-pst.md)が定める。

## FMの補正

FMは、特徴 $`i`$ ごとに長さ $`r = 32`$ のベクトル $`\mathbf{v}_i = (v_{i1}, \dots, v_{ir})`$ を持ち、潜在次元 $`f`$ ごとに符号付きの出力係数 $`a_f`$ を持つ。
補正 $`\Phi(p)`$ は、成り立つ特徴の全ての対について、出力係数で重み付けた内積を足したものであり、勝率のロジット（後述）の単位で表す。

```math
\Phi(p) = \sum_{f=1}^{r} a_f \sum_{\substack{i, j \in \mathcal{A}(p) \\ i < j}} v_{if}\, v_{jf}.
```

先獅子の特徴も同じ集合に入るので、FMが扱う組には、2駒の関係だけでなく先獅子の対象升と駒の関係も含まれる。
FMには序中盤用と終盤用の区別がなく、補間係数も掛けない。

2駒の組ごとに独立な係数を置くと約 $`13680^2 / 2 \approx 9.4 \times 10^7`$ 個の係数が要るが、FMは組の係数を $`\sum_f a_f v_{if} v_{jf}`$ という低い階数の形に制限するので、パラメータは $`13680 \times 32`$ 個と32個で済む。
この制限により、学習データにまれにしか現れない組にも、他の組から推定したベクトルを通じて値が入る。
$`a_f`$ は負にもなり得るので、組の係数の行列は半正定値に限られない。

二値の特徴では $`x_i^2 = x_i`$ なので、和の2乗を展開すると次の恒等式が成り立つ。

```math
\Bigl( \sum_{i \in \mathcal{A}(p)} v_{if} \Bigr)^{2}
= \sum_{i \in \mathcal{A}(p)} v_{if}^{2} + 2 \sum_{\substack{i, j \in \mathcal{A}(p) \\ i < j}} v_{if}\, v_{jf}.
```

したがって補正は、対を列挙せずに次の形で計算できる。

```math
\Phi(p) = \frac{1}{2} \sum_{f=1}^{r} a_f \left[ \Bigl( \sum_{i \in \mathcal{A}(p)} v_{if} \Bigr)^{2} - \sum_{i \in \mathcal{A}(p)} v_{if}^{2} \right].
```

この形では、32次元の和 $`\sum_i v_{if}`$ と自分自身との積の和を差分更新するだけで済む。
FMの設計は[FMの設計書](../plans/factorization-machine.md)が定める。

### 整数による計算

Rustの実装は、浮動小数点の $`\mathbf{v}_i`$ と $`a_f`$ の代わりに、出力係数の絶対値と後述の出力尺度 $`K = 1072.6529541015625`$ をベクトルへ吸収して量子化した16ビット整数 $`u_{if}`$、符号 $`d_f`$、および指数 $`e`$ を保存する。

```math
u_{if} = \operatorname{round}\Bigl( 2^{e} \sqrt{K\, |a_f|}\; v_{if} \Bigr),
\qquad
d_f =
\begin{cases}
-1, & a_f < 0,\\
+1, & a_f \ge 0.
\end{cases}
```

指数 $`e`$ は、全ての $`|u_{if}|`$ が16,383以下に収まる範囲で最大の整数（0から30）として選び、現行の重みファイルでは $`e = 9`$ である。
評価時には、潜在次元ごとの整数の和 $`A_f`$ と、自分自身との積の和 $`C`$ を累算する。

```math
A_f(p) = \sum_{i \in \mathcal{A}(p)} u_{if},
\qquad
C(p) = \sum_{i \in \mathcal{A}(p)} \sum_{f=1}^{r} d_f\, u_{if}^{2}.
```

各特徴の自己項 $`\sum_f d_f u_{if}^2`$ は、浮動小数点の値を別に丸めるのではなく、量子化した整数表から読み込み時に計算する。
このため前述の恒等式は整数のまま厳密に成り立ち、次の分子は全ての対の積の和のちょうど2倍になる。

```math
T(p) = \sum_{f=1}^{r} d_f A_f(p)^{2} - C(p)
  = 2 \sum_{f=1}^{r} d_f \sum_{\substack{i, j \in \mathcal{A}(p) \\ i < j}} u_{if}\, u_{jf}.
```

丸めを無視すれば $`d_f u_{if} u_{jf} = 2^{2e} K a_f v_{if} v_{jf}`$ なので、分子を $`2^{2e+1}`$ で割った値は $`K \Phi(p)`$、すなわちcp単位の補正に一致する。
近似が入るのは $`u_{if}`$ を整数へ丸める段階だけである。

```math
E_{\mathrm{FM}}(p) = \operatorname{trunc}\left( \frac{T(p)}{2^{2e+1}} \right) \approx K\, \Phi(p).
```

$`K`$ はこの量子化の段階でベクトルへ吸収されるので、推論は $`K`$ を参照しない。
$`A_f`$ と $`C`$ はPSTの和と同じく先手と後手の両方の視点について差分更新し（`crates/minase/src/eval/pst/fm.rs`）、ベクトルの和は32ビット整数、2乗と自己項の集計は64ビット整数で計算する。
学習器は、検証集合から選んだ1万局面で、浮動小数点の評価と整数の評価の差の平均絶対値が2 cp以下であることを確かめてから重みファイルを書く。

### 補正の倍率の焼き込み

現行の重みファイルのFMは、学習で得た出力係数を倍率 $`b`$ 倍してから、上の式で量子化し直したものである。

```math
b = \frac{611}{1024} = 0.5966796875,
\qquad
a_f^{\mathrm{deploy}} = b\, a_f.
```

ベクトルへ吸収する係数は $`\sqrt{K |a_f|}`$ なので、整数表には $`\sqrt{b}`$ 倍として入る。
すなわち推論で使う補正は、学習の損失を最小にした補正の約0.6倍であり、PSTの部分、探索用駒価値、および出力尺度は学習で得た値のままである。
倍率は重みに焼き込んであるので、評価の式には倍率が現れない。

倍率を調整する間は、焼き込む前の重みの分子 $`T`$ と指数 $`e`$ を使い、整数化の前に倍率を掛ける調整用の式で補正を計算した。

```math
E_{\mathrm{FM}}^{\mathrm{tuning}}(p) = \operatorname{trunc}\left( \frac{\mathrm{FmScale} \cdot T(p)}{1024 \cdot 2^{2e+1}} \right),
\qquad
\mathrm{FmScale} \in \{0, 1, \dots, 1024\}.
```

焼き込みでは量子化をやり直すので、焼き込んだ補正と調整中の補正は完全には一致しないが、検証集合の1万局面での差は平均0.13 cp、最大1 cpだった（[焼き込んだ候補の記録](../measurements/fm-scale-spsa-candidate.md)）。
倍率を学習の損失ではなく対局の勝敗から決めた理由は、「損失で決めないもの」の節で述べる。

## 探索用駒価値

重みファイルには、PSTとFMのほかに、47駒状態それぞれの探索用駒価値を整数で保存している。
探索用駒価値は、静的交換評価（SEE、static exchange evaluation、ある升での駒の取り合いの損得を見積もる計算）、捕獲手の並べ替え、および歩兵の価値を単位とする枝刈りの余裕値に使い、静的評価 $`E(p)`$ には含まれない。
王駒以外の値は、あるPSTの保存重み $`W`$ から、駒状態 $`d`$ ごとに手番側の駒と相手の駒の144升平均の差を取って求めた。

```math
\mathrm{value}(d) = \operatorname{round}\left( \frac{ \overline{W}_{\mathrm{own}, d} - \overline{W}_{\mathrm{enemy}, d} }{16} \right).
```

ここで $`\overline{W}_{\mathrm{own}, d}`$ と $`\overline{W}_{\mathrm{enemy}, d}`$ は、手番側と相手の駒状態 $`d`$ の重みの144升平均であり、除数16は2つの平均の中間を取る2と量子化の倍率8の積である。
王駒（王将、玉将、太子）の値は、王駒以外の最大値に歩兵1枚分を足した値とし、王駒を取る手がどの駒を取る手よりも先に並ぶようにする。
現行の重みファイルでは、成っていない歩兵が100 cp、獅子が2,522 cp、王駒が2,622 cpである。

この表は、2端点PSTを導入したときの開始版（コミット `af200b4` の重み）からこの式で導いた値に固定しており、PSTやFMを学び直しても導き直さない。
評価関数を変えたときに交換評価や枝刈りの基準まで同時に変わると、効果を切り分けられないためである（[棋力向上段階3](../plans/strength-stage3.md)の「駒価値の再調整」、[PSTの序中盤と終盤の補間](../plans/tapered-pst.md)の「探索用駒価値を固定する」）。
PSTの重みは升ごとに異なり、FMの寄与は他の駒にも依存するので、静的評価の中の駒の寄与が探索用駒価値と一致する必要はない。

## 学習の目的関数

ここからは、現行の重みを作った学習の目的関数を説明する。
現行の重みは、PSTとFMを1つの損失で同時に学習した候補J75に、前述の倍率を焼き込んだものである（[PSTとFMの同時学習](../plans/pst-fm-joint-training.md)、[FMの補正の倍率のSPSAによる調整](../plans/fm-scale-spsa.md)）。
同時学習の学習器（コマンド `train-joint`）はmasterに取り込まれておらず、ブランチ `pst-fm-joint-training` の `tools/train/src/minase_train/joint/train.py` にあり、`git show pst-fm-joint-training:tools/train/src/minase_train/joint/train.py` で読める。
教師値の構成、教師尺度の推定、および駒除去差分の補助損失は、masterにあるPSTとFMの学習器と共通の部品（`tools/train/src/minase_train/pst/teacher.py`、`pst/removal.py`、`data/lookahead.py`）を使っている。

### 勝率のモデル

学習の目標は、局面の手番側の勝率を予測することである。
ここでいう勝率は、勝ちを1、引き分けを1/2、負けを0と数えた期待得点である。
モデルの出力は、PSTの補間値を出力尺度 $`K`$ で割ってロジットへ直し、FMの補正を足した実数 $`z_\theta(p)`$ とする。
$`\theta`$ はPSTの重み、FMのベクトル、および出力係数をまとめた学習パラメータである。

```math
z_\theta(p) = \frac{P_\theta(p)}{K} + \Phi_\theta(p),
\qquad
\hat{P}_\theta(p) = \sigma\bigl(z_\theta(p)\bigr) = \frac{1}{1 + e^{-z_\theta(p)}}.
```

$`\sigma`$ はシグモイド関数であり、ロジット $`z`$ を勝率 $`\hat{P}`$ へ写す。
ロジットとは、確率 $`P`$ に対する $`\log(P / (1 - P))`$ のことである。
cp単位の評価値は $`K z_\theta`$ に当たるので、評価値 $`K \approx 1073`$ cpが勝率 $`\sigma(1) \approx 73\%`$ に対応する。
学習中は勾配を流すために浮動小数点のPSTとFMを使い、推論時の整数への丸めと切り詰めは適用しない。

出力尺度 $`K = 1072.6529541015625`$ は、[棋力向上段階7](../plans/strength-stage7.md)で固定した値であり、学習しない。
教師の世代やデータを変えても評価値の目盛りが変わらないように、学習のたびに推定し直さないことにしている。

### 先読み教師

学習データは、エンジン同士の自己対局で現れた局面ごとに、局面、そのとき指した側の探索値 $`v_t`$（cp）、および手番側から見た最終結果 $`\rho_t \in \{0, \tfrac{1}{2}, 1\}`$（負け、引き分け、勝ち）を記録したものである。
探索値には、記録した局面自身の値ではなく、同じ対局の後続の局面の探索値を減衰率 $`\gamma`$ で重み付けて平均した先読み値 $`\hat{v}_t`$ を使う（[先読み教師](../plans/lookahead-teacher.md)）。
浅い探索の値は数手後に判明する形勢の変化を含まないので、後続の値を混ぜてその変化を早めに教師へ伝えるためである。

手数 $`t`$ の局面について、$`t < s \le t + n`$ の範囲で記録が残っている手数 $`s`$ の集合を $`\mathcal{W}_t`$ とする。
先読み値は次の式で定める。

```math
\hat{v}_t =
\begin{cases}
\dfrac{ \sum_{s \in \mathcal{W}_t} \gamma^{\,s - t - 1} \, (-1)^{\,s - t}\, v_s }{ \sum_{s \in \mathcal{W}_t} \gamma^{\,s - t - 1} }, & \mathcal{W}_t \neq \varnothing,\\
v_t, & \mathcal{W}_t = \varnothing,
\end{cases}
\qquad
\gamma = 0.9,\quad n = 40.
```

探索値はそれぞれの局面の手番側の視点で記録されているので、因子 $`(-1)^{s-t}`$ で奇数手後の値の符号を反転し、局面 $`t`$ の手番側の視点へそろえる。
符号と減衰は、記録の件数の差ではなく実際の手数の差で決める。
記録が除外された手数は平均に含めず、重みは含めた手数だけで正規化し、対局の最後の局面のように窓が空のときは自身の探索値を使う。
先読み値は同じ対局の中だけで計算するので、後述の対局単位の訓練と検証の分割をまたがない。

### 教師値

先読み値は、教師の分類 $`c`$ ごとの尺度 $`K_c`$ で勝率へ直し、最終結果と混合比 $`\lambda`$ で混ぜる。

```math
y_t = \lambda\, \sigma\!\left( \frac{\hat{v}_t}{K_c} \right) + (1 - \lambda)\, \rho_t,
\qquad
\lambda = 0.75.
```

探索値は雑音が少ないが読みの範囲しか見ておらず、最終結果は対局全体の帰結を含むが1局ごとの偶然に左右されるので、両者を混ぜて補い合う。
現行の重みの学習では、先読み値の成分を75%、最終結果を25%とした。
教師の分類とは、教師を作った探索のコミットと重み、探索ノード数、規則セット、先読みの設定などの組であり、学習データの来歴ファイルに記録されている。
実戦棋譜に由来する分類では $`\lambda = 0`$ として最終結果だけを使い、探索値も教師尺度も参照しないが、現行の重みの学習データは自己対局だけである。

教師尺度 $`K_c`$ は、出力尺度 $`K`$ とは別の量である。
$`K_c`$ は、分類 $`c`$ の訓練局面 $`\mathcal{T}_c`$ だけを使い、先読み値から最終結果を予測するロジスティックモデルの対数尤度を最大にする値として推定する。

```math
K_c = \operatorname*{arg\,min}_{50 \le k \le 4000} \sum_{t \in \mathcal{T}_c} \left[ \log\left(1 + e^{\hat{v}_t / k}\right) - \rho_t\, \frac{\hat{v}_t}{k} \right].
```

括弧の中は、予測 $`\sigma(\hat{v}_t / k)`$ と結果 $`\rho_t`$ の二値交差エントロピーから $`k`$ によらない項を除いたものであり、引き分けは $`\rho = \tfrac{1}{2}`$ として扱う。
最小化は区間 $`[50, 4000]`$ の黄金分割探索を64回行い、残った区間の中点を採る。
検証集合はこの推定にも使わない。
現行の重みの学習では、世代2と世代3の2つの分類について $`K_c`$ は758.35と765.95だった（[学習の記録](../measurements/pst-fm-joint-training-training.md)）。
教師尺度を分類ごとに推定するのは、探索の深さや評価関数が違えば探索値の目盛りが違い、同じcpが同じ勝率を意味しないからである。
教師尺度を推定し直しても出力尺度は固定したままなので、モデルのcpとロジットの換算は変わらない。

### 損失

学習の損失は、教師値に対する二値交差エントロピー（BCE、binary cross-entropy）に、FMの補正の大きさを抑える正則化項と、駒除去差分の補助損失を加えたものである。
大きさ16,384のミニバッチ $`\mathcal{B}`$ ごとに、次の量を最小化する。

```math
J_{\mathcal{B}}(\theta) = \frac{1}{|\mathcal{B}|} \sum_{p \in \mathcal{B}} \ell\bigl(z_\theta(p),\ y(p)\bigr)
          + \lambda_{\mathrm{res}}\, \frac{1}{|\mathcal{B}|} \sum_{p \in \mathcal{B}} \Phi_\theta(p)^{2}
          + \eta\, R_{\mathcal{B}}(\theta),
\qquad
\lambda_{\mathrm{res}} = 10^{-4},\quad \eta = 1000.
```

第1項の $`\ell`$ はロジット $`z`$ と教師値 $`y`$ の二値交差エントロピーである。

```math
\ell(z, y) = -\,y \log \sigma(z) - (1 - y) \log\bigl(1 - \sigma(z)\bigr) = \log\left(1 + e^{z}\right) - y\, z.
```

予測した勝率が教師値に一致するとき、$`\ell`$ はその $`y`$ について最小になる。
第2項は、ロジットの単位で測ったFMの補正そのものの2乗平均であり、平均を引いた分散でも、ベクトルの2乗和でもない。
この項は、PSTで説明できる部分までFMが受け持つことを抑える。

学習中は各局面を確率0.5で左右に鏡映してから特徴を作る。
PSTは鏡映で重なる特徴の重みを共有するので鏡映の影響を受けないが、FMは鏡映で対応する特徴のベクトルを共有しないので、この拡張で左右の対称性を学ばせる。
ただしこれは確率的な拡張であり、FMを含む評価全体の厳密な左右対称性を保証する制約ではない。

### 駒除去差分の補助損失

第3項の $`R`$ は、王駒以外の駒を盤上から1枚取り除いたときの評価の変化の向きを制約する。
自分の駒を除けば評価は下がり、相手の駒を除けば上がるべきなので、この向きに反する重みに罰則を課す。

局面 $`p`$ から駒 $`m`$ を除いた局面を $`p \setminus m`$ と書く。
これは合法手を指した局面ではなく、評価の性質を調べるための仮想的な入力である。
除去後の補間係数は、総駒数が1つ減った $`q(p \setminus m) = \min(90, \max(0, N(p) - 3))`$ で計算し直し、手番と先獅子の状態は保つ。
候補の除去差分 $`\Delta_\theta`$ は、PSTとFMを合わせたcp単位の評価の変化である。
潜在次元ごとの和を $`V_f(p) = \sum_{j \in \mathcal{A}(p)} v_{jf}`$ と置けば、駒 $`m`$ に当たる特徴 $`i`$ の除去による差分は、除去した局面ごとに評価をやり直さず、次の式でまとめて計算できる。

```math
\Delta_\theta(p, m) = K\, z_\theta(p \setminus m) - K\, z_\theta(p)
 = P_\theta(p \setminus m) - P_\theta(p) - K \sum_{f=1}^{r} a_f\, v_{if} \bigl( V_f(p) - v_{if} \bigr).
```

FMの項は、除いた特徴と残りの特徴との組の寄与を取り除いたものである。

比較の基準には、駒得だけの評価表、すなわちエンジンの最初の手書き評価関数v0の駒価値を全升と両端点に同じ値で置いた表を使う（`tools/train/src/minase_train/data/mnpt.py` の `initial_weights`）。
この基準の補間値を $`P_0`$ とし、整数化して切り詰めた評価を $`E_0 = \operatorname{clip}(\operatorname{trunc}(P_0))`$ とする。
基準については、向きを決める差分と大きさを決める差分を分けて求める。

```math
s_0(p, m) = \operatorname{sgn}\bigl( E_0(p \setminus m) - E_0(p) \bigr),
\qquad
\Delta_0(p, m) = P_0(p \setminus m) - P_0(p).
```

向き $`s_0`$ は整数化して切り詰めた評価の差から、大きさ $`|\Delta_0|`$ は整数化しない差から取る。
$`s_0 = 0`$ の除去と王駒の除去は対象から外し、局面 $`p`$ で対象となる除去の集合を $`\mathcal{M}(p)`$ とする。
1回の除去の罰則を次の式で定める。

```math
\pi(p, m) = \max\Bigl(0,\ \min\bigl(|\Delta_0|,\ 0.25\bigr) - s_0\, \Delta_\theta\Bigr)
          + \omega\, \max\Bigl(0,\ s_0\, \Delta_\theta - |\Delta_0|\Bigr).
```

第1項は、候補の差分が基準と同じ向きに、少なくとも $`\min(|\Delta_0|, 0.25)`$ cp だけ動くことを求める。
第2項の $`\omega`$ は、基準自身の向きが逆である場合、すなわち自駒を除くと基準の評価が上がるか、相手の駒を除くと下がる場合にだけ1になり、その逆向きを基準より強めることを禁じる。
v0の表では駒の寄与は常に正の駒価値なので、評価が上限に切り詰められない限り基準の向きは逆にならず、$`\omega = 0`$ である。
したがって現行の学習では、$`R`$ は「自駒を除けば少なくとも0.25 cp下がり、相手の駒を除けば少なくとも0.25 cp上がる」という単調性の制約として働く。
第2項はPSTだけの学習器で直前の採用PSTを基準にする場合のためにある。

罰則は、局面ごとに対象の除去で平均し、さらに局面で平均して、出力尺度 $`K`$ で割る。

```math
R_{\mathcal{B}}(\theta) = \frac{1}{K} \cdot \frac{1}{|\mathcal{B}|} \sum_{p \in \mathcal{B}} \frac{1}{\max\bigl(1,\ |\mathcal{M}(p)|\bigr)} \sum_{m \in \mathcal{M}(p)} \pi(p, m).
```

対象がない局面も寄与0として平均の分母に含めるので、全局面の全除去を一括して平均する計算とは異なる。
この損失は基準の駒価値そのものを再現させる2乗誤差ではなく、向きと最小の幅に対する片側の罰則である。
係数1000は有限なので、学習後や倍率の焼き込み後の整数評価で、全ての除去が望ましい向きになるとは限らない。
補助損失の定義の詳細は[評価関数の設計書](../plans/evaluation.md)の「教師値と損失」と[PSTとFMの同時学習](../plans/pst-fm-joint-training.md)の設計判断にある。

### 最適化と制約

最適化には、重み減衰を勾配の更新から分離したAdamWを使い、1つのAdamWに2つのパラメータ群を置く。
PSTの群は学習率0.03、重み減衰0であり、前述のとおり各更新の後で重みを $`[-4096, 4095.875]`$ cpへ切り詰める。
FMの群はベクトルと出力係数を含み、学習率 $`10^{-3}`$、重み減衰 $`10^{-4}`$ とする。
この重み減衰は、損失の第2項の補正の2乗平均とは別の正則化である。
訓練集合とその鏡映に一度も現れない特徴のFMのベクトルは、学習しても情報がないので0に固定し、各更新の後に0へ戻す。
現行の重みの学習では、この固定の対象は13,680特徴のうち4,158特徴だった。

初期値は、それまで別々に学んだPSTの重み（候補L）と、そのPSTを固定して学んだFMの重み（候補Fa、補正を縮める前）である。
初期値と補助損失の基準は別の役割であり、前者は学習の出発点、後者は除去差分の向きの目標である。

### 検証集合と早期終了

学習データは対局単位で訓練集合と検証集合に分け、自己対局の生成シードと対局番号のハッシュを20で割った余りが0の対局、約5%を検証に充てる。
同じ対局の局面を両方に入れると、隣接する局面が似ているために検証損失が実力より良く見えるからである。
現行の重みの学習では、世代2と世代3の各5ファイルを使い、訓練は27,745,843局面、検証は1,462,975局面だった。

各エポックでは訓練局面を並べ替えて1,694回更新し、エポックの後に検証集合の二値交差エントロピーを測る。
検証損失には、損失の第2項と第3項を含めず、鏡映の拡張もしない。
最良値を厳密に下回ったエポックの重みを保持し、5エポック続けて最良値が更新されなければ学習を止める（上限は200エポック）。
返すのは学習したエポックの中で最良の重みであり、学習前の重み（エポック0）は比較のために記録するだけで候補にしない。
現行の重みはエポック2の重みであり、学習はエポック7、総計11,858更新で止まった。
検証損失はエポック0の0.430003から0.429552へ下がり、選んだ重みの量子化による誤差は平均0.77 cpだった。

## 損失で決めないもの

FMの補正の倍率 $`b`$ と探索用駒価値は、学習の損失では決めていない。

倍率 $`b`$ は、PSTとFMの重みを固定したまま、自己対局の勝敗から係数を調整するSPSA（simultaneous perturbation stochastic approximation、同時摂動確率近似）で決めた。
SPSAは、係数を正負に揺らした2つの設定を対局させ、その勝敗から係数を更新する手法であり、$`\mathrm{FmScale}`$ を0から1024の範囲で調整して611を得た。
Eloを対局の勝率から換算した強さの差の尺度とすると、損失を最小にした補正をそのまま使った候補J75は、それまでのmasterに短時間条件の自己対局で約8 Elo負けたが、倍率611/1024を焼き込んだ候補は長時間条件で約120 Elo勝った（[FMの補正の倍率のSPSAによる調整](../plans/fm-scale-spsa.md)）。

学習の損失と対局の強さは、実測で異なる倍率を支持した。
同じ教師で検証集合の整数評価の二値交差エントロピーを測ると、焼き込む前のJ75が0.429550、611/1024を焼き込んだ候補が0.429709であり、損失は縮めない補正を好む（[焼き込んだ候補の記録](../measurements/fm-scale-spsa-candidate.md)）。
したがって損失を基準にする限り、対局で強い倍率は選ばれない。
設計書は、同じPSTに縮めないFMを足した同時学習の出発点もmasterに約67 Elo負けたことから、補正の過大を不採用の有力な原因と考えたが、損失と強さが食い違う仕組みは切り分けていない。
得た611も有限の対局から得た採用値であり、最適な倍率であるとは確かめていない。
このため倍率は対局で決め、PSTまたはFMを学び直したときは決め直す。

探索用駒価値は、前述のとおり開始版のPSTから導いた値に固定している。
評価関数の採否は、いずれの場合も検証損失ではなく、新旧のコミットを自己対局させる段階ゲートで決める（[棋力測定の手引き](sprt.md)）。

## masterの学習器との関係

masterにある2つの学習器は、現行の重みの学習と同じ教師値と二値交差エントロピーを使い、学習するパラメータと追加の項だけが異なる。

PSTの学習器 `train-pst`（`tools/train/src/minase_train/pst/train.py`）は、FMを持たないモデル $`z = P_\theta / K`$ を学び、損失は二値交差エントロピーに係数 $`\eta`$ の駒除去差分の補助損失を加えたものである。
この学習器の補助損失の基準は、v0の表ではなく学習の初期値の重みファイルであり、候補の差分もPSTの部分だけで計算する。
手順は[PSTの学習手順](pst-training.md)にある。

FMの学習器 `train-fm`（`tools/train/src/minase_train/fm/train.py`）は、整数で評価したPSTを定数として固定し、$`z = E_{\mathrm{PST}} / K + \Phi_\theta`$ のFMの部分だけを学ぶ。
損失は二値交差エントロピーに正則化項 $`\lambda_{\mathrm{res}} \overline{\Phi_\theta^2}`$ を加えたものであり、駒除去差分の補助損失は持たない。
この学習器は、補正の倍率を出力係数へ焼き込んで量子化し直すサブコマンド `train-fm scale` も持つ。

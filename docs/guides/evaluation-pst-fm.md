# PSTとFMによる評価関数と学習の目的関数

本書は、駒と升ごとの点数の表PSTと、2駒の組の関係を補う補正項FMを足し合わせる評価関数の計算式と、その重みを学習したときの目的関数を数式で説明する。
評価関数とは、局面を受け取り、手番側から見た有利さを1つの整数で返す関数である。
PSTとFMの評価関数は2026年10月12日まで探索の既定の評価関数であり、同日にNNUE（差分更新できる小型のニューラルネットワーク）へ置き換わった。
現在の探索はNNUEだけを使い、その式と学習は[NNUEによる評価関数と学習の目的関数](evaluation-nnue.md)が説明する。
PSTとFMのコードは、学習した評価関数を比べる基準としてテストとともにソースに残っており、探索からは呼ばれない（[探索が使う評価関数をNNUEの1つにし、PSTとFMのコードは比較用に残す](../adr/use-nnue-as-the-only-search-evaluation.md)）。
NNUEの評価値のうち駒と升ごとの点数を足すだけの部分を線形の経路と呼び、この部分はPSTの式をそのまま使い、PSTの重みを初期値として学習するので、本書の入力特徴、補間、および教師値の説明はNNUEを読む前提にもなる。

値の単位はセンチポーン（以下cp）であり、成っていない歩兵1枚をおよそ100とする目盛りである。
この目盛りは、学習を始める前の手書きの評価関数が歩兵を100と定めたものを、学習の初期値を通じて引き継いでいる。
ただし学習した評価では、駒の寄与は位置や他の駒との関係で変わるので、どの局面でも歩兵1枚が100 cpに当たるわけではない。
本書は、置き換えの直前に採用されていた式と重みの作り方を記す。
方式を選んだ詳しい経緯と比較実験は、各節で示す設計書と測定記録にある。

## 前提となる用語

中将棋は、12×12の盤で各対局者が46枚の駒を使うボードゲームであり、規則は[RULES.md](../rules/RULES.md)にある。
局面とは、盤上の全ての駒の配置と、次に指す側（手番）を合わせた状態をいう。
最初に指す側を先手、相手を後手と呼び、1回の着手を1手と数える。
王駒とは王将、玉将、および醉象が成った太子をいい、相手の王駒を全て取るか詰めた側が勝つ。
獅子は、王将の1升の動きを1手で2回続けて行える強力な駒であり、獅子の取り合いには特別な規則がある（RULES.md第13条から第16条）。
成りとは、駒が相手の陣地に入るなどしたときに、より強い別の駒へ変わることであり、一度成った駒は戻らない。

エンジンは探索によって着手を選ぶ。
探索とは、現在の局面から先の着手を枝分かれさせて何手か先まで読み、読みの末端の局面を評価関数で採点して、最も良い結果につながる着手を選ぶ計算である。
評価関数は探索の中で非常に多くの回数呼ばれるので、速く計算できることが求められる。
学習データは、エンジン同士を対局させる自己対局で集める。
masterとは、開発中のリポジトリの主ブランチであり、その時点で採用されているエンジンを指す。

## 全体の構成

この評価関数は、駒の種類と升ごとの点数を足し合わせる表（PST、piece-square table）と、2駒の組の関係を補う補正項（FM、Factorization Machine）の和である。
PSTは序中盤用と終盤用の2組の表を持ち、盤上の総駒数に応じた比率で混ぜて使う。
この混ぜ方は一般に tapered evaluation と呼ばれる。
FMは、各特徴に長さ32のベクトルを持たせ、局面に現れた特徴の全ての対についてベクトルの重み付き内積を足すことで、2駒の位置関係を少ないパラメータで表す。
重みは、自己対局で現れた局面に付けた勝率の目標値（教師値）を予測するように、学習で決める。
学習した実数の重みは、整数へ丸めて（量子化して）重みファイル `crates/minase/nets/pst.bin` に保存し、エンジンは整数演算だけで評価する。
推論のRust実装は `crates/minase/src/eval/pst/` にあり、学習器は `crates/minase-trainer` の実行ファイル `minase-trainer` にある。
`pst.bin` は置き換えの直前に採用されていた重みをそのまま保存しており、本書で「採用時の重み」と呼ぶのはこのファイルの重みである。
採用時の重みはPythonの学習器で作ったが、その学習器は2026年10月にRustへ移植して撤去した（[Python学習器の撤去](../plans/python-trainer-retirement.md)）。

局面 $`p`$ に対する最終的な評価値 $`E(p)`$ は、後で定めるPSTの整数評価 $`E_{\mathrm{PST}}(p)`$ とFMの整数補正 $`E_{\mathrm{FM}}(p)`$ から、次の式で計算する。

```math
E(p) = \mathrm{clip}\bigl(E_{\mathrm{PST}}(p) + E_{\mathrm{FM}}(p)\bigr),
\qquad
\mathrm{clip}(y) = \max\bigl(-28999,\ \min(28999,\ y)\bigr).
```

本書では、値を範囲の端で止める操作 $`\mathrm{clip}`$ を「切り詰め」、小数点以下を0の方向へ落とす操作 $`\mathrm{trunc}`$ を「切り捨て」と呼んで区別する。
$`E_{\mathrm{PST}}`$ はそれ自体の定義の中で同じ範囲へ切り詰めた整数であり、FMの補正を足した後にもう一度切り詰める。
上限28,999は、静的評価（探索せずに局面だけから計算する評価関数の値）の絶対値を29,000未満に保つという、探索の実装との取り決めによる。
探索は詰みを、絶対値が30,000から手数を引いた値になる評価値で表し、絶対値が29,744（30,000から探索の最大手数256を引いた値）以上の値を詰みの値として扱うので、静的評価が詰みの値と取り違えられることはない。
以下では、入力特徴、PST、FMの順に式を定め、その後で学習の目的関数を説明する。

## 入力特徴

評価関数の入力は、局面で成り立つ特徴の集合である。
特徴は全部で13,680個あり、内訳は盤上の駒を表す13,536個と、先獅子の対象升を表す144個である。
対局で現れる局面では盤上の駒が初期配置の92枚より増えず、先獅子の特徴は高々1つなので、成り立つ特徴は高々93個である。
評価関数は144升すべてに駒を置いた入力局面も受け付けるので、実装が想定する上限は145個である。

盤上の駒の特徴は、「手番側の駒か相手の駒か」の2通り、駒状態の47通り、升の144通りの組で番号を付ける。
駒状態は駒種と現在の成り可否の組であり、29駒種（初期配置の21種と、成ったときにだけ現れる8種）のそれぞれに「成れない」状態を、成れる18駒種に「成れる」状態を割り付けて47通りとする。
たとえば、初期配置の金将は飛車へ成れるが、歩兵が成った金将はもう成れないので、動きが同じでも別の駒状態になる。
47通りのうち盤上に現れるのは37通りであり、残りの10通りは、成った形では現れない10駒種（歩兵、仲人、香車、反車、猛豹、盲虎、銅将、銀将、麒麟、鳳凰）の「成れない」状態に当たる未使用の枠である。
これらの駒種は成ると別の駒種に変わるので、「成れない」状態で盤上に現れることがない（`crates/minase/src/eval/features.rs`の`piece_state`）。

先獅子の特徴は、獅子以外の駒が相手の獅子を取った直後にだけ1つ成り立ち、獅子が取られた升（取った駒が今いる升）を表す。
このとき、取った側に残る獅子に足（その獅子が取られてもすぐに取り返せる味方の駒の利き）があれば、相手は直後の1手でその獅子を取れない。
この一時的な禁止を先獅子といい（RULES.md第15条）、同じ駒配置でも次に指せる手が変わるので、評価を変えられるように入力へ含める。

特徴は常に手番側の視点で符号化する。
盤の筋（左右方向の列）を $`f`$、段（前後方向の行）を $`r`$ とし、ともに0から11の番号で表す。
駒が手番側のものなら $`c = 0`$、相手のものなら $`c = 1`$、駒状態の番号を $`d`$（0から46）とすると、特徴の番号 $`i`$ は次の式で決まる。

```math
r_{\mathrm{rel}} =
\begin{cases}
r, & \text{先手番の局面},\\
11 - r, & \text{後手番の局面},
\end{cases}
\qquad
i = (47c + d) \cdot 144 + 12\, r_{\mathrm{rel}} + f.
```

先獅子の特徴の番号は、獅子が取られた升の筋 $`f`$ と、上と同じ規則で求めた $`r_{\mathrm{rel}}`$ から、$`13536 + 12\, r_{\mathrm{rel}} + f`$ とする。
陣営は $`c`$ によって手番側から見た相対的なものとして表し、後手番の局面では段だけを反転するので、後手番の局面も先手番の局面と同じ規則で番号へ写る。
多くの駒の動きは前後で異なるが、中将棋の全ての駒の動きは左右対称なので、視点の変換では段だけを反転し、筋は反転しない。
この符号化により、評価値は符号を反転せずにそのまま手番側から見た値になり、先手と後手で同じ重みを共有できる。
一方で、手番だけを入れ替えた同じ駒配置の評価がちょうど符号反転するという制約は課していないので、手番を持つこと自体の有利さも評価に表れる。

以下では、局面 $`p`$ で成り立つ特徴の番号の集合を $`\mathcal{A}(p)`$ と書く。
符号化の実装は、PSTとNNUEが共有する `crates/minase/src/eval/features.rs` にあり、学習器も `minase` のライブラリの同じ関数で特徴を作る。

## PSTの補間

PSTは、特徴 $`i`$ ごとに、序中盤（駒の多い局面）用の重み $`w_i^{\mathrm{mg}}`$ と終盤（駒の少ない局面）用の重み $`w_i^{\mathrm{eg}}`$ をcp単位で持つ。
この2組の表を本書では2つの「端点」と呼ぶ。
PSTの重み自体が駒の価値と位置の寄与をまとめて表しており、駒の価値だけの表を別に足すことはしない。
局面で成り立つ特徴の重みの和を、端点ごとに次のように置く。

```math
S_{\mathrm{mg}}(p) = \sum_{i \in \mathcal{A}(p)} w_i^{\mathrm{mg}},
\qquad
S_{\mathrm{eg}}(p) = \sum_{i \in \mathcal{A}(p)} w_i^{\mathrm{eg}}.
```

2つの和は、王駒を含む盤上の総駒数 $`N(p)`$ から求める補間係数 $`\phi(p)`$ で混ぜる。
先獅子の特徴は駒ではないので駒数に含めない。

```math
q(p) = \min\bigl(90,\ \max(0,\ N(p) - 2)\bigr),
\qquad
\phi(p) = \frac{q(p)}{90}.
```

90は初期配置の92枚から王駒2枚を引いた数である。
初期配置では $`\phi = 1`$ となって序中盤用の表だけを使い、王駒2枚だけが残った局面では $`\phi = 0`$ となって終盤用の表だけを使う。
その間は総駒数について線形に補間するので、駒を取ると係数が変わり、成りだけでは変わらない。
実数で書いたPSTの評価は次のとおりである。

```math
P(p) = \phi(p)\, S_{\mathrm{mg}}(p) + \bigl(1 - \phi(p)\bigr)\, S_{\mathrm{eg}}(p).
```

重みファイルには、各重みを8倍して最も近い整数へ丸めた16ビット整数 $`W_i = \mathrm{round}(8 w_i)`$ を保存し、ちょうど中間の値は偶数の側へ丸める。
すなわち重みの単位は1/8 cpであり、1特徴あたりの丸めの誤差は1/16 cp以下である。
16ビット整数は −32,768から32,767を表せるので、これを8で割った $`[-4096,\ 4095.875]`$ cpが保存できる範囲であり、学習中の重みも各更新の後でこの範囲へ切り詰める。
Rustの実装は、整数の重み和を補間してから最後に1回だけ整数除算する。

```math
E_{\mathrm{PST}}(p) = \mathrm{clip}\left( \mathrm{trunc}\left( \frac{ q(p) \sum_{i \in \mathcal{A}(p)} W_i^{\mathrm{mg}} + \bigl(90 - q(p)\bigr) \sum_{i \in \mathcal{A}(p)} W_i^{\mathrm{eg}} }{720} \right) \right).
```

除数720は、補間の分母90と量子化の倍率8の積である。
$`\mathrm{trunc}`$ は負の値でも0の側へ切り捨てるので、より小さい整数へ落とす床関数とは結果が異なる。
探索中は、手番の交代に備えて先手と後手の両方の視点の和を持ち、着手で変わった特徴の重みだけを足し引きして更新し（差分更新）、評価のたびに盤全体を数え直すことはしない（`crates/minase/src/eval/pst/accumulator.rs`）。

学習器は、盤を左右に裏返す（鏡映する）と互いに重なる2つの特徴に、同じ重みを持たせる。
筋 $`f`$ の特徴を、陣営、駒状態、段を保ったまま筋 $`\min(f, 11 - f)`$ の特徴と同一視するので、12筋が6筋に畳まれ、学習する特徴は13,680個の半分の6,840個（先獅子の特徴も含む）になる。
保存時には6,840個の重みを元の13,680特徴へ複製して展開するので、Rust側の評価は鏡映の共有を意識しない。
補間の式を選んだ理由は[線形の評価の2組の重みを盤上総駒数で補間する](../adr/interpolate-the-linear-path-by-total-piece-count.md)にあり、比較の経緯は[PSTの序中盤と終盤の補間](../plans/tapered-pst.md)にある。
NNUEの線形の経路は、この補間の式、量子化、および鏡映の共有をそのまま引き継いでいる。

## FMの補正

FMは、特徴 $`i`$ ごとに長さ32のベクトル $`\mathbf{v}_i = (v_{i1}, \dots, v_{i,32})`$ を持ち、ベクトルの成分の番号 $`h`$（潜在次元と呼ぶ）ごとに符号付きの係数 $`a_h`$（出力係数と呼ぶ）を持つ。
補正 $`\Phi(p)`$ は、成り立つ特徴の全ての対について、出力係数で重み付けた内積を足したものである。

```math
\Phi(p) = \sum_{h=1}^{32} a_h \sum_{\substack{i, j \in \mathcal{A}(p) \\ i < j}} v_{ih}\, v_{jh}.
```

$`\Phi`$ はcpではなく、後述する勝率のロジットの単位で表し、cpへは出力尺度 $`K`$（「勝率のモデル」の節で定める定数1072.65）を掛けて換算する。
先獅子の特徴も同じ集合に入るので、FMが扱う組には、2駒の関係だけでなく先獅子の対象升と駒の関係も含まれる。
FMには序中盤用と終盤用の区別がなく、補間係数も掛けない。
最初の導入では補間しない形で効果を確かめ、補間するかは結果を見て判断することにしたためである（[FMの設計書](../plans/factorization-machine.md)）。

2駒の組ごとに独立な係数を置くと約 $`13680^2 / 2 \approx 9.4 \times 10^7`$ 個の係数が要るが、FMは組の係数を $`\sum_h a_h v_{ih} v_{jh}`$ の形に限るので、パラメータはベクトルの $`13680 \times 32`$ 個と出力係数の32個で済む。
この制限により、学習データにまれにしか現れない組の係数も、他の組から学んだベクトルを通じて推定される。
$`a_h`$ は負にもなり得るので、組の係数は正にも負にもなる。

局面で成り立つ特徴の集合 $`\mathcal{A}(p)`$ には同じ特徴が重複して入らないので、和の2乗を展開すると次の恒等式が成り立つ。

```math
\Bigl( \sum_{i \in \mathcal{A}(p)} v_{ih} \Bigr)^{2}
= \sum_{i \in \mathcal{A}(p)} v_{ih}^{2} + 2 \sum_{\substack{i, j \in \mathcal{A}(p) \\ i < j}} v_{ih}\, v_{jh}.
```

したがって補正は、対を列挙せずに次の形で計算できる。

```math
\Phi(p) = \frac{1}{2} \sum_{h=1}^{32} a_h \left[ \Bigl( \sum_{i \in \mathcal{A}(p)} v_{ih} \Bigr)^{2} - \sum_{i \in \mathcal{A}(p)} v_{ih}^{2} \right].
```

この形では、32個の和 $`\sum_i v_{ih}`$ と、各特徴の成分の2乗の和を差分更新するだけで済む。
FMの推論の実装は`crates/minase/src/eval/pst/fm.rs`のdocコメントにあり、方式を選んだ経緯は[FMの設計書](../plans/factorization-machine.md)にある。

### 整数による計算

Rustの実装は、浮動小数点のベクトルと出力係数を、16ビット整数の表 $`u_{ih}`$、符号 $`\epsilon_h`$、および指数 $`e`$ に置き換えて保存する。
組の係数 $`K a_h v_{ih} v_{jh}`$（cp単位）を2つの特徴へ等しく割り振るために、$`\sqrt{K |a_h|}`$ を両方のベクトルに掛け、符号だけを別に持つ。
さらに整数で精度を保つために $`2^{e}`$ 倍してから丸める。

```math
u_{ih} = \mathrm{round}\Bigl( 2^{e} \sqrt{K\, |a_h|}\; v_{ih} \Bigr),
\qquad
\epsilon_h =
\begin{cases}
-1, & a_h < 0,\\
+1, & a_h \ge 0.
\end{cases}
```

指数 $`e`$ は、全ての $`|u_{ih}|`$ が16,383（16ビット整数の上限32,767のおよそ半分）以下に収まる範囲で最大の整数として選び、重みファイルの形式上0から30に限る。
採用時の重みファイルでは、この規則により $`e = 9`$ となった。
評価時には、潜在次元ごとの整数の和 $`U_h`$ と、各特徴の成分の2乗に符号を付けた和 $`C`$ を累算する。

```math
U_h(p) = \sum_{i \in \mathcal{A}(p)} u_{ih},
\qquad
C(p) = \sum_{i \in \mathcal{A}(p)} \sum_{h=1}^{32} \epsilon_h\, u_{ih}^{2}.
```

各特徴の自己項 $`\sum_h \epsilon_h u_{ih}^2`$ は、浮動小数点の値を別に丸めるのではなく、エンジンの起動時に重みファイルを読み込む際に整数表から計算する。
このため前述の恒等式は整数のまま厳密に成り立ち、次の分子 $`D(p)`$ は全ての対の積の和のちょうど2倍になる。

```math
D(p) = \sum_{h=1}^{32} \epsilon_h U_h(p)^{2} - C(p)
  = 2 \sum_{h=1}^{32} \epsilon_h \sum_{\substack{i, j \in \mathcal{A}(p) \\ i < j}} u_{ih}\, u_{jh}.
```

丸めを無視すれば $`u_{ih} u_{jh} = 2^{2e} K |a_h| v_{ih} v_{jh}`$ であり、$`\epsilon_h |a_h| = a_h`$ なので $`\epsilon_h u_{ih} u_{jh} = 2^{2e} K a_h v_{ih} v_{jh}`$ となる。
これを $`D(p)`$ の式に代入すると $`D(p) = 2^{2e+1} K \Phi(p)`$ となるので、分子を $`2^{2e+1}`$ で割った値は $`K \Phi(p)`$、すなわちcp単位の補正に一致する。
近似が入るのは $`u_{ih}`$ を整数へ丸める段階だけである。

```math
E_{\mathrm{FM}}(p) = \mathrm{trunc}\left( \frac{D(p)}{2^{2e+1}} \right) \approx K\, \Phi(p).
```

$`K`$ はこの量子化の段階でベクトルへ吸収されるので、推論は $`K`$ を参照しない。
$`U_h`$ と $`C`$ はPSTの和と同じく先手と後手の両方の視点について差分更新し（`crates/minase/src/eval/pst/fm.rs`）、桁あふれしないように、ベクトルの和は32ビット整数、2乗と自己項の集計は64ビット整数で計算する。
学習器は、検証集合（学習に使わない局面の集合、後述）から無作為に選んだ1万局面で、浮動小数点の評価と整数の評価の差の平均絶対値が、PSTの量子化と同じ合格基準の2 cp以下であることを確かめてから重みファイルを出力する。

### 補正の倍率の焼き込み

採用時の重みファイルのFMは、学習で得た出力係数に倍率 $`b`$ を掛けてから、上の式で量子化し直したものである。
倍率は整数 $`\mathrm{FmScale}`$（0から1024）を1024で割った値として扱い、採用時の値は $`\mathrm{FmScale} = 611`$ である。
このように、学習後に決めた係数を重みの値へ組み込み、推論の式を変えずに済ませることを、本書では「焼き込む」と呼ぶ。

```math
b = \frac{\mathrm{FmScale}}{1024} = \frac{611}{1024} = 0.5966796875,
\qquad
a_h^{\mathrm{deploy}} = b\, a_h.
```

ベクトルへ吸収する係数は $`\sqrt{K |a_h|}`$ なので、整数表には $`\sqrt{b}`$ 倍として入る。
すなわち推論で使う補正は、学習の損失を最小にした補正の約0.6倍である。
PSTの部分は学習で得た値を保ち、後述する探索用駒価値と出力尺度はもともと学習しない固定値なので、倍率は評価の式には現れない。

倍率を調整する間は、焼き込む前の重みの分子 $`D`$ と指数 $`e`$ を使い、整数化の前に倍率を掛ける調整用の式で補正を計算した。

```math
E_{\mathrm{FM}}^{\mathrm{tuning}}(p) = \mathrm{trunc}\left( \frac{\mathrm{FmScale} \cdot D(p)}{1024 \cdot 2^{2e+1}} \right),
\qquad
\mathrm{FmScale} \in \{0, 1, \dots, 1024\}.
```

$`\mathrm{FmScale} = 1024`$ が学習したままの補正、0が補正なしに当たる。
焼き込みでは量子化をやり直すので、焼き込んだ補正と調整中の補正は完全には一致しないが、検証集合から選んだ1万局面での差は平均0.13 cp、最大1 cpであり、PSTの量子化の合格基準2 cpを十分下回った（[焼き込んだ候補の記録](../measurements/fm-scale-spsa-candidate.md)）。
倍率を学習の損失ではなく対局の勝敗から決めた理由は、「損失で決めないもの」の節で述べる。

## 探索用駒価値

重みファイルには、PSTとFMのほかに、47駒状態それぞれの探索用駒価値を整数で保存している。
探索用駒価値は、静的評価 $`E(p)`$ には含まれず、探索の次の3つの計算だけに使う。
1つ目は、ある升での駒の取り合いの損得を見積もる静的交換評価（SEE、static exchange evaluation）である。
2つ目は、駒を取る着手を価値の高い駒を取るものから先に読むための並べ替えである。
3つ目は、見込みのない枝を読まずに打ち切る枝刈りであり、打ち切ってよいかの判定に使う余裕幅を、歩兵の探索用駒価値の定数倍として定める。

王駒以外の値は、序中盤用と終盤用の2組に分ける前の単一のPSTの保存重み $`W`$ から、駒状態 $`d`$ ごとに求めた。
駒状態 $`d`$ の自駒の重みの144升平均 $`\overline{W}_{\mathrm{own}, d}`$ はその駒を持つ価値の推定であり、相手の駒の重みの144升平均 $`\overline{W}_{\mathrm{enemy}, d}`$ の符号を反転したものも同じ価値の別の推定なので、その2つを平均してcpへ直す。

```math
\mathrm{value}(d) = \mathrm{round}\left( \frac{ \overline{W}_{\mathrm{own}, d} - \overline{W}_{\mathrm{enemy}, d} }{16} \right).
```

除数16は、2つの推定の平均を取る2と、量子化の倍率8の積である。
王駒の値は、王駒以外の全ての駒状態の値の最大値に歩兵1枚分を足した値とし、王駒を取る手がどの駒を取る手よりも先に並ぶようにする。
この式で導いた結果、採用時の重みファイルでは、成っていない歩兵が100 cp、獅子が2,522 cp、王駒が2,622 cpとなっている。

この表は、2端点PSTを導入した計画の開始時点の重み（コミット `af200b4`）からこの式で導いた値に固定しており、PSTやFMを学び直しても計算し直さない。
評価関数を変えたときに交換評価や枝刈りの基準まで同時に変わると、どちらの効果かを切り分けられないためである（[探索用駒価値は学習PSTから導いた値に固定する](../adr/derive-search-piece-values-from-the-learned-pst.md)）。
PSTの重みは升ごとに異なり、FMの寄与は他の駒にも依存するので、静的評価の中の駒の寄与が探索用駒価値と一致する必要はない。
NNUEへの置き換えでは、この47個の値を `pst.bin` からNNUEの重みファイル `nnue.bin` へそのまま写したので、現在の探索も同じ値を使う。

## 学習の目的関数

ここからは、採用時の重みを作った学習の目的関数を説明する。
学習とは、目的関数（損失）と呼ぶ1つの数値を定め、それが小さくなる方向へ重みを少しずつ動かすことを繰り返す計算である。
採用時の重みは、PSTとFMを1つの損失で同時に学習した候補J75（教師の混合比 $`\lambda = 0.75`$ で学習した候補）に、前述の倍率を焼き込んだものである（[PSTとFMの同時学習](../plans/pst-fm-joint-training.md)、[FMの補正の倍率のSPSAによる調整](../plans/fm-scale-spsa.md)）。
J75はPythonの同時学習器（ブランチ `pst-fm-joint-training` にだけあった）で学んだ。
その数式は、Rustへ移植した同時学習器 `minase-trainer joint train`（`crates/minase-trainer/src/joint/`）と同じであり、移植時に短縮した条件で同じ結果になることを確かめた（[照合の記録](../measurements/python-trainer-retirement-checks.md)）。
教師値の構成、教師尺度の推定、および先読み教師は、すべての学習器が共有するデータ層（`crates/minase-trainer/src/data/`）にある。

### 勝率のモデル

学習の目標は、局面の手番側の勝率を予測することである。
ここでいう勝率は、勝ちを1、引き分けを1/2、負けを0と数えた得点の期待値である。
勝率 $`x`$ を、$`-\infty`$ から $`+\infty`$ の実数で表し直したものをロジットといい、$`\log(x / (1 - x))`$ で定める。
ロジット $`z`$ から勝率へは、シグモイド関数 $`\sigma(z) = 1 / (1 + \exp(-z))`$ で戻せる。

モデルの出力は、PSTの評価を出力尺度 $`K`$ で割ってロジットへ直し、FMの補正を足した実数 $`z_\theta(p)`$ とする。
$`\theta`$ はPSTの重み、FMのベクトル、および出力係数をまとめた学習パラメータである。

```math
z_\theta(p) = \frac{P_\theta(p)}{K} + \Phi_\theta(p).
```

$`P_\theta`$ は前述のPSTの実数評価（cp）であり、予測する勝率は $`\sigma(z_\theta(p))`$ である。

cp単位の評価値は $`K z_\theta`$ に当たる。
出力尺度は $`K = 1072.6529541015625`$ であり、評価値100 cpが勝率約52%、500 cpが約61%、1,073 cpが約73%に対応する。
この値は[棋力向上段階7](../plans/strength-stage7.md)の時点の重みファイルに記録されていた値であり、同段階以降は学習のたびに推定し直さずに固定している。
教師の世代やデータを変えても、評価値の目盛りが変わらないようにするためである。
学習中は、重みを動かす向きを微分（勾配）で求めるために浮動小数点のPSTとFMを使い、推論時の整数への丸めと切り詰めは適用しない。

### 先読み教師

学習データは、自己対局で現れた各局面について、盤面、手番側が着手を選ぶために行った探索の値 $`s_t`$（cp、手番側から見た値）、および対局の最終結果 $`\rho_t \in \{0, \tfrac{1}{2}, 1\}`$（手番側から見た負け、引き分け、勝ち）を記録したものである。
添字 $`t`$ は対局の何手目の局面かを表す。
採用時の重みの学習データには、1手あたり10万ノード（探索が調べる局面の数）で打ち切る浅い探索を使った。

探索値には、記録した局面自身の値ではなく、同じ対局の後続 $`n`$ 手以内の局面の探索値を減衰率 $`\gamma`$ で重み付けて平均した先読み値 $`\hat{s}_t`$ を使う（[教師の探索値を同じ対局の将来の探索値の幾何加重平均に置き換える](../adr/use-lookahead-teacher-values.md)）。
浅い探索の値は数手後に判明する形勢の急変を含まないので、後続の探索値を混ぜて、その変化を早めに教師値へ反映させるためである。

手数 $`t`$ の局面について、$`t < t' \le t + n`$ の範囲で記録が残っている手数 $`t'`$ の集合を $`\mathcal{L}_t`$ とする。
先読み値は次の式で定める。

```math
\hat{s}_t =
\begin{cases}
\dfrac{ \sum_{t' \in \mathcal{L}_t} \gamma^{\,t' - t - 1} \, (-1)^{\,t' - t}\, s_{t'} }{ \sum_{t' \in \mathcal{L}_t} \gamma^{\,t' - t - 1} }, & \mathcal{L}_t \neq \varnothing,\\
s_t, & \mathcal{L}_t = \varnothing,
\end{cases}
\qquad
\gamma = 0.9,\quad n = 40.
```

探索値はそれぞれの局面の手番側の視点で記録されているので、因子 $`(-1)^{t'-t}`$ で奇数手後の値の符号を反転し、局面 $`t`$ の手番側の視点へそろえる。
符号と減衰は、記録の件数の差ではなく実際の手数の差で決める。
自己対局の生成器は、詰みが見えている局面、最善手が駒を取るか成る局面、および同じ対局で同一の局面が2回目以降に現れたときのその局面を記録しない。
最善手が駒を取るか成る局面を除くのは、探索値には次の手で得る駒得が織り込まれているのに、静的評価はそれを見ないので、両者の差が大きいからである。
記録のない手数は平均に含めず、重みは含めた手数だけで正規化する。
対局の最後の局面のように窓 $`\mathcal{L}_t`$ が空のときは、自身の探索値を使う。
欠けた手数がない場合、40手の窓の中で正規化した重みは、$`\gamma = 0.9`$ では12手先が約3.2%、20手以内の合計が約89%（$`(1 - 0.9^{20}) / (1 - 0.9^{40})`$）になる。
負けた対局では形勢の急落が始まる12手から16手前の局面にも、その変化が伝わる。
40手で打ち切ることで除かれる重みの合計は約1.5%である。
先読み値は同じ対局の中だけで計算するので、後述の対局単位の訓練と検証の分割をまたがない。

### 教師値

先読み値は、教師の分類 $`g`$ ごとの尺度 $`K_g`$ で勝率へ換算し、最終結果と混合比 $`\lambda`$ で混ぜる。

```math
\tau_t = \lambda\, \sigma\!\left( \frac{\hat{s}_t}{K_g} \right) + (1 - \lambda)\, \rho_t,
\qquad
\lambda = 0.75.
```

探索値は雑音が少ないが読みの範囲しか見ておらず、最終結果は対局全体の帰結を含むが1局ごとの偶然に左右されるので、両者を混ぜて補い合う。
採用時の重みの学習では、先読み値の成分を75%、最終結果を25%とした。
$`\lambda = 1.0`$（探索値だけ）で同時学習した候補は、当時のmasterに対する対局の成績が $`\lambda = 0.75`$ の候補より悪かった（[PSTとFMの同時学習](../plans/pst-fm-joint-training.md)）。

教師の分類とは、教師を作った探索のコミットと重み、探索の局面数、規則セット、先読みの設定などの組であり、学習データに付けた来歴ファイル（データの出どころを記録したJSONファイル）に記録されている。
採用時の重みの学習データは、評価関数の世代2と世代3で生成した自己対局データであり、それぞれが1つの分類をなす。
世代とは、教師の生成に使った評価関数の版を、学習と採用を繰り返した順に数えたものである。

教師尺度 $`K_g`$ は、出力尺度 $`K`$ とは別の量である。
$`K_g`$ は、分類 $`g`$ の訓練局面の集合 $`\mathcal{T}_g`$ だけを使い、先読み値 $`\hat{s}`$ から勝率 $`\sigma(\hat{s} / \kappa)`$ を予測するモデルが、実際の最終結果に最もよく合う $`\kappa`$ として推定する。
「最もよく合う」とは、次の二値交差エントロピー（後述）の和を最小にすることをいい、これは結果が観測される確率の対数の和（対数尤度）を最大にすることと等価である。

```math
K_g = \underset{50 \le \kappa \le 4000}{\mathrm{arg\,min}} \sum_{t \in \mathcal{T}_g} \left[ \log\left(1 + \exp\left(\frac{\hat{s}_t}{\kappa}\right)\right) - \rho_t\, \frac{\hat{s}_t}{\kappa} \right].
```

$`\mathrm{arg\,min}`$ は、右の式を最小にする $`\kappa`$ の値を表す。
引き分けは $`\rho = \tfrac{1}{2}`$ として扱う。
最小化には、区間を黄金比で縮めながら最小点を挟み込む黄金分割探索を使い、区間 $`[50, 4000]`$ から始めて64回縮め、残った区間の中点を採る。
64回で区間は元の約 $`10^{-13}`$ 倍になるので、推定値の精度には十分である。
検証集合はこの推定にも使わない。
採用時の重みの学習では、世代2と世代3の $`K_g`$ はそれぞれ758.35と765.95だった（[学習の記録](../measurements/pst-fm-joint-training-training.md)）。
教師尺度を分類ごとに推定するのは、探索の深さや評価関数が異なれば探索値の目盛りも変わり、同じcpが同じ勝率を意味しないからである。
$`K_g`$ は教師値を作るときだけに使い、モデルの出力をロジットへ直すときは常に $`K`$ を使う。
このため教師尺度を推定し直しても、モデルのcpとロジットの換算は変わらない。

### 損失

学習は、訓練局面を16,384局面ずつの組（ミニバッチ）に分け、組ごとに損失を計算して重みを1回更新する。
訓練局面を一通り使い終えるまでを1エポックと呼ぶ。
ミニバッチ $`\mathcal{B}`$ の損失は、教師値に対する二値交差エントロピー（BCE、binary cross-entropy）に、FMの補正の大きさを抑える正則化項と、駒除去差分の補助損失を加えたものである。

```math
J_{\mathcal{B}}(\theta) = \frac{1}{|\mathcal{B}|} \sum_{p \in \mathcal{B}} \ell\bigl(z_\theta(p),\ \tau(p)\bigr)
          + \mu\, \frac{1}{|\mathcal{B}|} \sum_{p \in \mathcal{B}} \Phi_\theta(p)^{2}
          + \eta\, R_{\mathcal{B}}(\theta),
\qquad
\mu = 10^{-4},\quad \eta = 1000.
```

第1項の $`\ell`$ はロジット $`z`$ と教師値 $`\tau`$ の二値交差エントロピーである。

```math
\ell(z, \tau) = -\,\tau \log \sigma(z) - (1 - \tau) \log\bigl(1 - \sigma(z)\bigr) = \log\bigl(1 + \exp(z)\bigr) - \tau\, z.
```

教師値 $`\tau`$ を固定して $`z`$ を動かすと、$`\ell`$ は予測した勝率 $`\sigma(z)`$ が $`\tau`$ に一致するときに最小になるので、この項は予測を教師値へ近づける。
第2項は、各局面のFMの補正（ロジット単位）を2乗して平均したものであり、PSTで説明できる部分までFMが受け持つことを抑える。
第3項は次の節で定める。
係数 $`\mu`$ は、FMを単独で学習したときに $`10^{-2}`$、$`10^{-3}`$、$`10^{-4}`$ を検証損失で比べて選んだ値であり、$`\eta`$ は棋力を段階的に高める計画の第7段階（[棋力向上段階7](../plans/strength-stage7.md)）で、PSTの学習のために訓練集合内の予備比較で選んだ値である。
同時学習ではこれらを選び直さず、それまでの学習の値を引き継いだ（[PSTとFMの同時学習](../plans/pst-fm-joint-training.md)の設計判断）。

学習中は各局面を左右どちらも同じ確率0.5で鏡映してから特徴を作る。
PSTは鏡映で重なる特徴の重みを共有するので鏡映の影響を受けないが、FMは鏡映で対応する特徴のベクトルを共有しないので、この鏡映によるデータ拡張で左右の対称性を学ばせる。
ただしこれは確率的な拡張であり、FMを含む評価全体の厳密な左右対称性を保証する制約ではない。

### 駒除去差分の補助損失

第3項の $`R`$ は、王駒以外の駒を盤上から1枚取り除いたときの評価の変化の向きを制約する。
盤上の自分の駒は持ち主にとって不利にならないので、自分の駒を除けば評価は下がり、相手の駒を除けば上がることが望ましい。
学習データだけに合わせた重みはこの性質を破ることがあり、探索が駒の損得を誤って判断するおそれがあるので、この向きに反する重みに罰則を課す。
王駒を除くと対局そのものが終わるので、王駒の除去は対象にしない。

局面 $`p`$ から駒 $`m`$ を除いた局面を $`p \setminus m`$ と書く。
これは合法手を指した局面ではなく、評価の性質を調べるための仮想的な入力である。
除去後の補間係数は、総駒数が $`N(p) - 1`$ に減るので、$`q(p \setminus m) = \min(90, \max(0, N(p) - 3))`$ で計算し直し、手番と先獅子の状態は保つ。
学習中のモデルの除去差分 $`\Delta_\theta`$ は、PSTとFMを合わせたcp単位の評価の変化である。
潜在次元ごとの和を $`V_h(p) = \sum_{j \in \mathcal{A}(p)} v_{jh}`$ と置けば、駒 $`m`$ に当たる特徴 $`i`$ の除去による差分は、除去した局面ごとに評価をやり直さず、次の式でまとめて計算できる。

```math
\Delta_\theta(p, m) = K\, z_\theta(p \setminus m) - K\, z_\theta(p)
 = P_\theta(p \setminus m) - P_\theta(p) - K \sum_{h=1}^{32} a_h\, v_{ih} \bigl( V_h(p) - v_{ih} \bigr).
```

FMの項は、除いた特徴と残りの特徴との組の寄与を取り除いたものである。

向きの基準には、駒の価値だけの表を使う。
この表は、学習を始める前の手書きの評価関数v0の駒価値（H. G. Muller作の中将棋エンジンHaChuの駒価値を、歩兵100へ換算した値）を、全升と両端点に同じ値で置いたものである（学習器では `minase::eval::handcrafted::piece_value` から作る）。
この基準の補間値を $`P_0`$ とし、整数化して切り詰めた評価を $`E_0 = \mathrm{clip}(\mathrm{trunc}(P_0))`$ とする。
基準の除去差分の向き $`\varepsilon_0`$ は整数評価の差の符号 $`\mathrm{sgn}`$（正なら+1、負なら−1、0なら0）から、大きさ $`|\Delta_0|`$ は整数化しない差から取る。

```math
\varepsilon_0(p, m) = \mathrm{sgn}\bigl( E_0(p \setminus m) - E_0(p) \bigr),
\qquad
\Delta_0(p, m) = P_0(p \setminus m) - P_0(p).
```

除去の前後で基準の整数評価が変わらない場合、たとえば両方が上限に切り詰められた場合は $`\varepsilon_0 = 0`$ となり、向きが決まらないので対象から外す。
局面 $`p`$ で対象となる除去の集合を $`\mathcal{M}(p)`$ とする。
基準自身の向きが駒の持ち主から期待される向きと逆であるかを表す $`\omega`$ を、次のように定める。

```math
\omega(p, m) =
\begin{cases}
1, & m \text{ が手番側の駒で } \varepsilon_0 > 0, \text{ または相手の駒で } \varepsilon_0 < 0,\\
0, & \text{それ以外}.
\end{cases}
```

1回の除去の罰則を次の式で定める。

```math
\pi(p, m) = \max\Bigl(0,\ \min\bigl(|\Delta_0|,\ 0.25\bigr) - \varepsilon_0\, \Delta_\theta\Bigr)
          + \omega\, \max\Bigl(0,\ \varepsilon_0\, \Delta_\theta - |\Delta_0|\Bigr).
```

第1項は、候補の差分が基準と同じ向きに、少なくとも $`\min(|\Delta_0|, 0.25)`$ cp だけ動くことを求め、足りない分を罰する。
0.25 cpは、向きを保たせるための小さな余裕であり、差分の大きさまでは求めない。
この項は基準の向きを保たせるものなので、基準自身の向きが逆である除去では、候補にもその逆向きを保たせる。
第2項は、そのような除去に限り、候補の逆向きが基準より大きくなることを罰する。
同時学習の基準であるv0の表では、各駒の寄与は正の駒価値であり、最小の歩兵でも100 cp（仲人は125 cp）なので、評価が上限に切り詰められない限り $`|\Delta_0| \ge 100`$ で、向きも逆にならない。
したがって最小の幅はつねに0.25 cp、$`\omega`$ はつねに0であり、$`R`$ は「自駒を除けば少なくとも0.25 cp下がり、相手の駒を除けば少なくとも0.25 cp上がる」ことを求める制約として働く。
第2項は、後述のPSTだけの学習器が、駒の向きが逆の箇所を含み得る直前の採用PSTを基準にする場合のためにある。

罰則は、局面ごとに対象の除去で平均し、さらに局面で平均して、出力尺度 $`K`$ で割ってロジットの単位にそろえる。

```math
R_{\mathcal{B}}(\theta) = \frac{1}{K} \cdot \frac{1}{|\mathcal{B}|} \sum_{p \in \mathcal{B}} \frac{1}{\max\bigl(1,\ |\mathcal{M}(p)|\bigr)} \sum_{m \in \mathcal{M}(p)} \pi(p, m).
```

対象がない局面も寄与0として平均の分母に含める。
この損失は基準の駒価値そのものを再現させる2乗誤差ではなく、向きと最小の幅だけに課す片側の罰則であり、駒の価値の大きさは教師値から学ぶ。
係数1000は有限なので、学習後や倍率の焼き込み後の整数評価で、全ての除去が望ましい向きになるとは限らない。
補助損失を選んだ理由は[駒除去差分の符号を守らせる片側絶対値の補助損失を学習に加える](../adr/penalize-wrong-signed-piece-removal-differences.md)にあり、実装の契約は`minase-trainer`の`pst::removal`と`nnue::reference::removal_forward`のdocコメントにある。
同時学習でFMの寄与を補助損失に含めた経緯は、[PSTとFMの同時学習](../plans/pst-fm-joint-training.md)の設計判断にある。

### 最適化と制約

重みの更新には、勾配の過去の平均と大きさから各重みの更新幅を自動で調整するAdamという手法に、重みを毎回少しずつ0へ縮める重み減衰を組み合わせたAdamWを使う。
1回の更新でどれだけ動かすかの目安を学習率と呼ぶ。
1つのAdamWの中で、PSTとFMに別々の学習率を与える。
PSTは学習率0.03、重み減衰なしであり、前述のとおり各更新の後で重みを $`[-4096, 4095.875]`$ cpへ切り詰める。
FMはベクトルと出力係数に学習率 $`10^{-3}`$、重み減衰 $`10^{-4}`$ を与える。
この重み減衰は、損失の第2項の補正の2乗平均とは別の正則化である。
これらの値は、それぞれPSTとFMを別々に学習したときの値を引き継いだ（[PSTとFMの同時学習](../plans/pst-fm-joint-training.md)の設計判断）。
訓練集合とその鏡映に一度も現れない特徴のFMのベクトルは、学習で値が決まらないので0に固定し、各更新の後に0へ戻す。
採用時の重みの学習では、この固定の対象は13,680特徴のうち4,158特徴だった。

初期値は、それまで別々に学んだ2つの重みである。
PSTには、FMなしで最大200エポックまで学習した候補Lの重みを使い、FMには、候補LのPSTを固定してFMだけを学習した候補Faの重みを使った。
当時のmasterはFaの補正を1/4に縮めて使っていたが、同時学習の初期値には縮める前のFaを使った。
候補Lに至るPSTの学習は、最初の世代でv0の駒価値を全升に置いた表から始まり、以後は直前に採用した重みを初期値として続けてきたので、cpの目盛りもv0から引き継いでいる。
初期値と補助損失の基準は別の役割であり、前者は学習の出発点、後者は除去差分の向きの目標である。

### 検証集合と早期終了

学習データは対局単位で訓練集合と検証集合に分ける。
自己対局の生成シードと対局番号から計算したハッシュ値を20で割った余りが0の対局、すなわち約5%の対局を検証に充て、残りを訓練に使う。
同じ対局の局面を両方に入れると、隣接する局面が似ているために検証損失が実際より良く見えるからである。
採用時の重みの学習では、世代2と世代3の各5ファイルを使い、訓練は27,745,843局面、検証は1,462,975局面であり、1エポックは1,694回の更新だった。

各エポックの後に、検証集合での二値交差エントロピー（検証損失）を測る。
重みを選ぶ基準は勝率の予測の良さなので、検証損失には損失の第2項と第3項を含めず、鏡映によるデータ拡張もしない。
最良値を厳密に下回ったエポックの重みを保持し、5エポック続けて最良値が更新されなければ学習を止める（上限は200エポック）。
この止め方は一般に早期終了（early stopping）と呼ばれ、学習データに合わせすぎて未知の局面での予測が悪くなる過学習を防ぐ。
採用するのは学習したエポックの中で最良の重みであり、学習前の重み（エポック0）は比較のために記録するだけで候補に含めない。
採用時の重みはエポック2の重みであり、学習はエポック7、総計11,858回の更新で止まった。
浮動小数点の評価で測った検証損失はエポック0の0.430003から0.429552へ下がり、選んだ重みの浮動小数点の評価と整数の評価の差は平均0.77 cpだった。

## 損失で決めないもの

FMの補正の倍率 $`b`$ と探索用駒価値は、学習の損失では決めていない。

強さの差はEloで表す。
Eloは、対局の得点率 $`s`$ から $`400 \log_{10}(s / (1 - s))`$ で換算した強さの差であり、0が互角、正が優勢を表す。
対局の条件には2種類あり、短時間条件（STC）は持ち時間10秒と1手ごとの加算0.1秒、長時間条件（LTC）は持ち時間60秒と1手ごとの加算0.2秒である。
新しい評価関数は、STCで選別してからLTCで最終判定する段階ゲートで採否を決める（[棋力測定の手引き](sprt.md)）。

倍率 $`b`$ は、PSTとFMの重みを固定したまま、自己対局の勝敗から係数を調整するSPSA（simultaneous perturbation stochastic approximation、同時摂動確率近似）で決めた。
SPSAは、係数を正負に少し揺らした2つの設定を対局させ、勝った側へ係数を動かすことを繰り返す手法である。
STCで375回の更新（各8ペア、計3,000ペアの対局）を行い、$`\mathrm{FmScale}`$ を0から1024の範囲で調整して611を得た。

学習の損失と対局の強さは、異なる倍率を支持した。
同じ教師で、整数の評価から検証集合の二値交差エントロピーを測ると、倍率1（焼き込む前のJ75）が0.429550、611/1024を焼き込んだ候補が0.429709であり、損失の上では補正を縮めない方が良い（[焼き込んだ候補の記録](../measurements/fm-scale-spsa-candidate.md)）。
一方、倍率1のJ75は、当時のmaster（候補LのPSTに、候補Faの補正を1/4に縮めて足した評価）にSTCで約8 Elo負けた（95%信頼区間 −21〜+5）。
611/1024を焼き込んだ候補は、当時のmasterにLTCで得点率66.6%、約120 Elo勝ち、採用された（[FMの補正の倍率のSPSAによる調整](../plans/fm-scale-spsa.md)）。
この1件では、損失を基準にすると対局で強い倍率が選ばれなかったことになる。
なおJ75の−8 Eloは信頼区間が0を含み、masterより弱いとまでは言えない。
同時学習の出発点（候補LのPSTに、縮めないFaの補正を足した評価）も当時のmasterにSTCで約67 Elo負けていたので、設計書は、補正が大きすぎたことを不採用の有力な原因と考えた。
ただし損失と強さが食い違う仕組みは切り分けていない。
得た611も有限の対局から得た採用値であり、最適な倍率であるとは確かめていない。
このため倍率は対局で決め、PSTまたはFMを学び直したときは決め直す。

探索用駒価値は、前述のとおり2端点PSTの開始時点の重みから導いた値に固定している。
評価関数の採否は、いずれの場合も検証損失ではなく段階ゲートの対局で決める。

## PSTとFMだけの学習器との関係

PSTだけとFMだけを学ぶ2つの学習器は、採用時の重みの学習と同じ教師値と二値交差エントロピーを使い、学習するパラメータと追加の項だけが異なる。

PSTの学習器 `minase-trainer pst train`（`crates/minase-trainer/src/pst/`）は、FMを持たないモデル $`z = P_\theta / K`$ を学び、損失は二値交差エントロピーに係数 $`\eta`$ の駒除去差分の補助損失を加えたものである。
この学習器の補助損失の基準は、`--removal-reference init` では学習の初期値の重みファイル（通常は直前に採用したPST）、`--removal-reference v0` ではv0の表である。
学習中のモデルの除去差分もPSTの部分だけで計算する。
手順は[PSTの学習手順](pst-training.md)にある。

FMの学習器 `minase-trainer fm train`（`crates/minase-trainer/src/fm/`）は、PSTを学習せずに固定し、その整数評価 $`E_{\mathrm{PST}}`$ を定数として $`z = E_{\mathrm{PST}} / K + \Phi_\theta`$ のFMの部分だけを学ぶ。
同時学習のモデルがPSTに勾配を流すために浮動小数点の $`P_\theta`$ を使うのに対し、PSTを動かさないこの学習器は推論と同じ整数評価を使う。
損失は二値交差エントロピーに正則化項 $`\mu \overline{\Phi_\theta^2}`$ を加えたものであり、駒除去差分の補助損失は持たない。
補正の倍率を出力係数へ焼き込んで量子化し直すには、サブコマンド `minase-trainer fm scale` を使う。

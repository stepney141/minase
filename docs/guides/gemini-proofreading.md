# Geminiによる文書推敲の手引き

本書は、AGENTS.mdの「文書作成時のポリシー」に従って、書き終えた文書をGeminiに推敲させる手順を記す。
推敲には、コマンドラインツールagyから呼び出すGemini 4 Argonを使う。
推敲の観点と指摘の採否の基準はAGENTS.mdで定めているので、本書は呼び出し方と注意点だけを扱う。

## 呼び出し方

agyは次の形で呼び出す。

```console
agy -p "<プロンプト>" --model gemini-4-argon-high --mode plan
```

プロンプトは`-p`の直後に置く。
agyは`-p`の次の引数をプロンプトとして扱うので、ほかのオプションを間に挟むと、そのオプションがプロンプトになる。
推敲ではファイルを書き換えず指摘だけを受け取るので、実行モードには`plan`を指定する。
`--dangerously-skip-permissions`は、agyが文書を書き換えるおそれがあるので付けない。
モデル名は`agy models`の一覧で確かめられる。

## プロンプトに含める内容

`-p`による非対話の実行では、agyがファイルを読もうとしても許可を与える手段がなく、読み取りは拒否される。
そのため、推敲させる文書の全文に`cat -n`で行番号を付けてプロンプトへ埋め込み、ツールを使わずに答えるよう指示する。
行番号があると、Geminiの指摘を該当する行と突き合わせやすい。

1つの引数に渡せる長さの上限は128 KBである。
上限に収めるために、変更前との差分は付けずに全文だけを渡し、それでも収まらなければ文書ごとに呼び出しを分ける。

## 指摘を選ぶときの注意

Geminiの指摘には、文書の意味を変える提案が混ざる。
過去の推敲では、「王駒」を「玉将」に置き換える案、典拠を削る案、および規則の意味を変える言い換えの案があり、いずれも採らなかった。
指摘は1件ずつAGENTS.mdの基準に照らし、意味、数値、典拠、および用語の定義を変えないものだけを文書へ反映する。

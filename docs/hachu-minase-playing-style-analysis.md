# HaChuとMinaseの勝ち方・負け方

## 結論

Minaseの典型的な勝ち方は、中盤から捕獲価値差を広げ、十分な駒得を作ってから長距離駒で王を包囲する形である。
一方、HaChuの典型的な勝ち方は、Minaseより遅い段階で優勢を確立し、獅子を中心とする王攻めで接戦または駒損の局面を覆す形である。
したがって、両者の差は単純な「駒得型対攻撃型」ではないが、Minase勝ちは物質的優位の早期確立、HaChu勝ちは終盤の急な評価反転にそれぞれ強く偏っている。

公式結果はMinase 281勝、HaChu 119勝、引き分け0局で、Minaseの勝率は70.25%、Elo差は+149.3、95%信頼区間は+115.5～+186.0だった。
ただし、Minaseの1勝はHaChuの不正着手による反則勝ちなので、勝ち方の分析から除外し、合法に終局したMinase勝ち280局とHaChu勝ち119局を対象とした。

「Minaseの読みがHaChuより正確」とは、この棋譜だけからは判定できない。
HaChuの内部評価値が保存されておらず、共通の十分深い参照探索も行っていないためである。
観測できる範囲では、Minaseは勝つ局を早く安定して評価する一方、負ける局では自身を有利とする評価を終盤まで維持し、その後に急落することが多かった。

## 対象と方法

分析には、同じ200個の開始手順から先後を入れ替えた400局の保存棋譜を用いた。
条件は持ち時間60秒、1手ごとに1秒加算、ハッシュ256 MB、規則集合`L1,L3,P0,P5,P6,R2,E1,E2`であり、Minaseは1スレッド、HaChuはワーカー数を報告しない。
実行条件とバイナリ識別子は[manifest](../data/matches/strength-stage2-hachu-elo200/manifest.json)に、公式結果は[棋力測定記録](measurements/strength-stage2-hachu-elo200.md)に保存されている。

測定対象のMinaseはコミット`ce654d93ab9130df2168fbd883b0910d61133e62`である。
このコミットから分析時のHEAD `2d1831eb0c912abf0d2c059783b812e0cc98b4aa`まで、局面処理、評価、探索、プロトコル、埋め込み重み、およびMinase本体に差分がないことを確認した。
このため、完走済みの400局を現在のMinaseとの比較標本として再利用した。

```console
git diff --quiet ce654d9..HEAD -- \
  Cargo.toml Cargo.lock nets src/core src/eval src/search src/protocol src/bin/minase.rs
```

保存された開始手順と全着手を、指定規則の`Game`とUniversal Shogi Interface（USI）表記解析器で初期局面から再生した。
合法終局399局の全着手が再生時の合法手検査を通り、各局面から捕獲、成り、盤上駒価値、駒数、およびMinase評価値を集計した。
保存形式と再読込時の検査は[対局ハーネス](../src/bin/match_runner.rs#L2201)に実装されている。

駒価値にはMinaseの[固定駒価値表](../src/eval/handcrafted.rs#L19)を使い、歩兵を100センチポーン、横行と竪行を各500センチポーン、獅子を2500センチポーンとした。
この尺度は比較用であり、HaChu自身の評価値でも、現在のMinaseが使う学習済み評価値でもない。

ランダム開始手順の終了時点で既に駒価値差がある対局が400局中52局あった。
そこで、主指標の捕獲価値差は開始手順後に勝者が取った駒の累計価値から敗者が取った駒の累計価値を引き、開始手順終了時を0とした。
盤上価値変化差も、各時点の勝者視点の盤上価値差から開始手順終了時の値を引いた。
王将、玉将、太子の最終捕獲は終局条件そのものなので、HaChu勝ちの最後の王駒捕獲を捕獲価値差から除いた。

## 駒得の進み方

次表は、各対局の進行率における勝者側の捕獲価値差の中央値である。
開始手順後の実着手列を0～100%とし、終局直前ではHaChuによる最後の王駒捕獲を除いた。

| 進行率 | Minase勝ち280局 | HaChu勝ち119局 |
|---|---:|---:|
| 25% | +403.5 | -25 |
| 50% | +883.5 | +442 |
| 75% | +1810 | +895 |
| 90% | +2671 | +1118 |
| 終局直前 | +4804 | +1380 |

Minase勝ちでは、中間点から終局直前まで捕獲価値差の中央値が+883.5から+4804センチポーンへ拡大した。
終局直前の捕獲価値差は274局で正となり、成りも含む盤上価値変化差は279局で正となった。
盤上価値変化差の終局直前中央値は+5642センチポーン、盤上枚数差の中央値は+9枚だったため、Minaseの通常勝ちは大きな駒得を伴う形が明瞭である。

HaChu勝ちでも駒得が主流だが、その幅は小さかった。
終局直前の捕獲価値差は85局で正、34局で負となり、盤上価値変化差は109局で正、10局で負となった。
盤上価値変化差の中央値は+2999センチポーン、盤上枚数差の中央値は+5枚であり、HaChuは駒損のまま王を取った局も10局あった。

事後的な「安定した物質的優位」は、盤上価値変化差が+500センチポーン以上となり、その後は0未満へ戻らない最初の時点と定義した。
この時点はMinase勝ち278局で観測され、中央値は対局の43.4%地点だった。
HaChu勝ちでは108局で観測され、中央値は61.5%地点だったため、Minaseのほうが勝つ局で物質的優位を早く固定している。

この差は対局長にも現れた。
開始手順後の実着手数は、Minase勝ちが平均405.5手、中央値374.5手、HaChu勝ちが平均484.6手、中央値419手だった。
終局直前の盤上総駒数も、Minase勝ちが平均27.1枚、HaChu勝ちが平均22.5枚であり、HaChu勝ちは低駒数まで進む長期戦になりやすい。
ただし、Minase勝ち280局はすべてHaChuの投了、HaChu勝ち119局はすべて王駒捕獲で終わったため、対局長の差には両実装の終局方針が混ざる。

## 王攻めの違い

Minaseが勝った280局では、最後の連続した詰ませる評価へ入った着手の駒種が複数に分散した。
内訳の上位は角鷹45局、飛鷲42局、獅子42局、飛牛34局、奔王26局、龍王24局であり、長距離の成駒を組み合わせて守備駒を剥がす形が多かった。
この結果は、Minaseの勝ちが単一の攻撃駒に依存せず、先行する駒得を複数の大駒で勝ちへ変換する傾向を示す。

HaChuが勝った119局では、Minaseが連続した詰まされる評価へ入る直前のHaChu着手は獅子が49局で最多だった。
最後の王または太子を捕獲した駒も獅子が83局、69.7%を占めた。
Minase勝ちではHaChuが捕獲前に投了するため同じ数え方ができないが、少なくともHaChu勝ちでは獅子による接近と王追いが中心的だった。

実装上も、この観測と整合する差がある。
現在のMinaseの静的評価は、駒種、成り状態、所有者、および升を組み合わせた特徴と、先獅子状態の特徴との線形和である。[Minaseの特徴定義](../src/eval/features.rs#L43) [評価値の計算](../src/eval/pst.rs#L239)
一方、HaChuは機動力に加え、王の安全、王周辺の守備駒、獅子に耐える囲い、終盤の王位置、麒麟の成りやすさ、および歩兵配置を明示的に評価する。[有効な評価項目](../../hachu-debian/hachu.c#L18) [HaChuの評価関数](../../hachu-debian/hachu.c#L1897)
HaChuが駒損でも王を取り切る実戦傾向は、この王安全評価と整合する。
ただし、探索と評価の両方が異なり、評価項目を個別に無効化した比較実験ではないため、王安全評価だけを原因とは断定できない。

## 読みの安定性

保存棋譜にはHaChuの評価値がないため、両者の読みの正確さを同じ尺度で比較できない。
ここでは、Minaseが各局面で報告した評価値の符号が最終勝敗と一致した割合を代理指標とした。

対局の10%地点における符号正解率は72.4%であり、Minaseの全体勝率70.2%とほぼ同じだった。
符号正解率は中間点で80.7%、75%地点で88.2%、90%地点で92.5%へ上がったため、Minaseの勝敗認識は後半ほど結果と整合した。
一方、HaChuが勝った119局のうち74局では、中間点でもMinaseが自分を有利と評価していた。
90%地点でも29局はMinase評価が0以上であり、24局は+300以上、19局は+1000以上だった。

この遅い認識は、終盤の急な評価変化として現れた。
HaChu勝ちの94局、79.0%では、最後の10%区間における連続するMinase手番間の評価が一度に500センチポーン以上悪化し、59局、49.6%では1000センチポーン以上悪化した。
同じ現象はMinase勝ちではそれぞれ2局と1局だけだった。
連続するMinase手番の間にはMinaseの着手とHaChuの応手が1手ずつ含まれるため、この値だけから特定の1手をMinaseの悪手とは判定できない。
それでも、HaChu勝ちが緩やかな優勢拡大より、終盤の鋭い転機を伴うという記述には十分な差がある。

近い詰みを認識した後のMinase評価は結果と整合した。
Minase勝ち280局では最後のMinase評価がすべて詰ませる評価となり、HaChu勝ち119局ではすべて詰まされる評価となった。
これは終局直前の強制手順を正しく識別した証拠だが、中盤の読みやHaChuとの相対的な探索精度を証明するものではない。

## 代表局と反例

ペア93第1局は、Minaseの駒得蓄積型を示す。
開始手順後の第50、100、150、200、250、300手におけるMinase側の盤上駒価値差は、+125、+717、+855、+1080、+1805、+3345センチポーンと増え、終局直前には+5511センチポーンとなった。
Minaseは36枚、HaChuは27枚を捕獲し、第374手後にHaChuが投了したため、単発の必殺手より交換差の累積が支配的だった。

ペア59第2局は、HaChuの駒損からの王攻めを最も明瞭に示す。
第250手でHaChuは4905センチポーンの駒損であり、第281手でもMinaseは自分を+1594センチポーンと評価していた。
しかし、第282手にHaChuの王がMinaseの飛鷲を取り、次のMinase評価は7手で詰まされる値へ変わった。
第290手にHaChuの獅子がMinaseの王を捕獲し、王の価値を加えた後でさえHaChu側は348センチポーンの駒損だった。

この傾向には反例もある。
ペア176第2局では、Minaseが終局直前に70センチポーンの駒損だったが、龍王と角鷹の包囲でHaChuを投了させた。
反対に、ペア163第1局ではHaChuが序盤にMinaseの獅子を取り、Minase評価を全局にわたって負に保ったまま王を捕獲した。
したがって、ここで示した特徴は勝敗を決める規則ではなく、399局で頻度の高かった勝ち方と負け方である。

## 限界

本結果は、HaChu 0.21のDebian版、指定規則、指定時間制御、および保存された200個の開始手順に限られる。
同一開始手順の色替え200ペアでは、Minaseが2勝したペアが94、HaChuが2勝したペアが13、1勝1敗が93だったため、開始局面と先後の影響も小さくない。

また、勝者別の数値は「そのエンジンが勝ったときの形」を表す記述統計であり、因果を証明しない。
例えば、開始手順後の第200手時点で500センチポーン以上不利だった局からの勝率はMinaseが23/76局、30.3%、HaChuが34/222局、15.3%であり、不利から実際に勝ち直す能力は全体としてMinaseのほうが高かった。
これは、HaChuの少ない勝ちに逆転型が多いことと矛盾せず、Minaseの基礎棋力が高い影響を含む。

両者の読みを直接比較するには、HaChuの評価値を保存するか、一定間隔で抽出した局面を共通の十分深い参照探索で再評価し、各着手の評価損失を同一尺度で測る必要がある。
今回の一次資料から支持される結論は、Minase勝ちが早期の安定した駒得と複数の長距離駒による包囲を伴い、HaChu勝ちが長期戦、獅子中心の王攻め、および終盤の急な評価反転を多く含むという範囲である。

## 再集計

終局内訳は保存されたペア記録から再集計できる。

```console
jq -s '[.[].games[].termination] | group_by(.kind) |
  map({kind: .[0].kind, count: length})' \
  data/matches/strength-stage2-hachu-elo200/pairs/*.json
```

駒価値と評価値の集計では、[ペア記録](../data/matches/strength-stage2-hachu-elo200/pairs/)の`opening.moves`と`games[].turns[].response.usi`を順に`minase::notation::usi::parse`へ渡し、`Game::play`で局面を更新した。
各局面の全144升を走査して固定駒価値を合計し、開始手順終了時を基準として勝者視点へ符号を統一した。
Minase評価値は`games[].turns[].evaluation`だけを使い、欠測しているHaChu評価値を補完していない。

# GeForceのGPUで学習する大きな中間配列を倍精度にしない

## 症状

PSTとFMの同時学習器は、FMの駒除去差分を (バッチ, 145, 潜在次元) の倍精度の配列で計算していた。
GeForce RTX 3060 Tiで1本あたり最大3.6 GBのGPUメモリを使い、2本目の学習がメモリ不足で止まった。
1本だけでも1エポックに約6分かかり、PSTだけの学習（約2分）の約3倍だった。

## 原因

GeForceのGPUは倍精度の演算性能が単精度よりはるかに低く、配列の大きさも単精度の2倍になる。
バッチ16,384で差分の計算だけを測ると、倍精度は1更新あたり約105ミリ秒と2.9 GB、単精度は約49ミリ秒と1.5 GBだった。
差分の大きさは最大でも数千センチポーンであり、補助損失の下限幅0.25センチポーンに対して倍精度を要しなかった。

## 以後の規則

GPUで学習する損失の中間配列は、埋め込みと同じ単精度で計算し、倍精度は (バッチ, 升) 程度の小さな集約後の値に限る。
倍精度が必要かどうかは、扱う値の大きさと許容誤差から先に見積もり、学習を始める前に1更新の時間と最大GPUメモリを試走で測る。

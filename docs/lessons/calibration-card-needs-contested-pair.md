# 効果量が極端な対は測定条件の比較情報を持たない

## 症状

時間制御の校正で負例カードとしたP型NNUE対学習PSTが400局全敗し、正規化ペア得点の分散が0になった。
分散と平均CPU時間から作る校正主指標が算出不能となり、校正全体が不成立となった。

## 原因

測定条件の効率比較は、条件間で推定の狭さ（得点分散と計算量の積）を比べる構図であり、勝敗が割れないカードでは分散が0になって比較の情報が消える。
カードの選定を符号が既知であることだけで行い、効果量が測定の解像度内に収まることを要件にしていなかった。

## 以後の規則

測定条件やハーネスの比較に既知の対戦カードを使うときは、符号だけでなく効果量が拮抗する対（勝ちと負けが混ざる規模、目安として数十elo以内）を選び、全勝または全敗が予想される対を使わない。

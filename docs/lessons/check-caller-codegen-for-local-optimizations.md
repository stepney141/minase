# 局所最適化では呼び出し元の機械語も比較する

## 症状

利き計算を小さな表への参照に置き換えると、変更していない方向も含めて探索速度が低下した。

## 原因

関数が大きくなってインライン展開が失われ、呼び出しとレジスタ退避の費用が増えた。
強制インライン化で呼び出しを除いても、呼び出し元の命令数やスタック使用量まで元に戻るとは限らなかった。
変更前のプロファイルで対象関数へ帰属した割合だけでは、この影響を見積もれない。

## 以後の規則

局所最適化が探索全体を遅くした場合は、呼び出し元の機械語とスタック使用量を比較し、インライン属性を変える実験では現行方式にも同じ属性を付けた対照を測る。
単体計測は原因の切り分けに使い、採用候補へ進める判断には計測用コードを外した探索全体の速度を使う。

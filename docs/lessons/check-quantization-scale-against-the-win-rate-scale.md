# 先行エンジンの量子化の尺度は勝率尺度に照らして確かめる

## 症状

NNUEの隠れ層の重みをtataraやStockfishと同様にi8の尺度64で持つと、学習したネットの量子化誤差の平均が29.80 cpとなり、検査の上限26.82 cpを超えた。
第1層の尺度を127から255へ上げて誤差を減らす計画だったが、直接内積だけのネットの21.12 cpより悪くなった。
本学習を終えるまで、この誤差の大きさは分からなかった。

## 原因

整数化の段を1つずつ適用して測ると、誤差の大半は隠れ層の重みの丸めから来ていた（幅32の層だけで20.55 cp、幅15の層だけで15.11 cp）。
重みの1刻みは活性化の1.0に対する比率なので、cpでの大きさは勝率尺度に比例する。
minaseの勝率尺度は約1,072 cpであり、tataraの290 cpの3.7倍ほどなので、同じ1/64の刻みでも同じ比率で粗くなる。
当初の計画ではこの理由でskip接続の重みだけをi16にしており、隠れ層の重みには同じ計算をしていなかった。
切り捨てを最近接の丸めに変えても誤差は28.06 cpまでしか改善せず、尺度を256へ上げると再学習なしで9.45 cpまで下がった。

## 以後の規則

重みの型と尺度を先行エンジンから流用するときは、活性化の1.0が何cpにあたるかを両者で比べ、すべての層について1刻みのcpを計算してから決める。
少ないエポックで学んだネットで、実数の評価を基準に整数化の段を1つずつ適用した誤差を測り、本学習の前に誤差の大きい段の型と尺度を見直す。
量子化の検査に通らなかったら、閾値の変更や再学習の前に、同じ集計で原因の段を特定する。
書き出しは再学習なしでやり直せるので、形式の変更だけで解決できるかを先に確かめる。

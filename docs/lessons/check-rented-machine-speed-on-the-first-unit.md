# 借りた機械の速さは、最初の1単位の所要時間で確かめる

## 症状

NNUEの世代反復の第3世代で、教師ファイルを生成するために、出品の表示がEPYC 9654、384スレッドの機械を、計算機を時間単位で借りられる市場vast.aiで借りた。
同じ機種の別の機械は、それまで教師ファイル1本を700〜800秒で生成していたが、この機械は最初の1本に1,664秒かかった。
この速さのまま129本を生成すると、費用は上限の60米ドルに収まらず、時間単価が高くて1本に約1,200秒かかる別の機種のほうが、1本あたりの費用が安かった。

## 原因

出品が表示する機種とスレッド数は、その機械の速さを保証しない。
この機械のメモリは128 GBで、同じ機種のほかの機械より少なかったが、遅さの原因は確かめていない。
借りる前の見積りは、同じ機種の過去の実績を、借りる機械にもそのまま当てはめていた。

## 以後の規則

借りた機械で同じ単位の仕事を繰り返すときは、最初の1単位の所要時間を、同じ機種の実績と比べる。
見積りの費用や期限に収まらない遅さなら、その1単位を受け入れた後に機械を止め、その機械を除外して借り直す。
借りる前の速さの見積りは、[機械を借りる前に現行のコードの全負荷の速さを測り直す](remeasure-generation-speed-with-current-code-before-renting.md)に従う。

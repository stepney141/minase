# 学習前に1エポックのステップ数を確認する

## 症状

世代0のNNUEの最初の学習は、バッチ16,384、20エポックの設定で走らせたが、1エポックが58ステップしかなく、20エポック終了時点でも検証損失0.4251が低下し続けたまま止まった。
エポック数だけを見て収束を判断すると、重み更新回数が桁で足りないことに気づけない。

## 原因

局面数が100万程度のデータでは、大きなバッチにするとエポックあたりの重み更新回数が数十回に落ちる。
収束はエポック数ではなく重み更新の総回数で決まる。

## 以後の規則

学習を始める前に「局面数÷バッチサイズ」で1エポックのステップ数を計算し、総ステップ数が数千回以上になるようバッチサイズとエポック数を決めてから学習曲線を評価する。

# 教師探索の順位は予算を変えて検証する

## 症状

FMの選択手をPST教師で比較したところ、教師の予算を1,000,000から10,000,000ノードへ増やしても、16局面中5局面で最上位手の集合が変わった。
大きな静的FM補正は観測できたが、その量を選択手の悪さへ直接読み替えることはできなかった。

## 原因

教師の探索値も予算と探索の近似に依存し、候補手の順位が確定した真値ではない。
静的評価の差は局面に付けた値の差であり、同じ親局面の選択手間の価値差とは測定対象が異なる。

## 以後の規則

提案手を固定し、教師予算ごとの最善手も加えた同じ候補集合を、各予算で独立に読む。
子の評価を親視点へ揃え、詰み・終局・未完了値を通常の評価差から分ける。
厳密な正負反転、0との変化、同点を含む最上位手集合の変化を区別し、比較不能件数も示す。
教師が安定しない場合は標本数を増やすだけで確定的な結論を出さず、採否は別の自己対局測定で判定する。

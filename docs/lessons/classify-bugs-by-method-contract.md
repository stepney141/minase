# 探索の不具合は手法の契約違反に限って分類する

## 症状

探索部の監査で、静止探索が手番側の王駒がすべて狙われた局面でもstand-patを使い、深さ1で詰みを見落とすことを「不具合」に分類した。
修正（その局面で全合法手を読む方式）を「正しさの修正」として非劣性で判定したところ、親コミットに対する診断のSTCで約120 Elo弱かった。

## 原因

stand-patは「現局面の評価値を下回らない手がある」とみなす楽観的な近似であり、避けられない脅威はすべて無視する。
王駒が詰んでいる局面での誤りはその一例にすぎず、深さ1の見落としも固定深さの探索に伴う地平線効果である。
真の値と食い違う再現例があることだけを根拠に不具合と判定したので、近似の限界を不具合と取り違えた。
チェスの特例（王手中のstand-pat禁止）も、中将棋で同じ理由が成り立つかを確かめずに持ち込んだ。

## 以後の規則

探索の監査で不具合に分類するのは、実装がその手法自身の契約（delta pruningなら「最善でもαに届かない捕獲だけを省く」、反復検出なら「対局上の同一局面の再現を引き分けとする」）に反する場合に限り、近似が真の値を外す例は探索の改良の候補として通常の段階ゲートにかける。

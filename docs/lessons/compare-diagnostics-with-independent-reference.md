# 診断値は独立した参照値と照合する

## 症状

棋力向上段階7で既存の成り診断を点検したところ、Rustが返した成りの評価差は報告書へ保存されていたが、Pythonの参照評価とは照合されていなかった。
照合していたのは着手前の評価だけであり、その値が正しくても、成りによる評価差の誤りを検出できなかった。

## 原因

Rustから受け取る成りの情報は着手と評価差に限られ、参照実装で着手後を評価するための局面が含まれていなかった。
着手前の評価の一致検査と差分値の保存だけでは、設計書が要求する差分の照合を実施できなかった。

## 以後の規則

診断項目ごとに、照合する量、参照値の算出元、および不一致時の停止条件を明示する。
差分を照合するときは、前後の状態を共通の形式で渡して参照実装で再計算し、視点と単位を揃えて比較する。
照合対象だけを意図的に変えた入力で診断が失敗することを、回帰テストで固定する。

## 出典

起点は[棋力向上段階7](../plans/strength-stage7.md)の成り診断である。
修正後の[pst_diagnostics.py](../../tools/train/pst/pst_diagnostics.py)は着手後局面からPythonで評価差を再計算し、[回帰テスト](../../tools/train/pst/test_pst_diagnostics.py)は着手前の評価を保ったまま成りの評価差だけを変えた入力を拒否することを確認する。

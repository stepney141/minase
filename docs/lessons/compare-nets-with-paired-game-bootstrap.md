# ネットの汎化の差は対局単位の対応のある比較で測る

## 症状

先読み教師の有無で学んだNNUEの汎化差（検証の対局と訓練の対局での、対局結果を目標とした損失の差）を比べたところ、1つのネットの汎化差の95%区間は幅が約0.014あり、ネット間の差（約0.002）よりはるかに広く、ネットごとの区間を並べても差を区別できなかった。

## 原因

対局の結果は同じ対局のすべての局面で共通なので、損失のばらつきの大半は、どの対局を標本に含めたかという対局ごとの勝敗の偏りで決まる。
この偏りはどのネットにも同じように効くので、各回で抽出した同じ対局の標本をすべてのネットに当てて差を取ると、偏りは打ち消し合う。
対局を単位とする対応のあるブートストラップでは、同じ差の95%区間の幅は約0.0006だった。

## 以後の規則

学習したネットの汎化差や検証の損失を比べるときは、対局を単位とし、各回で抽出した同じ標本をすべてのネットに当てる対応のあるブートストラップで差の区間を求め、ネットごとに求めた区間の重なりでは判断しない。

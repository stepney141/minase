# 予算の機構を変えたら総思考時間と使い残しを現行と比べる

## 症状

時間管理の候補のうち、予算を公平な分担そのものにして探索中の中断で止める構成（[分解測定](../plans/time-management-decomposition.md)のD1とD2）は、各手の思考時間の中央値が基準と同等以上で、時計の診断（初手、hardの超過、時間切れ）をすべて満たしたが、STCで基準に有意に劣った。
保存記録を手数帯ごとに比べると、候補は1局の総思考時間を基準より約14%使い残し（終局時の残り時間の中央値6.4秒対2.6秒）、同じ思考時間で完了深さが約0.5浅かった。

## 原因

旧式は予算softを反復の開始の門として使い、始めた反復を完了させる超過（softの1〜2.8倍）で持ち時間を使い切っており、超過分が実質的な配分になっていた。
候補は超過を探索中の中断で断ち、途中結果を採用したが、深さ6〜9の探索では中断した反復の大半が直前の最善手を確認するだけで着手に反映されず、最後に完了した反復以後の時間が無駄になった。
1手ごとの指標（予算に対する比、超過、初手の時間）はこの2つの効果を検出できない。

## 以後の規則

予算の機構を変える候補は、採否測定の前に、採否測定と同じ時間制御の煙試験で1局の総思考時間、終局時の残り時間、および手数帯ごとの完了深さを現行と並べ、総思考時間が現行の90%以上110%以下に収まり、完了深さがどの帯でも現行を下回らないことを確かめてから測定へ進む。
探索中の中断で止める方式を採るときは、中断した反復が着手を変えた割合も同じ煙試験で数え、その割合が低ければ反復の完了を待つ方式を候補に戻す。

# 探索値と静的評価の差を学習するときは戦術上の利得を除外する

## 症状

棋力向上段階8の起案時の設計は、静的評価の補正（correction history）を、置換表へ保存する値が修正の向きを確定する全ノードで更新していた。
フェーズ1の診断では、観測点の97%が下限で、探索値と静的評価の差の平均絶対値が歩兵12枚分あり、鍵を細かくしても予測誤差の改善率がほぼ変わらなかった。
非捕獲手の判断に使う観測点だけで評価し直すと、この更新の条件の改善率は−4.84%から1.99%であり、補正は予測に寄与していなかった。

## 原因

観測点の78%は最善手が捕獲手であり、その差は評価関数の偏りではなく、捕獲手による駒得という戦術上の利得であった。
これを取り込んだ補正は「手番側は駒を取れることが多い」という期待値を学習し、補正を使う場面（非捕獲手を展開するかどうかの判断）の誤差を減らさない。
StockfishとYaneuraOuは、最善手が捕獲手であるノードと王手を受けているノードを更新から除外しており、起案時にソースを確認していれば設計の段階で避けられた。

## 以後の規則

探索値と静的評価の差を学習する仕組みは、最善手が捕獲手であるノードと手番側の王駒に利きが届くノードを更新から除外し、候補の比較は補正を使う場面と同じ母集団での予測誤差で行う。

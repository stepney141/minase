# 合成データのテストの許容誤差は標準誤差から決め、入力を中立な値に固定しない

## 症状

ロジスティック回帰の実装を確かめるテストで、結果を乱数で合成した20,000局から既知の係数を回復できることを、許容誤差15 cpで検査するよう実装者へ指示した。
実装は正しかったが、推定値が−80.2 cp（真の値−60 cp）となって失敗した。
また、評価値0、手番の切片0、補間係数の最大値、勝敗だけの結果で作った合成データのテストが通る状態で、回帰の基準の評価値を落とす、手番の切片を取り違える、補間係数を無視する、および引き分けの目的値を誤るという変異を入れても、すべてのテストが通った。

## 原因

各区分に入る局数と勝率から求めると、この係数の標準誤差は約12.5 cpであり、許容誤差15 cpは約1.2σにすぎなかった。
期待値を決めるときに標準誤差を見積もっていなかった。
中立な値に固定した入力は、その入力を使う式の項を0にするので、その項の誤りをテストが検出できなかった。

## 以後の規則

乱数で合成したデータで推定値を検査するときは、標準誤差を先に見積もって許容誤差を3σ以上にし、固定シードで偶然通る値を選ばない。
式の各項は、解析解を計算できる事例で0でない値を与えて検査し、変異を入れて検出を確かめる。

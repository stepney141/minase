# 外部エンジンの固定時間は時間切れ判定との余裕を本測定前に見積もる

## 症状

HaChuに1手2秒の固定時間（`st 2`）を与えた200ペアの測定で、HaChuの思考時間が2秒を1〜168 ms超えた手が81,585手中12手あり、その12局が時間切れの反則負けとして算入された。
1ペアの煙試験では最大1.97秒で収まっていたため、超過を予見できなかった。

## 原因

HaChuは`st`のとき`time`の0.98倍で探索を中断するので、時間切れ判定までの余裕が2秒に対して40 msしかない。
中断の検査は一定ノード数ごとに行われ、着手の入出力にも遅延があるため、稀にその余裕を超える。
発生率0.015%の尾は1ペアの煙試験では観測できない。

## 以後の規則

外部エンジンに固定時間や秒読みを与える測定では、そのエンジンの中断上限と時間切れ判定の差を仕様から先に求め、差が判定値の数%以下なら、時間切れの扱い（そのまま算入して感度計算を併記する、または余裕を広げる）を測定前に決めてから本測定へ進む。

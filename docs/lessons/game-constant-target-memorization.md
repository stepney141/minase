# 対局内で一定な教師成分は関係を表せるモデルに記憶される

## 症状

現行PSTを固定して2駒関係の補正項（Factorization Machine）を既存の自己対局データで学習したところ、潜在次元16、32、64のすべてで訓練損失が1エポック目から下がる一方、検証損失は1エポック目から上がり、正則化係数を100倍にしても解消しなかった。

## 原因

教師値の25%を占める対局結果は同じ対局のすべての局面で同じ値を取る。
2駒の組は対局中に動かない駒の組で対局を識別できるため、FMは結果の成分を局面の評価ではなく対局の記憶として学び、対局単位の検証分割で過学習として現れた。
線形のPSTは駒の組を使えないので、同じ教師値でもこの問題は顕在化しない。
教師値を探索値だけ（λ=1.0）にすると、同じデータで検証損失が20エポックまで単調に下がった。

## 以後の規則

駒の組や隠れ層のように対局を識別できる表現力を持つ評価関数を学習するときは、対局結果のような対局内で一定な教師成分を混ぜず、探索値だけを教師にするか、混ぜる場合は対局単位で検証損失を監視して1エポック目の乖離で判定する。

# 低精度の推論の照合の許容誤差は学習したネットの出力で決める

## 症状

AlphaZero型探索のネットの出力の照合で、TensorRTのFP16の許容誤差1×10⁻²は、ランダムに初期化したネットでは差4.8×10⁻⁴で余裕をもって通った。
ところが、1サイクル分学習したネットではlogitの差が0.034〜0.043となり、許容誤差を超えた。
配線の誤りも値の飽和もなく、学習したネットを推論に使えない状態になった。

## 原因

FP16の丸めの誤差は値の大きさに比例し、層を重ねるほど累積する。
ランダムに初期化したネットは、局面ごとの合法手のlogitの標準偏差が0.05〜0.07しかなく、差も小さく出た。
学習したネットはlogitの最大が約14あり、約22層を通した丸めの累積がそのまま差に現れた。
許容誤差を、学習で大きく変わる出力の大きさのもとで決めていた。

## 以後の規則

低精度の推論を照合する許容誤差は、学習した重みの出力で確かめてから固定する。
照合する値は、logitのように大きさが学習で変わる値ではなく、下流が使う値（合法手の確率、勝率）にする。
ランダムに初期化した重みは、出力の並びのずれや読み違えを検出する照合にだけ使い、許容誤差の根拠にしない。

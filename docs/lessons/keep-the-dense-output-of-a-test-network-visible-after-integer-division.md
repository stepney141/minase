# 試験用の固定ネットは、後段の出力が整数の除算の後にも評価値に現れる大きさにする

## 症状

NNUEをtataraの形式へ載せ替えたとき、探索の試験が使う固定ネットを、駒割のPSQTと、重みを−2〜2に抑えた後段で組み立てた。
`fv_scale`を128にしたので、後段の整数の出力は128未満にとどまり、128で割ると0 cpに切り捨てられて、評価値は駒割だけになった。
初期局面から深さ4の探索では、駒を取らない静かな局面がすべて同じ評価値になり、βカットが起きなくなった。
固定ネットを差し替えた変更では、βカットの数が正であること、教師生成で序盤の候補を捨てたこと、および規則で決まる反復の勝ちの値の3つの検査が、通らないという理由で外された。

## 原因

整数の推論は、後段の出力とPSQTの和を`fv_scale`で割って0の方向へ切り捨てる。
後段の重みを小さく選ぶと、駒割が評価値の大小を支配する性質は保てても、後段の寄与が切り捨てで消え、評価値が局面の違いをほとんど区別しなくなる。
探索の多くの試験は、評価値が局面ごとに違うことを暗に前提にしている。

## 以後の規則

試験用の固定ネットは、後段の寄与が除算の後にも数十cp残り、駒割が評価値を支配する範囲に重みを選ぶ。
選んだ範囲がこの性質を満たすことを、後段の寄与の最大値と取る値の種類の数、初期局面から各合法手を指した後の評価値の種類の数、および評価値と駒割の差の最大値を確かめる試験で固定する。
固定ネットを替えて探索の試験が落ちたときは、検査を外さず、試験の条件を改めるか、固定ネットが退化していないかを先に疑う。

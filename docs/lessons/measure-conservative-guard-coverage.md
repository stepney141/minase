# 保守的な適用除外は実装直後に除外率を測ってから確定する

## 症状

段階3のSEEは、獅子が絡む交換列をすべて「判定不能」として枝刈りの対象外にする契約で実装したが、benchの深さ3で捕獲手の69.6%が判定不能となり、SEEが働く手は3割に満たなかった。

## 原因

規則依存を避けるための除外条件を、規則が実際に捕獲の可否を変える場合（獅子が獅子を取る段階と麒麟の成獅子）ではなく、獅子が関与するすべての場合に広げていた。
設計時に除外率を見積もらず、実装後の発動計測で初めて過大さが分かった。

## 以後の規則

規則依存や安全性を理由に適用を除外する条件を設けるときは、実装直後にbenchで除外の内訳（条件ごとの件数）を測り、規則が実際に働く場合だけに条件を限定してから採否測定へ進む。

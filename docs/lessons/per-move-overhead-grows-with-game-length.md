# 手数に比例する固定費は超長手数の対局で時間切れを起こす

## 症状

時間管理の変更を判定するSTCで、2,873手の対局の2,864手目に基準側が時間切れを起こした。
残り時間120msに対するhard limitは30msだったが、思考時間は124msであった。
段階1の966局と段階2のそれまでの数千局には時間切れがなく、原因の切り分けに保存記録の再構成を要した。

## 原因

`position startpos moves ...`を受けるたびに全着手を開始局面から再生していたため、1手あたりの固定費が着手数に比例して増え、2,860手で約65msに達していた。
対局ハーネスは`position`送信直後から計時するので、この固定費は思考時間として時計から引かれ、残り時間が加算の近傍まで下がった局面で安全余裕の30msを超えた。
平均的な対局長では数msに収まるため、通常の測定では現れない。

## 以後の規則

エンジンの1手あたりの固定費（`position`の処理、探索の準備、出力）は対局長に依存しない大きさに保ち、時間管理を変更したときは、手数上限に近い超長手数の対局でも固定費が予算の安全余裕の内側に収まることを、着手列を1手ずつ与える計測で確認する。

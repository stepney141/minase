# 合法手生成を疑似利きへ置き換える判定では、置き換えが成り立たない規則の例外を固定例で試験する

## 症状

[審判層の裁定が繰り返す合法手生成の削減](../plans/archived/referee-adjudication-movegen.md)では、審判層の判定の一部を、全件の合法手生成から疑似利き（`Position::attackers_to_by`）や駒1枚の生成へ置き換え、現行の全件生成による判定を試験の中に複製した参照実装と突き合わせて検証した。
突き合わせは10規則セットの乱数対局330局、32,726手に及び、詰み、駒枯れ、裸玉、および王駒捕獲による終局も含んでいた。
しかし、駒枯れの猶予（RULES.md第22条第5項）を疑似利きで判定する誤りを意図的に入れても、試験はすべて通った。

## 原因

疑似利きと合法な捕獲が食い違うのは、獅子の捕獲制限や先獅子（第14条から第16条）が働く局面に限られる。
駒枯れの猶予で食い違いが現れるのは、王駒だけになった側の王駒が余分な獅子に疑似利きを持つものの、直前に獅子以外の駒が獅子を取ったことで先獅子が働き、実際にはその獅子を取れない局面だけである。
乱数対局は、このように複数の規則が重なる局面をほとんど生まないので、件数を増やしても置き換えの誤りを検出できなかった。

## 以後の規則

合法手生成を疑似利きや部分的な生成で置き換える判定では、置き換えが成り立たなくなる規則の例外（獅子の捕獲制限、先獅子、付け喰い、成りの強制など）ごとに、疑似利きと合法手が食い違う固定例を書く。
固定例の中で疑似利きが届くことも確かめ、その局面が食い違いの例であることを試験の中で示す。
そのうえで、判定を疑似利きへ置き換えた誤りを一時的に入れて、試験が失敗することを確かめる。

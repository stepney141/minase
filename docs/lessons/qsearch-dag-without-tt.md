# 置換表なしの静止探索は捕獲木の重複を全列挙する

## 症状

Lazy SMP初版では、補助ワーカーを増やすとノード毎秒は比例して伸びるのに、固定深さbenchの経過時間は短縮せず、時間制御の自己対局でも棋力差が出なかった。
単一ワーカーの深さ5探索を数えると、置換表を照会する残り深さ1以上のノードは全ノードの約2%（242K／12.76M）であり、残りの約98%は置換表を使わない静止探索と深さ0ノードであった。

## 原因

静止探索は捕獲手を続けて読むが、互いに独立な升の捕獲は順序を入れ替えても同じ局面へ合流する。
置換表を照会しない静止探索はこの合流を検出できず、同じ局面を捕獲の順列ごとに探索し直す。
探索時間の大半をこの重複が占めていたため、通常探索だけを対象にした置換表共有や指し手順序付けの改善では総時間がほとんど動かなかった。
静止探索で置換表を照会・記録すると、深さ5のbenchの総ノード数は12,764,630から5,959,065へ、経過時間は11.1秒から4.2秒へ減り、固定ノード数のGSPRTもH1に到達した。

## 以後の規則

探索の速度や並列化の効果を論じる前に、benchで置換表を照会するノードの割合を数え、大半のノードが置換表を使わない経路にあるなら、順序付けや並列化より先にその経路への置換表の適用を検討する。

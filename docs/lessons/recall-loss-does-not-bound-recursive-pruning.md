# 失う良手の割合は深さの上限のない再帰での枝刈りの損失を抑えない

## 症状

段階12の項目4（静止探索の手数制限）では、「失う良い結果の割合が10%以下の候補のうち最小の手数上限」という段階4以来の規則で`N=1`を選んだ。
診断では、`N=1`で失う良い結果はbench深さ6で4.83%、時間制御の予算で2.57〜3.04%であり、基準を十分に満たしていた。
ところがSTCは147有効ペアで`H0`となり、得点率は27.0%（約−173 Elo）だった。

## 原因

失う良い結果の割合は、参照探索の各ノードで、枝刈りが読まなくなる手のうち良い結果だった手の割合を1段だけ数える指標である。
主探索の枝刈りは残り深さの浅いノードだけに掛かるので、読まなかった手の影響は限られた深さで止まる。
静止探索は深さの上限なく捕獲を再帰するので、各ノードで数%ずつ取り返しの手順を読み落とすと、その誤りが捕獲の連鎖を通じて積み重なり、根の評価値を大きく誤らせる。
1段の損失率は、この積み重なりを表さない。

## 以後の規則

失う良い結果の割合で閾値を選ぶ規則は、残り深さに上限のあるノードの枝刈りに限って使う。
静止探索のように深さの上限なく再帰するノードの枝刈りでは、枝刈りを適用した探索と参照探索の根の評価値や最善手の差を診断で直接比べるか、基準を満たす候補のうち最も控えめなもの（手数上限なら最大の値）を選ぶ。

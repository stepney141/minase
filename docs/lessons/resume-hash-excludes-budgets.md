# 再開の設定ハッシュに予算を含めない

## 症状

Rust製NNUE学習器で、1エポックで止めた学習を`--epochs 2`で再開しようとすると「設定ハッシュの不一致」で拒否された。

## 原因

再開時に照合する設定のハッシュに、エポック数、改善なしの許容数、時間の上限、ワーカー数まで含めていた。これらは学習の軌跡（重みと最適化器の状態の列）を変えない予算と並列度であり、再開で延長するために変える値である。

## 以後の規則

再開の照合には、軌跡を変える設定（入力特徴集合、幅、データの検査和、初期値、教師の作り方、バッチ、シード、学習率と減衰）だけを含め、予算（エポック数、patience、時間の上限）と並列度（ワーカー数）は含めない。再開の検証は、連続した実行とエポック境界で再開した実行の重みと最適化器の状態がビット単位で一致することで行い、経過時間と検査和の差だけを許す。

# GPUを要する学習はcodexへ委任しない

## 症状

学習PSTの学習をcodexサブエージェントへ委任したところ、codexのサンドボックスからGPUが見えず、学習はCPUで実行された。
100万局面のPST学習は数分で済んだが、NNUEのような大きなモデルでは同じ経路が数十倍の時間を要する。

## 原因

codexの実行環境はホストのGPUデバイスを共有しない。
委任時に学習器の実行環境を指定しなかったため、委任先の環境で黙ってCPUへ退避した。

## 以後の規則

GPUを要する学習は、codexには学習器のコードだけを委任し、学習の実行は本環境で直接行う。

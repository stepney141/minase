# 枝刈りの閾値は条件付き誤り率ではなく失う良手の割合で選ぶ

## 症状

段階4の診断benchで、余裕値と手数上限を「候補値以上の対象のうち探索値が境界と食い違う割合が10%以下になる最小の候補値」で選ぶ規則を事前に定めたが、全項目・全深さで最小候補（余裕値50、手数上限1）が選ばれ、手数上限1はαを上回る静かな手をすべて失う値であった。

## 原因

零窓の非PVノードでは、βを下回るノードやαを上回る静かな手（枝刈りが失う良い結果）が全体の1%から10%程度しかない。
基礎率が閾値の10%を下回る事象では、条件付き誤り率は候補値によらず10%以下になるので、この規則は候補値を判別できない。

## 以後の規則

枝刈りの余裕値や手数上限を診断から選ぶときは、条件付き誤り率ではなく「候補値を適用したときに失う良い結果が、良い結果全体に占める割合」を指標にし、事前に良い結果の基礎率を確かめて閾値が基礎率を上回っていないことを検査する。

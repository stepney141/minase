# 煙試験の指標は破棄局とエンジンの起動直後の手を分けて見る

## 症状

[固定時間の探索の締切と途中結果](../plans/movetime-deadline.md)の1手1,000 msの煙試験（24ペア）で、事前に定めた判定基準のうち2つを満たさなかった。
1つは手数200以上の帯で候補の完了深さの平均が基準を下回ったことであり、もう1つは`movetime`を超えた量の最大値が50 msを超えたこと（候補70.2 ms、基準69.2 ms）である。
同じ局面で2つのバイナリを比べた診断では、候補の完了深さは基準より平均0.675（標準誤差0.072）大きく、後の本測定（有効325ペア）でも時間切れは0件だった。

## 原因

深さの帯の逆転は、手数上限4,096手に達して破棄された1局が、その帯の約4分の1の手を占めたことによる。
対局記録の各手は候補と基準で別の局面を探索するので、1局に偏った手数帯の平均は、エンジンの差よりもその局で両者が読んだ局面の違いを反映する。
超過の大きい手は、どの局でも最初の数手（エンジンの起動直後）に集中し、特に、測定の開始時に全局のエンジンが一斉に起動したときの局に多い。
24ペアの最大値は、この少数の手によるものだった。

## 以後の規則

対局記録から手数帯ごとの完了深さを比べるときは、ハーネスの統計と同じく破棄ペアを除いて数え、深さの比較の主な根拠には同じ局面に候補と基準を当てる対比較（`scripts/lishogi_byoyomi_usage/paired_depth_probe.py`の方式）を使う。
思考時間の超過の最大値や裾を判定基準にするときは、各局の最初の数手と、測定の開始時に同時に始まった局の手を分けて集計し、どの手が最大値を決めているかを確かめる。

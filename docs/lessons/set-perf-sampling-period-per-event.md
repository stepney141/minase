# perfの採取周期はイベントごとに指定する

## 症状

教師生成のプロファイルで、サイクルを2,000,003回ごと、L3キャッシュのミスを1,009回ごとに採取するつもりで、`perf record`へ`-e`と`-c`の組を2つ渡した。
`perf evlist -v`で記録を確認すると、両方のイベントの採取周期が1,009回になっていた。

## 原因

`-c`は直前の`-e`だけに適用される指定ではなく、最後に指定した値が各イベントへ適用された。
そのため、引数を交互に並べるだけではイベントごとに採取周期を分けられない。

## 以後の規則

異なる周期で複数のイベントを採取するときは、`-e 'cpu_core/cycles,period=4000037/u'`のように、各イベントの中に`period=`を指定する。
集計前に`perf evlist -v -i <記録>`で各イベントの`sample_period`を確認し、意図と違う記録は比較に使わない。

# 探索木の終局判定は審判層の裁定を共有する

## 症状

AlphaZero型探索のMCTSは、新しい節点を作るときに相手の最後の王駒の捕獲と合法手なしだけを終局と判定していた。
そのため、審判層が詰みと駒枯れで終局と裁定する局面でも、ネットに評価を要求していた。
監査の再現では、駒枯れの勝ち、駒枯れの引き分け、および詰みの3例で、審判層が終局と裁定したのに対し、探索木はネットの評価を要求して確定した結果と異なる期待得点Qを返した。
探索と審判の単体試験はすべて通っており、両者の判定の一致を確かめる試験がなかった。

## 原因

探索木の終局判定を探索側で独自に実装したため、審判層が裁定する終局の種類（詰み、駒枯れ、裸玉、正確な反復）の一部が判定から欠けた。
αβ探索は王駒の捕獲まで読み切ることで詰みの判定を代用できたが、探索回数の少ないMCTSではその代用が働かず、終局の近くの教師データが歪む。

## 以後の規則

探索木の終局判定は、審判層の裁定を呼ぶか審判の状態を進めて得るものとし、探索側で裁定の順序や規則の優先順位を書き直さない。
反復の判定などの近似を残す場合は、正確な裁定を先に適用し、近似に由来する結果に印を付ける。
両者の判定の一致は、乱数で進めた対局の各手について審判層の結果と探索木の分類を突き合わせる試験で固定する。

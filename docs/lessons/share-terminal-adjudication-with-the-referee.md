# 探索木の終局判定は審判層の裁定を共有する

## 症状

AlphaZero型探索のMCTSは、新しい節点を作るときに相手の最後の王駒の捕獲と合法手なしだけを終局とし、審判層が詰みと駒枯れで終局とする局面をネットに評価させていた。
監査の再現では、駒枯れの勝ち、駒枯れの引き分け、および詰みの3例で、審判層は終局とし、探索木はネットの評価を要求して確定した結果と異なるQを返した。
探索と審判の単体試験はすべて通っており、不一致は試験の範囲の外にあった。

## 原因

探索木の終局判定を探索側に書き直したので、審判層が裁定する終局の種類（詰み、駒枯れ、裸玉、正確な反復）の一部が抜けた。
αβ探索は深さで王駒の捕獲まで読んで詰みを代用できたが、探索回数の少ないMCTSではその代用が働かず、終局の近くの教師が歪む。

## 以後の規則

探索木の終局判定は、審判層の裁定を呼ぶか審判の状態を進めて得て、探索側に裁定の順序や規則の優先順位を書き直さない。
近似を残す場合は、正確な裁定を先に適用し、近似に由来する結果に印を付ける。
一致は、乱数で進めた対局の各手について審判層の結果と探索木の分類を突き合わせる試験で固定する。

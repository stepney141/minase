# 採否の判定条件は候補の式にも事前に当てて試算する

## 症状

秒読みつき時間制御の候補K1（hardの4倍から秒読み分を外す式）は、持ち時間局面の「思考時間とsoftの比の中央値が1に近づくこと」を採用条件の1つにして診断へ進んだ。
診断の結果、比の90パーセンタイルは2.0〜2.2から0.9〜1.2へ下がったが、中央値は0.95〜1.08から0.66〜0.73へ下がって1から遠ざかり、候補は不採用になった。
設計書の予算表は、K1では反復の開始条件を拘束する予算がsoftからhard（経過時間の2.5倍がhard以下、初手で5.3秒）へ移ることを診断前に示していた。

## 原因

判定条件を現行構成の値で固定する一方、候補の式から導ける判定指標の期待値を試算しなかった。
開始条件がsoftより手前で閉じる候補では、比の中央値は構造上1を下回るので、候補と判定条件は診断前から両立していなかった。

## 以後の規則

採否の判定条件を固定する前に、各指標の期待値を候補の式または短い模擬から試算し、候補が構造上満たせない条件があれば、候補か条件を診断前に改める。

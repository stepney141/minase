# 段階生成の固定費は件数の削減率から見積もらない

## 症状

静止探索の捕獲を価値グループ順に段階生成し、生成する捕獲を診断値で63.6%減らしたのに、探索速度は先行する変更から0.6%しか上がらなかった。

## 原因

段階生成はノードごとに相手駒の走査、グループの線形探索、および整列という固定費を新たに払い、その包含時間（約14%）が生成件数の削減分を相殺していた。
件数の削減は「生成しない手」の数を数えるが、時間は「ノードごとに必ず行う準備」に支配されていた。

## 以後の規則

生成や整列を段階化したら、件数ではなくperfでノードごとの固定費（初期化、走査、整列）を包含時間で測り、探索中に変わらない順位や表はノードごとに作らず探索開始時に前計算する。

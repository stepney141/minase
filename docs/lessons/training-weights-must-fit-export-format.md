# 学習する重みの範囲を保存形式に合わせる

## 症状

棋力向上段階7の世代2の再学習では、10エポックを計算して最良エポック8を選択した後、量子化時の範囲超過で候補を保存できなかった。
序中盤用の鏡映1対が約−4,236.5366センチポーンとなり、1/8センチポーン単位の整数−33,892は符号付き16ビット整数の下限−32,768を下回った。

## 原因

学習中の重みに保存形式の範囲制約がなく、有限な重みでも保存できない値になり得た。
全27,360値の丸め結果と格納可否は独立した参照計算と一致し、単位変換と鏡映展開にも不整合は検出されなかった。
当該特徴は18,848回観測され、補間係数の偏差平方和257.632は識別性の基準100以上を満たしていたが、この基準は重みが保存範囲に収まることを保証しない。

## 以後の規則

学習の最適化領域を出力形式が表せる範囲と一致させ、範囲の違反を出力時の例外や後処理まで持ち越さない。
非有限値と有限な範囲外の値を区別して検査し、量子化の単位と境界を独立した参照計算で照合する。
各更新後の射影を導入する場合は最適化規則の変更として条件を明示し、その条件で再学習して候補を診断したうえで、既存の棋力測定ゲートにより採否を判定する。

## 出典

起点は[段階7の世代2追加後の再学習](../measurements/strength-stage7-gen2-training.md)に記録した量子化失敗と独立診断である。

# 判定規則の誤判定は、差がないと分かっている比較で確かめる

## 症状

配置の距離の判定規則（差の95%区間の上限が0未満）が誤って「偏りが減った」としないことを、線形経路の初期値だけを変えて学び直した2つのネットで確かめたところ、規則は「偏りが減った」と判定した。
差は200ペアで−0.0094（95%区間−0.0129〜−0.0055）であり、全1,779ペアでも−0.0079と安定していた。

## 原因

学び直した2つのネットは棋力が同程度でも、配置の分布まで同じとは限らない。
駒種ごとの差は王将−0.096、龍馬−0.070、龍王+0.054と大きく、規則は実在する小さな差を正しく検出していた。
差が0であるという根拠のない比較を対照に使ったので、誤判定かどうかを区別できなかった。

## 以後の規則

判定規則の誤判定を確かめるときは、同じネットや同じコミットを本番と同じ比較の構造でもう1回測り、棋力が同程度であることを、測りたい指標の差が0であることの根拠にしない。

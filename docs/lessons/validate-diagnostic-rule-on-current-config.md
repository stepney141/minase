# 診断の適格基準は現行構成に当ててから固定する

## 症状

LMRの減深量の係数を「失う良い結果が10%以下」という段階4の枝刈りと同じ絶対基準で選ぼうとしたところ、候補75組のどれも適格にならず、診断が縮退した。
採用済みの現行の減深量そのものを同じ標本に当てると、失う割合は31.5%であった。

## 原因

良い結果（本来の深さで読めばαを上回る後方の静かな手）の基礎率が0.6%と低く、減深はその大半を失っても読み直しで補うことを前提にした機構なので、枝刈り向けの絶対的な損失上限は減深には合わない。
基準を他の機構から流用し、現行構成が満たすかどうかを確かめずに固定していた。

## 以後の規則

診断で候補を選ぶ適格基準を決めたら、本診断の前に現行構成を同じ標本で評価し、現行構成が適格にならない基準は「現行構成より悪化しない」という相対基準へ置き換えてから固定する。

# 検証損失の近さは駒価値の正しさを保証しない

## 症状

世代0の100万局面で学習したP型NNUEは、検証損失が学習PSTより0.01悪いだけであったが、学習PSTに対する固定ノードGSPRTで204ペア中196ペアに2局とも負けて`H0`となった。

## 原因

二値交差エントロピーは、勝率が飽和する大差の局面では評価値の誤差にほとんど反応しないため、損失が近くても駒価値が大きく歪み得る。
実際に、教師探索値に対する平均絶対誤差は学習PSTの193センチポーンに対してNNUEは404センチポーンであり、初期配置から駒を除いた局面の評価は獅子1枚で−3,865センチポーン（学習PSTでは約−2,500）、歩兵12枚で−289センチポーンと、獅子を過大に、歩兵をほぼ無価値に見ていた。
歩兵を無価値と見なす評価は駒損を重ねるので、対局結果はこの歪みと整合する。

## 以後の規則

学習した評価関数をGSPRTへ出す前に、検証集合で教師探索値との平均絶対誤差と相関を測り、初期配置から駒種を1つずつ除いた局面の評価を採用中の評価関数と比べて、駒価値の歪みを損失とは別に点検する。

# 検証分割を変えたら旧分割の重みを基準にしない

## 症状

学習器を来歴に基づく検証分割へ変更した後、旧分割で学習した`nets/pst.bin`の新分割での検証損失0.41289が、再学習の最良0.41463より低く見えた。
旧重みのほうが良いという誤った結論を招きかねなかった。

## 原因

旧分割では、新しい検証集合に含まれる対局の約95%が訓練に使われていた。
旧重みは新しい検証集合をほぼ学習済みなので、検証損失が不当に低く出る。

## 以後の規則

検証分割を変更したときは、旧分割で学習した重みを新分割での比較基準に使わず、新分割で学習し直した重みどうしで比較する。

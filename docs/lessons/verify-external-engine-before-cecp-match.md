# 外部エンジンは接続前に棋譜照合と着手転送で検証する

## 症状

HaChuのddugovic派生版は`usermove`で受けた着手の照合に欠陥があり、審判層が合法とした着手を拒否して対局が進行不能になる。
対局ハーネスは拒否を反則負けとして統計へ算入するため、欠陥のある版に接続すると測定結果が規則差ではなく実装欠陥で汚れる。

## 原因

外部エンジンは自前の規則検査を持ち、ハーネスの審判層とは独立に着手を拒否する。
どの版のどの経路が信頼できるかは、対局を回す前には分からない。

## 以後の規則

外部エンジンを`cecp:`で接続する前に、そのエンジンの自己対局棋譜を審判層で全手照合し、2プロセス間で数十手を`usermove`転送して両者の盤面が一致することを確認してから本測定に進む。

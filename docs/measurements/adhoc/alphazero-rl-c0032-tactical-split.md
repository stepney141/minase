# サイクル32のネットの価値の偏りを戦術の局面と静かな局面に分ける診断

## 目的

[価値の偏りの診断](alphazero-rl-c0032-value-bias.md)で見つかった、αβ探索との対局の局面でネットが駒の損得によらずMCTS側を有利と見積もる偏りが、取られる駒を見落とす戦術の問題か、駒の取り合いがない局面でも読み違える局面の型の問題かを、対局なしで判定する。
この判定は、[自己対局の分布の提案](../../proposals/alphazero-selfplay-distribution.md)の「起案の前に測れること」にあたり、戦術が主なら探索側の対策、局面の型が主なら自己対局の分布の拡大が効くと見込む（推論）。

局面の分け方は次のとおりである。
同じ局面をαβ探索に深さ3で読ませ、その読み筋の中で駒を取る手があれば「戦術的」、なければ「静か」とする。
αβが詰みを読んだ局面は戦術的な局面に含める。
提案は静止探索の値との比較を挙げたが、エンジンはUSIで静止探索だけの値を返さない（`go depth 0`は拒否される）ので、エンジンを変えずに済む深さ3の読み筋で代えた。
この代用は開発者が決めたものではなく、診断を設計したClaudeが選んだ。

判定の規則は、測定の前に次のとおり固定した。
駒の損得（[価値の偏りの診断](alphazero-rl-c0032-value-bias.md)と同じ歩を1とする概算）が−5以上5未満の局面を互角と呼ぶ。
基準の集合をサイクル30対サイクル20の対局とし、対象の集合（サイクル32対αβの、MCTSの手番とαβの手番）ごとに、対象の集合のネットの探索なしの勝率の中央値から基準の集合の中央値を引いた差を、互角の全局面で求めたものを$G_{\mathrm{all}}$、互角の静かな局面で求めたものを$G_{\mathrm{quiet}}$とし、$R = G_{\mathrm{quiet}} / G_{\mathrm{all}}$とする。
比べる4つの部分集合のどれかが100局面未満なら判定不能とし、$|G_{\mathrm{all}}| < 0.1$なら偏りが小さく判定不能とする。
それ以外では、$R \ge 2/3$なら局面の型が主、$R \le 1/3$なら戦術が主、その間なら混合と判定する。
前回の結果では$G_{\mathrm{all}}$は約±0.3と見込まれ、静かな局面が互角の局面の13%以上あれば各部分集合は100局面を超える（推論）。

## コマンドライン

作業機で次を実行した。
スクリプト、出力、および局面ごとの値（`positions.tsv`）は、本記録と同じ名前のディレクトリにある。
スクリプトは、前回の診断のディレクトリの`common.py`と`engine.py`を読み込む。

```console
BIN=target/match-cache/45d5db5498e1739b2307b3719891a1eec24f7fbd/minase
NET=/mnt/synology_nas/minase/alphazero/nets/cycle-0032.onnx
STC=data/matches/alphazero-rl-restart-stc-c0032
PROGRESS=/mnt/synology_nas/minase/alphazero/progress/c0030-vs-c0020
OUT=<展開先のディレクトリ>
D=docs/measurements/adhoc/alphazero-rl-c0032-tactical-split
tar --zstd -xf data/matches/nnue-material-linear-init-noninferiority-stc.tar.zst -C $OUT
source tools/train/zero/env.sh    # bashで実行する
export XDG_CACHE_HOME=$HOME/.cache
python3 $D/tactical_split.py $BIN $NET $STC $PROGRESS $OUT/nnue-material-linear-init-noninferiority-stc 5000 $D/positions.tsv > $D/tactical-split.out
```

抽出のシードはスクリプトに固定した20261103であり、乱数の消費の順は前回の`raw_net_value.py`と同じである。
実行は、`systemd-run --user`で`MemoryMax=6G`、`MemorySwapMax=0`、および`Nice=19`を課したサービスとして行った。

## エンジン

MCTSとαβ探索はどちらもコミット45d5db54のバイナリであり、規則は`engine-default`（`L0,P0,R1,E0`）である。
ネットはNASの`nets/cycle-0032.onnx`（SHA-256の先頭16桁は`a386eed89aac5c7e`）であり、推論はTensorRTのFP16である。
ネットの値は、MCTSの`NnBatchSize` 16で`go nodes 1`を探索させた評価値である。
αβ探索は`Threads` 1、`USI_Hash` 256 MBとし、局面ごとに`usinewgame`を送ってから`go depth 3`で読ませ、最後の`info`の評価値と読み筋を使った。
勝率は、どちらの評価値も前回と同じ1ロジットあたり1,072.65 cpで換算した。
局面の集合は前回と同じ4つであり、各集合の40手目から299手目の局面から5,000局面を抽出した。

## 環境

作業機（Intel Core Ultra 7 265KF、20コア20スレッド、GPUはNVIDIA GeForce RTX 3060 Ti 8 GB）で、2026年11月9日に行った。
同じ機械で、lishogiのBotと、同時対局数10の別の対局測定が動いていた。
この診断は時間の制限なしに1局面ずつ評価するので、結果は機械の負荷に左右されない。
所要時間は16分4秒、最大の常駐メモリは1.7 GBであった。

## 結果

### 前回の値の再現

4つの集合のどれでも、ネットの値の表（損得の区間ごとと手数帯ごとの中央値）は、前回の`raw-net-value.out`の探索1回の表と行単位で一致した。
標本とネットの値は前回と同じである。

### 静かな局面の割合

| 局面の集合 | 静か | 戦術的（うち詰み） |
|---|---|---|
| サイクル32対αβ、MCTSの手番 | 3,130（62.6%） | 1,870（7） |
| サイクル32対αβ、αβの手番 | 2,908（58.2%） | 2,092（0） |
| αβ同士 | 3,233（64.7%） | 1,767（0） |
| サイクル30対20 | 3,194（63.9%） | 1,806（2） |

### 判定

互角の局面でのネットの勝率の中央値は次のとおりであった。
括弧の中は局面数である。

| 局面の集合 | 互角の全局面 | 互角の静かな局面 |
|---|---|---|
| サイクル32対αβ、MCTSの手番 | 0.820（792） | 0.814（533） |
| サイクル32対αβ、αβの手番 | 0.223（816） | 0.220（474） |
| αβ同士 | 0.511（3,429） | 0.512（2,328） |
| サイクル30対20（基準） | 0.517（1,486） | 0.514（936） |

| 対象の集合 | $G_{\mathrm{all}}$ | $G_{\mathrm{quiet}}$ | $R$ | 判定 |
|---|---|---|---|---|
| サイクル32対αβ、MCTSの手番 | +0.303 | +0.300 | 0.989 | 局面の型が主 |
| サイクル32対αβ、αβの手番 | −0.293 | −0.294 | 1.002 | 局面の型が主 |
| αβ同士（参考） | −0.006 | −0.002 | 0.320 | 偏りが小さく判定不能 |

### ネットとαβ探索の値の差

互角の静かな局面で、ネットの勝率からαβ探索の深さ3の勝率を引いた差の中央値を、損得の区間ごとに求めた。

| 局面の集合 | 損得−5〜−1 | 損得0 | 損得+1〜+4 |
|---|---|---|---|
| サイクル32対αβ、MCTSの手番 | +0.497 | +0.444 | +0.492 |
| サイクル32対αβ、αβの手番 | −0.444 | −0.391 | −0.497 |
| αβ同士 | +0.001 | +0.014 | +0.005 |
| サイクル30対20 | +0.018 | +0.001 | −0.002 |

ネットとαβ探索の値は、サイクル32のネットが対局に関わらない2つの集合では、互角の静かな局面で0.02以内で一致する。
サイクル32対αβの局面では、互角の静かな局面でも差が約0.4〜0.5あり、向きはどちらの手番でもMCTS側を有利と見る方向である。
同じ局面のαβ探索の勝率の中央値は、MCTSの手番で0.303〜0.366、αβの手番で0.638〜0.719であり、駒の損得が互角でもαβ探索はαβ側を有利と見ている。
戦術的な局面での同じ差も、MCTSの手番で+0.457〜+0.541、αβの手番で−0.455〜−0.509であり、静かな局面と同じ大きさである。

互角の静かな局面のネットの勝率の中央値を手数帯ごとに見ると、MCTSの手番では40〜59手目の0.751から80〜119手目の0.879へ、αβの手番では0.274から0.155へ開いていく。
同じ40〜119手目で、サイクル30対20は0.510〜0.527、αβ同士は0.504〜0.517であった。
前回の全局面の表と同じく、手数とともに偏りが大きくなる。

## 結論

サイクル32のネットがαβ探索との対局の局面でMCTS側を有利と見積もる偏りは、深さ3の読み筋に捕獲のない静かな局面でもほぼ同じ大きさで残り（$R$は0.989と1.002）、取られる駒の見落としではなく局面の型の読み違いが主である。

この結果は、[自己対局の分布の提案](../../proposals/alphazero-selfplay-distribution.md)の候補の選び方に対し、探索側の対策より自己対局の局面の分布を広げる対策を支持する（推論）。
ただし、静かな局面は、αβ探索の深さ3の最善の読み筋に捕獲がないことしか意味しない。
読み筋の外の脅威と、4手以上先の戦術は除いていない。

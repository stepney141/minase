# 乱数対局における合法手数の分布

## 目的

`Game::legal_moves`が返す合法手の数の分布を乱数対局で数え、生成器の出力バッファの容量の目安と、成りの展開および獅子の捕獲制限の検査が実際に働く着手の割合を得る。
この測定は、[やねうら王の合法手生成の構造をMCTSの葉の全件生成へ応用する調査](../../research/yaneuraou-movegen-for-leaf-legal-moves.md)のために行い、どの設計書も計画していない。

## コマンドライン

測定日は2026年10月28日である。
測定道具は[main.rs](legal-move-counts-random-play/main.rs)であり、[Cargo.toml](legal-move-counts-random-play/Cargo.toml)で`minase-core`へパス依存する使い捨てのcrateとして、作業ディレクトリの外でビルドした。
各局は初期局面から始め、手番側の合法手を`Game::legal_moves`で生成して一様に1手を選び、終局または400手で打ち切る。
乱数はxorshift64で、初期値は`0x9E3779B97F4A7C15`、規則は`engine-default`、対局数は300である。

```console
cd <使い捨てのディレクトリ>   # Cargo.tomlとsrc/main.rsを置いたcrateのルート
cargo build --release --offline --target-dir ./target
./target/release/movecount 300 400
```

`Cargo.toml`の`minase-core`への依存は、作業機のリポジトリの絶対パスで書いてある。
再現するときは、そのパスを手元の`crates/minase-core`に合わせる。

## エンジン

`minase-core`はmasterの`936530b4`（2026年10月28日）である。
対局相手はなく、乱数の着手だけで局面を進めた。

## 環境

Intel Core Ultra 7 265KF（物理20コア、論理20コア）、Rust 1.98.0、1スレッドで実行した。
結果は乱数の着手の列だけで決まり、実行時間は測っていない。

## 結果

出力の全文は[output.txt](legal-move-counts-random-play/output.txt)にある。
74,118局面の合法手数は、平均87.9手、中央値88手、90パーセンタイル122手、99パーセンタイル151手、最大206手であった。
手数帯ごとの平均は、1手目から50手目までが58.1手、51手目から100手目までが84.3手で、101手目以降は94手から103手の間にあった。
生成した着手のうち、成りを選んだ着手（`promote`が真）は2.0%、到達升または経由升が相手の獅子の升である着手は0.52%であった。

## 結論

乱数対局では合法手数の99パーセンタイルが151手、最大が206手であり、成りの展開と獅子の捕獲制限の検査が実際に働く着手はそれぞれ2.0%と0.52%にとどまる。
乱数対局の局面は実戦の局面と分布が異なるので、容量の確定と割合の確認は、実際の探索の局面で測り直す。

# nnue-placement-outcome-regression

## 目的

通常の自己対局の棋譜で、NNUEの評価値と駒の枚数の差で条件付けても駒の配置が対局結果を予測するかをロジスティック回帰（Texel tuningと同種の回帰）で調べ、対局結果で評価を補正する案に使える信号があるかを判定する。

## コマンドライン

スクリプトと標準出力は、本記録と同じディレクトリの`nnue-placement-outcome-regression/`にあり、そのディレクトリで実行する。
抽出した局面（`rows2.pkl`）は`data/nnue-placement-outcome-regression/`に置き、リポジトリには含めない。

```console
python3 -I -u check2.py > check2.out
OMP_NUM_THREADS=6 OPENBLAS_NUM_THREADS=6 python3 -I -u fit3.py > fit3.out
OMP_NUM_THREADS=6 OPENBLAS_NUM_THREADS=6 python3 -I -u head_fit.py > head_fit.out
```

## エンジン

新しい対局は行わず、保存済みの棋譜を再生した。
対局は`data/matches/nnue-material-linear-init-noninferiority-ltc`と`-stc`であり、候補は`b8bebfb3`、基準は`6d47da2a`、規則セットは`L0,P0,R1,E0`である。
静的評価は、現行の埋め込みネットを持つ`6d47da2a`のビルド（`target/match-cache/`）のUSIの独自コマンド`eval`で求めた。
対局の探索値は保存された値をそのまま使った。

## 環境

2026年11月3日に作業機で行った。
計算は棋譜の再生、静的評価、および回帰だけである。

## 結果

### 集計の定義

手数上限で打ち切った52局を除く6,254局（3,188ペア）から1局あたり最大5局面を取り、次の除外の後に30,974局面が残った。
探索値の絶対値が3,000 cp以上の局面と詰みの値の局面は除いた。
局面の手数は、60、81、100、121、140手の組と、手番を反転した61、80、101、120、141手の組を、ペア番号と対局番号で割り当て、手番側の割合が先手50.0%になるようにした。
各局の重みを1にそろえ、目的変数は手番側から見た結果（勝ち1、引き分け0.5、負け0）とした。

基準のモデルは、手番、測定の条件（STCとLTC）、およびその交互作用の切片と、手数帯ごとの評価値の傾きからなる。
枚数のモデルは、基準のモデルに21駒種と成駒の枚数の差（手番側−相手、事前分布の標準偏差160 cp）を加える。
配置のモデルは、枚数のモデルに成っていない21駒種×段7区分と21駒種×中央からの筋6区分の数の差を加える。
配置の事前分布の標準偏差τは{20, 40, 80} cpから訓練側の選択用のペアで選び、勝率尺度も訓練側だけで求めた。
評価はペア単位の5分割の交差検証で行い、95%区間はペアを単位とする対応のあるブートストラップ（1,000回）である。
区間は予測を固定してペアを再抽出したものであり、回帰をやり直す変動を含まない。

### 配置の信号

| 評価値 | 基準の損失 | 枚数を足す効果 | 配置をさらに足す効果 |
|---|---:|---|---|
| 静的評価 | 0.66584 | −0.000823（−0.001637〜+0.000015） | −0.003319（−0.005174〜−0.001491） |
| 探索値 | 0.66245 | −0.000837（−0.001691〜+0.000036） | −0.003439（−0.005312〜−0.001476） |

### 配置の違いの量

両者の数が異なる局面の割合は、奔王が1〜2段で15.6%、龍馬が1〜2段で42.7%、醉象が3〜5筋で44.3%、金将が3段以上で51.4%、麒麟が右端2筋で39.6%である。
配置の数え方は[集計](piece-placement-census.md)と同じである。

### 5配置の係数

枚数の差で条件付けて5配置を足した回帰の係数を、評価値のcpへ換算した。
負の値は、評価値がその配置を対局結果より高く見ていることを表す。
95%区間はペアを単位とするブートストラップ（80回）である。

| 配置 | 静的評価（cp） | 探索値（cp） |
|---|---:|---:|
| 奔王が1〜2段 | −34.0（−143.8〜+75.1） | −41.0（−134.5〜+32.9） |
| 龍馬が1〜2段 | +77.3（+35.2〜+123.7） | +81.9（+22.8〜+133.3） |
| 醉象が3〜5筋 | −45.4（−105.4〜−0.2） | −48.4（−106.0〜−9.5） |
| 金将が3段以上 | +8.4（−54.2〜+44.1） | +23.6（−22.1〜+64.5） |
| 麒麟が右端2筋 | −35.6（−96.2〜+26.8） | −27.1（−81.4〜+23.8） |

### 出力重みの回帰との比較

第1層を固定すると、評価値は出力重みについて線形なので、出力重みだけを対局結果へ回帰する問題も同じ形の凸問題になる。
`head_fit.py`は、エンジンの推論をPythonで再現し、先頭4,000局面の非線形部分がエンジンの`eval`とすべて一致することを確かめてから、この回帰と段と筋の補正を同じ分割で比べた。
基準は枚数の差を含まない静的評価のモデル（損失0.66584）である。
特徴は鏡映の共有後の128個を標準化したものとし、τは{5, 10, 20, 40} cpから訓練側の選択用のペアで選んだ。
95%区間は上と同じくペアを単位とする対応のあるブートストラップ（1,000回）である。

| モデル | 基準との損失の差 |
|---|---|
| 段と筋の補正 | −0.003900（−0.006034〜−0.002055） |
| 出力重みの回帰 | −0.001806（−0.002883〜−0.000757） |
| 両方 | −0.004049（−0.006125〜−0.001817） |

出力重みの回帰は段と筋の補正より損失の改善が小さく（差+0.002094、+0.000337〜+0.004051）、両方を入れても段と筋の補正からの改善は区間が0をまたぐ（差−0.000149、−0.000565〜+0.000284）。

### 解釈の限界

この回帰は観察データの予測であり、配置の因果的な損得を示さない。
配置が評価値に現れない形勢の代理変数にすぎなければ、補正した評価関数を探索が使うと、その関係は崩れる可能性がある。
対局はほぼ同じ2つのネットの6,254局であり、現行の教師の対局では確かめていない。
両者の数の差の多くは、配置が完成する時期の差である可能性がある。

## 結論

通常の自己対局だけでも、評価値と枚数の差を条件にして配置が対局結果を予測する信号があり、結果回帰を試す前提は満たすが、癖の向きは一様ではなく、対局結果は醉象の配置を過大評価と示す一方で、龍馬の配置はむしろ過小評価と示す。

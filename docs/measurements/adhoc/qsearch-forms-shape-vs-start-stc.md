# 静止探索の形の変更の効果を係数の調整と切り分けるSTC（形の変更対起点）

## 目的

[静止探索の補正と枝刈りの形の見直し](../../plans/archived/qsearch-forms.md)の候補は、起点に対するSTCで約+261 Eloだった（[STCの記録](../qsearch-forms/qsearch-forms-stc.md)）。
この差を、形の変更そのものの効果と、SPSAで係数を調整し直した効果に切り分けるため、係数を開始値に置いた形の変更の最後のコミットを、設計書を始めた時点のmasterと短時間条件（10秒＋1手0.1秒）の逐次検定STCで対局させる。
設計書の完了後に追加で行った診断であり、採否には使わない。
係数を調整し直した効果は、[もう1本のSTC](qsearch-forms-tuned-vs-shape-stc.md)で測った。

## コマンドライン

測定機で、形の変更の最後のコミットからビルドしたrunnerを使って実行した。

```console
data/spsa/qsearch-forms-runner/minase match run \
  --run-dir data/matches/qsearch-forms-shape-vs-start-stc --seed 4610000000 \
  --candidate commit:e9abbc864554983399e250a2b28fdcf3d304debc \
  --baseline commit:662c1ab6789e05ae8ef3c994772055f190d34996 \
  --each time=10000+100 --concurrency 16 gsprt --max-pairs 3000
```

## エンジン

候補は、形の変更の最後のコミット`e9abbc864554983399e250a2b28fdcf3d304debc`であり、7項目（Q1〜Q7）の形の変更を入れ、新しい係数と開始値を置き直した係数をStockfishの換算値に置き、そのほかの係数を起点の値のままにした版である。SPSAの調整対象はこのコミットだった。
基準は、設計書を始めた時点のmaster`662c1ab6789e05ae8ef3c994772055f190d34996`である。
実行ファイルのSHA-256は、候補が`d7f7bc85…`、基準が`0cb8cb39…`、runner（版2.4.0）が`b35870aa…`である。
規則は`engine-default`（`L0,P0,R1,E0`）である。

## 環境

測定機は、Intel Core Ultra 7 265KF（性能コア8個と高効率コア12個、物理20コア、論理20スレッド）である。
両エンジンの`Threads`は1、`USI_Hash`は既定の256 MB、同時対局数は16である。
lishogiのBotは止めていない。ほかの対局測定、SPSA、教師生成、および学習は動いていなかった。
GSPRTの仮説は既定のelo0 = 0、elo1 = 10、α = β = 0.05である。

## 結果

| 量 | 値 |
|---|---:|
| 判定 | `H1` |
| 判定までのペア | 128（有効127、手数上限到達による破棄1） |
| ペンタノミアル度数 | [6, 2, 50, 7, 62] |
| LLR | +2.957 |
| エンジン異常 | 不正着手0、クラッシュ0、応答タイムアウト0、時間切れ0、拒否着手0 |
| 経過時間 | 1,062.6秒（`summary.json`の`active_wall_time_ns`） |

有効127ペアの度数から求めた候補の平均得点は0.730であり、Eloに直すと約+173、正規化したペア得点の分散から求めた95%信頼区間はおよそ+131〜+221である。
逐次検定は境界を越えた時点で止まるので、この点推定は真の差より大きめに出やすい。
保存されたペアは番号1〜130のうち129個であり、統計に入ったのはペア番号順に128番目までである。
測定は2026年10月21日21時50分に始め、22時8分ごろに終えた。その後に測定機が再起動したが、この測定の実行ディレクトリは完了した状態で残っており、`summary.json`の`interrupted`は偽である。

## 結論

係数を開始値に置いた形の変更だけで、起点より有意に強かった（約+173 Elo）。

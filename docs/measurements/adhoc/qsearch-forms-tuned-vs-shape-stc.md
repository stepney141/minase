# 静止探索の形の変更の効果を係数の調整と切り分けるSTC（調整後対形の変更）

## 目的

[静止探索の補正と枝刈りの形の見直し](../../plans/archived/qsearch-forms.md)の候補の起点に対する差（STCで約+261 Elo、[記録](../qsearch-forms/qsearch-forms-stc.md)）を、形の変更そのものの効果と、SPSAで係数を調整し直した効果に切り分けるため、SPSAの最終値を反映した候補を、係数を開始値に置いた形の変更の最後のコミットと短時間条件（10秒＋1手0.1秒）の逐次検定STCで対局させる。
設計書の完了後に追加で行った診断であり、採否には使わない。
形の変更そのものの効果は、[もう1本のSTC](qsearch-forms-shape-vs-start-stc.md)で測った。

## コマンドライン

測定機で、形の変更の最後のコミットからビルドしたrunnerを使って実行した。

```console
data/spsa/qsearch-forms-runner/minase match run \
  --run-dir data/matches/qsearch-forms-tuned-vs-shape-stc --seed 4630000000 \
  --candidate commit:c6cf0c729a6b8209e34c2a1df0f9744a87aae733 \
  --baseline commit:e9abbc864554983399e250a2b28fdcf3d304debc \
  --each time=10000+100 --concurrency 16 gsprt --max-pairs 3000
```

最初の起動は、2026年10月21日22時9分ごろに候補をビルドしている途中で測定機の再起動により止まり、実行ディレクトリは作られなかった。
ビルドの一時ファイルを消してから、22時53分に同じコマンドで最初から実行した。

## エンジン

候補は、形の変更に[SPSAの最終値](../qsearch-forms/qsearch-forms.md)を反映したコミット`c6cf0c729a6b8209e34c2a1df0f9744a87aae733`である。
基準は、SPSAの調整対象だった形の変更の最後のコミット`e9abbc864554983399e250a2b28fdcf3d304debc`である。2つのコミットの違いは、`params.rs`の表の既定値だけである。
実行ファイルのSHA-256は、候補が`7794223e…`、基準が`d7f7bc85…`、runner（版2.4.0）が`b35870aa…`である。
規則は`engine-default`（`L0,P0,R1,E0`）である。

## 環境

測定機は、Intel Core Ultra 7 265KF（性能コア8個と高効率コア12個、物理20コア、論理20スレッド）である。
両エンジンの`Threads`は1、`USI_Hash`は既定の256 MB、同時対局数は16である。
lishogiのBotは止めていない。ほかの対局測定、SPSA、教師生成、および学習は動いていなかった。
GSPRTの仮説は既定のelo0 = 0、elo1 = 10、α = β = 0.05である。

## 結果

| 量 | 値 |
|---|---:|
| 判定 | `H1` |
| 判定までのペア | 191（有効184、手数上限到達による破棄7） |
| ペンタノミアル度数 | [16, 7, 87, 11, 63] |
| LLR | +2.979 |
| エンジン異常 | 不正着手0、クラッシュ0、応答タイムアウト0、時間切れ0、拒否着手0 |
| 経過時間 | 1,948.4秒（`summary.json`の`active_wall_time_ns`） |

有効184ペアの度数から求めた候補の平均得点は0.633であり、Eloに直すと約+95、正規化したペア得点の分散から求めた95%信頼区間はおよそ+62〜+129である。
逐次検定は境界を越えた時点で止まるので、この点推定は真の差より大きめに出やすい。
保存されたペアは番号1〜225のうち222個であり、統計に入ったのはペア番号順に191番目までである。

## 結論

SPSAで係数を調整し直した候補は、係数を開始値に置いた形の変更より有意に強かった（約+95 Elo）。
[形の変更対起点のSTC](qsearch-forms-shape-vs-start-stc.md)の約+173 Eloと合わせると、起点からの差のうち形の変更の分が大きく、係数の調整し直しの分も大きい。
2本は相手が違い、Eloは厳密には足し合わせられないが、和の約+268は、調整機で測った候補対起点の約+261と同じ程度である。

# 標準ネットと第2世代の教師生成機の対局

## 目的

中将棋のP型評価関数の学習に使った2組の教師データについて、それぞれを生成したエンジンの棋力を比べた。下表の候補と基準を同じ開始局面から先後を入れ替えて対局させ、2局を1ペアとして候補側から見た棋力差を推定した。

## コマンドライン

`ROOT` は本体リポジトリのルートを指す。実行時の設定は測定ディレクトリの `manifest.json` にある。対局ハーネスの版は2.6.0で、ハーネスの実行ファイルのSHA-256は `b6066b1dee6eea6d8d6d3d1740778e7a0e5c4b387e22486bd8ec3a065c32897d` である。

```sh
minase match run --run-dir "$ROOT/data/tatara-p-diagnosis-20261119/teacher-generators" --candidate commit:31c2a465820007fe0136471cc5d239bd7202f8a1 --baseline commit:7c2cfe4eb868fe54ddcc31187a900efe3a30a7d4 --rules L0,P0,R1,E0 --each nodes=20000 --candidate-hash 16 --baseline-hash 16 --seed 20261119120000 --concurrency 3 elo --pairs 100
```

## エンジン

日本中将棋連盟の規則を表す `L0,P0,R1,E0` を使った。両エンジンは組み込みのネットを使用する。重みのSHA-256は各コミットの `crates/minase/nets/nnue.bin` から計算した。

## 環境

Intel Core Ultra 7 265KF（物理20コア、論理20コア）で3ペアを並行して測った。
探索は双方とも1スレッドで、置換表は候補16 MB、基準16 MBとした。

## 結果

100ペアのうち有効は99ペア、1ペアは手数上限に達した局を含むため破棄した。
候補から見たペアの得点が0、0.5、1、1.5、2点だった度数は順に `[79, 2, 16, 0, 2]` だった。
棋力差は-370.3 Eloで、95%信頼区間は-472.7〜-300.8 Eloだった。
不正着手、異常終了、応答のタイムアウト、時間切れ、着手の拒否はすべて0件だった。
累計実行時間は880.5秒だった。

## 結論

この条件では第2世代の教師生成機の得点率が高かった。

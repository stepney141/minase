# 教師30本で約2.05エポック学んだ旧型と終盤の教師値を付け直して浮動小数点で学習した新型の対局

tatara方式への移行で生じたA型評価関数の棋力低下を調べるため、検証のための対局を行った。
旧型はtatara方式への移行前のA型、新型は移行後のA型を指す。教師30本はmasterの標準ネットの学習に使った30ファイルである。
候補は教師30本で約2.05エポック学んだ旧型、基準は終盤の教師値を付け直して浮動小数点で学習した新型で、同じ開始局面から先後を入れ替えた2局を1ペアとした。
追加学習したモデルは、教師30本で約2.05エポック学んだ新型を出発点とし、訓練集合から抽出した262,144局面を2エポック学んだ。
終盤の教師値を付け直す条件では、駒が25枚以下の65,536局面をmaster標準ネットで各3,000ノード再探索した。

日本中将棋連盟の規則で双方に持ち時間10秒、1手につき0.1秒加算を与え、シード 20261119450000 から開始局面を生成した。
Intel Core Ultra 7 265KFで12ペアを並行実行し、両側とも探索は1スレッド、置換表は256 MBとした。

1020ペアのうち手数上限に達した対局を含む11ペアを除き、1009ペアを集計した。
2局合計で候補の得点が順に0、0.5、1、1.5、2点だったペア数は `[231, 39, 496, 47, 196]` で、得点率は48.46%だった。
基準に対する候補の棋力差は-10.7 Elo、95%信頼区間は-25.0〜+3.6 Eloだった。
対数尤度比は-2.9451942022、逐次検定の判定は `H0` だった。
エンジン異常、時間切れ、着手の拒否はいずれも0件だった。実行時間は11,172.3秒だった。

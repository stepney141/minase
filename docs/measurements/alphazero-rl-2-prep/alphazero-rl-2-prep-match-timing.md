# 2回目の学習の初期ネットによる作業機での対局の所要時間

## 目的

[2回目の実行の準備の設計書](../../plans/archived/alphazero-rl-2-prep.md)のフェーズ2として、20ブロック256チャネルの初期ネットどうしを、10サイクルごとの進捗測定と同じ条件（`NnBatchSize=16`、同時対局数2、1手800シミュレーション）で少数ペア対局させ、1手あたりの時間とGPUのメモリの最大値を測る。
[2回目の実行の設計書](../../plans/alphazero-rl-2.md)は、大きいバッチの推論の速さの比（1回目の学習の10ブロック128チャネルの4.3〜6.3分の1）から、200ペアの進捗測定を約10〜15時間と見積もっており、その見積もりを対局で確かめる。

## コマンドライン

測定日は2026年11月10日である。
`<wt>`はmasterのマージコミット`cd156c0ec18993bfc1a45450229f16b3f5bfa6a4`の作業ツリー、`$A`はNASの`/mnt/synology_nas/minase/alphazero`である。
1ペアの試走の後に、10ペアの本測定を行った。

```console
cd <wt>
N=$A/cycles-rl2/cycle-0000/model.onnx
S=docs/measurements/alphazero-rl-2-prep/alphazero-rl-2-prep-match-timing/progress-workstation.sh
# 試走
bash $S $N $N 16 1 20261110001 0 20261110002 data/matches/alphazero-rl-2-prep-match-timing-probe
# 本測定
bash $S $N $N 16 10 20261110011 4 20261110012 data/matches/alphazero-rl-2-prep-match-timing
```

[progress-workstation.sh](alphazero-rl-2-prep-match-timing/progress-workstation.sh)は10サイクルごとの進捗測定のスクリプトであり、引数は順に、1つ目のネット、2つ目のネット、`NnBatchSize`、MCTSどうしの対局のペア数とシード、探索なしのネットと乱択のエンジンの対局のペア数とシード、および出力先である。
スクリプトは、2つのネットのTensorRTのエンジンを先に作ってから、`minase match run`で`--each nodes=800 --concurrency 2 elo --pairs <ペア数>`の対局を行い、続けて1つ目のネットの探索なし（`nodes=1`）と乱択のエンジン`random`の対局を行う。
後者は進捗測定ではサイクル10でだけ行う対局であり、試走では0ペアとして省き、本測定では4ペア行った。
実行ディレクトリは、試走が`data/matches/alphazero-rl-2-prep-match-timing-probe/model-vs-model`、本測定が`data/matches/alphazero-rl-2-prep-match-timing/model-vs-model`と`model-nodes1-vs-random`である。
GPUのメモリは、対局の間に`nvidia-smi --query-gpu=memory.used`を1秒ごとに記録した。
`minase match run`の出力は、同じディレクトリの`model-vs-model.out`、`model-nodes1-vs-random.out`、および`probe-model-vs-model.out`にある。
1局ごとの手数と経過時間の集計は、比べる1回目の学習のサイクル30の進捗測定（`$A/progress/c0030-vs-c0020`）も含めて、同じディレクトリの[summarize.py](alphazero-rl-2-prep-match-timing/summarize.py)で行い、出力を[summarize.out](alphazero-rl-2-prep-match-timing/summarize.out)に置いた。

```console
python3 -I summarize.py $A/progress/c0030-vs-c0020 \
  data/matches/alphazero-rl-2-prep-match-timing-probe/model-vs-model \
  data/matches/alphazero-rl-2-prep-match-timing/model-vs-model
```

## エンジン

MCTSどうしの対局では、対局ハーネスの候補と基準のどちらにも、コミット`cd156c0e`でビルドした`minase --protocol usi --rules engine-default --search mcts`に同じ初期ネット（SHA-256 `8be01e2ed1608d4287853d8b43a871ce08d6f8dda4864b15ae966a62459683a6`）を与えたものを使った。
探索なしの対局では、候補を同じエンジンの`nodes=1`、基準を乱択のエンジン`random`とした。
USIオプションは`NnBatchSize=16`のほかは既定値であり、推論は既定のTensorRTのFP16で行った。
規則セットは`engine-default`、開始局面は対局ハーネスが初期局面から8〜12手を乱択で指した局面、手数の上限は4,096手である。

## 環境

作業機（Intel Core Ultra 7 265KF、20コア20スレッド、NVIDIA GeForce RTX 3060 Ti、GPUのメモリ8,192 MiB、ドライバ615.78.08）で、ONNX Runtime 1.28.3とTensorRT 10.14.1を使った。
同時対局数は2であり、測定の間に作業機でほかの対局の測定は動いていなかった。

## 結果

MCTSどうしの対局は、試走と本測定のどちらも全局が反復による引き分けであった。
時間切れ、反則、異常終了、および破棄したペアはなかった。

| 対局 | ペア（局数） | ペンタノミアル度数 | Elo | 全体の経過時間 | 1局の手数（平均、最小〜最大） | 1手あたりの経過時間 |
|---|---|---|---|---|---|---|
| 試走（MCTSどうし） | 1（2局） | [0, 0, 1, 0, 0] | 0 | 136.2秒 | 424（424〜424） | 0.160秒 |
| 本測定（MCTSどうし） | 10（20局） | [0, 0, 10, 0, 0] | 0 | 272.0秒 | 92.9（22〜252） | 0.290秒 |
| 本測定（探索なしと乱択） | 4（8局） | [3, 0, 1, 0, 0] | −338（95%区間の上限−117） | 19.7秒 | 606.9（44〜1,006） | 0.0072秒 |

1ペアは先後を入れ替えた2局であり、ペンタノミアル度数は、候補の2局の得点が0、0.5、1、1.5、2のペアの数である。
同時対局数2で2局ずつ並行して指すので、全体の経過時間は各局の経過時間の合計より短い。
1手あたりの経過時間は、各局の経過時間の合計を手数の合計で割った値であり、1局ごとのエンジンの起動などの固定費を含む。
そこで、MCTSどうしの22局（試走の2局と本測定の20局）について、1局の経過時間を「固定費＋1手あたりの時間×手数」とみて最小二乗法で当てはめると、固定費は8.44秒、1手あたりの時間は0.181秒であった（当てはめの残差の絶対値は最大17.2秒）。
同じ当てはめを、1回目の学習のサイクル30の進捗測定（10ブロック128チャネル、400局、1局平均495.3手、8,377秒）に行うと、固定費は1.52秒、1手あたりの時間は0.0808秒であり、20ブロック256チャネルの1手あたりの時間はその2.2倍である。

当てはめた固定費と1手あたりの時間を、サイクル30の進捗測定の400局の手数（合計198,109手）に当てはめると、同時対局数2で200ペアの所要時間は19,593秒（約5.4時間）となる。
これは、2回目の実行の設計書が大きいバッチの推論の速さの比から見積もった約10〜15時間より短い。
`NnBatchSize=16`の条件では、20ブロック256チャネルと10ブロック128チャネルの速さの比が、大きいバッチのときほど開かないとみられる（推論）。
探索なしのネットと乱択のエンジンの対局は4ペアで19.7秒であり、100ペアでも10分前後と見込まれる（推論）。

GPU全体のメモリの使用量は、本測定の間の最大が976 MiB（測定の前は57 MiB）、試走の間の最大が569 MiBであり、8,192 MiBに対して十分に余裕がある。
各エンジンのプロセスの常駐メモリの最大は1,489 MiBであった。

この測定の初期ネットの対局は短い反復で終わるので、学習したネットの対局とは手数の分布が異なる。
見積もりは、1手あたりの時間が手数と局面によらないとみなしており、学習したネットの探索でこれが成り立つかは確かめていない。
2回目の実行の設計書のとおり、サイクル10の測定を始める前に、サイクル10のネットで所要時間を見積もり直す。

## 結論

20ブロック256チャネルのネットの作業機での対局は、1手あたり10ブロック128チャネルの約2.2倍の時間で、GPUのメモリは1 GiB未満で収まり、200ペアの進捗測定は約5.4時間と見込まれる。

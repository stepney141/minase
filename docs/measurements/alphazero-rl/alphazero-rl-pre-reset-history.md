# リセット前のサイクル1〜37の学習の経過

## 目的

[強化学習の実行の設計書](../../plans/archived/alphazero-rl.md)の系列のうち、学習率を一定にしていたリセット前のサイクル1〜37について、価値と方策の学習の経過、投了、対局数、および終局の理由を残す。
この系列の出力と記録は2026年10月31日のリセットで削除したので、本書の値は削除の前にNASの記録ファイルから読んだものである。

## 結果

「検証の対局」は、学習に使わない最新サイクルの対局の約5%である。
「固定の検証用棋譜」は、生成と無関係なαβ探索の自己対局1,000局である。
損失は、各サイクルの最終の重みで測った。

| 項目 | 値 |
|---|---|
| 検証の対局の価値の損失（対局結果に対する） | サイクル1で0.742、サイクル6以後は0.612〜0.757、サイクル31〜37は0.629〜0.656、サイクル37で0.640 |
| 最新サイクルの訓練の標本の価値の損失 | サイクル37で0.586 |

| 固定の検証用棋譜の価値の損失 | サイクル6〜30で0.670〜0.763、下がる傾向なし |
| 検証の対局の方策の損失 | サイクル1の4.441からサイクル37の2.426へ低下 |

| 1サイクルの時間 | サイクル30の生成が1,115秒、学習の更新が143秒であり、学習の更新の143秒には読み込みの98秒と診断の11秒を含まない |

同じ系列の強さの伸びは、[20サイクル目の進捗測定](alphazero-rl-progress-c0020.md)にある。
サイクル20のネットは、サイクル10のネットに対して+456 Elo（95%信頼区間は+405〜+525）であった。

## 結論

方策の損失と一致率は着実に改善したが、検証の対局の価値の損失は、勝敗を常に五分と予測したときのln 2（約0.693）をわずかに下回るまでしか下がらなかった。
固定の検証用棋譜はαβ探索が指し継いだ対局であり、自己対局とは局面の分布が異なるので、その値が下がらないことは、自己対局の局面での価値の改善を否定する材料にはならない。

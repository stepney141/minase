# 強化学習の20サイクル目の進捗測定

## 目的

[強化学習の実行の設計書](../../plans/alphazero-rl.md)の「進捗測定」の節に従い、サイクル20のネットとサイクル10のネットを、PUCTの1手800シミュレーションの固定200ペアで比べてEloを記録し、伸びが止まっていないかを判定する。
あわせて、サイクル11〜20の学習の診断をまとめる。

## コマンドライン

[progress-workstation.sh](alphazero-rl-progress-c0020/progress-workstation.sh)を`progress-workstation.sh 0020 0010 16 10020 20020 <出力先>`として実行した。
800回の対局は[10サイクル目の記録](alphazero-rl-progress-c0010.md)と同じ形で、候補をサイクル20、基準をサイクル10のネットとし、`NnBatchSize=16`、`--each nodes=800 --concurrency 2 elo --pairs 200`、シード10020である。
続く探索なし（`nodes=1`）の乱択との100ペアはシード20020で行った。
スクリプトの最後のサイクル0の乱択との対局は、最初の進捗測定でだけ求められるもので、10サイクル目の実行ディレクトリが既にあるので開始時に失敗し、結果はない。
作業機での3者の出力の照合は[check.sh](alphazero-rl-progress-c0020/check.sh)、固定の検証用棋譜の診断は学習器の`external-eval`（αβの教師データ`generated-8200000.bin`、1,000局、シード20261030）で行った。

## エンジン

`minase`はブランチ`alphazero-rl`のworktreeでmasterのコミットd786c5e1と同じ`crates/`からリリースビルドしたものである。
サイクル20のネットは`nets/cycle-0020.onnx`（SHA-256 `2417f76907d8b11d659861a31bbb0ca80eb17958ee0481144beb40ed24ee3b83`）、サイクル10のネットは`nets/cycle-0010.onnx`（SHA-256 `6a44415f2645896468b7bb473fd1021fb680708bbd74a3e8a44006d74ae2a676`）である。
規則セットは`engine-default`（L0＋P0＋R1＋E0）である。
サイクル11〜20の生成と学習はコミットe66de512で行った。

## 環境

作業機（Intel Core Ultra 7 265KF、20コア20スレッド、GPUはRTX 3060 Ti 8 GB）で、2026年10月30日15時2分から17時27分に行った。
同じ時間帯に、Colab機でサイクル21〜24の生成と学習が走っていたが、作業機の資源は使わない。
MCTSは`Threads=1`、`USI_Hash`は既定、同時対局数は2である。

どちらも破棄したペアとエンジンの異常は0件で、経過時間は8,522秒と123秒であった（[出力](alphazero-rl-progress-c0020/c0020-vs-c0010.out)）。
10サイクル前のネットに対するEloの点推定は正なので、伸びは止まっていない。
10サイクル目の対局と比べて対局が長くなり、詰みと反復による終局が増えた。

### 作業機での照合

サイクル20のネットは作業機でも6通りとも合格し、TensorRTのFP16の価値の差は最大9.0×10⁻³であった（[ログ](alphazero-rl-progress-c0020/check.log)）。

方策の検証の損失は3.24から2.70へ下がった一方、対局結果に対する価値の損失は、検証集合で0.67〜0.76、固定の検証用棋譜で0.68〜0.72と、ln 2（約0.693）の付近で横ばいであった。

## 結論

サイクル20のネットはサイクル10のネットに対してElo +456（95%信頼区間+405〜+525）であり、強化学習は伸び続けている。
方策の学習は進む一方、価値の頭部の対局結果の予測は、検証集合でも生成と無関係な棋譜でもln 2の付近にとどまっている。

# 学び直した本線の10サイクル目の進捗測定

## 目的

2026年10月31日に学び直した強化学習の本線について、サイクル10のネットとサイクル0（ランダム初期化）のネットをPUCTの1手800シミュレーションで固定200ペア対局させて伸びを記録し、あわせてサイクル1〜10の経過、作業機での出力の照合、および生成と無関係な固定の検証用棋譜での診断を記録する。

## コマンドライン

作業機で次の3つを実行した。
`check.sh`と`progress-workstation.sh`は本記録と同じ名前のディレクトリにあり、学び直す前の[20サイクル目の進捗測定](alphazero-rl-progress-c0020.md)のものから、使う作業ツリーを本体のリポジトリに変えただけである。

```console
bash check.sh 0010
bash progress-workstation.sh 0010 0000 16 2026110110 2026110111 /mnt/synology_nas/minase/alphazero/progress
# 固定の検証用棋譜の診断（tools/train/zero で、サイクル0〜10の各チェックポイントについて実行した）
uv run --frozen python -m minase_zero external-eval --checkpoint <チェックポイント> \
  --data data/nnue-lr-schedule-gen/generated-8200000.bin --games 1000 --seed 20261030 --device cuda \
  --out /mnt/synology_nas/minase/alphazero/external/cycle-NNNN.json
```

`progress-workstation.sh`は、`minase match run`で、サイクル10対サイクル0を`--each nodes=800 --concurrency 2 elo --pairs 200`（シード2026110110）、探索なし（`nodes=1`）のサイクル10とサイクル0をそれぞれ乱択の`random`と`elo --pairs 100`（シード2026110111）で対局させる。
両エンジンのUSIオプションは`NnBatchSize=16`である。

## エンジン

両エンジンとも、masterのコミット33e94041をビルドしたminaseのMCTS（`--search mcts`）であり、規則は`engine-default`（`L0,P0,R1,E0`）である。
ネットはNASの`nets/cycle-0010.onnx`と`nets/cycle-0000.onnx`である。
サイクル1〜10の生成器と学習器のコミットは、サイクル1〜2がmasterの522192f3、サイクル3〜9の学習とサイクル4〜9の生成がf8eac7e9、サイクル10が29b01a5cであり、サイクル3の生成は522192f3の対局を新しい生成器で締めたものである（各サイクルの記録は`cycles.jsonl`にある）。
サイクル9までの手数の上限は1,000手、サイクル10からは3,000手である（[手数の上限のADR](../../adr/discard-zero-self-play-games-that-reach-3000-plies.md)）。

## 環境

作業機（Intel Core Ultra 7 265KF、20コア20スレッド、GPUはNVIDIA GeForce RTX 3060 Ti 8 GB）で、2026年11月1日14時24分から14時56分に行った。
推論はTensorRTのFP16、同時対局数は2である。

## 結果

サイクル10対サイクル0の200ペアのペンタノミアル度数は[0, 0, 1, 1, 198]であり、サイクル10の得点は400局中398.5であった。
Eloの点推定は+970、95%信頼区間は[+813, +∞]である。
破棄したペア、エンジンの異常、および時間切れは0件で、経過時間は1,513秒であった（[出力](alphazero-rl-restart-progress-c0010/c0010-vs-c0000.out)）。

探索なしの乱択との対局では、サイクル10が100ペアすべてに勝ち（[0, 0, 0, 0, 100]）、サイクル0は[11, 0, 33, 0, 56]でEloの点推定+168、95%信頼区間[+114, +232]であった。

作業機での出力の照合（`check.sh`）は、ONNX RuntimeのCPUとTensorRTのFP16の2通りをバッチ1、7、256で行い、6通りすべてが許容誤差内であった。
TensorRTのFP16の価値の差は最大0.0026（許容誤差5×10⁻²）、方策の確率の差は最大0.0070（許容誤差10⁻²）であった（[記録](alphazero-rl-restart-progress-c0010/check.log)）。

## 結論

サイクル10のネットはサイクル0に400局中398.5点で勝ち、生成と無関係なαβの棋譜に対する価値の損失はサイクル4以後0.60前後で、学び直す前の0.68〜0.71より低いが、サイクル4からは横ばいである。

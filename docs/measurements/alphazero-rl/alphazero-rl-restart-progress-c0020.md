# 学び直した本線の20サイクル目の進捗測定

## 目的

2026年10月31日に学び直した強化学習の本線について、サイクル20のネットとサイクル10のネットをPUCTの1手800シミュレーションで固定200ペア対局させて伸びを測定する。
あわせて、サイクル11〜20の経過、作業機での出力の照合、固定の検証用棋譜での診断、および引き延ばしの兆候を記録する。

## コマンドライン

作業機で次の3つを実行した。
`check.sh`と`progress-workstation.sh`は本記録と同じ名前のディレクトリにあり、[10サイクル目の進捗測定](alphazero-rl-restart-progress-c0010.md)のものから、サイクル0の乱択との対局を除いただけである。

```console
bash check.sh 0020
bash progress-workstation.sh 0020 0010 16 2026110120 2026110121 /mnt/synology_nas/minase/alphazero/progress
# 固定の検証用棋譜の診断（tools/train/zero で、サイクル13〜20の各チェックポイントについて実行した）
uv run --frozen python -m minase_zero external-eval --checkpoint <チェックポイント> \
  --data data/nnue-lr-schedule-gen/generated-8200000.bin --games 1000 --seed 20261030 --device cuda \
  --out /mnt/synology_nas/minase/alphazero/external/cycle-NNNN.json
# 引き延ばしの兆候の集計（alphazero-rl-long-games/ のスクリプト）
uv run --frozen --project tools/train/zero python long_trend.py /mnt/synology_nas/minase/alphazero/cycles/cycle-0020
```

`progress-workstation.sh`は、`minase match run`で、サイクル20対サイクル10を`--each nodes=800 --concurrency 2 elo --pairs 200`（シード2026110120）で対局させる。
あわせて、探索なし（`nodes=1`）のサイクル20を、乱択の`random`と`elo --pairs 100`（シード2026110121）で対局させる。
両エンジンのUSIオプションは`NnBatchSize=16`である。

## エンジン

両エンジンとも、masterのコミットd673bc1fと同じソースをビルドしたminaseのMCTS（`--search mcts`）であり、規則は`engine-default`（`L0,P0,R1,E0`）である。
ネットはNASの`nets/cycle-0020.onnx`と`nets/cycle-0010.onnx`である。
サイクル11〜13の生成器と学習器のコミットは29b01a5c、サイクル14の生成は29b01a5cで学習はd0e22dbf、サイクル15〜20はd0e22dbfである。
サイクル13までのリプレイバッファはサイクル1から、サイクル14からはサイクル3から始まる（[リプレイバッファのADR](../../adr/sample-four-times-from-a-zero-replay-buffer-of-ten-times-the-parameter-count-from-cycle-3.md)）。

## 環境

作業機（Intel Core Ultra 7 265KF、20コア20スレッド、GPUはNVIDIA GeForce RTX 3060 Ti 8 GB）で、2026年11月1日23時10分から11月2日0時57分に行った。
推論はTensorRTのFP16、同時対局数は2である。
固定の検証用棋譜の診断を同じGPUで同時に実行した時間帯がある。
対局はノード数の制限なので、時間には影響するが、制限の内容には影響しない。

## 結果

サイクル20対サイクル10の有効な199ペアのペンタノミアル度数は[0, 8, 49, 70, 72]であり、サイクル20の1局あたりの得点は0.759であった。
Eloの点推定は+199、95%信頼区間は[+171, +229]である。
1ペアが、ハーネスの手数の上限4,096手に達して破棄された。
エンジンの異常と時間切れは0件で、経過時間は6,290秒であった（[出力](alphazero-rl-restart-progress-c0020/c0020-vs-c0010.out)）。
400局の長さは中央値278.5手、90パーセンタイル896手であり、終局は反復が155局、詰みが131局、王駒の捕獲が113局、手数の上限が1局であった。
学び直す前の同じ組の測定は+456であったが（[記録](alphazero-rl-progress-c0020.md)）、基準のサイクル10の強さが異なるので直接は比べられない。

探索なし（`nodes=1`）での乱択との対局では、サイクル20が100ペアすべてに勝った（[0, 0, 0, 0, 100]）。

作業機での出力の照合（`check.sh`）は、ONNX RuntimeのCPUとTensorRTのFP16の2通りをバッチ1、7、256で行い、6通りすべてが許容誤差内であった（[記録](alphazero-rl-restart-progress-c0020/check.log)）。

αβの指し手との一致率も、サイクル13の0.032からサイクル14で0.039に上がった。
この変化はサイクル14のリプレイバッファの変更と時期が一致するが、1回の変化であり、リプレイバッファの変更が原因であるとは確かめていない。

引き延ばしの兆候は見られない。
1局の手数はサイクル11の589手からサイクル20の475手へ縮み、自己対局の引き分けは14.5%から8.4%へ減り、3,000手での破棄は0.1%以下であった。
サイクル20の800手以上の1,061局のうち、600手目で評価値が有利な側が勝った割合は86.8%（569局中）で、[上限の調査](alphazero-rl-long-games.md)のサイクル8の86.0%と同じ水準である。

## 結論

サイクル20のネットはサイクル10にEloの点推定+199［+171, +229］で勝ち、伸びは止まっておらず、手数の上限を3,000手に上げた後も引き延ばしの兆候はない。

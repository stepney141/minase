# 学び直した本線の30サイクル目の進捗測定

## 目的

2026年10月31日に学び直した強化学習の本線について、サイクル30のネットとサイクル20のネットをPUCTの1手800シミュレーションで固定200ペア対局させて伸びを測定する。
あわせて、サイクル21〜32の経過、作業機での出力の照合、固定の検証用棋譜での診断、および引き延ばしの兆候を記録する。

## コマンドライン

作業機で次の3つを実行した。
`check.sh`と`progress-workstation.sh`は本記録と同じ名前のディレクトリにあり、[20サイクル目の進捗測定](alphazero-rl-restart-progress-c0020.md)のものと同じである。

```console
bash check.sh 0030
bash progress-workstation.sh 0030 0020 16 2026110230 2026110231 /mnt/synology_nas/minase/alphazero/progress
# 固定の検証用棋譜の診断（tools/train/zero で、サイクル21〜30の各チェックポイントについて実行した）
uv run --frozen python -m minase_zero external-eval --checkpoint <チェックポイント> \
  --data data/nnue-lr-schedule-gen/generated-8200000.bin --games 1000 --seed 20261030 --device cuda \
  --out /mnt/synology_nas/minase/alphazero/external/cycle-NNNN.json
# 引き延ばしの兆候の集計（alphazero-rl-long-games/ のスクリプト）
uv run --frozen --project tools/train/zero python long_trend.py /mnt/synology_nas/minase/alphazero/cycles/cycle-0030
```

`progress-workstation.sh`は、`minase match run`で、サイクル30対サイクル20を`--each nodes=800 --concurrency 2 elo --pairs 200`（シード2026110230）で対局させる。
あわせて、探索なし（`nodes=1`）のサイクル30を、乱択の`random`と`elo --pairs 100`（シード2026110231）で対局させる。
両エンジンのUSIオプションは`NnBatchSize=16`である。

## エンジン

両エンジンとも、masterのコミット43bf6962と同じ`crates/`をビルドしたminaseのMCTS（`--search mcts`）であり、規則は`engine-default`（`L0,P0,R1,E0`）である。
ネットはNASの`nets/cycle-0030.onnx`と`nets/cycle-0020.onnx`である。
サイクル21〜25の生成器と学習器のコミットは6c9b9cda、サイクル26〜32はaa9a7fa8である。
サイクル21〜25は重みの移動平均も書き出したが、自己対局と本測定には使っていない（[移動平均のADR](../../adr/do-not-keep-a-moving-average-of-the-zero-network-weights.md)）。

## 環境

作業機（Intel Core Ultra 7 265KF、20コア20スレッド、GPUはNVIDIA GeForce RTX 3060 Ti 8 GB）で、2026年11月2日9時37分から11時59分に行った。
推論はTensorRTのFP16、同時対局数は2である。
固定の検証用棋譜の診断を同じGPUで同時に実行した。
対局はノード数の制限なので、時間には影響するが、制限の内容には影響しない。

## 結果

サイクル30対サイクル20の200ペアのペンタノミアル度数は[1, 6, 36, 69, 88]であり、サイクル30の1局あたりの得点は0.796であった。
Eloの点推定は+237、95%信頼区間は[+206, +271]である。
破棄したペア、エンジンの異常、および時間切れは0件で、経過時間は8,377秒であった（[出力](alphazero-rl-restart-progress-c0030/c0030-vs-c0020.out)）。
400局の長さは中央値471.5手、90パーセンタイル924手であり、終局は詰みが157局、王駒の捕獲が150局、反復が93局であった。

探索なし（`nodes=1`）での乱択との対局では、サイクル30が100ペアすべてに勝った（[0, 0, 0, 0, 100]）。

作業機での出力の照合（`check.sh`）は、ONNX RuntimeのCPUとTensorRTのFP16の2通りをバッチ1、7、256で行い、6通りすべてが許容誤差内であった（[記録](alphazero-rl-restart-progress-c0030/check.log)）。

固定の検証用棋譜の価値の損失は、サイクル20の0.573からサイクル30の0.562へ下がり、αβの指し手との一致率は0.043から0.052へ上がった（[診断の出力](alphazero-rl-restart-progress-c0030/external/)）。

引き延ばしの兆候のうち、1局の手数、引き分け、および3,000手での破棄は、いずれも減る方向にある。
一方、800手以上の対局で600手目に評価値が有利な側が勝った割合は、サイクル20の86.8%（569局中）からサイクル30の78.4%（519局中）へ下がった。
駒数が多い側が勝った割合も76.3%から66.1%へ下がった。
この集計は投了以外で終えた対局だけを数えるので、差のついた対局が早く終わるようになると、残る長い対局は差の小さいものに偏る。
下がった原因がこの偏りなのか、評価値の精度なのかは調べていない。

## 結論

サイクル30のネットはサイクル20にEloの点推定+237［+206, +271］で勝ち、伸びは止まっていない。

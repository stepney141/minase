# 学習窓からの抽出の作業機での事前確認

## 目的

[強化学習の実行の設計書](../../plans/alphazero-rl.md)の「学習窓と局面の抽出」の節の規則を実装した学習器で、サイクル1〜6の実データの窓からサイクル6の局面数を抽出して学び、読み込みの時間と最大常駐メモリが抽出の数に見合うこと、および価値の損失の訓練と検証の差を、Colab機でサイクル6を学び直す前に作業機で確かめる。

## コマンドライン

NASの`/mnt/synology_nas/minase/alphazero`を作業ディレクトリにして、次を実行した。
`--data`はサイクル1〜6の生成の`training_files`を古い順に並べた240ファイル、`--latest-data`はそのうちサイクル6の40ファイルである。

```console
PYTHONPATH=<worktree>/tools/train/zero nice -n 19 /usr/bin/time -v uv run --frozen --project <worktree>/tools/train/zero \
  python -m minase_zero train --init cycles/cycle-0005/train/checkpoint.pt \
  --data <サイクル1〜6の240ファイル> --latest-data <サイクル6の40ファイル> \
  --out-dir <作業用のディレクトリ> --cycle 6 --seed 20261106 --batch-size 256 --lr 0.01 --momentum 0.9 \
  --weight-decay 0.0001 --clip-grad-norm 10 --value-lambda 0.333 --precision bf16 --checkpoint-steps 200 \
  --device cuda --trainer-commit e66de512c9e4bf9f68a09ca6d62677ce521bb1da
```

出力は作業用のディレクトリに置き、強化学習の記録には使っていない。

## エンジン

学習器は、ブランチ`alphazero-rl`のコミットe66de512である。
初期値は、サイクル5の最終のチェックポイント（直近1サイクルの全局面で学んだもの）である。

## 環境

作業機（Intel Core Ultra 7 265KF、20コア20スレッド、GPUはRTX 3060 Ti 8 GB）で、2026年10月30日7時に、作業機の再起動の直後でほかの負荷がない状態で実行した。

## 結果

窓の訓練局面のうち、サイクル6の訓練局面の数831,804を抽出し、3,250回の更新で学んだ（[集計](alphazero-rl-window-precheck/summary.json)、[学習曲線](alphazero-rl-window-precheck/train.log)）。
検証集合は、サイクル6の検証の分割の40,203局面（128局）である。

| 項目 | 値 |
|---|---|
| 読み込み（計数、240ファイルの再生、検査和） | 20.7秒 |
| 学習 | 180.0秒（毎秒4,621局面） |
| 診断 | 6.3秒 |
| 最大常駐メモリ（`time -v`） | 3.1 GB |
| プロセス全体の経過時間 | 3分37秒 |

サイクル1〜5の直近1サイクルの全局面を読む方式では、100万局面の読み込みに約55秒、メモリ1局面あたり約1.2 KBを使っていた。
窓は約730万局面に広がったが、読み込みは20.7秒、メモリは抽出の数に見合う大きさにとどまった。

最終の重みでの対局結果に対する価値の損失は、次のとおりである。

| 集合 | 対局数 | 局面数 | 価値の損失（対局結果） | 方策の損失 |
|---|---|---|---|---|
| 抽出した局面の訓練の標本（窓全体） | 1,851 | 43,801 | 0.535 | 3.905 |
| 同じ標本のうちサイクル6のもの | 124 | 5,344 | 0.579 | 3.375 |
| サイクル6の検証集合 | 128 | 40,203 | 0.731 | 3.449 |

直近1サイクルの全局面で学んで照合に通らなかったサイクル6のネットでは、同じサイクル6の対局について、訓練の標本で0.271、検証集合で0.809であった。
最新のサイクルの訓練の標本と検証集合の差は、0.538から0.152へ縮んだが、検証の値はまだln 2（約0.693）を上回っている。

## 結論

学習窓からの抽出は、約730万局面の窓でも読み込み20.7秒、最大常駐メモリ3.1 GBで動き、価値の損失の訓練と検証の差を縮めたので、この学習器でColab機のサイクル6から学び直す。

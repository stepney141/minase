# 世代1NNUEのbench NPS（深さ5）

## 目的

世代1のP型NNUE（コミット`e0b8314`）のbench NPSを深さ5で測り、採用PST（コミット`af200b4`）に対する探索速度の低下を診断指標として記録する。

## コマンドライン

コマンドラインの原文は記録なし。
条件は`bench`の深さ5、3回実行の中央値である。

## エンジン

対象は分岐`nnue-gen1`のコミット`e0b831439eb9023be09e0790a1ce3ffa21396655`（残差線形項つきP型NNUE、エポック6のネットを埋め込む）であり、比較値はbench-pst-gen1-depth5.mdの採用PST（コミット`af200b4`）の1,314,504である。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア）である。
2026年8月28日に、他の対局を走らせずに測った。
`Threads`と`USI_Hash`の設定は記録なし。

## 結果

NNUEのbench NPSは1,071,104（ノード数5,680,925、経過5.30秒）で、採用PSTの1,314,504より18.5%低い。
評価呼び出し1回と差分更新1回の単体計測は、前マイルストーンと同じコードであるため再計測せず、前回の値（第2層以降の推論0.68マイクロ秒、差分更新0.068マイクロ秒）を引用する。

分岐`nnue-gen1`のエポック0ネット（線形項だけを持つ）で2026年8月27日に16並列の世代1生成と同時に測った参考値669,500（ノード数は3回とも6,479,633）は、負荷下の値であり診断指標としない。

## 結論

NNUEは同じ探索コードでNPSを18.5%下げ、この低下は時間制御GSPRT（nnue-gen1-tc.md）の解釈で持ち時間0.815倍に相当する速度の代価として扱う。

# 再学習PSTのbench NPS（深さ5）

## 目的

採用した再学習の学習PST（コミット`af200b4`）のbench NPSを深さ5で測り、前マイルストーンの学習PST（コミット`7e13888`）と比べて評価関数の変更が探索速度を変えていないことを確認する。

## コマンドライン

コマンドラインの原文は記録なし。
条件は`bench`の深さ5、3回実行の中央値である。

## エンジン

対象は再学習した学習PSTのコミット`af200b4c4b38e0493dabcfa23c2b4c0b4558bf2b`であり、比較値は前マイルストーンの学習PST（コミット`7e13888`）の同条件のbench NPS（bench-pst-gen0-nps.md）である。
両者の探索コードは同一である。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア）である。
2026年8月28日18時50分（JST）に、他の対局を走らせずに測った。
`Threads`と`USI_Hash`の設定は記録なし。

## 結果

再学習PSTのbench NPSは1,314,504（ノード数6,533,492、経過4.97秒）であり、前マイルストーンの学習PSTは1,295,869であった。

## 結論

再学習PSTのNPSは前マイルストーンの学習PSTと同じ水準であり、探索コードは変わっていないので差は評価値の分布の変化による探索木の違いだけを反映する。

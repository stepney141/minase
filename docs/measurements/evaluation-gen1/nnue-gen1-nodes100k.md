# 世代1NNUE対再学習PSTの固定ノードGSPRT

## 目的

世代0と世代1の1,106万局面で学習した残差線形項つきP型NNUE（候補）を、同じデータで再学習した学習PST（基準）と固定ノード100,000で対局させ、同じノード予算での棋力差を診断指標として判定する。

## コマンドライン

```console
cargo run --release --bin match_runner -- \
  --run-dir data/matches/nnue-gen1-nodes100k --seed 20260830 \
  --candidate commit:e0b8314 --baseline commit:af200b4 \
  --each nodes=100000 --concurrency 16 gsprt
```

実行に使った`match_runner`は、対局ハーネスの効率化（`--run-dir`と再開、`match_report`）を含む作業ツリーからビルドしたバイナリ（SHA-256 `da126857f6961975f74107e1f9823a0bf26ff1f69dcfe69c323178914c033f22`）であり、その内容は後にコミット`3b35793`としてmasterへ入った。

## エンジン

候補は分岐`nnue-gen1`のコミット`e0b831439eb9023be09e0790a1ce3ffa21396655`（採用PSTのコミット`af200b4`を含むmasterの子で、第1層の初期化を修正した学習器で学習したエポック6のネットを埋め込む）であり、バイナリのSHA-256は`c6b0f8483fa251dd9fab7d38abd2fe11d428089edc3ade37d7f820d11172a503`である。
基準は再学習した学習PSTのコミット`af200b4c4b38e0493dabcfa23c2b4c0b4558bf2b`であり、バイナリのSHA-256は`4f0db5ba4a19fb03766803f352bc046884840232abb3b701a4ebb300c0c3cc9e`である。
規則セットは`engine-default`（L0＋P0＋R1＋E0）を両エンジンと審判層に与えた。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ33,218,965,504バイト）であり、OSはLinuxである。
候補と基準のワーカー数はいずれも`Threads=1`、`USI_Hash`はいずれも256 MB、同時対局数は16、手数上限は4,096手、応答タイムアウトは120秒とした。

## 結果

2026年8月28日19時28分（JST）に開始し、21時00分に判定`H0`で終了した。
ペア数は1,159（有効1,151、手数上限による破棄8）、ペンタノミアル度数は`[315, 10, 590, 11, 225]`、LLRは−2.967、判定は`H0`である。
エンジン異常、`time_forfeits`、および拒否着手はいずれも0件であり、経過は5,447秒である。
候補の得点率は46.1%（2連勝225ペア、2連敗315ペア）で、約−27 Eloに相当する。

## 結論

同じノード数では世代1のNNUEは再学習PSTより有意に弱く、検証損失が再学習PSTを0.00018下回るにもかかわらず対局で劣ることは、損失の改善が棋力の証拠にならないことを示す。

# 再学習PST対現行PSTの固定ノードGSPRT

## 目的

世代0と世代1を合わせた1,106万局面で再学習した学習PST（候補）を、現行の学習PST（基準）と固定ノード100,000で対局させ、同じノード予算での棋力差を診断指標として判定する。

## コマンドライン

```console
cargo run --release --bin match_runner -- \
  --run-dir data/matches/pst-gen1-nodes100k --seed 20260828 \
  --candidate commit:af200b4 --baseline commit:bfeb1aa \
  --each nodes=100000 --concurrency 16 gsprt
```

実行に使った`match_runner`は、対局ハーネスの効率化（`--run-dir`と再開、`match_report`）を含む作業ツリーからビルドしたバイナリ（SHA-256 `da126857f6961975f74107e1f9823a0bf26ff1f69dcfe69c323178914c033f22`）であり、その内容は後にコミット`3b35793`としてmasterへ入った。

## エンジン

候補は再学習した学習PSTのコミット`af200b4c4b38e0493dabcfa23c2b4c0b4558bf2b`（親はmaster、探索コードは基準と同一）であり、バイナリのSHA-256は`4f0db5ba4a19fb03766803f352bc046884840232abb3b701a4ebb300c0c3cc9e`である。
基準は現行の学習PSTのコミット`bfeb1aa284c934b1eec5e692808d0914d2facf8d`であり、バイナリのSHA-256は`480aaaf7a92d91c719cbec5aa2cc9c6ab98ac3013390db310473a93c208f883c`である。
規則セットは`engine-default`（L0＋P0＋R1＋E0）を両エンジンと審判層に与えた。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ33,218,965,504バイト）であり、OSはLinuxである。
候補と基準のワーカー数はいずれも`Threads=1`、`USI_Hash`はいずれも256 MB、同時対局数は16、手数上限は4,096手、応答タイムアウトは120秒とした。
この測定はNNUEのGPU学習と並行して実行した。

## 結果

2026年8月28日13時30分（JST）に開始し、13時52分に判定`H1`で終了した。
ペア数は224（有効223、手数上限による破棄1）、ペンタノミアル度数は`[6, 0, 58, 0, 159]`、LLRは2.952、判定は`H1`である。
エンジン異常（不正着手、クラッシュ、タイムアウト）、`time_forfeits`、および拒否着手はいずれも0件であり、経過は1,319秒（`summary.json`の`active_wall_time_ns`は1,318.6秒）である。
候補の得点率は84.3%（2連勝159ペア、1勝1敗58ペア、2連敗6ペア、引き分けなし）で、終局はほぼすべて詰みである。

## 結論

固定ノードでは再学習PSTが現行PSTより有意に強いが、評価値の尺度がモデル出力Kの変更（807から1,073）で約33%拡大し枝刈りの効き方も変わっているため、この結果は診断指標にとどめ、採否は時間制御GSPRT（pst-gen1-tc.md）で決めた。

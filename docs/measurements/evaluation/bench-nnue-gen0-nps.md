# bench-nnue-gen0-nps

## 目的

世代0で学習したP型NNUE（段階2）への差し替えによるbenchのNPSの低下を、学習PSTおよびv0と比べ、SIMD追加の予算（現行比40%）の内側にあるかを記録する。

## コマンドライン

`cargo run --release --bin bench`を深さ5で3回実行し、NPSの中央値を採った。
引数の全体は記録なし。
推論と差分更新の単体計測は10万回の呼び出しで行った（計測手順の詳細は記録なし）。

## エンジン

候補はコミット05362b1（P型NNUE、世代0の学習済みネット）である。
比較対象は学習PST（bench-pst-gen0-nps.md の1,295,869）とv0（同1,423,417）である。

## 環境

CPU型、物理コア数、論理コア数は記録なし。
`Threads=1`である。

## 結果

NNUEのNPSは888,257で、学習PST比−31%、v0比−38%である。
単体計測では、第2層以降の推論が1回あたり0.68マイクロ秒、通常手の差分更新が0.068マイクロ秒であり、探索1ノードあたり約0.77マイクロ秒（学習PSTでのNPS 1.30M）に対して推論の費用が支配的である。
対局ではないため、ペンタノミアル度数、LLR、破棄ペア数、異常件数、`time_forfeits`、経過時間は該当しない。

## 結論

NPSの低下はSIMDを追加する予算（現行比40%）の内側にあり、明示的なSIMD命令は追加しない。

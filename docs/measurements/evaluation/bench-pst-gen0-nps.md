# bench-pst-gen0-nps

## 目的

学習PST（段階1）への差し替えによるbenchのNPS（1秒あたりの探索ノード数）の低下を、駒得評価関数v0と比べて記録する。

## コマンドライン

`cargo run --release --bin bench`を深さ5で3回実行し、NPSの中央値を採った。
引数の全体は記録なし。

## エンジン

基準はコミット739634d（v0、学習PST導入の直前）である。
候補は学習PSTの初版と、駒状態の計算を呼び出しごとの数え直しからコンパイル時に作る表へ置き換えた版の2つであり、それぞれのコミットは記録なし。

## 環境

CPU型、物理コア数、論理コア数は記録なし。
`Threads=1`である。

## 結果

v0のNPSは1,423,417、学習PST初版は1,221,178（−14%）、駒状態の表を置き換えた版は1,295,869（−9%）である。
対局ではないため、ペンタノミアル度数、LLR、破棄ペア数、異常件数、`time_forfeits`、経過時間は該当しない。

## 結論

残りの−9%は特徴の列挙と重みの参照そのものの費用であり、設計書の方針どおり採否は時間制御GSPRT（pst-gen0-tc.md）に吸収させた。

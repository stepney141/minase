# pst-gen0-nodes100k

## 目的

世代0の自己対局データで学習した学習PST（段階1）の初版と、着手前の駒得評価関数v0の最終コミット（v0基準）を、両エンジンに同じ探索ノード数を与える固定ノードGSPRTで比べ、探索速度の差を除いた評価の質で学習PSTが有意に強いかを判定する。

## コマンドライン

```console
cargo run --release --bin match_runner -- --candidate commit:588363a --baseline commit:e553493 --each nodes=100000 --concurrency 8 --seed 20260826 gsprt
```

この測定は`--run-dir`の導入前に実施したため、実行ディレクトリは残っていない。
測定名は本記録で付けた名前である。

## エンジン

候補はコミット588363a（学習PSTの初版）、基準はコミットe553493（v0基準）である。
規則セットはコマンドラインで指定せず、`commit:`指定でハーネスが自動付与する既定の規則セットを両エンジンに与えた（名前は記録なし）。

## 環境

CPUはIntel Core Ultra 7 265KF（20コア。論理コア数は記録なし）、両エンジン`Threads=1`、`USI_Hash`は既定、同時対局数は8である。

## 結果

ペア数は638（有効634、手数上限4,096による破棄4）、ペンタノミアル度数は[100, 2, 328, 1, 203]、LLRは2.951、判定は`H1`である。
`engine_failures`はすべて0であり、`time_forfeits`は固定ノード数の対局のため該当しない。
経過時間は5,859秒である。
候補の得点率は58.1%（約+57 Elo）である。

## 結論

速度差を除いた評価の質では学習PSTがv0に有意に勝る（`H1`）が、採否は時間制御GSPRT（pst-gen0-tc.md）で決める。

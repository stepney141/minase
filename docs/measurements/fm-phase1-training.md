# FM補正項の第1フェーズの学習

## 目的

[Factorization Machineによる2駒関係評価](../plans/factorization-machine.md)の第1フェーズとして、現行の2端点PSTを固定し、既存の世代0と世代1のデータでFMの補正項を潜在次元16、32、64について学習して、候補を1つに絞れるかを確定する。

## コマンドライン

学習は[PSTの学習手順](../pst-training.md)のワークフローのモデル種別`fm`で実行した。
設定ファイルはworktree `minase-fm` の `fm-<条件>.toml` であり、条件ごとに `run.directory`、`train.rank`、`train.lambda_res`、`train.lambda`、`train.learning_rate` だけが異なる。

```console
tools/train/.venv/bin/python tools/train/pst/pst_workflow.py prepare --config fm-<条件>.toml
tools/train/.venv/bin/python tools/train/pst/pst_workflow.py train --run-dir data/fm-<条件>
```

生成シードは空配列であり、既存の6ファイル（`data/gen0.bin`と`data/gen1-s{100000,200000,300000,400000,500000}.bin`、訓練10,520,846局面、検証541,965局面）だけで学習した。
共通の学習条件はAdamW、学習率0.001、重み減衰0.0001、最大20エポック、忍耐3エポック、バッチ4,096、乱数シード1、CUDAであり、1エポックは2,569更新である。
設計書の初回条件は教師探索値の比率λ=0.75、補正量の正則化係数λres=0.001である。

## エンジン

基準コミットは開始版`b0153cf27df655a32cb9a255fd380b21bba002b5`であり、その`nets/pst.bin`（SHA-256 `b172a1b3e1c620bbdb1b2f22d0c5ebc9fa11a891703d88c59c710301173feb5a`）の2端点PST、探索用駒価値、および出力K=1072.6529541015625を固定した。
世代別の教師Kは804.030と1099.675である。
規則セットは`L0,P0,R1,E0`である。

## 環境

Intel Core Ultra 7 265KF（20コア）、メモリ30 GB、NVIDIA GeForce RTX 3060 Ti 8 GB、Python 3.12.14、PyTorch 2.13.0+cu130、CUDA 13.0である。
1本の学習は3エポックで約4分であり、ボトルネックはCPU側の特徴生成である。

## 結果

### 学習曲線

すべての条件で、初期状態（FMの補正が0）の検証損失は開始版の記録と同じ0.509634である。
最初の5更新の損失勾配は、出力係数が非0、埋め込みが1更新目だけ0でその後は非0であり、初期化の意図どおりである。
訓練集合とその鏡映で数えた未観測特徴は4,422個である。

| 条件 | 初期の検証損失 | 訓練損失（エポック1/2/3） | 検証損失（エポック1/2/3） | 補正の標準偏差（ロジット、最終エポック） | 最良エポック |
|---|---|---|---|---|---|
| 潜在次元32、λ=0.75、λres=1e-3 | 0.509634 | 0.504690 / 0.503458 / 0.502879 | 0.510292 / 0.510730 / 0.510859 | 0.191 | 0 |
| 潜在次元16、λ=0.75、λres=1e-3 | 0.509634 | 0.504974 / 0.504236 / 0.503879 | 0.509840 / 0.510086 / 0.510088 | 0.153 | 0 |
| 潜在次元64、λ=0.75、λres=1e-3 | 0.509634 | 0.504263 / 0.502290 / 0.501409 | 0.511040 / 0.511917 / 0.512153 | 0.231 | 0 |
| 潜在次元32、λ=0.75、λres=1e-2 | 0.509634 | 0.504767 / 0.503674 / 0.503174 | 0.510111 / 0.510456 / 0.510551 | 0.162 | 0 |
| 潜在次元32、λ=0.75、λres=1e-1 | 0.509634 | 0.505073 / 0.504530 / 0.504290 | 0.509645 / 0.509720 / 0.509709 | 0.079 | 0 |

設計書の初回条件では、3つの潜在次元すべてで訓練損失が1エポック目から開始版の訓練損失（0.505368）を下回る一方、検証損失は1エポック目から上がり、次元が大きいほど乖離が大きい。
正則化係数を100倍にしても検証損失は初期状態を下回らず、補正の標準偏差が0.08ロジットまで抑えられるだけである。
これは設計書が定める「訓練損失が下がって検証損失が上がる」過学習の形である。

### 過学習の原因の切り分け

教師値の対局結果の成分は同じ対局のすべての局面で一定であり、2駒関係は動かない駒の組で対局を識別できるため、この成分を記憶できるという仮説を立て、λ=1.0（教師探索値だけ）と学習率1e-4の2条件を潜在次元16で追加した。

学習率1e-4の条件は、λ=1.0の結果で仮説が支持されたため実行前に取りやめた。

| 条件 | 初期の検証損失 | 訓練損失（エポック1/10/20） | 検証損失（エポック1/10/20） | 補正の標準偏差（ロジット、最終エポック） | 最良エポック | 量子化（指数、平均誤差、最大誤差） |
|---|---|---|---|---|---|---|
| 潜在次元16、λ=1.0、λres=1e-3 | 0.510763 | 0.507507 / 0.506805 / 0.506748 | 0.508489 / 0.508211 / 0.508181 | 0.216 | 20 | k=9、0.518 cp、1.680 cp |

λ=1.0では教師値が変わるので初期の検証損失はλ=0.75の値と比較できないが、同じ教師値の下でFMの補正は検証損失を初期状態から0.002582下げ、20エポックの上限まで単調に下がり続けた。
訓練損失と検証損失の差は0.0014にとどまり、λ=0.75で見られた乖離は生じていない。
補正の標準偏差は約0.22ロジット（出力尺度で約230センチポーン）、最大絶対値は約2.2ロジットであり、PSTが残す探索値との差が大きいことを示す。

（λ=1.0の潜在次元32と64、および候補次元の追加シードは学習完了後に追記する。）

# 凍結ベースライン対randomの移行検証

## 目的

対局ハーネスをUSIプロセス方式へ差し替えた直後の移行検証として、凍結ベースライン（コミット0045833のバイナリに`depth=1`を指定したもの）がランダム着手エンジン`random`に全勝することを再現し、in-process時代の同一シード実行と同じ結果になるかを確認する。

## コマンドライン

記録なし。
設計書に残る条件は、候補が凍結ベースライン（0045833、`depth=1`）、基準が`random`、100ペアで停止したことであり、モード（GSPRTか固定局数Eloか）とシードは記録なし。

## エンジン

候補はコミット0045833（`depth=1`）、基準は同一ビルドの`usi_random`（予約spec `random`）である。
規則セットは記録なし。

## 環境

2026年8月11日にフェーズ2（プロセス供給層への差し替え）完了時点の逐次実行で測定した。
CPU型、コア数、ワーカー数、`USI_Hash`、同時対局数は記録なし。

## 結果

ペンタノミアル度数は[0, 0, 0, 0, 100]で、100ペア200局に全勝した。
全勝のためロジスティックEloの点推定は無限大であり、信頼区間は記録なし。
破棄ペア数と異常件数は0、経過時間は2.6秒だった。
固定深さ対局のため`time_forfeits`は該当しない。

## 結論

凍結ベースラインは`random`に100ペア全勝し、in-process時代の結果をプロセス方式で再現した。

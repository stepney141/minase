# HaChu対minaseの探索深さとNPSの実測

## 目的

等時間で−252 Eloだった差の要因分析として、同一持ち時間（60秒＋1秒加算）における両エンジンの探索深さと1秒あたり探索ノード数（NPS）を比較し、探索量の差が主因かを確認する。

## コマンドライン

記録なし。
自己対局の各24手について、両エンジンの思考出力から深さとNPSを読み取った。

## エンジン

minaseはコミットa49bd46、HaChuはDebianパッケージ収録のオリジナル版（コミットdf26f4a、`gcc -O2`でビルド、規則オプションは既定）である。
規則セットは記録なし。

## 環境

時間制御は60秒＋1秒加算である。
CPU型、コア数、ワーカー数、`USI_Hash`、同時対局数は記録なし。
測定日は2026年8月25日である。

## 結果

minaseは公称深さ8〜11、約140万〜270万NPSだった。
HaChuは思考出力の深さ6〜7、約80万〜95万NPSだった。
HaChuの表示深さは反復深さからQSdepth=4を引いた値であり、全幅相当では10〜11である。
勝敗の統計を取る測定ではないため、ペンタノミアル度数、Elo、破棄ペア数、異常件数、`time_forfeits`、経過時間は該当しない。

## 結論

探索深さとNPSのいずれでもminaseはHaChuに劣っておらず、等時間の差の主因は探索量ではない。

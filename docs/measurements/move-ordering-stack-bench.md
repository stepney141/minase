# move-ordering-stack-bench

## 目的

[手の順序付けの改善](../plans/move-ordering.md)の候補を1候補1コミットで積み上げながら、各コミット直後の`bench`深さ6の総ノード数とNPSを記録し、全候補を積み上げた構成の探索量と速度の変化を説明する材料にする。

## コマンドライン

各コミットのリリースビルド（フィーチャなし）をCPU 3へ固定し、5回の計測反復の中央値を取った。

```console
cargo build --release --bin minase
taskset -c 3 target/release/minase dev bench --depth 6 --repetitions 5
```

## エンジン

ブランチ`move-ordering`の各コミット。段階開始版はmaster `b784fe5`であり、コードは`cd081f4`と同一である。規則は`engine-default`（`L0,P0,R1,E0`）、ワーカーは1、置換表は`bench`の既定の256 MBである。

## 環境

Intel Core Ultra 7 265KF（物理20コア、論理20コア）、`rustc 1.98.0`。lishogi Botのminaseが2プロセス同居しているので、NPSは参考値であり、1〜3%の揺れを含む。対局ではないので、ペンタノミアル度数、判定、破棄ペア数、異常件数、`time_forfeits`、経過時間は該当しない。

## 結果

| 日付 | コミット | 積み上げた候補 | 総ノード数（深さ6） | 前段比 | NPS |
|---|---|---|---:|---:|---:|
| 2026年10月9日 | `b784fe5` | なし（段階開始版） | 715,206 | | 1,838,818 |
| 2026年10月9日 | `09716b6` | 候補1　静かな手のβカット時の捕獲履歴の減点 | 717,278 | +0.29% | 1,831,275 |
| 2026年10月10日 | `70dbe39` | 候補2　先頭の捕獲手のSEE判定によるkiller手の前置 | 677,570 | −5.54% | 1,878,366 |
| 2026年10月10日 | `d9f4967` | 候補3　静止探索の群内の順序への捕獲履歴の適用 | 809,452 | +19.46% | 1,775,114 |
| 2026年10月10日 | `c5a298e` | 候補4　捕獲履歴の持ち越し（`bench`は局面ごとに表を消すので探索量は変わらない） | 809,452 | 0.00% | 1,767,271 |
| 2026年10月10日 | `a57a09e` | 候補5　静かな手のPST差分による同点破り | 816,626 | +0.89% | 1,707,820 |
| 2026年10月10日 | `14272f9` | 候補7　根の手の前回反復の部分木ノード数による整列 | 624,200 | −23.56% | 1,714,058 |
| 2026年10月10日 | `ea0c75a` | 候補8　history malus（加点と減点の尺度は既定の100%） | 690,307 | +10.59% | 1,610,443 |

## 結論

候補6を除く7候補を積み上げた構成（`ea0c75a`）は、段階開始版に対して`bench`深さ6の総ノード数が715,206から690,307へ3.5%減り、NPSは1,838,998から1,610,266へ12.4%下がった（同じ時刻に交互に2回ずつ測った中央値）。
ノード数の減少は候補2（−5.5%）と候補7（−23.6%）が、増加は候補3（+19.5%）と候補8（+10.6%）が主である。
NPSは探索するノードの構成（静止探索と通常探索の比など）にも依存するので、この差を追加の計算の費用とは読めない。
固定深さの指標は採否の根拠にしないので、効果は全候補の構成のSTCとLTCで判定する。

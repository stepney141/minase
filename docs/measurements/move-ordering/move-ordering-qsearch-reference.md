# move-ordering-qsearch-reference

## 目的

[手の順序付けの改善](../../plans/archived/move-ordering.md)の候補3（静止探索の群内の順序への捕獲履歴の適用）について、設計書が採否測定の前に求める確認として、無作為に抽出した局面で候補と現行を同じノード予算で探索し、根の評価値と最善手をより深い参照探索と比べて、候補の誤差が現行より悪化していないかを調べる。

## コマンドライン

現行は候補3を含まない直前のコミット`70dbe39`（候補1と候補2を含む）、候補は候補3を加えたコミット`d9f4967`の作業ツリーのビルドである。参照探索は現行のバイナリに20倍のノード予算を与えた。

```console
python3 docs/measurements/move-ordering-qsearch-reference/reference_compare.py \
  <70dbe39のminase> target/release/minase data/matches/fm-scale-spsa-stc 200 20271003 200000 20 8 \
  docs/measurements/move-ordering-qsearch-reference/reference-200k-x20.json
python3 docs/measurements/move-ordering-qsearch-reference/reference_compare.py \
  <70dbe39のminase> target/release/minase data/matches/fm-scale-spsa-ltc 380 20271004 200000 20 8 \
  docs/measurements/move-ordering-qsearch-reference/reference-200k-x20-ltc.json
```

局面は、[fm-scale-spsa-stc](../fm-scale-spsa/fm-scale-spsa-stc.md)と[fm-scale-spsa-ltc](../fm-scale-spsa/fm-scale-spsa-ltc.md)の保存記録から固定シードで対局を選び、各局の10手目から最終手の1手前までの局面を1つ一様に選んだ。ノード予算は200,000（STCの思考時間の中央値に相当）、参照は4,000,000ノードである。スクリプトと各局面の結果は[付属ディレクトリ](move-ordering-qsearch-reference/)にある。

## エンジン

現行はコミット`70dbe39`、候補はコミット`d9f4967`。規則は`L0,P0,R1,E0`、`Threads`は1、`USI_Hash`は既定の256 MBであり、局面ごとにプロセスを起動し直した。

## 環境

2026年10月10日、Intel Core Ultra 7 265KF（物理20コア、論理20コア）で、8プロセスを並列に実行した。lishogi Botのminaseが2プロセス同居していた。固定ノード数の探索なので経過時間は使わない。対局ではないので、ペンタノミアル度数、判定、破棄ペア数、異常件数、`time_forfeits`は該当しない。

## 結果

| 標本 | 指標 | 現行（`70dbe39`） | 候補（`d9f4967`） |
|---|---|---:|---:|
| STCの記録から200局面 | 参照との評価値の平均絶対誤差（センチポーン） | 116.8 | 118.7 |
| 同 | 同、中央値 | 42 | 46 |
| 同 | 参照と最善手が一致した割合 | 46.5% | 48.0% |
| 同 | 参照に近い側の件数（候補／現行／同点） | 40／52／108 | |
| LTCの記録から380局面 | 平均絶対誤差 | 121.0 | 120.1 |
| 同 | 中央値 | 45 | 44 |
| 同 | 最善手の一致 | 48.4% | 47.4% |
| 同 | 参照に近い側の件数（候補／現行／同点） | 83／105／187 | |
| 合計580局面 | 平均絶対誤差 | 119.5 | 119.6 |
| 同 | 中央値 | 44 | 45 |
| 同 | 最善手の一致 | 47.8% | 47.6% |
| 同 | 参照に近い側の件数（候補／現行／同点） | 123／158／299 | |

参照探索が詰みを報告した5局面は誤差の計算から除いた。到達深さの平均は両者とも8.6〜8.7で同じである。

## 結論

580局面の合計では、平均絶対誤差（119.5対119.6）、中央値（44対45）、最善手の一致率（47.8%対47.6%）のいずれも現行と候補の差は1%未満であり、候補の誤差が現行より悪化しているとは言えない。
ただし、局面ごとに参照に近い側を数えると、同点を除く281局面のうち現行が近い局面が158、候補が近い局面が123であり、わずかに現行に偏る（参照は現行と同じコードの深い探索なので、現行に有利な比較である）。
設計書の確認条件は満たすと判断して候補3を積み上げに残すが、全候補の採否測定が`H0`となった場合に帰属を調べるなら、候補1とともに最初に外して確かめる候補である。

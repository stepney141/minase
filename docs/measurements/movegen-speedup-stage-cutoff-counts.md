# 静止探索の価値グループごとの打ち切り位置の診断（bench深さ5）

## 目的

静止探索の捕獲を捕獲価値のグループ順に段階生成した場合に、探索の打ち切り後に生成せずに済む捕獲の割合を数え、入口の閾値による捕獲対象の除外と合わせた削減見込みを求める。

## コマンドライン

診断は本番の経路へ入れず、[診断差分](movegen-speedup-stage-cutoff-counts/diagnostic.patch)を単位A採用版へ当てた別ターゲットディレクトリのビルドで数えた。経過時間は使わない。

```console
git apply docs/measurements/movegen-speedup-stage-cutoff-counts/diagnostic.patch
CARGO_TARGET_DIR=<別ディレクトリ> cargo build --release --bin bench
<別ディレクトリ>/release/bench --depth 5 --threads 1 --repetitions 1
```

## エンジン

単位A採用版（コミット`283a0a6`）に診断差分を当てたものである。
`bench`は規則セット`engine-default`を固定で使う。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア）であり、2026年9月15日に1スレッドで測った。

## 結果

静止探索で捕獲を生成したノードは469,829であり、そのうちβ打ち切りで終わったノードは217,398である。
生成した捕獲手3,247,848件について、次の件数を数えた。
段階生成の見込みは、打ち切りを起こした手と同じ捕獲価値のグループまでを生成済みとみなし、それより低い価値のグループだけを未生成と数える。
打ち切りが起きないノードでは全捕獲を生成済みとみなす。
入口の閾値は`alpha - stand_pat - delta_margin`であり、捕獲価値がこの値以下で最後の王駒を取らない手を除外対象とする。

| 診断項目 | 件数 | 全生成手に対する割合 |
|---|---:|---:|
| ループ内で検査した手 | 1,719,799 | 53.0% |
| 途中の打ち切りにより検査しなかった手 | 1,528,049 | 47.0% |
| 価値グループ単位の段階生成でも生成する手 | 2,253,005 | 69.4% |
| 段階生成で生成せずに済む手 | 994,843 | 30.6% |
| 入口の閾値で除外できる手 | 1,461,527 | 45.0% |
| 閾値除外と段階生成を合わせても生成する手 | 1,180,903 | 36.4% |
| 閾値除外と段階生成を合わせて生成せずに済む手 | 2,066,945 | 63.6% |

独立した参照との照合として、検査した手と検査しなかった手の和が生成数に一致すること、段階生成でも生成する手が検査した手以上であること、および閾値除外を合わせた生成数が段階生成だけの生成数以下であることを確認した。
局面別の生の件数は[counts.log](movegen-speedup-stage-cutoff-counts/counts.log)、合計は[totals.json](movegen-speedup-stage-cutoff-counts/totals.json)にある。

## 結論

未検査の手の47.0%のうち、同じ価値グループ内で生成済みとなる分を除くと、段階生成だけで省ける生成は30.6%であり、入口の閾値除外と合わせると63.6%の捕獲を生成せずに済む。

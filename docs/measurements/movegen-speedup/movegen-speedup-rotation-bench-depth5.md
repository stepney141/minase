# 静止探索の置換表の手の回転による探索木の変化（bench深さ5）

## 目的

静止探索で置換表の手を先頭へ移す方法を`swap`から回転へ改めた照合参照コミットが、基準コミットに対して局面別のノード数、最善手、探索値をどれだけ変えるかを記録する。

## コマンドライン

基準は`git archive`で展開し、`bench`の出力拡張（最善手と探索値の表示）だけを当ててビルドした。
参照はブランチ`movegen-speedup`の照合参照コミットをそのままビルドした。
いずれも1回実行の局面別出力を比べた。

```console
git archive 0e3dfa6 | tar -x -C <基準ディレクトリ>
(cd <基準ディレクトリ> && git apply <benchの出力拡張の差分> && cargo build --release --bin bench)
<基準ディレクトリ>/target/release/bench --depth 5 --threads 1 --repetitions 1
cargo build --release --bin bench
target/release/bench --depth 5 --threads 1 --repetitions 1
```

## エンジン

基準はコミット`0e3dfa6b59c489049c15e2cd00455e190a3fbf52`（master）に`src/bin/bench.rs`の出力拡張だけを当てたものである。
参照は照合参照コミット`5c1db50`であり、基準に対する探索の差分は`src/search/mod.rs`の静止探索で`captures.swap(0, index)`を`captures[..=index].rotate_right(1)`へ改めた1箇所だけである。
`bench`は規則セット`engine-default`を固定で使う。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア）であり、2026年9月15日に他の負荷を走らせずに1スレッドで測った。
置換表は既定容量を1個使い回し、局面ごとの`clear()`は計測区間外である。

## 結果

最善手と探索値は15局面すべてで一致した。
ノード数は次の5局面で変わり、残る10局面は一致した。

| 局面 | 基準のノード数 | 参照のノード数 | 差 |
|---|---:|---:|---:|
| game-3-ply-465 | 53,585 | 53,595 | +10 |
| game-4-ply-164 | 23,266 | 23,262 | −4 |
| game-5-ply-170 | 139,879 | 139,855 | −24 |
| game-6-ply-77 | 172,049 | 171,981 | −68 |
| game-10-ply-277 | 39,097 | 38,985 | −112 |

総ノード数は1,268,805から1,268,607へ198ノード（0.016%）減った。

## 結論

回転は探索木を変えるが、深さ5の15局面では最善手と探索値を変えず、ノード数の差は0.016%にとどまる。

# 単位A（利き逆引きの片側化、方向主導化、特殊利きの走査限定）のbench比較（深さ5）

## 目的

利き逆引きの片側化、方向主導化、および特殊利きの走査限定を一体で含む単位Aが、照合参照コミットと局面別のノード数、最善手、探索値で一致するかを確かめ、基準コミットと参照コミットに対する速度比を測って採否を決める。

## コマンドライン

```console
scripts/bench_compare.py --reference 5c1db50 --baseline 0e3dfa6 --depth 5 --repetitions 3 --threads 1
```

スクリプトは参照と基準を`git archive`で`target/bench-cache/`へ展開して通常のrelease設定でビルドし、局面別の一致は1回実行、速度は3回実行の中央値で取る。

## エンジン

基準はコミット`0e3dfa6b59c489049c15e2cd00455e190a3fbf52`（master）である。
参照は照合参照コミット`5c1db5000baea831ce53d994cbf664ee12a0e5e6`であり、基準に対して静止探索の置換表の手の回転と`bench`の出力拡張だけを含む。
候補は参照に対して`Position::attackers_to`を`attackers_to_by`へ片側化し、走りの逆引きを方向主導に、特殊利きの走査を獅子、角鷹および飛鷲に限定した変更（`src/core/movegen/mod.rs`、`src/search/mod.rs`、`src/search/see.rs`）を加えたものである。
`bench`は規則セット`engine-default`を固定で使う。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア）であり、2026年9月15日に他の負荷を走らせずに1スレッドで測った。
置換表は既定容量を1個使い回し、局面ごとの`clear()`は計測区間外である。

3回実行の中央値は次のとおりである。

| 版 | 総ノード数 | 経過（中央値） | NPS（中央値） |
|---|---:|---:|---:|

候補の基準比はNPS 1.319倍、ノード数 0.9998倍、経過時間 0.758倍である。
候補の参照比はNPS 1.343倍、ノード数 1.0000倍、経過時間 0.744倍である。

## 結論

単位Aは参照と局面別に一致し、NPSを基準比1.319倍にしたので採用する。

# nnue-architecture-revision-stc

## 目的

幅256の第1層、要素積、2段の隠れ層、およびskip接続を持つネットを候補、幅128の直接内積のネットを基準とする短時間の時間制御（STC）のGSPRTで、世代反復に使う構成を確定できるかを[設計書](../../plans/nnue-architecture-revision.md)の規則で判定する。

## コマンドライン

対局は、候補のコミットからビルドしたrunner（`data/nnue-architecture-revision/minase-runner`、SHA-256 `acf542acaa67657c0640a406a5f01678b25c69cedf2376c535b69e0c5855036b`）で、本体のリポジトリのルートから実行した。

```console
minase-runner match run --run-dir data/matches/nnue-architecture-revision-stc --seed 20261110000000 \
  --candidate commit:77e11950125c7215f8c7041cbd39a8d6f82e2295 \
  --baseline commit:ee1d6e08f294a5bfdc41c6737d445e0944928f77 \
  --each time=10000+100 --concurrency 16 gsprt --max-pairs 3000
```

配置の距離の集計は[placement_single.py](nnue-architecture-revision-stc/placement_single.py)で行い、[標準出力](nnue-architecture-revision-stc/placement_single.out)を残した。

## エンジン

| 役 | コミット | 実行ファイルのSHA-256 | 埋め込みのネット |
|---|---|---|---|
| 候補 | `77e11950125c7215f8c7041cbd39a8d6f82e2295` | `ea801e5ae26a07c60e8c399d386adf8fd49340f30b7d74334317d5ccff3bdf7f` | 幅256（`d622b076…`） |
| 基準 | `ee1d6e08f294a5bfdc41c6737d445e0944928f77` | `e6289d55c2874d46a71a8fce0f03e5b35338c71d9643ff19b0f0079d37965f12` | 幅128（`5257f374…`） |

基準はmasterの探索のコードに、結果回帰の補正を加える前のネットを載せたコミットである。
候補も補正を加えていない。
規則セットは`engine-default`（L0,P0,R1,E0）である。
2つのネットは同じ30ファイルの教師、同じ引数、および同じシードで学習した（[学習の記録](nnue-architecture-revision-training.md)）。

## 環境

2026年11月4日に測定機（Intel Core Ultra 7 265KF、物理20コア、論理20コア）で行った。
候補と基準のワーカー数（`Threads`）はともに1、`USI_Hash`はともに256 MB、同時対局数は16、時間制御は持ち時間10秒、1手0.1秒加算である。
同じ機械でlishogiのBotと、別の作業の探索が動いていた時間がある。

## 結論

`H0`であり、この候補は基準より10 Elo以上強いとは言えない。
得点率からは基準より弱いと見られるので、計画の切り分けとして固定ノードの対局で速度を除いた評価の質を調べる。

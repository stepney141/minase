# nnue-gen0-nodes100k

## 目的

世代0の100万局面で学習したP型NNUE（段階2）と、採用済みの学習PST（段階1）を固定ノードGSPRTで比べ、探索速度の差を除いた評価の質でNNUEが有意に強いかを判定する。

## コマンドライン

```console
cargo run --release --bin match_runner -- --candidate commit:05362b1 --baseline commit:7e13888 --each nodes=100000 --concurrency 16 --seed 20260828 gsprt
```

この測定は`--run-dir`の導入前に実施したため、実行ディレクトリは残っていない。
測定名は本記録で付けた名前である。

## エンジン

候補はコミット05362b1（P型NNUEの整数推論と差分更新、世代0で学習したネット）、基準はコミット7e13888（学習PST）である。
設計書の記録は候補を「コミット05362b1（レビュー修正3ee849cを含む）」と記すが、コマンドラインの指定は05362b1である。
規則セットはコマンドラインで指定せず、`commit:`指定でハーネスが自動付与する既定の規則セットを両エンジンに与えた（名前は記録なし）。

## 環境

CPU型、物理コア数、論理コア数は記録なし。
両エンジン`Threads=1`、`USI_Hash`は既定、同時対局数は16である。

## 結果

ペア数は204（破棄0）、ペンタノミアル度数は[196, 0, 8, 0, 0]、LLRは−2.957、判定は`H0`である。
`engine_failures`は0であり、`time_forfeits`は固定ノード数の対局のため該当しない。
経過時間は949秒である。
NNUEは204ペア中196ペアで2局とも負け、終局はすべて詰みであった。

## 結論

世代0のP型NNUEは学習PSTに有意に劣り（`H0`）、不採用とした。
原因の診断（教師探索値との平均絶対誤差404センチポーン対193センチポーン、獅子の過大評価と歩兵の過小評価）は docs/plans/evaluation.md の「世代0の学習結果と診断」にある。

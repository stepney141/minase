# 学習機だけを借りて学習する連続生成スクリプトの試走

## 目的

[世代反復の設計書](../../plans/nnue-generation-iteration.md)のフェーズ1では、連続生成スクリプト`scripts/vast/generation_chain.py`を改めた。
このスクリプトは、借りた機械で教師ファイル（以下、本）の生成から学習までを続けて行うものであり、改めた後は、手元の計算機（以下、作業機）に本がすべてそろっている世代について、GPUつきの機械（以下、学習機）を借りて学習だけを行える。
本書は、フェーズ1の完了条件として、この流れが最後まで通ることを、安い機械と少ない本で確かめた試走の記録である。
確かめる点は次の7つである。

- 本がすべて作業機にある世代で、`--offer`で指定した出品（計算機を時間単位で借りられる市場vast.aiの貸出の単位）を学習機として借りる。
- 本を生成しないために作業ツリーのない学習機で、学習の前にコミットを展開し、学習器をビルドする。
- 標準レシピv3の検証の引数（`--validation-superbatches 1 --validation-patience 2`）を付けた学習と、検証損失が最小だった時点の重み`best.npz`を使う駒除去差分の診断（盤上の駒を1枚ずつ除いたときの評価値の差分を調べる診断）が終わる。
- 学習の結果、各ステップのログ、および学習器のプロセスの最大常駐メモリの記録が作業機へ届く。
- 学習機の作業プロセスは、仕事のない時間が`--idle-limit-hours`を超えると学習機を自己停止させる。学習が終わるまでは、この自己停止が起きない。
- 学習の後に学習機が止められて削除され、インスタンスの一覧が空になる。
- ネットがNAS（ネットワーク接続の記憶装置）にSHA-256の名前で置かれ、深さ5の`bench`（決まった局面を探索するエンジンの動作の試験）が完走し、世代の記録`generation.json`が書かれる。

## コマンドライン

試走の本は、作業機で、試走に使うコミットのworktreeから4本を生成した。
1本は200局、1手2,000ノードであり、番号iの本のシードは`19,100,000,000 + 100,000×i`である。

```console
minase data selfplay generate --eval-file <v0のネット> --output-dir <本ごとのディレクトリ> \
  --seed <シード> --games 200 --nodes 2000 --random-moves 0 --concurrency 16 --max-ply 4000 \
  --hash-mb 16 --chunk-games 50
```

生成した4本と生成ログを、連続生成スクリプトの実行ディレクトリの`gen-1/teacher/`と`gen-1/logs/`へハードリンクで置き、[`run-trial.sh`](nnue-generation-iteration-training-rental-trial/run-trial.sh)で連続生成スクリプトを`systemd-run --user`のサービスとして起動した。
`run-trial.sh`の引数は、順に、実行ディレクトリの名前、`--idle-limit-hours`の値（単位は時間）、およびコミットである。
実行は2回行った。
2回目は、学習が終わる前に自己停止の待ち時間が尽きる条件を作るために、待ち時間を縮めたものであり、実行ディレクトリと`--idle-limit-hours`だけが1回目と違う。

```console
run-trial.sh run 0.05 659e059314b2327631bf92bb818577701e10f5fb --offer 60869357
run-trial.sh run2 0.02 659e059314b2327631bf92bb818577701e10f5fb --offer 60869357
```

本番と値を変えた引数は、`--books-per-generation 4`、`--games 200`、`--nodes 2000`、`--chunk-games 50`、`--seed-base 19000000000`、`--batches-per-superbatch 6`、`--superbatches 20`、`--lr-schedule cosine:20:0.027`、`--train-threads 8`、`--removal-sample 100`、および学習機の選定条件と待ち時間（`--training-wait-hours 0.75`、`--idle-limit-hours`）である。
`--structure layerstack`、`--batch 16384`、`--lambda 1.0`、`--validation-superbatches 1`、`--validation-patience 2`、`--replay-buffer-generations 1`、`--calibration-books 4`、`--train-seed 1`、`--device cuda`、および`--train-place generator`は、設計書の「世代の手順」と同じ値である。
訓練局面169,710を16,384局面のバッチでひととおり学ぶ1エポックは11回の更新であり、1 superbatchの6回の更新はその約半分にあたる。

## エンジン

連続生成スクリプト、教師の生成器、学習器、およびエンジンは、ブランチ`nnue-generation-iteration`のコミット`659e059314b2327631bf92bb818577701e10f5fb`である。
作業機では、このコミットのworktreeでビルドした`minase`（エンジンと教師の生成器）と`minase-trainer`（学習器）を使い、学習機では、連続生成スクリプトが送ったコードから同じコミットを展開して学習器をビルドした。
第0世代のネットは、`minase-trainer nnue export-handcrafted`で書き出した手書きの評価関数v0のネット（SHA-256は`b2a0a450…`）である。
規則セットは、本、学習器の引数、および`bench`のいずれも`lishogi`（`L1,L2,P0,P3,R1,E1,E3`）である。

## 環境

作業機はIntel Core Ultra 7 265KF（20コア、メモリ30 GB、RTX 3060 Ti）である。
学習機には、2回とも、vast.aiの出品60869357をオンデマンドで借りた。

| 項目 | 値 |
|---|---|
| CPU | 13th Gen Core i5-13400F、16スレッド（`cpu-info`のcpusetは16、cgroupの上限は15.36 CPU分） |
| メモリ | 31.9 GB |
| GPU | RTX 3060（12 GB） |
| 場所 | ベトナム |
| 時間単価 | 0.0856米ドル |
| イメージ | `rust:1.98.0-bookworm` |

実行は2026年11月20日で、1回目は08時36分54秒から08時41分34秒まで、2回目は08時42分21秒から08時46分07秒まで（いずれもUTC）である。

## 結果

2回とも、連続生成スクリプトは「完了」を表示し、終了コード0で終わった。

| 確かめた点 | 結果 |
|---|---|
| 学習機を借りる | 借りた機械の記録がまだなく、本が4本そろった実行ディレクトリで、スクリプトは本を生成せずに出品60869357を借りた。停止期限は`--training-wait-hours`の0.75時間後に置かれた。 |
| コミットの展開とビルド | 学習機の`checkout.log`は、空の作業ツリーを作り、送られたコードからコミット`659e0593`を取り出したことを示した。続く`build`ステップは学習器を1分25秒でビルドした。 |
| 学習 | 学習器は訓練169,710局面、検証10,377局面で20 superbatch（120回の更新、10.91エポック）を学び、`summary.json`の`status`は`candidate`、`stopped_by`は`completed`だった。`training.jsonl`の`epochs`は1 superbatchごとに0.545ずつ増えた。検証損失は最後のsuperbatchまで下がり続けたので、検証損失の停止条件は働かず、選ばれた重みは第20 superbatchのものである。学習器の引数には、`--rules lishogi`と、探索値を勝率へ換算する教師の勝率尺度として較正した951.87 cp（cpはセンチポーンで、歩兵1枚の100分の1）が渡された。 |
| 診断 | 駒除去差分の診断の`--float`には`train/best.npz`が渡された。標本100局面の4,559件の除去で、符号の反転は0件だった。 |
| ログと最大常駐メモリ | `gen-1/training-logs/`に、`checkout.log`、3つのステップのログ、および`build.rusage.json`、`train.rusage.json`、`removal.rusage.json`が届いた。学習器のプロセスの最大常駐メモリは、1回目が670,672 KiB、2回目が670,976 KiBだった。 |
| 自己停止の保留 | 1回目は待ち時間を180秒（`--idle-limit-hours 0.05`）にしたが、作業プロセスが動き始めた時刻を記録しなかったので、学習が終わる前に待ち時間が尽きる条件だったかを確かめられなかった。そこで2回目は、待ち時間を72秒（`--idle-limit-hours 0.02`）に縮め、学習機の時刻を約9秒おきに記録した。学習機の作業プロセスが動き始めたのは08時43分05秒、学習の作業ディレクトリができたのはその26〜35秒後、学習が終わったのは08時45分41秒である。作業プロセスは、動き始めてから156秒のあいだ自己停止せず、学習機は学習の後までSSHに応答した。改める前の作業プロセスであれば、72秒後のビルドの途中で自己停止する条件である。 |
| 停止と削除 | 2回とも、スクリプトは学習の結果を取得してから学習機に停止を要求し、削除した。実行の後の`vastai show instances`の一覧は空だった。 |
| NASと世代の記録 | 学んだネット（SHA-256は`622a62c1…`）は`/mnt/synology_nas/minase/nnue/nets/`にSHA-256の名前で置かれ、エンジンに`EvalFile`で渡した深さ5の`bench`が15局面を完走した。`gen-1/generation.json`には、コミット、ネットのパスとSHA-256、および教師の勝率尺度が書かれた。2回の実行のネットはバイト単位で一致した。 |

口座の残高は、1回目の前の100.7072米ドルから、2回目の後に値が落ち着いた時点の100.6901米ドルへ減った。
2回の試走の費用は、合わせて約0.02米ドルである。

本が少なく1手2,000ノードなので、ネットの値、損失、および教師の勝率尺度951.87 cpに意味はない。
学習の最大常駐メモリ約0.64 GiBも、訓練17万局面での値であり、本番の見積りには使えない。

## 結論

改めた連続生成スクリプトは、作業機にある本をもとに学習機を借り、コミットの展開、ビルド、学習、診断、結果と最大常駐メモリの記録の取得、学習機の停止と削除、およびネットのNASへの保存と世代の記録までを通した。
これで、フェーズ1の完了条件を満たした。

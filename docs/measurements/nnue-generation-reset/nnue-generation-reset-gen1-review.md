# 世代反復の第1世代を見直すための比較

## 目的

[第1世代のSTC](nnue-generation-reset-gen1-stc.md)で、設計書の条件であるλ=0.75のネットが第0世代に`H0`となった。
2026年11月5日の利用者の決定により、第2世代の生成へ進まず、次の2点を作業機で確かめる。

- λ=0.75のネットの弱さは、検証損失の最小を過ぎた後の対局の記憶によるのか、対局結果を混ぜること自体によるのかを切り分ける。
- 対局結果を線形の経路だけに反映すると棋力が上がるのかを確かめる。線形の経路は駒の組を使えないので、対局を見分けにくい（[教訓](../../lessons/game-constant-target-memorization.md)）。

## コマンドライン

検証損失の最小付近で止めたネットは、[起動スクリプト](nnue-generation-reset-gen1-review/start_stop1000.py)を使って次の条件で学習した。
教師、初期値、シード、および他の設定は[第1世代の学習](nnue-generation-reset-gen1-training.md)と同じである。

```console
minase-trainer nnue train ... --lambda 0.75 --epochs 1 --train-subsample positions:4:0 --lr-schedule cosine:12:0.1
```

訓練集合の4分の1で1エポック学習すると952更新になる。
学習率スケジュールは、全局面で学習したときの最初の952更新とほぼ同じになるように、余弦の期間を3エポックの4倍にした。

線形の経路だけを補正したネットは、[第1世代の学習](nnue-generation-reset-gen1-training.md)で`fit-linear`が書き出した`gen-1/diag/fit-lambda100/nnue.bin`である。
2つのネットは[スクリプト](nnue-generation-reset-gen1-review/make_review_commits.py)で別のコミットにした。

STCは[スクリプト](nnue-generation-reset-gen1-review/review_stc.py)で順に実行した。

```console
minase match run --run-dir data/matches/<測定名> --seed 20261201000000 \
  --candidate commit:<候補> --baseline commit:<基準> \
  --each time=10000+100 --concurrency 16 gsprt --max-pairs 3000
```

STCは、ブランチ`teacher-speedup`を統合する前のコミットの作業ツリー（`data/worktrees/nnue-generation-reset-premerge`）から実行した。
`minase match run`は作業ツリーの`target/`の下で`cargo build`を実行し、cargoは親ディレクトリの`.cargo/config.toml`の`rustflags`を連結する。
統合後の作業ツリーで古いコミットをビルドすると、統合で加わったインライン化のフラグが混ざり、候補の側だけが速くなるおそれがあるからである。

## 結果

### 952更新で止めたネットの学習

| 項目 | λ=0.75（952更新） | λ=0.75（3,806更新） | λ=1.0（7,612更新） |
|---|---:|---:|---:|
| 検証損失 | 0.479983 | 0.482181 | 0.479712 |
| 検証損失−エポック中の訓練損失 | 0.00191 | 0.00768 | 0.00084 |
| 対局結果との符号一致率 | 0.7542 | 0.7521 | 0.7459 |
| 駒除去差分の符号反転 | 0.145%（719件） | 0.853%（4,220件） | 0.091%（450件） |
| 量子化誤差の平均 | 6.33 cp | 8.48 cp | 4.64 cp |

検証損失の目標はλで異なるので、λ=1.0の列とは絶対値を直接比べられない。
反転の8割以上を占める番号29の駒状態は、番号の並びと件数から歩兵とみられる。
学習を続けるほど反転が増えるので、対局の記憶と駒の価値の歪みは同時に進むと考えられる。
因果関係は確かめていない。

## 結論

λ=0.75でも検証損失の最小付近で止めれば第0世代に`H1`を取るので、λ=0.75の`H0`は対局結果を混ぜること自体ではなく、最小を過ぎた後の学習で生じた。
ただし、止めたネットの得点率はλ=1.0を上回らず、この教師の量でλ=0.75を残す利点は確認できない。
対局結果を線形の経路だけに反映すると、λ=1.0のネットに対して得点率92.1%で`H1`を取り、`fit-linear`のD（−0.0100）が棋力の差としても現れた。
第1世代の時点で最も強いネットは、λ=1.0に`fit-linear`を足したものである。
どの手順で第2世代へ進むかは利用者が決める。

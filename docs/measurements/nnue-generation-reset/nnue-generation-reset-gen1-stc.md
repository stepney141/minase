# 世代反復の第1世代と第0世代のSTC

## 目的

[世代反復の設計書](../../plans/archived/nnue-generation-reset.md)の第1世代の判定として、[第1世代のネット](nnue-generation-reset-gen1-training.md)を第0世代（手書きの評価関数v0）と対局で比べる。
設計書の条件であるλ=0.75のネットに加えて、同じ教師をλ=1.0で学習した比較のネットも測り、λの影響を切り分ける。

## コマンドライン

2つのネットは、同じシードを使って同じ開始局面で比べた。
`<候補>`はλ=0.75では`fb92b0bc3fcf50a8f32b214a56db7f8f200deca6`、λ=1.0では`5f81bb71dfed92070bbfe040fac488c4f7d0eecc`である。

```console
minase match run --run-dir data/matches/<測定名> --seed 20261201000000 \
  --candidate commit:<候補> --baseline commit:6f874692fb91544c94394ca0e8df25299ef2e02d \
  --each time=10000+100 --concurrency 16 gsprt --max-pairs 3000
```

測定名は、λ=0.75が`nnue-generation-reset-gen1-stc`、λ=1.0が`nnue-generation-reset-gen1-lambda1-stc`である。
配置は`placement_distance.py single`で、1局ごとの集計は[スクリプト](nnue-generation-reset-gen1-stc/stc_games.py)で求めた。

## エンジン

ネットの内容は[学習の記録](nnue-generation-reset-gen1-training.md)にある。
3つのコミットの`crates/`の違いは、埋め込んだネットだけである。
規則セットは`L0,P0,R1,E0`である。

## 環境

2026年11月5日に作業機（Intel Core Ultra 7 265KF、20コア、メモリ30 GB）で、`systemd-run`のサービス（通常の優先度、メモリ上限22 GB）として順に実行した。
測定中に本計画の学習や診断は動かしていない。

## 結論

設計書の条件であるλ=0.75のネットは第0世代に対して`H0`であり、設計書の「反復を止める条件」に該当する。
同じ教師、同じ分割、同じ初期値で、λだけを1.0にしたネットは第0世代に対して`H1`であるから、弱さの主因はλ=0.75である。
第0世代に大差で勝つネットができたので、教師の生成、v0の書き出し、および`--base`の読み込みに、棋力を損なう大きな不具合はないと判断する。
λ=1.0のネットは配置の偏りも少ない。
第2世代以降のλを変えるかは利用者が決める。

# 第2世代の教師での対局数と局面数の比較

## 目的

[教師の量の比較](nnue-generation-reset-gen2-volume.md)は、教師を減らすと弱くなることを示したが、対局と局面が一緒に減るので、どちらが効いたかは分からなかった。
2026年11月6日の利用者の指示により、局面数をそろえて対局数だけが違う2つの訓練集合から学び、対局で比べる。
過去に検証損失で行った[比較](../nnue-early-best-epoch/nnue-train-subsample.md)を、対局で確かめ直すものである。

## コマンドライン

学習、補正、コミット、およびSTCは[スクリプト](nnue-generation-reset-gen2-diversity/run_diversity.py)で順に実行した。
第2世代の教師（全37本）を`--train-subsample`で半分に間引いた。
`games:2:0`は対局の半分の全局面、`positions:2:0`は全対局の局面の半分を使う。
学習のその他の引数は[第2世代の学習](nnue-generation-reset-gen2-training.md)と同じで、`--threads 8`と、途中検証を省いた点だけが違う。
補正にはどちらも全37本を与えた。

```console
minase match run --run-dir data/matches/nnue-generation-reset-gen2-diversity-stc --seed 20261202900000 \
  --candidate commit:9c8481b07e2fab1ee520c387c840c26bb1661b11 \
  --baseline commit:6d6091d1ee9665f816a53b29b2fb87696e57be33 \
  --each time=10000+100 --concurrency 16 gsprt --max-pairs 3000
```

候補は対局が多い側（`positions:2:0`）であり、`H1`は、局面数が同じなら多くの対局から採るほうが強いことを示す。

## 結果

### 学習

`--train-subsample`は検証集合を間引かず、教師の勝率尺度、観測マスク、および初期値を間引く前の訓練集合全体から作るので、対局半分と局面半分で次の条件がそろう。

| 項目 | 対局半分 | 局面半分 | 全量（参考） |
|---|---:|---:|---:|
| 訓練の対局 | 130,886局 | 261,004局 | 261,963局 |
| 訓練局面 | 48,296,873 | 48,230,651 | 96,462,343 |
| 検証局面 | 5,162,867 | 5,162,867 | 5,162,867 |
| 教師の勝率尺度 | 707.88 cp | 707.88 cp | 707.88 cp |
| 最良エポック / 停止エポック | 3 / 8 | 3 / 8 | 2 / 7 |
| 総更新回数 | 23,584 | 23,552 | 41,216 |
| 最良の検証損失 | 0.521538 | 0.521393 | 0.521349 |
| 量子化誤差の平均 | 5.14 cp | 5.73 cp | 4.46 cp |
| D | −0.005631 | −0.005629 | −0.005679 |
| Dの95%区間 | [−0.007037, −0.004266] | [−0.006926, −0.004333] | [−0.007093, −0.004309] |

全量の列は[第2世代の学習](nnue-generation-reset-gen2-training.md)の値であり、訓練の対局の数は全275,798局から検証の13,835局を引いた値である。
検証集合が同じなので、検証損失は3つの間で比べられる。
局面半分の検証損失は全量より0.000044高く、対局半分は0.000189高い。
補正の出力は[対局半分](nnue-generation-reset-gen2-diversity/fit_report-games-half.out)と[局面半分](nnue-generation-reset-gen2-diversity/fit_report-positions-half.out)にある。

度数は候補（局面半分）の側から見た、0、0.5、1、1.5、および2点の順である。
逐次検定は判定が出た時点で止まるので、得点率から求めたEloは真の差より大きく出やすい。

## 結論

局面数と更新回数をそろえると、多くの対局から疎に採った教師のネットが、少ない対局から全局面を採った教師のネットに`H1`を取った。
同じ対局から採る局面は情報が重なっており、教師の価値は対局の数に大きく依存する。
局面を半分に間引いても、全対局を残せば検証損失は全量とほぼ同じだった。
ただし、全量と局面半分の棋力は比べていない。
対局と局面の分け方と学習のシードは各1通りである。
記録しない手を少ないノード数で指して対局を増やす生成方式（[設計書](../../plans/sparse-teacher-recording.md)）は、対局の質と局面の分布も変えるので、この結果だけでは効果を判断できない。

# 世代反復の第2世代と第1世代のSTC

## 目的

[世代反復の設計書](../../plans/nnue-generation-reset.md)の第2世代の判定として、[第2世代のネット](nnue-generation-reset-gen2-training.md)を暫定最良世代の第1世代と対局で比べる。

## コマンドライン

```console
minase match run --run-dir data/matches/nnue-generation-reset-gen2-stc --seed 20261202000000 \
  --candidate commit:c5910ea55fc0bf928690a730a264c48573aba04f \
  --baseline commit:7c2cfe4eb868fe54ddcc31187a900efe3a30a7d4 \
  --each time=10000+100 --concurrency 16 gsprt --max-pairs 3000
```

診断の後に[スクリプト](nnue-generation-reset-gen2-training/gen2_diag_and_stc.py)で続けて実行した。
配置は`placement_distance.py single`で、1局ごとの集計は[スクリプト](nnue-generation-reset-gen2-stc/stc_games.py)で求めた。

## エンジン

| 名前 | コミット | 内容 |
|---|---|---|
| 第1世代 | `7c2cfe4e` | λ=1.0のネットに`fit-linear`を加えたネットを埋め込む。 |
| 第2世代 | `c5910ea5` | 第1世代の教師から同じ手順で作ったネットを埋め込む。 |

2つのコミットの`crates/`の違いは埋め込んだネットだけであり、どちらにも教師生成の高速化が入っている。
対局は世代反復の作業ツリーから実行したので、両方のビルドに同じビルド設定が適用される。
規則セットは`L0,P0,R1,E0`である。

## 環境

2026年11月5日の夜に、作業機（Intel Core Ultra 7 265KF、20コア、メモリ30 GB）で`systemd-run`のサービス（通常の優先度、メモリ上限22 GB）として実行した。
測定中に本計画の学習や診断は動かしていない。

## 結果

| 項目 | 値 |
|---|---:|
| 有効ペア | 116 |
| 度数 | [4, 0, 34, 1, 77] |
| LLR | +2.9597 |
| 判定 | `H1` |
| 得点率 | 81.7% |
| 得点率から求めたElo | 約+260 |
| 所要時間 | 990秒 |
| エンジン異常、時間切れ、拒否着手 | 0件 |

度数は候補の側から見た、0、0.5、1、1.5、および2点の順である。
逐次検定は判定が出た時点で止まるので、得点率から求めたEloは真の差より大きく出やすい。

1局ごとの平均は次のとおりである（[出力](nnue-generation-reset-gen2-stc/games-nnue-generation-reset-gen2-stc.out)）。
集計は打ち切りの時点で終わっていた236局を含む。

| 項目 | 第2世代 | 第1世代 |
|---|---:|---:|
| 勝ち | 191局 | 43局 |
| 平均の探索深さ | 16.57 | 16.26 |
| 1局のCPU時間 | 28.3秒 | 29.8秒 |

引き分けは2局である。
1手で終わった2局は、開始局面で先手が玉を取れる組の先後の2局で、両者が1勝ずつ挙げた。

候補の側の配置は次のとおりである（[出力](nnue-generation-reset-gen2-stc/placement-nnue-generation-reset-gen2-stc.out)）。
相手と標本数が他の記録と違うので参考値である。
設計書の目安は、補正前のネットが0.461、PST世代1が0.330である。

| 項目 | 第2世代 | 第1世代の比較時のλ=1.0（参考） |
|---|---:|---:|
| M | 0.3110 | 0.2642 |
| 奔王が1〜2段 | 2.9% | 5.5% |
| 龍馬が1〜2段 | 12.4% | 10.5% |
| 醉象が3〜5筋 | 11.4% | 2.2% |
| 金将が3段以上 | 27.3% | 3.2% |
| 麒麟が右端2筋 | 0.0% | 0.4% |

参考の列は、[第1世代のSTC](nnue-generation-reset-gen1-stc.md)でλ=1.0のネットを第0世代と対局させたときの値である。

## 結論

第2世代は第1世代に`H1`を取り、暫定最良世代になった。
Mは偏りの再発の目安とした0.46前後には達していないが、金将が3段以上にいる割合が増えたので、次の世代でも推移を追う。

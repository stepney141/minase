# 世代反復の第2世代の生成と学習

## 目的

[世代反復の設計書](../../plans/nnue-generation-reset.md)の第2世代として、第1世代のネットで教師を生成し、λ=1.0で学習して`fit-linear`で補正する。
本書は、生成、生成機での学習、補正、および診断を記録する。
棋力は[第2世代のSTC](nnue-generation-reset-gen2-stc.md)に記録する。

## コマンドライン

連続生成スクリプトで、生成から学習、補正、コミットまでを行った。
主な引数は次のとおりであり、シードは本の番号`i`について$`9{,}020{,}000{,}000+100{,}000i`$である。

```console
python3 scripts/vast/generation_chain.py run --first-generation 1 --last-generation 2 \
  --positions-per-generation 100000000 --books-estimate 40 \
  --games 7500 --nodes 20000 --random-moves 0 --max-ply 4000 --hash-mb 16 \
  --lambda 1.0 --feature-set P --width 256 --head pairwise-l16-l32 --batch 16384 \
  --epochs 50 --patience 5 --train-seed 1 --device cuda --validation-interval 1000 --lr-schedule cosine:3:0.1 \
  --train-threads 32 --train-place generator --training-wait-hours 3 \
  --fit-tau 10 20 40 80 --fit-seed 20261105 --fit-threads 12 --removal-sample 10000 --removal-seed 1 --bench-depth 5
```

生成を始めた時点では学習を作業機で行う設定だった。
2026年11月5日の利用者の指示で、生成の途中（本8の生成中）にスクリプトを止め、生成機で学習する設定で再開した。
生成機の作業プロセスは止めていないので、生成中の本は失っていない。

学習は生成機で次のコマンドで行った。
`<37本>`は本0から本36まで、初期値は第1世代の補正後のネット（`gen-1/fit/nnue.bin`）である。

```console
minase-trainer nnue train --data <37本> --base base.bin --lambda 1.0 --teacher-cp-per-logit calibrate \
  --seed 1 --threads 32 --feature-set P --width 256 --head pairwise-l16-l32 --batch 16384 \
  --epochs 50 --patience 5 --device cuda --validation-interval 1000 --lr-schedule cosine:3:0.1
```

診断と第1世代とのSTCは、作業機で[スクリプト](nnue-generation-reset-gen2-training/gen2_diag_and_stc.py)により順に実行した。
Dの区間は[`fit_report.py`](../nnue-outcome-regression/nnue-outcome-regression-fit/fit_report.py)、対局単位の汎化差は[構成の見直しの集計](../nnue-architecture-revision/nnue-architecture-revision-init-training/outcome_gap.rs)と[区間の計算](../nnue-architecture-revision/nnue-architecture-revision-init-training/gap_report.py)で求めた。

| 名前 | コミット | 内容 |

## 環境

生成と学習は、2026年11月5日の15時28分から22時58分まで、vast.aiの出品58885120で行った。
機械はAMD EPYC 9B14の2基構成（384スレッド、cgroupのCPU上限368.64）、メモリ251 GB、RTX 5090が4枚（ドライバ615.71.09）、単価は1時間3.203米ドルである。
選定条件の価格の上限と貸出期限の条件を緩めて借りた。
診断は作業機（Intel Core Ultra 7 265KF、20コア、メモリ30 GB、RTX 3060 Ti）で行った。

## 結果

### 生成

| 項目 | 値 |
|---|---:|
| 本 | 37本 |
| 対局 | 275,798局（手数の上限で破棄した1,702局を除く） |
| 記録局面 | 101,625,210 |
| 訓練と検証 | 96,462,343局面、5,162,867局面 |
| 1本の所要時間 | 中央値631.9秒（612.9〜718.1秒） |
| 全体の探索速度 | 中央値約1億1,200万NPS（約9,890万〜1億1,510万NPS） |
| 生成の時間 | 約6.5時間 |
| 教師の勝率尺度 | 707.88 cp（ネットのKは第1世代から固定の679.03 cp） |
| 生成機の実費 | 23.64米ドル（学習と補正を含む） |

実費は、作成の前と削除の後の残高の差である。
探索速度は第1世代の本5（EPYC 9654の2基構成、約3,770万NPS）の約3倍である。
統合した高速化、機種、およびネットの違いのそれぞれの寄与は分けて測っていない。

### 教師ファイルの末尾の計算資源

生成中の本10から本12で、生成プロセスのスレッド数、CPU時間、および常駐メモリを1秒ごとに記録した。
開始から終了までを観測できた本11の値は次のとおりである。

| 項目 | 値 |
|---|---:|
| 1本の時間 | 634秒 |
| 100スレッド以下になるまで | 552秒 |
| 25スレッド以下になるまで | 569秒 |
| 使われなかった計算資源 | 13.25% |
| 常駐メモリ | 全スレッドで約83 GB、100スレッドで約24 GB |

100スレッド以下になった時点で次の本を始めると、CPU時間で数えた回収の上限は1.142倍である。
スレッドが少ない間は1スレッドあたりの探索が速い。
第1世代のコードで測った同時対局数ごとの速度の比（[記録](nnue-generation-reset-generator-speed.md)）を当てはめると、増える量は約1.12〜1.13倍になる。
この変更は、節約に対してスクリプトの変更が大きいので、2026年11月5日の利用者の決定により見送った。

### 生成機での学習

学習器のビルドから補正までは約50分である。

| 工程 | 終了時刻 |
|---|---:|
| 本36の受け取り | 22時5分 |
| 学習（2,566秒、うち前処理693秒） | 22時48分 |
| 駒除去差分の診断 | 22時53分 |
| 補正 | 22時56分 |
| 生成機の停止と削除、作業機でのbench、コミット | 22時58分 |

作業機で同じ条件を`--validation-interval 0`にして再学習すると、学習は1,355秒（うち前処理347秒）で終わり、書き出したネットはバイト単位で同じだった（[教師の量の比較](nnue-generation-reset-gen2-volume.md)）。
したがって、学習器はGPUによらず同じ結果を出す。
生成機の学習の内訳は、更新の計算が370秒、エポック境界の検証が231秒、途中検証が1,268秒である。
作業機は更新の計算が829秒、エポック境界の検証が178秒で、途中検証はない。
前処理は生成機の32スレッドで693秒、作業機の8スレッドで347秒だった。

### 評価の形

評価値の分布は、PST＋FMを基準にした標準偏差の比とピアソン相関で次のとおりである。

| ネット | 標準偏差の比 | 相関 |
|---|---:|---:|
| 第0世代 | 0.607 | 0.949 |
| 第1世代 | 0.649 | 0.969 |
| 第2世代（補正前） | 0.655 | 0.972 |
| 第2世代 | 0.654 | 0.969 |

駒除去差分の符号反転は、第2世代の教師の検証集合の10,000局面（516,352件の除去）で次のとおりである。
番号29の駒状態は歩兵、番号30は仲人であり、成れる駒種に駒種の順で番号を振る規則（`crates/minase/src/eval/features.rs`）から確かめた。

| ネット | 全体 | 平均の大きさ | 歩兵 | 仲人 |
|---|---:|---:|---:|---:|
| 第2世代（補正前） | 1.99% | 8.9 cp | 9.8% | 0.2% |
| 第2世代 | 4.21% | 21.0 cp | 13.4% | 55.9% |
| 第1世代 | 2.62% | 12.5 cp | 12.9% | 0.5% |

補正で仲人の補正の平均が−50 cpになり、仲人を取り除くと評価が上がる除去が半分を超えた。
量子化前の2つの計算経路の差は最大1.4×10⁻¹² cpで、上限1×10⁻⁶ cpを下回った。
合法手の評価差の診断では、補正の前後とも47局面すべてで合法手の集合がPST＋FMと一致した。

### 対局単位の汎化差

対局の結果を目標とした損失を、エンジンの整数の評価で求めた（[出力](nnue-generation-reset-gen2-training/gap_report.out)）。
訓練の対局は260,889局（10局面ごとに選んだ9,646,250局面）、検証の対局は13,835局（全5,162,867局面）である。

| 比較 | 汎化差の差 | 検証の損失の差 |

区間は対局を単位とする対応のあるブートストラップ（1,000回、シード1）の95%区間である。

## 結論

第2世代の教師は約1億局面、約27.6万局で、生成機の実費は学習を含めて23.64米ドルだった。
学習の健全性に問題は見られない。
汎化差は第0世代と区別できず、対局の記憶は見られない。
補正は予測を改善し（Dの区間の上限が負）、補正後のネットは、検証の対局の勝敗の予測の損失が補正前より0.0083低い。
一方で、補正は仲人の価値を下げ、駒除去差分の符号反転を増やした。
棋力への影響は[第2世代のSTC](nnue-generation-reset-gen2-stc.md)で判断する。

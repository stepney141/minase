# 第2世代の教師の量の比較

## 目的

世代反復の教師は1世代約1億局面である。
将棋の先行例では1億〜5億局面のネットが20億局面のネットに負けており（[調査メモ](../../research/nnue-training-recipes.md)）、minaseの教師が足りているかは測っていなかった。
2026年11月6日の利用者の指示により、第2世代の教師の量だけを変えて学習し、対局で比べる。

## コマンドライン

学習、補正、コミット、およびSTCは[スクリプト](nnue-generation-reset-gen2-volume/run_volume.py)で順に実行した。
教師ファイルを本0から順に、全37本、19本、および9本選び、学習と補正の両方に同じファイルだけを与えた。
対局ごとに1本へ書かれるので、局数と局面数が一緒に減る。

学習の引数は[第2世代の学習](nnue-generation-reset-gen2-training.md)と同じで、`--threads 8`と、途中検証を省いた点だけが違う。
途中検証は学習の軌跡を変えない。
全量のネットは、GPUの違いを比較から除くために作業機で再学習した。
補正の条件は第2世代と同じ（$`\tau`$は10、20、40、80、シード20261105）である。

STCは、候補を全量のネット、基準を少ない教師のネットとした。
`H1`は、教師を増やすと強くなることを示す。

```console
minase match run --run-dir data/matches/<測定名> --seed <シード> \
  --candidate commit:<全量> --baseline commit:<少ない教師> \
  --each time=10000+100 --concurrency 16 gsprt --max-pairs 3000
```

| 測定名 | シード | 基準 |
|---|---:|---|
| `nnue-generation-reset-gen2-volume-half-stc` | 20261202700000 | 19本 |
| `nnue-generation-reset-gen2-volume-quarter-stc` | 20261202800000 | 9本 |

## 環境

2026年11月6日に、作業機（Intel Core Ultra 7 265KF、20コア、メモリ30 GB、RTX 3060 Ti）で、学習とSTCを順に実行した。

## 結果

### 学習

| 項目 | 全量 | 半分 | 4分の1 |
|---|---:|---:|---:|
| 教師ファイル | 37本 | 19本 | 9本 |
| 対局 | 275,798局 | 141,620局 | 67,099局 |
| 訓練局面 | 96,462,343 | 49,497,419 | 23,452,550 |
| 教師の勝率尺度 | 707.88 cp | 710.38 cp | 701.85 cp |
| 最良エポック / 停止エポック | 2 / 7 | 3 / 8 | 3 / 8 |
| 総更新回数 | 41,216 | 24,176 | 11,456 |
| 量子化誤差の平均 | 4.46 cp | 5.48 cp | 6.44 cp |
| D | −0.005679 | −0.006457 | −0.006413 |
| Dの95%区間 | [−0.007093, −0.004309] | [−0.008150, −0.004639] | [−0.008849, −0.004263] |
| 学習の時間（前処理） | 1,355秒（347秒） | 771秒（185秒） | 382秒（97秒） |

検証集合は教師ごとに違うので、検証損失は比べない。
全量のネットは、生成機で学習した第2世代のネットと、補正の前も後もバイト単位で同じだった（`nnue.bin`のSHA-256は補正前`08b408d9…`、補正後`a2fa3850…`）。
教師を減らしても、最良のエポックは2〜3から動かなかった。
補正の出力は[全量](nnue-generation-reset-gen2-volume/fit_report-full.out)、[半分](nnue-generation-reset-gen2-volume/fit_report-half.out)、および[4分の1](nnue-generation-reset-gen2-volume/fit_report-quarter.out)にある。

### STC

| 比較 | 有効ペア | 度数 | LLR | 判定 | 得点率 | 得点率から求めたElo |
|---|---:|---|---:|---|---:|---:|
| 全量対半分 | 195 | [19, 7, 93, 4, 72] | +2.9814 | `H1` | 63.2% | 約+94 |
| 全量対4分の1 | 114 | [3, 0, 38, 4, 69] | +2.9662 | `H1` | 79.8% | 約+239 |

度数は候補の側から見た、0、0.5、1、1.5、および2点の順である。
所要時間は1,737秒と886秒で、どちらもエンジン異常、時間切れ、および拒否着手は0件だった。
逐次検定は判定が出た時点で止まるので、得点率から求めたEloは真の差より大きく出やすい。

## 結論

教師を増やすと強くなり、1億局面でも頭打ちに達していない。
4分の1から全量への差は約+239 Elo、半分から全量への差は約+94 Eloで、倍にするたびの伸びは小さくなりつつある。
この比較では対局と局面が一緒に減るので、どちらが効いたかは分けられない。
同じ局面数なら多くの対局から疎に採るほうが検証損失が低いという[過去の記録](../nnue-early-best-epoch/nnue-train-subsample.md)は、対局数が効くことを示唆するが、棋力では測っていない。
学習器はGPUによらず同じネットを出すので、生成機と作業機の学習を対局で比べるときに、GPUを揃えた対照は不要である。

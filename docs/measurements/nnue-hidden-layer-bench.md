# NNUEの出力部の計算時間と探索時間の増分の見積り

## 目的

[NNUEの隠れ層と位相補間の出力](../plans/archived/nnue-hidden-layer.md)のフェーズ2で推論に加えた3つの出力部（位相補間の直接内積D2、隠れ層つきS1、隠れ層つきの位相補間S2）について、出力部1回の計算時間を現行の直接内積D0と比べ、深さ9のbenchの評価回数を掛けて探索1回あたりの時間の増分を見積もる。
棋力測定ではない。採否は時間制御の段階ゲートが決め、本書は学習器の実装へ進む前に利用者へ示す速度の見積りである。

## 方法

出力部1回の時間は、ブランチ`nnue-hidden-layer-heads`のコミット`3b3b94b5`の`crates/minase`に依存する計測用のcrateで測った。
幅128の各出力部を値域内の乱数重みで作り、両視点の累算値（−40以上170以下の乱数）と係数q（0以上90以下の乱数）の64組を繰り返し与えて400万回呼び、1回あたりの時間を3回測った。
ビルドは本体と同じ`-C target-cpu=native`（AVX2）、`lto = true`、`codegen-units = 1`のリリースビルドであり、`taskset`で性能コア（CPU 6）に固定した。
測定の間、同じ機械でlishogiのBot（4スレッド）が動いていた。3回の幅はいずれも±1%以内である。

探索1回あたりの増分は、同じコミットの`minase dev bench --depth 9`（15局面、`ActiveHead`は現行の`DirectScrelu`）を性能コア（CPU 3）に固定して3回実行し、`accumulators:`行の更新回数を評価回数の上限として、出力部1回の時間の増分を掛けて求めた。
乱数重みのネットでは探索木が変わるので、新しい出力部をエンジンに入れたbenchのNPSは測っていない。

## 出力部1回の計算時間

| 出力部 | 積和の回数 | 1回の時間（3回の範囲） | D0との差 |
|---|---:|---:|---:|
| D0 `direct-screlu`（現行） | 256 | 17.2 ns（17.2〜19.1） | 0 |
| D2 `direct-screlu-phase2` | 512 | 28.4 ns（28.4〜28.5） | +11.2 ns |
| S1 `screlu-hidden16` | 4,368 | 136.5 ns（136.4〜136.5） | +119.3 ns |
| S2 `screlu-hidden16-phase2` | 4,624 | 145.1 ns（145.0〜145.2） | +127.9 ns |

隠れ層つきの時間は設計書が見込んだ積和の約17倍ではなく約8倍である。
現行の直接内積はLLVMが`vpmaddwd`（16ビットの積を隣接対で足す命令）へ自動ベクトル化しており、新しい出力部も同じ命令列になるよう、活性化を`u8`の一時配列に書いてから16ビットへ広げた積和を取る形にした。
`objdump -d`で数えた命令は、D0の呼び手に`vpmaddwd`54個、`vpmulld`0個、S1の隠れ層`Hidden16::output`に`vpmaddwd`4個と`vpmovsxbw`4個であり、32ビット乗算`vpmulld`は端数の処理にだけ残る。
最初の実装は活性化を`i32`の配列に置いていたため`vpmulld`（32ビット乗算）の経路になり、S1は415 ns、D2は177 nsだった。
さらに活性化のループが2つのスライスを`chain`で連結していたため、そのループがベクトル化されず、約140 nsの固定費がD2、S1、S2に共通して乗っていた（分割前のS1は238 ns、D2は158 ns）。
自動ベクトル化で`vpmaddwd`が得られたので、SIMDのクレートは試していない。

## 探索時間の増分の見積り

深さ9のbench（15局面）は、3回とも総ノード数6,228,009、累算器の更新6,400,021回（再計算15回）であり、所要時間は4.22〜4.30秒（NPS 1,447,458〜1,477,435）だった。

| 出力部 | 出力部1回の増分 | 評価6,400,021回での増分 | 探索時間に対する割合 |
|---|---:|---:|---:|
| D2 | +11.2 ns | +0.072秒 | +1.7% |
| S1 | +119.3 ns | +0.76秒 | +18% |
| S2 | +127.9 ns | +0.82秒 | +19% |

割合の分母は3回のbenchの所要時間の中央値4.23秒である。
評価のたびに出力部を全計算するので、隠れ層つきの出力部は同じ時間で読めるノード数を約15%減らす。
位相補間だけの出力部の費用はほぼ無視できる。

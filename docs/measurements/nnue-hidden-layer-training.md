# NNUEの隠れ層と位相補間の出力の学習の記録

## 目的

[NNUEの隠れ層と位相補間の出力](../plans/nnue-hidden-layer.md)のフェーズ1とフェーズ4について、補助損失なしの直接内積である基準D0と、位相補間の直接内積D2、隠れ層つきS1、隠れ層つきの位相補間S2の学習の結果を、比較の起点のネットの値と並べて記録する。
棋力測定ではないので、ペンタノミアル度数やLLRは持たない。
段階ゲートの測定は別の記録に書き、設計書からリンクする。

## 比較の起点

比較の起点は、[学習率スケジュール](../plans/archived/nnue-lr-schedule.md)が採用し、masterに埋め込まれているcosineのネット（SHA-256 `311be801…`、出力ディレクトリ`data/nnue-lr-schedule-train/cosine-t3-f01/`）である。
このネットは、駒除去差分の補助損失（係数1,000）を使う学習器で、再生成した30ファイル（訓練79,458,082局面、検証4,153,303局面、教師の勝率尺度1,007.49）から、P型の幅128を学習率cosine（総長3エポック、下限0.1）で学んだものである（[学習の記録](nnue-lr-schedule-training.md)）。
起点の符号反転の割合は、`diag nnue-removal`で検証集合の1万局面（シード1）について測った値を用いる。
この1万局面は、起点とD0の`summary.json`の`quantization.indices_sha256`がともに`80d95361…`であることから同じ標本であり、除去の母数も両者とも562,129で一致するので、`diag nnue-removal`の値とフェーズ0で学習器の書き出し時に加えた検査の値は直接比べられる。

## フェーズ1　基準D0の学習

D0は、フェーズ0で補助損失を削除した学習器（ブランチ`nnue-hidden-layer`のコミット`a14d185c`、バイナリは`data/nnue-hidden-layer-train/minase-trainer-phase0`、SHA-256 `e15bd4dd…`）で、起点と同じデータ、初期値、先読み教師、バッチ、シード、学習率で学んだ。
学習は2026年10月16日に作業機（RTX 3060 Ti、Core Ultra 7 265KF、メモリ30 GB）で`data/nnue-hidden-layer-train/train.sh`により実行し、同じ機械でlishogiのBot（4スレッド）と推論側の実装の検査が並行していた。

```console
data/nnue-hidden-layer-train/minase-trainer-phase0 nnue train --feature-set P --width 128 \
  --data data/nnue-lr-schedule-gen/generated-*.bin \
  --init-pst data/pst-fm-joint-training/j75/pst-float.npz \
  --base crates/minase/nets/pst.bin \
  --lambda 1.0 --teacher-cp-per-logit calibrate \
  --lookahead-gamma 0.9 --lookahead-plies 40 \
  --batch 16384 --epochs 50 --patience 5 --seed 1 --threads 12 --device cuda \
  --lr-schedule cosine:3:0.1 \
  --output-dir data/nnue-hidden-layer-train/d0
```

D0の`nnue.bin`のSHA-256は`7b286e44…`、量子化誤差の上限は`K/40` = 26.8センチポーンであり、量子化の検査を通った。
1エポックの時間は、補助損失を外したことにより起点の約半分になった。
最良の検証損失は、起点より0.0000175（0.004%）低い。
一方、符号反転の割合は起点の約1,900倍に増え、駒を除いた局面を元の局面より高く評価する除去が全体の1.7%に現れた。
補助損失の罰則が学習中にほとんど発火しなかった（[学習の記録](nnue-replacement-training.md)）のは、補助損失が符号を保っていた結果であり、補助損失なしでも符号が保たれることを意味しなかった。
反転の内訳は`diag nnue-removal`の報告（`data/nnue-hidden-layer-train/d0.removal.json`）の`by_piece_state`にあり、9,495件のうち9,434件が成っていない歩兵の除去（131,705件中7.2%）、56件が仲人の除去（15,393件中0.36%）で、他の駒種は0〜3件である。
符号反転が棋力に与える影響は段階ゲートが測る。

## フェーズ4　候補の学習と選択

フェーズ3でCUDA側の出力部の内積の縮約をワープ内の固定の木に改めたため、直接内積の学習結果もフェーズ0の学習器と1ビット単位では一致しなくなった（[検査の記録](nnue-trainer-rust-checks.md)）。
候補との比較を同じ学習器で行うため、基準D0をフェーズ3完了時点の学習器（ブランチ`nnue-hidden-layer`、バイナリ`data/nnue-hidden-layer-train/minase-trainer-phase3`、SHA-256 `7435b6c6…`）で学び直し（D0b）、D2、S1、S2を同じ学習器、同じデータ、初期値、先読み教師、バッチ、シード、学習率で順に学んだ（2026年10月16日、`data/nnue-hidden-layer-train/phase4.sh`。コマンドはフェーズ1と同じで、`--head`だけが異なる）。
学習の間、同じ機械でlishogiのBot（4スレッド）が動いていた。

エポック0の検証損失は4本で一致し、学習の始点が同じ関数であることを示す。
4本とも量子化誤差の平均は上限`K/40` = 26.8センチポーン以内であり、量子化の検査を通った。
D0bの最良の検証損失は、フェーズ1のD0（0.4488899）と0.0000030（0.0007%）だけ異なり、縮約順の変更の影響はこの程度である。

3候補の最良の検証損失は、いずれも基準D0bより高い（D2が0.0000364、S1が0.0000725、S2が0.0000752高い）。
隠れ層つきの2候補は訓練損失が基準より低い（停止時に0.0003ほど）一方で検証損失が早いエポックで悪化し始め、最良エポックは1である。
これは、表現力を増やした分が検証集合の損失ではなく訓練集合への適合に使われたことを示し、設計書の「目的」が挙げた、エポック1以後に訓練損失だけが下がる過学習の兆候と整合する。
位相補間だけのD2も基準を下回らなかったので、非線形部分の重みを序盤と終盤で分けることも、このデータと学習の条件では検証損失を下げなかった。
隠れ層の活性化は、最良エポックの時点で約37〜41%が1に飽和し、25〜35%が0であった。

「設計判断」の選び方（量子化の検査を通った候補のうち、最良の検証損失が基準より低いものから最も低い1つを段階ゲートに出す）に該当する候補はないので、段階ゲートは行わない。
フェーズ4の4本の`nnue.bin`には、仕様から書いた整数参照（学習器のテストにあり、テスト内で短く学んだネットに対して推論側の評価と照合する）を当てていない。4本について確かめたのは、書き出し時の量子化誤差の検査（実数参照と整数推論の差）だけである。
候補が段階ゲートに出なかったので、候補のネットでの差分更新と全再計算の一致、鏡映の一致、および探索の確認も行っていない。

# 麒麟の右側の筋への選好の診断

## 目的

[線形経路を駒価値で初期化する計画](../../plans/archived/nnue-material-linear-init.md)の「麒麟の診断」として、人間同士の対局の局面で麒麟を同じ段の3筋と7筋へ置き直したときの静的評価の差Rを現行のネットと新しいネットで求め、線形経路の初期値だけを変えたときに3筋への選好の半分より多くが残るかを判定する。

## コマンドライン

スクリプトは本記録と同じディレクトリの`nnue-material-linear-init-kirin/`にあり、そのディレクトリで実行した。
`kirin_diag.py`が診断の本体、`test_kirin_diag.py`がそのテストであり、テストは筋によらず段だけで決まる仮の評価を与えるとRがちょうど0になることを含む25件である（`python3 -I -m unittest`ですべて成功した）。
`R`は本体のリポジトリのルート、`D`は`$R/data/nnue-material-linear-init`である。

```console
python3 -I kirin_diag.py evaluate $D/minase-master $R/data/lishogi/games.ndjson $D/kirin-current.json
python3 -I kirin_diag.py evaluate $D/minase-material $R/data/lishogi/games.ndjson $D/kirin-material.json
python3 -I kirin_diag.py judge $D/kirin-current.json $D/kirin-material.json --output $D/kirin-judge.json
```

`judge`の出力は、同じディレクトリの`kirin-judge.json`に写した。
置き直した全局面の評価値を含む`evaluate`の出力（各43 MB）は、リポジトリに含めていない。

## エンジン

両ネットとも、minaseのUSIの独自コマンド`eval`の評価値と非線形部分を使い、規則セットは`engine-default`とした。
線形経路の値は、評価値から非線形部分を引いた値である。

| ネット | 実行ファイル | 実行ファイルのSHA-256 | 埋め込みのネット |
|---|---|---|---|
| 現行 | `minase-master`（`b8bebfb3`と同じ`crates/minase`と`crates/minase-core`からビルド） | `bd0632e4e85237d443f171b647d0b4fef377a243e507d8937e0117681d4d8133` | `faa5fbe2…`（`f0a83cff`で埋め込み） |
| 新しい | `minase-material`（`6d47da2a`からビルド） | `c6786867406cb2aeceb9308660f8b31e69ad6b6ed4acc7500ac7f52c75bb03c5` | `5257f374…` |

## 環境

測定機（Intel Core Ultra 7 265KF、20コア）で、2026年10月25日に行った。
対局は行っておらず、計算は棋譜の再生と静的評価だけである。
`evaluate`の所要時間は、現行のネットが13.6秒、新しいネットが10.7秒だった。

## 結果

### 局面

棋譜は`data/lishogi/games.ndjson`（23,567局、2026年9月22日取得、SHA-256 `58bbec58…`）である。
標準の初期局面から始まり、両対局者が人間で、62手以上続いた対局は6,397局あり、再生に失敗した対局はなかった。
20、21、40、41、60、61手目を指した後の局面のうち、手番側の麒麟が成らずに盤上にいた局面は6,395局の37,661局面（麒麟がいなかった局面は721局面）だった。
これらの局面で麒麟を各置き直し先へ移した273,220局面を、各ネットで評価した。
Rに使ったのは、同じ段の3筋と7筋がともに置き直し先になる段を持つ5,213局の13,335局面であり、残りの24,326局面にはそのような段がなかった。
計画の起案時の検算はこの局面集合を29,485局面としていたが、その数え方は記録されておらず、本測定の手順では再現できなかった。
置き直した局面は棋譜の盤面から作ったSFENで評価したので、先獅子の一時状態は評価に含まれていない。

### 判定

95%区間は、Rの計算に使った5,213局を単位とするブートストラップの復元抽出を1,000回（乱数のシード1）繰り返し、2.5パーセンタイル点と97.5パーセンタイル点（順位の線形補間）から求めた。

| 量 | 点推定（センチポーン） | 95%区間（センチポーン） |
|---|---:|---|
| R_現 | 121.24 | [120.35, 122.03] |
| R_新 | 128.77 | [127.98, 129.50] |
| D = R_新 − 0.5 R_現 | 68.15 | [67.63, 68.65] |

R_現の区間の下限は0より大きく、Dの区間の下限も0より大きいので、判定は「半分より多くが残る」である。
R_新はR_現より大きく、選好は弱まらなかった。
この区間は、固定した2本のネットに対する局面の抽出の変動だけを表し、同じ条件で学習し直したときのネットのばらつきを含まない。

### 筋ごとの偏差

分析の記録[麒麟が自陣の右端へ寄る傾向](../adhoc/kirin-right-edge-bias.md)と同じ形で、各局面で置き直した全升の値の平均を引いた偏差を、持ち主から見た筋ごとに平均した（標本20未満の升は除く）。
筋1が持ち主の右端、12が左端である。
この表は筋ごとの傾向を見るための参考であり、判定には使っていない。

現行のネットは次のとおりである。

現行のネットでは、3筋と2筋への選好が線形経路と非線形部分の両方に現れる。
新しいネットでは、線形経路の偏差がどの筋でも4センチポーン以内であり、評価値の偏差のほぼすべてを非線形部分が担う。
[学習の記録](nnue-material-linear-init-training.md)のとおり、新しいネットの線形重みは駒価値の初期値から平均1センチポーン前後しか動いていない。
計画では、線形経路が駒価値から升ごとの値を学びきれない場合にも選好が小さくなり得ると見込んでいたが、選好は小さくならず、線形経路が持たない升ごとの差を非線形部分が学んだ。

## 結論

線形経路の初期値を学習済みPSTから探索用駒価値へ変えても麒麟の3筋への選好は残った（R_新128.8センチポーン、R_現121.2センチポーン、判定は「半分より多くが残る」）ので、この選好は前の世代のPSTの移植ではなく教師データに由来し、偏りを減らすには教師データの作り方を見直す必要がある。

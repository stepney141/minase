# 線形経路を駒価値で初期化したネットの非劣性のSTC

## 目的

[線形経路を駒価値で初期化する計画](../../plans/nnue-material-linear-init.md)のフェーズ5の選別として、masterを候補、線形経路を探索用駒価値で初期化したネットを埋め込んだコミットを基準とする短時間の時間制御のGSPRTで、新しいネットがmasterより約10 Elo以上弱い可能性を退けられるかを調べる。

## コマンドライン

本体のリポジトリのルートで、`b8bebfb3`と同じ`crates/minase`からビルドしたrunner（`data/nnue-material-linear-init/minase-master`、SHA-256 `bd0632e4e85237d443f171b647d0b4fef377a243e507d8937e0117681d4d8133`）で実行した。

```console
data/nnue-material-linear-init/minase-master match run \
  --run-dir data/matches/nnue-material-linear-init-noninferiority-stc --seed 6400000000 \
  --candidate commit:b8bebfb3 --baseline commit:6d47da2a \
  --each time=10000+100 --concurrency 16 gsprt --max-pairs 3000
```

仮説は既定のH0がelo=0、H1がelo=10、α=β=0.05である。
候補にmaster、基準に新しいネットを置いたので、`H0`は「masterが10 Elo強い」という仮説を誤り率5%で退けたこと、すなわち新しいネットが約10 Elo以上弱い可能性を退けたことを意味する。
シードは、既存の測定の最大のシード（[movetimeの計画](../../plans/movetime-deadline.md)の6,250,000,000）から上限ペア数より離れた値を選んだ。

## エンジン

| 役 | コミット | 実行ファイルのSHA-256 | 埋め込みのネット |
|---|---|---|---|
| 候補 | `b8bebfb370a6844f060eab1b7abb895d58c5345d`（master） | `4733e7e9f520e992c262a8f5d968706bce8d828e529ba0c746220e6f7c3c11aa` | 現行のネット（`faa5fbe2…`、線形経路の初期値は学習済みPST） |
| 基準 | `6d47da2a9663918f8992290834d9c47e695de98f` | `111b9f66765a9043b1d553de1792b501cd0ea563eeff04d46dacff34cfdec272` | 新しいネット（`5257f374…`、線形経路の初期値は探索用駒価値） |

2つのコミットの差は、学習器の変更、ドキュメント、および埋め込みのネットだけであり、探索と評価の実装は同じである。
規則セットは`engine-default`（L0,P0,R1,E0）である。

## 環境

測定機（Intel Core Ultra 7 265KF、物理20コア、論理20コア、実メモリ33,218,797,568バイト）で、2026年10月25日12時18分から16時24分まで行った。
候補と基準のワーカー数（`Threads`）はともに1、`USI_Hash`はともに256 MB、同時対局数は16、時間制御は持ち時間10秒、1手0.1秒加算である。
同じ機械でlishogiのBotが2局を4スレッドずつで指しており、対局のエンジンと合わせて20コアを超える負荷がかかっていた。
負荷は候補と基準に同じ条件でかかり、1ペアあたりの時間は約8.2秒だった。

## 結果

| 項目 | 値 |
|---|---|
| ペンタノミアル度数（候補のペア得点0、0.5、1、1.5、2） | [370, 65, 900, 67, 350] |
| 有効ペア数 / 実行ペア数 | 1,752 / 1,778 |
| 破棄ペア数（手数上限4,096） | 26 |
| LLR | −2.958 |
| 判定 | `H0` |
| エンジン異常（不正着手、クラッシュ、応答タイムアウト） | 0、0、0 |
| `time_forfeits` | 0 |
| `rejected_moves` | 0 |
| 経過時間（`summary.json`の`active_wall_time_ns`） | 14,651秒（4時間4分） |

ペンタノミアル度数は、候補の勝ち越し側（1.5と2）が417、負け越し側（0と0.5）が435であり、ほぼ対称である。

## 結論

STCは`H0`であり、異常は0件だったので、設計書の採否の規則に従い、新しいネットを非劣性のLTCへ進めた。

# 先読みなしの教師によるNNUEの学習と先読み教師の仮説の判定

## 目的

[NNUEの検証損失の頭打ちの切り分け](../plans/nnue-early-best-epoch.md)のフェーズ2として、現行の埋め込みネットD0bの学習コマンドから先読み教師を外した2本のネットを学習し、先読み教師が訓練の対局への適合を強めるという仮説を、設計書の「仮説ごとの判定」に定めた基準で判定する。
2本は、教師の勝率尺度を先読みなしの探索値から推定し直した候補（段階ゲートに出す）と、尺度をD0bの値に固定した対照（仮説の判定に使う）である。

## コマンドライン

学習は`data/nnue-early-best-epoch/train.sh`で行った。
学習器はmaster `7307d3d2`でビルドした`data/nnue-early-best-epoch/minase-trainer`（SHA-256 `431d2b5b…`）である。
測定機で別のSPSAが動いていたので、nice値19、CPUスレッド4本、メモリ上限13 GBで動かした。
`--threads`は再開時に変更できる引数であり学習の軌跡を変えないので、D0bの12スレッドから4スレッドへ減らした。
共通部分は次のとおりである。

```console
systemd-run --user --scope -q -p MemoryMax=13G -p MemorySwapMax=0 \
  nice -n 19 data/nnue-early-best-epoch/minase-trainer nnue train --feature-set P --width 128 \
  --data data/nnue-lr-schedule-gen/generated-*.bin \
  --init-pst data/pst-fm-joint-training/j75/pst-float.npz \
  --base crates/minase/nets/pst.bin --lambda 1.0 \
  --batch 16384 --epochs 50 --patience 5 --seed 1 --threads 4 --device cuda \
  --lr-schedule cosine:3:0.1 --output-dir <出力先> <各学習の引数>
```

各学習の引数は次のとおりである。

| 学習 | 出力先 | 引数 |
|---|---|---|
| D0bの再現 | `d0b-repro` | `--teacher-cp-per-logit calibrate --lookahead-gamma 0.9 --lookahead-plies 40` |
| 候補 | `no-lookahead` | `--teacher-cp-per-logit calibrate --validation-interval 1000` |
| 対照 | `no-lookahead-fixed-scale` | `--teacher-cp-per-logit calibration-raw-fixed-scale.json --validation-interval 1000` |

対照の較正ファイルは、先読みの引数なしで`minase-trainer data calibrate --data <学習と同じ30ファイル> --threads 4`が書き出した`calibration-raw.json`（教師の勝率尺度1,039.5786センチポーン）を写し、`teacher_cp_per_logit`だけをD0bの`config.json`の値1,007.4941198261047に書き換えたものである。

学習後の集計は、[決着局面の集計](nnue-teacher-decided-positions.md)と同じ`teacherstat`で、4つのネットと3つの教師について行った（出力は`data/nnue-early-best-epoch/phase2/`）。

```console
nice -n 19 teacherstat --threads 4 --stride 10 --boot 1000 --boot-seed 1 --bin-teacher la \
  --json phase2.json \
  --net e0=crates/minase/nets/nnue-epoch0.bin \
  --net d0b=data/nnue-hidden-layer-train/d0b/nnue.bin \
  --net cand=data/nnue-early-best-epoch/no-lookahead/nnue.bin \
  --net ctrl=data/nnue-early-best-epoch/no-lookahead-fixed-scale/nnue.bin \
  --teacher la=lookahead:0.9:40:1007.4941198261047 \
  --teacher rawc=raw:1039.5786170404363 --teacher rawf=raw:1007.4941198261047 \
  --compare d0b:ctrl --compare d0b:cand --compare e0:d0b --compare e0:ctrl --compare e0:cand \
  -- data/nnue-lr-schedule-gen/generated-*.bin
```

`la`はD0bの先読み教師、`rawc`は候補の先読みなしの教師、`rawf`は対照の先読みなしの教師である。
候補の診断は、[学習の手引き](../guides/nnue-training.md)の8節の3つのコマンドで行った。
評価値の分布は30ファイルの全局面から2万局面（シード1）を選び、基準を`crates/minase/nets/pst.bin`として候補とD0bを同じ標本で比べた。
駒除去差分は検証集合の1万局面（シード1）、合法手の評価差は[一様シャッフルの照合](out-of-core-shuffle-equivalence.md)のlishogiの47局面（`data/out-of-core-shuffle/teacher/lishogi.bin`）で行った。

## 環境

測定機（Intel Core Ultra 7 265KF、20コア、メモリ30 GB、RTX 3060 Ti）で、2026年10月17日に行った。
同じ機械で、別の計画のSPSA（同時対局数16）とlishogiのBotが動いていた。
経過時間と最大常駐メモリは、D0bの再現が40分38秒と10.4 GB、候補が2時間9分8秒と10.6 GB、対照が1時間49分17秒と10.6 GBである。
集計は約20分かかった。

## 結果

### D0bの再現

D0bのコマンドを学習器だけ変えて実行した学習は、エポック2で最良となり（検証損失0.44889290232297857）、書き出した`nnue.bin`のSHA-256は`046be0e6…`でD0bと一致した。
したがって、現行の学習器はD0bの学習と同じ更新を行う。

途中検証（1,000更新ごと、1エポックは4,850更新）での検証損失の最小は、2本ともエポック13の終わり近くの63,000更新目であった。

### 対局結果を目標とした汎化差

対局の結果（手番側から勝ち1、引き分け0.5、負け0）を目標とした損失を、訓練の対局（10局面ごとに選んだ7,945,793局面）と検証の対局（全4,153,303局面）で求めた。
汎化差は検証の損失から訓練の損失を引いた値である。

| ネット | 訓練 | 検証 | 汎化差 |
|---|---:|---:|---:|
| エポック0 | 0.468620 | 0.466801 | −0.001819 |
| D0b | 0.450530 | 0.450913 | +0.000383 |
| 候補 | 0.454536 | 0.453010 | −0.001526 |
| 対照 | 0.454564 | 0.452930 | −0.001633 |

### 候補の診断

評価値の分布では、候補の標準偏差はPST＋FMの1.035倍（判定の範囲0.9〜1.1の内側）、D0bは1.113倍であり、PST＋FMとのピアソン相関は候補が0.9940、D0bが0.9918である。
駒除去差分では、量子化前の重みの2つの計算経路の差の最大は3.8×10⁻¹²センチポーン（上限10⁻⁶）で、符号反転は562,129件中3,161件（0.56%）である。
合法手の評価差では、47局面すべてで候補とPST＋FMの合法手の集合が一致した。
量子化誤差の検査（検証1万局面の平均絶対誤差15.66センチポーン、上限26.82センチポーン）も通った。
いずれも計算経路の不一致を示さないので、候補を段階ゲートへ出した。

## 判定

d1の95%区間[+0.001726, +0.002323]の下限が0より大きいので、先読み教師が訓練の対局への適合を強めるという仮説は「支持」である。
ただし、d2の95%区間[−0.002295, −0.001715]は負であり、先読みを外すと検証の対局の結果の当てはまりは悪くなる。
したがって、設計書の基準により、「先読みを外すと訓練の対局への適合は弱まるが、検証の当てはまりは改善しない」と結論し、「先読み教師は頭打ちの一因である」とは結論しない。
なお、先読み教師は後続の局面の探索値を含むので、構成上、局面自身の探索値より対局の結果との相関が高い。
d2は汎化の良さだけでなく、教師が結果の情報をどれだけ含むかも反映するので、検証の結果の損失が低いことは、先読み教師で学んだネットが対局で強いことを意味しない。
実際に、先読みなしの候補は[STC](nnue-no-lookahead-stc.md)と[LTC](nnue-no-lookahead-ltc.md)でD0bより有意に強かった。

## 結論

先読み教師で学んだD0bは、データを学習していないネットより訓練の対局の結果に強く適合しており、先読みを外すとこの適合は学習前と区別できない程度まで消えた。
しかし、検証の対局の結果に対する損失はD0bのほうが低く、先読みを外しても結果の当てはまりは改善しなかった。

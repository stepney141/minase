# 補助損失なしで学んだNNUE対現行masterのネットのLTC

## 目的

[STC](nnue-no-removal-loss-stc.md)で選別した、補助損失なしで学んだNNUE（現行の埋め込みネットと同じ入力特徴集合P型、幅128、直接内積）を、現行の埋め込みネットの代わりに採用してよいかを、長時間の時間制御のGSPRTで判定する。

## コマンドライン

```console
target/release/minase match run \
  --run-dir data/matches/nnue-no-removal-loss-ltc --seed 2800100000 \
  --candidate commit:f98c1e81 --baseline commit:bfdb9f4e \
  --concurrency 16 --each time=60000+200 gsprt
```

## エンジン

STCと同じである。候補は`f98c1e81`（master `bfdb9f4e`の`crates/minase/nets/nnue.bin`を補助損失なしで学んだネット、SHA-256 `046be0e6…`へ差し替えたコミット）、基準は`bfdb9f4e`（master、埋め込みのネットは補助損失ありのcosineのネット、SHA-256 `311be801…`）。規則セットは`L0,P0,R1,E0`、`USI_Hash`は両者256 MB、`Threads`は両者1。

## 環境

作業機（Core Ultra 7 265KF、物理20コア、論理20コア、メモリ30 GB）、同時16ペア、runnerはmaster `29c729ac`の`minase`。
測定の間、同じ機械でlishogiのBot（4スレッド）が動いていた。

## 結果

| 項目 | 値 |
|---|---|
| 有効ペア数 | 966（実行978、破棄12） |
| ペンタノミアル度数 | [187, 5, 519, 11, 244] |
| LLR | 2.9506 |
| 判定 | H1 |
| 破棄ペア | 12（いずれも手数上限4,096手に到達） |
| 異常件数 | 不正着手0、クラッシュ0、応答タイムアウト0、時間切れ0、拒否着手0 |
| 経過時間 | 24,261秒（`summary.json`の累計24,177秒） |

LLRは531ペアで+1.58、782ペアで+1.25と一度戻ってから、966ペアで境界を越えた。

## 結論

候補はLTCでも有意に強く、異常件数、時間切れ、拒否着手はいずれも0件なので、補助損失なしで学んだネットを埋め込みネットとして採用する。
補助損失なしのネットは検証1万局面の除去の1.7%で駒を失った側が有利になる向きに評価が動く（補助損失ありでは5件）が、時間制御の対局ではその影響より検証損失の差（0.004%）を含む全体の差が勝った。

# 補助損失なしで学んだNNUE対現行masterのネットのSTC

## 目的

[NNUEの隠れ層と位相補間の出力](../plans/archived/nnue-hidden-layer.md)で学習器から駒除去差分の補助損失を外した後、現行の埋め込みネットと同じアーキテクチャ（入力特徴集合P型、幅128、直接内積）を補助損失なしで学んだネットが、補助損失ありで学んだ現行の埋め込みネットより強いかを、短時間の時間制御のGSPRTで選別する。
同書は候補の出力部が検証損失で基準を下回らなかったので段階ゲートを行わず、補助損失なしのネットは対局で試されていなかった。本測定は利用者の指示（2026年10月16日）による。

## コマンドライン

```console
target/release/minase match run \
  --run-dir data/matches/nnue-no-removal-loss-stc --seed 2800000000 \
  --candidate commit:f98c1e81 --baseline commit:bfdb9f4e \
  --concurrency 16 --each time=10000+100 gsprt --max-pairs 3000
```

## エンジン

- 候補: `f98c1e81`（ブランチ`nnue-no-removal-loss`。master `bfdb9f4e`に対し、`crates/minase/nets/nnue.bin`を補助損失なしで学んだネット（SHA-256 `046be0e6…`、[学習の記録](nnue-hidden-layer-training.md)のD0b）へ差し替えただけのコミット）。
- 基準: `bfdb9f4e`（master。埋め込みのネットは[学習率スケジュール](../plans/archived/nnue-lr-schedule.md)で採用したcosineのネット、SHA-256 `311be801…`）。
- 両ネットは同じ30ファイル（訓練79,458,082局面）、初期値、先読み教師、バッチ、シード、学習率（`cosine:3:0.1`）で学んだものであり、違いは補助損失の有無と、学習器のCUDA側で出力部の内積の縮約順を固定の木に改めたこと（[検査の記録](nnue-trainer-rust-checks.md)）だけである。候補の最良の検証損失は0.4488929（基準は0.4489074）、検証1万局面の除去562,129件の符号反転は9,358件（基準は5件）である。
- 規則セットは`L0,P0,R1,E0`、`USI_Hash`は両者256 MB、`Threads`は両者1（既定値）。

## 環境

作業機（Core Ultra 7 265KF、物理20コア、論理20コア、メモリ30 GB）、同時16ペア、runnerはmaster `29c729ac`の`minase`。
測定の間、同じ機械でlishogiのBot（4スレッド）が動いていた。

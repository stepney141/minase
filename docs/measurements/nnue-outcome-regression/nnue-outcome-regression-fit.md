# nnue-outcome-regression-fit

## 目的

現行のNNUEの線形の経路の序中盤の列を、既存の教師の対局結果へのロジスティック回帰（Texel tuningと同種）で補正し、判定の対局で予測が改善するかを[設計書](../../plans/archived/nnue-outcome-regression.md)の規則で判定して、配置の距離の比較に使うペア数を固定する。

## コマンドライン

`D`は`data/nnue-outcome-regression`である。
スクリプトとその標準出力は、本記録と同じディレクトリの`nnue-outcome-regression-fit/`にあり、スクリプトはそのディレクトリで実行した。

```console
$D/minase-trainer nnue fit-linear --base crates/minase/nets/nnue.bin \
  --data data/nnue-lr-schedule-gen/generated-*.bin --tau 10 20 40 80 \
  --seed 20261103 --output-dir $D/fit --threads 12
python3 -I fit_report.py --summary $D/fit/summary.json --data <リポジトリのdata>
python3 -I -u saved_games_d.py --data <リポジトリのdata> \
  --base-bin target/match-cache/6d47da2a9663918f8992290834d9c47e695de98f/minase \
  --corrected-bin $D/minase-corrected \
  --runs nnue-material-linear-init-noninferiority-ltc nnue-material-linear-init-noninferiority-stc
python3 -I -u placement_distance.py check --data <リポジトリのdata>
python3 -I -u placement_distance.py power --data <リポジトリのdata> \
  --run nnue-material-linear-init-noninferiority-stc
$D/minase-trainer diag nnue-distribution \
  --pair current crates/minase/nets/pst.bin <現行のネット> \
  --pair corrected crates/minase/nets/pst.bin $D/fit/nnue.bin \
  --data data/nnue-lr-schedule-gen/generated-*.bin --sample 20000 --seed 1 --output $D/diag/distribution.json
$D/minase-trainer diag nnue-moves --net $D/fit/nnue.bin --base crates/minase/nets/pst.bin \
  --positions data/out-of-core-shuffle/teacher/lishogi.bin --output $D/diag/moves.json
```

## 結果

### 回帰

対局と局面の数は次のとおりである。

| 集合 | 対局数 | 局面数 |
|---|---:|---:|
| 訓練 | 175,415 | 872,112 |
| τの選択 | 19,597 | 97,491 |
| 判定 | 10,271 | 51,081 |

手数帯ごとの勝率尺度K_tは、60〜79手から20手刻みの5区分の順に1,151.7、1,200.9、1,224.8、1,224.1、1,222.9 cpであり、基点のネットの勝率尺度1,072.7 cpに近い。
手番の切片c_uは先手番が−0.0122、後手番が+0.0072である。

τの選択に使う対局の損失は、補正なしで0.648724である。

| τ（cp） | 損失 | 補正なしとの差 |
|---:|---:|---:|
| 10 | 0.644436 | −0.004288 |
| 20 | 0.643278 | −0.005446 |
| 40 | 0.642650 | −0.006074 |
| 80 | 0.642474 | −0.006250 |

候補のうち最大のτ = 80を選んだ。
τをさらに大きくすれば、損失はわずかに下がる可能性がある。

### 判定の対局の予測

判定の対局で、書き出したネットの整数評価から求めた損失は、補正なしで0.644788、補正ありで0.637695である。
その差Dは−0.007093であり、対局を単位とする対応のあるブートストラップ（1,000回、乱数のシード1）の95%区間は−0.008847〜−0.005155である。
区間の上限が0より小さいので、規則のとおり先へ進む。

### 教師より新しい対局の診断

`nnue-material-linear-init-noninferiority`のLTCとSTCの対局から、30,908局面（6,230局）を取った。
ペア番号の偶数側で推定し直したK_tは820〜999 cp、c_uは先手番が+0.0956、後手番が−0.0664である。
奇数側の3,113局のDは−0.005599、95%区間は−0.009487〜−0.001452である。
区間全体が負であり、教師の対局と新しい対局で補正の向きは食い違っていない。
この対局は補正の区分を決めるのに使ったので、独立な確認にはならない。
設計書の定めるフェーズ3の基準の対局での診断は、その対局を終えた後に基準の対局の記録へ書く。

### 補正の内容

補正は駒種の配置の差だけでなく、駒種の価値の差も吸収している。
[回帰の式](../../plans/archived/nnue-outcome-regression.md#結果回帰の定義)には枚数の差の項がないので、駒1枚あたりの平均の補正がそのまま駒の評価を動かす。
現行のネットの20〜99手の配置で重みづけると、1枚あたりの平均は次のとおりである（q = 90、すなわち初期局面の駒数のときの値）。

|---|---:|---:|---|---:|---:|
| 竪行 | +262.1 | 43.7 | 仲人 | −92.3 | 16.8 |
| 反車 | +242.2 | 22.2 | 麒麟 | −89.8 | 21.9 |
| 飛車 | +207.5 | 31.1 | 歩兵 | −54.4 | 23.2 |
| 龍王 | +173.4 | 6.9 | 奔王 | −35.0 | 22.2 |
| 角行 | +154.9 | 18.3 | 盲虎 | −30.8 | 33.6 |
| 香車 | +146.2 | 0.6 | 王将 | −11.6 | 35.4 |
| 龍馬 | +144.9 | 24.3 | 猛豹 | −11.4 | 16.5 |
| 鳳凰 | +92.8 | 29.1 | 銀将 | +24.6 | 33.5 |
| 横行 | +79.8 | 11.4 | 銅将 | +25.6 | 12.3 |

### 書き出したネットの検査

補正ネットと基点のネットを比べると、長さは同じで、線形の区画より後の全バイト、終盤の列、先獅子の行、および検査和を除くヘッダが一致する。
序中盤の列は6,016行が変わり、変化の最大は±379.875 cpである。
検査和は本体のSHA-256と一致する。

評価値の分布の診断（20,000局面）では、PST＋FMに対する標準偏差の比が現行のネットで1.0269、補正ネットで1.0279であり、判定はどちらも「全体の尺度はほとんど変えていない」である。
PST＋FMとのピアソン相関は0.9938から0.9911へ、スピアマン相関は0.9799から0.9560へ下がった。
合法手の評価差の診断（47局面）では、合法手の集合の不一致は0件である。
PST＋FMとの差の標準偏差は、先頭の局面で現行のネットの12.65 cpから補正ネットの30.86 cpへ広がった。
駒除去差分の診断は実数のチェックポイントを要するので行わず、設計書のとおり、補正量の式と整数評価の変化の照合をテストで確かめた。

新しい対局の診断の局面では、静的評価の変化の絶対値の平均が205.7 cpであり、99.8%の局面で評価値が変わった。
この大きさの変更が探索にどう効くかは、対局でしか分からない。

### 配置の距離のペア数

`placement_distance.py check`は、[集計](../adhoc/piece-placement-census.md)の配置の距離M（現行のネット0.461、PST＋FM 0.432、PST世代1 0.330）、配列（差の絶対値の和0、総数4,956,670）、および5配置の割合を再現した。

同じネット（`b8bebfb3`）の`nnue-material-linear-init-noninferiority-stc`の互いに素なペアを2組に分け、設計書のとおりMの差の95%区間を求めた。
開始局面が揃わないので、半幅は保守的な見積もりである。

| ペア数 | 半幅の平均 | 区間の上限が0未満になった回数 |
|---:|---:|---:|
| 200 | 0.0081 | 0/4 |
| 400 | 0.0057 | 0/2 |
| 800 | 0.0040 | 0/1 |

半幅0.021以下を満たす最小のペア数は200である。

設計書は、ほとんど同じ2つのネットの対局へ判定を当てて誤って「偏りが減った」とならないことを確かめると定めていた。
線形経路の初期値だけを変えて学び直した`b8bebfb3`と`6d47da2a`を同じ対局の両側で比べると、Mの差は200ペアで−0.0094（−0.0129〜−0.0055）であり、規則は「偏りが減った」と判定する。
全1,779ペアでもMの差は−0.0079であり、駒種ごとの差は王将−0.096、龍馬−0.070、龍王+0.054、竪行+0.040と符号が混ざる。
これは統計の誤判定というより、学び直した2つのネットに実在する小さな差を検出した結果と読む。
2つのネットの配置が等しい根拠はないので、この比較は差が0の対照にならない。

そこで、判定の規則（区間の上限が0未満）は変えず、対局の前に次のように手順を改めた。

- 対照として、基準の対局と同じシードとペア数でmaster同士の対局をもう1回行い、基準の対局とのMの差を同じ手順で求める（`nnue-outcome-regression-control-stc`）。
- 閾値は足さない。0.03は検出力の計算に使う効果量であり、採用に必要な最小の改善幅ではない。

規則が0.01程度の小さな差でも「偏りが減った」と判定することは、判定を読むときの注意として補正ネットの記録に書く。
その判定だけでは採用にならず、段階ゲートの`H1`も必要である。

## 結論

判定の対局の予測はD = −0.007093（95%区間−0.008847〜−0.005155）で改善し、教師より新しい対局の診断でも向きは一致したので、フェーズ3へ進み、配置の距離の比較は各200ペアで行う。

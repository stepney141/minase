# nnue-outcome-regression-ltc

## 目的

線形の経路を対局結果への回帰で補正したネット（補正ネット）を候補、masterを基準とする長時間の時間制御（LTC）のGSPRTで、候補の採否を[設計書](../../plans/archived/nnue-outcome-regression.md)の規則で判定する。

## コマンドライン

対局は、`da460a24`の`crates/minase`からビルドしたrunner（`data/nnue-outcome-regression/minase-runner`、SHA-256 `3a5dfa9ee988afea4f3c2bcbdc3e6533b6f0f6863c9a9d70f6899783878eeb06`）で実行した。

```console
minase-runner match run --run-dir data/matches/nnue-outcome-regression-ltc --seed 20261107000000 \
  --candidate commit:da460a24865724dab055aed94e5c5aadae0e2929 --baseline commit:dab974640967939cc3ef73fcfec4dba6dcce0775 \
  --each time=60000+200 --concurrency 16 gsprt
```

仮説は既定のとおり、H0をelo=0、H1をelo=10とし、誤り率はα=β=0.05である。
シードは、[STC](nnue-outcome-regression-stc.md)のシード20,261,106,000,000からペア数より離れた未使用の値を選んだ。

## 環境

2026年11月3日に測定機（Intel Core Ultra 7 265KF、物理20コア、論理20コア）で行った。
候補と基準のワーカー数（`Threads`）はともに1、`USI_Hash`はともに256 MB、同時対局数は16、時間制御は持ち時間60秒、1手0.2秒加算である。
同じ機械でlishogiのBotが同時に対局しており、確認した時点では2局を約4スレッドずつで指していて、ロードアベレージは最大で約38だった。

### 時間切れの1件

[手引き](../../guides/sprt.md#異常時の裁定)の確認項目に沿って原因を調べた。

時間切れは候補側の1件だけであり、ペア96の第1局で候補（先手）が639手目に時間切れで負けた。
その手の開始時の残り時間は約977 msである。
エンジンが報告した完了時刻は89 ms、ハーネスが測った思考時間は1,051 msであり、エンジンが探索を終えてからハーネスが応答を受け取るまでに約962 msの遅れが生じていた。
エンジンは残り時間内に探索を終えているので、時間管理の不具合ではない。

この遅れは候補だけに起きたものではない。
思考時間がエンジンの完了時刻より500 ms以上長かった手は、候補が62,485手のうち64手、基準が62,419手のうち197手であり、遅れの最大は候補が4,594 ms、基準が4,687 msである。
遅れは両側に起きており、残り時間の短い手に当たったのがこの1件である。

`journalctl`には、測定の時間帯にOOM killerの記録はない。
停止の原因は特定できていない。
測定はBotの対局と同時に動いており、スワップも約5 GB使われていたので、機械の負荷が原因である可能性が高いが、これは推論である。

該当するペア96（候補の得点0の区分）を除いた度数は[4, 0, 47, 2, 67]であり、`minase::stats::gsprt_llr`で計算し直したLLRは3.0149で、上側境界を超える。
同じ関数は元の度数で2.9488を返し、ハーネスの値と一致する。
このペアは候補の負けとして算入済みなので、判定のLLRはこの時間切れで候補に不利な側へ動いている。

### 配置

判定には使わない参考の値として、保存された123ペアの配置を集計した（判定の後に完了した1ペアを含む）。
20〜99手の5配置の割合は次のとおりであり、[STCの比較](nnue-outcome-regression-placement-stc.md)と同じ向きである。

| 配置 | 基準 | 候補 |
|---|---:|---:|
| 奔王が1〜2段 | 86.3% | 13.7% |
| 龍馬が1〜2段 | 64.1% | 10.0% |
| 醉象が3〜5筋 | 61.1% | 1.9% |
| 金将が3段以上 | 38.4% | 40.4% |
| 麒麟が右端2筋 | 30.3% | 2.0% |

Mは候補で0.4350、基準で0.4437である。
この2つは同じ対局の候補側と基準側の値であり、STCの比較とは構造が異なる。

## 結論

判定は`H1`である。
時間切れ1件は機械の一時的な停止によるもので、停止は両側に及び、該当ペアを除いてもLLRは判定境界を超える。
[手引き](../../guides/sprt.md#異常時の裁定)の規定により、測定をやり直さずに採用するかどうかはエンジンの開発者が判断する。

# nnue-outcome-regression-placement-stc

## 目的

線形の経路を対局結果への回帰で補正したネット（補正ネット）の配置の距離Mが、[基準の対局](nnue-outcome-regression-reference-stc.md)のmasterより統計的に減っているかを、[設計書](../../plans/archived/nnue-outcome-regression.md)の規則で判定する。

## コマンドライン

runnerは基準の対局と同じである。
比較のスクリプトは`nnue-outcome-regression-fit/placement_distance.py`、標準出力は`nnue-outcome-regression-placement-stc/compare.out`である。
対局の集計のスクリプトと標準出力は`nnue-outcome-regression-placement-stc/game_summary.py`と`game_summary.out`である。

```console
minase-runner match run --run-dir data/matches/nnue-outcome-regression-placement-stc --seed 20261105000000 \
  --candidate commit:da460a24865724dab055aed94e5c5aadae0e2929 --baseline commit:dab974640967939cc3ef73fcfec4dba6dcce0775 \
  --each time=10000+100 --concurrency 16 elo --pairs 200
python3 -I -u placement_distance.py compare --data <リポジトリのdata> \
  --reference nnue-outcome-regression-reference-stc --placement nnue-outcome-regression-placement-stc
python3 -I game_summary.py --data <リポジトリのdata> \
  --runs nnue-outcome-regression-reference-stc nnue-outcome-regression-placement-stc
```

開始局面ごとに2回の対局の計4局をまとめて復元抽出し（1,000回、乱数のシード1）、Mの差の95%区間を求めた。

2つのコミットの探索と評価の処理は同じである。

規則セットは`engine-default`（L0,P0,R1,E0）である。

深さ9のbenchでは、候補のNPSは基準の1.0104倍（基準803,269、候補811,600）であり、遅くなっていない。
ノード数はネットの変更により変わる（0.9337倍）。

候補と基準のワーカー数（`Threads`）はともに1、`USI_Hash`はともに256 MB、同時対局数は16、時間制御は持ち時間10秒、1手0.1秒加算である。
同じ機械でlishogiのBotが動いている。

## 結果

### 対局

| 項目 | 値 |
|---|---|
| ペア数 | 200（有効198、破棄2） |
| ペンタノミアル度数 | [10, 0, 91, 5, 92] |
| Elo | +158.41（95%区間 +125.24〜+194.53） |
| 異常 | 不合法手0、クラッシュ0、タイムアウト0、`time_forfeits` 0、`rejected_moves` 0 |
| 経過時間 | 1,716.9秒 |

候補は281勝112敗5分（打ち切り2局）である。
勝った281局のうち280局は詰み、1局は駒枯れで終わり、手数の中央値は458手である。
1手の思考時間の平均は候補131.4 ms、基準135.3 ms、到達深さの平均は候補16.29、基準16.35であり、時間と深さに偏りはない。
Eloの大きさは、この固定局数の測定の値であり、採否の根拠には使わない。

### 配置の距離

Mは基準の対局で0.4602、補正ネットで0.4332である。
Mの差は−0.0270、95%区間は−0.0324〜−0.0218、半幅は0.0053である。
区間の上限が0より小さいので、判定は「偏りが減った」である。
差の大きさは、設計書が検出力の計算に置いた0.03に近い。

5配置の割合（20〜99手）は次のとおりである。

| 配置 | 基準の対局 | 補正ネット |
|---|---:|---:|
| 奔王が1〜2段 | 86.0% | 14.6% |
| 龍馬が1〜2段 | 68.5% | 11.2% |
| 醉象が3〜5筋 | 62.2% | 2.7% |
| 金将が3段以上 | 41.8% | 40.2% |
| 麒麟が右端2筋 | 39.9% | 1.2% |

金将を除く4配置は大きく減り、[集計](../adhoc/piece-placement-census.md)の人間のレーティング2000以上（順に26.3%、10.7%、1.0%、4.2%、0.0%）に近い水準まで下がった。

仲人、銀将、王将、および金将の距離は大きく増えた。

設計書の「失敗したときの読み方」の「特定の駒種で距離が大きく増える」に当たるので、この結果は次の候補を考えるときの材料とする。

## 結論

Mの差の95%区間の上限が0より小さいので「偏りが減った」と判定し、段階ゲートへ進む。

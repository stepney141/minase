# 教師局面を静止探索の末端へ置き換えたNNUEの比較　STC

## 目的

[NNUEの教師局面を静止探索の末端へ置き換える比較](../../plans/archived/nnue-qsearch-leaf.md)のフェーズ3として、教師局面を静止探索の主要変化の末端へ置き換えて学んだ候補（qsearch leaf replacement）が、現行の教師で学んだ基準より強いかを、短時間条件STCのGSPRTで判定する。

## コマンドライン

```console
target/release/minase match run --run-dir data/matches/nnue-qsearch-leaf-stc --seed 20261104500000 \
  --candidate commit:499fd963728235c6f05481fa1c3b75e0d398340b \
  --baseline commit:760290677dbabfbc072b864724a083179052aa24 \
  --each time=10000+100 --concurrency 30 gsprt --max-pairs 3000
```

実行は、ブランチ`nnue-qsearch-leaf`のコミット`430e12c3`を機能フラグなしでビルドしたrunner（minase 2.6.0、SHA-256 `4770586b…`）で、2026年11月4日に行った。
基本シード20,261,104,500,000は、既存の測定のシードから上限の3,000ペア以上離れている。

## エンジン

- 候補：`499fd963`。`430e12c3`に、[学習の記録](nnue-qsearch-leaf-training.md)の候補のネット（SHA-256 `bf2dfe32…`）を埋め込んだコミットである。エンジンのSHA-256は`2c87f40e…`である。
- 基準：`76029067`。`430e12c3`に、補正前の幅128のネット（SHA-256 `5257f374…`）を埋め込んだコミットである。
- 両者の差は埋め込みのネットだけである。エンジンは機能フラグなしでビルドした。
- 規則セットは`L0,P0,R1,E0`、`USI_Hash`は両者256 MB、`Threads`は両者1である。

## 環境

作業機とは別の機械ryzen0（AMD Ryzen Threadripper 2990WX、物理32コア、論理64コア、メモリ125 GB）で、同時30ペアで実行した。
runnerは物理コア数を8と記録しているが、これは誤判定である。同時対局数はコマンドラインで明示したので、測定への影響はない。
同じ機械で他の測定は動いていなかった。

## 結果

| 項目 | 値 |
|---|---:|
| 実行ペア数と有効ペア数 | 409、406（破棄3） |
| ペンタノミアル度数（候補の得点0、0.5、1、1.5、2） | [94, 13, 228, 11, 60] |
| LLR | −2.968 |
| 判定 | `H0` |
| 候補の得点率 | 45.7% |
| 異常件数 | 不正着手0、クラッシュ0、応答タイムアウト0、時間切れ0、拒否着手0 |
| 終局理由 | 詰み786局、反復25局、駒の枯渇3局、王駒の捕獲1局 |
| 経過時間 | 1,800秒 |

得点率をEloへ換算すると約−30で、ペア単位の標準誤差から求めた95%区間は約−51から約−9である。
この値は逐次検定で止めた後の参考値であり、判定には使わない。

## 結論

判定は`H0`であり、10 Elo以上の改善は確認できなかった。
設計書の読み方に従い、世代反復の教師に置き換えを入れない。

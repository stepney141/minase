# NNUEの初代のネットの学習と診断

## 目的

[NNUEによるPST＋FMの完全代替（初代のネット）](../plans/nnue-replacement.md)のフェーズ2の学習試走とフェーズ4の学習について、設定、学習曲線、量子化誤差、および対局前の検査の結果を記録する。
フェーズ2の試走は、学習器が本環境のGPUで幅128を実行できることと、1エポックの所要時間を確かめるためのものであり、候補ではない。

## コマンドライン

学習器は、ブランチ`nnue-replacement`の`tools/train/`（コマンド`train-nnue`、本体の仮想環境を`PYTHONPATH=tools/train/src`で使う）である。
基準Mはmaster `6b97cc26`であり、初期値はJ75の整数化前のPST（`data/pst-fm-joint-training/j75/pst-float.npz`、SHA-256 `828f8c00…`）、駒価値と出力用Kは基準Mの`crates/minase/nets/pst.bin`（SHA-256 `efe2c145…`）から写す。

フェーズ2の試走は次の2本である。

```console
# エポック0（幅64）。フェーズ3の埋め込みと一致テストに使う。
train-nnue train --data data/gen3/generated-1500000.bin \
  --init-pst data/pst-fm-joint-training/j75/pst-float.npz --base crates/minase/nets/pst.bin \
  --width 64 --epochs 0 --device cuda --output <scratch>/epoch0-w64.bin
# 幅128、1エポック、先読み教師。GPUメモリと1更新の時間の測定用。
train-nnue train --data data/gen3/generated-1500000.bin \
  --init-pst data/pst-fm-joint-training/j75/pst-float.npz --base crates/minase/nets/pst.bin \
  --width 128 --epochs 1 --device cuda --lookahead-gamma 0.9 --lookahead-plies 40 \
  --output <scratch>/trial-w128.bin
```

その他の引数は既定値（バッチ16,384、除去差分の分割2,048、シード1、線形の学習率0.03、非線形の学習率10⁻³、非線形の重み減衰10⁻⁴、除去損失の係数1000、λ=1.0）である。

## 環境

学習機はRTX 3060 Ti（8 GB）、PyTorch 2.13.0（CUDA 13.0）である。
試走の間、同じ機械で浅い教師データの生成（同時12対局）とlishogiのBotが動いていた。

## 結果

### フェーズ2の試走

入力は世代3の1ファイル（2,958,151局面、訓練2,814,063、検証144,088）である。

| 項目 | エポック0（幅64） | 幅128、1エポック |
|---|---:|---:|
| 線形部分が基準MのPST部分と一致 | 一致 | ― |
| 駒価値と出力用Kが基準Mと一致 | 一致 | 一致 |
| 未観測の特徴数 | 4,742 | 4,742 |
| エポック0の検証損失 | 0.443791（先読みなし） | 0.437095（先読みあり） |
| 1エポック後の検証損失 | ― | 0.436078 |
| 1エポック後の訓練損失 / 除去損失 | ― | 0.417325 / 9.4×10⁻⁸ |
| 非線形出力の標準偏差（センチポーン） | 0 | 264.7 |
| 活性化の飽和率（acc≤0 / acc≥1） | 54.8% / 0.27% | 35.2% / 3.8% |
| 1エポックの所要時間（172更新） | ― | 約120秒（0.70秒/更新） |
| GPUメモリの最大確保量 | ― | 1,267 MiB（予約1,426 MiB） |
| 量子化誤差（検証1万局面、平均 / 最大、センチポーン） | 0.52 / 1.66 | 6.15 / 35.8 |
| 量子化誤差の閾値 K/40 | 26.8 | 26.8 |
| 教師用K（世代3、100,000ノード） | ― | 774.26 |

幅128の学習は本環境で実行でき、最大GPUメモリは8 GBの16%にとどまる。
1更新0.70秒を、既存の約2,920万局面と新規の約5,100万局面の合計（約8,000万局面、1エポック約4,900更新）に当てはめると、1エポックは検証を含めて約1時間である。
24時間の上限は約24エポックに当たり、50エポックの上限より先に時間の上限が働く。
エポック0の非線形部分は出力重みが0なので、量子化誤差は線形部分の丸めだけであり、幅128の1エポック後の誤差6.15センチポーンは活性化の整数近似（127で割る代わりに128で切り捨て）と第1層の尺度127による。

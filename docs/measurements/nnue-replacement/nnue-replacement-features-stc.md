# NNUEの入力特徴集合の比較（HalfKP-hm-b8対P型、幅128、STC）

## 目的

[NNUEの共通土台と初代のネットの設計書](../../plans/archived/nnue-replacement.md)のフェーズ5として、同じデータと設定で学習したHalfKP-hm-b8（候補）とP型（基準）の幅128のネットを、対称仮説のSTCで直接対局させ、段階ゲートに出す型を決める。

## コマンドライン

```console
cargo run --release --bin minase -- match run \
  --run-dir data/matches/nnue-replacement-features-stc --seed 2200000000 \
  --candidate commit:3dc5e9e --baseline commit:90280a0 \
  --each time=10000+100 --concurrency 12 gsprt --max-pairs 3000 --elo0 -5 --elo1 5
```

実行はブランチ`nnue-replacement`のworktreeの`target/release/minase`（runner 2.3.0、SHA-256 `7cdb784c…`）で、再学習の完了を待つ常駐スクリプト`data/nnue-replacement-train/phase5-stc.sh`から2026年10月12日13時05分に起動した。

## エンジン

- 候補: `3dc5e9e`（`ActiveFeatureSet`をHalfKP-hm-b8に切り替え、同型の学習済みネットを`nets/nnue.bin`に埋め込んだコミット。バイナリのSHA-256 `3707afa6…`）。
- 基準: `90280a0`（P型の学習済みネットを`nets/nnue.bin`に埋め込んだコミット。SHA-256 `02f25af1…`）。
- 両者は`ActiveFeatureSet`と`nets/nnue.bin`だけが異なる。ネットはどちらも[Rust製NNUE学習器](../../plans/archived/nnue-trainer-rust.md)で全30ファイルから学んだ最良エポック（エポック1）のものである（[学習の記録](nnue-replacement-training.md)の「フェーズ4の学習」）。
- 規則セットは`L0,P0,R1,E0`、`USI_Hash`は両者256 MB、`Threads`は1。

## 環境

Intel Core Ultra 7 265KF（物理20コア、論理20コア）、メモリ32 GB、同時12ペア。lishogiのBot（Threads 4、同時2局）が同居していた。GPUの学習は終了済み。

## 結果

| 項目 | 値 |
|---|---:|
| 実行ペア数と有効ペア数 | 116、114（手数上限による破棄2） |
| ペンタノミアル度数（候補の得点0、0.5、1、1.5、2） | [80, 0, 30, 0, 4] |
| LLR | −2.969 |
| 判定 | `H0` |
| 異常件数 | 不正着手0、クラッシュ0、応答タイムアウト0、時間切れ0、拒否着手0 |
| 終局理由 | 詰み229局、反復1局 |
| 経過時間 | 1,204秒 |

候補の勝ちは4ペアだけで、80ペアを両局とも失っており、Eloに換算するとおよそ−200に相当する差である。
検証損失の差（候補0.434844対基準0.434275）やNPSの差（候補が約5%遅い）では説明できない大きさである。
候補の整数評価はPythonの整数参照と20,000局面で全一致し、差分更新と完全再計算のビット単位の一致（自玉の移動による区分と鏡映の変化を含む）はテストで固定されているので、評価の実装の不具合ではなく、ネット自身の判断の差とみなす。
初期局面と`7i7h 6d6e 8i8h 5d5e`の後の局面を深さ7で探索させると、候補は両方で`5l4k`を最善とし、基準と基準Mは別の手を選んだ。深さ1の評価では、3者とも`5l4k`を指した直後の局面を負と評価した。
`5l4k`は5lの金将を4kへ動かす着手であり、先手の王将は初期位置の7lから動かない。
この着手は候補の文脈を変えないので、自玉の区分の変化による評価の不連続を示す例にはならない。
HalfKP-hm-b8は特徴の行109,440行のうち39,413行が訓練集合で未観測であり、自玉が稀な区分へ動いた局面の評価は仮想行だけに依る。

### 対局後の診断（2026年10月17日）

敗因を調べるため、追加の対局は行わず、保存済みの対局と両方のネットを用いて3つの診断を行った。
ネットは`3dc5e9e`と`90280a0`の`crates/minase/nets/nnue.bin`（SHA-256は順に`3a99f03b…`と`3679bebf…`）であり、評価は`minase::eval::nnue::evaluate_for_diagnostics`による整数評価の完全再計算である。
診断のプログラムはこの調査専用のものであり、リポジトリには含めていない。
なお、`feature_index`は後手視点で段だけを反転し、`HalfKpHmB8`の鏡映の判定も同じ筋を使うので、先後の視点で文脈の定め方が食い違うことはない。

1つ目は、実行ディレクトリの`pairs/`にある232局を再生し、候補と基準それぞれの王将の着手を数えたものである。

| 項目 | 候補（HalfKP-hm-b8） | 基準（P型） |
|---|---:|---:|
| 自分の最初の40手に占める王将の着手 | 2.5%（228/9,280） | 0.8%（77/9,280） |
| 最初に王将を動かした手（自分の手数の中央値） | 36手目 | 174手目 |
| 全着手に占める王将の着手 | 4.6%（2,331/50,174） | 6.0%（3,007/50,249） |

候補が最初の40手で行った王将の着手228手のうち、196手（86%）は候補の文脈（区分または鏡映）を変えた。
最初の40手で王将を動かした125局の候補の得点は13.5（得点率11%）、動かさなかった107局の得点は25.5（得点率24%）だった。

2つ目は、局面の全合法手について、着手した側から見た静的評価の差（着手後の相手視点の評価の符号を反転した値から、着手前の評価を引いた値）を両方のネットで計算し、着手を3種類に分けて比べたものである。
3種類は、着手した側のHalfKP-hm-b8の文脈を変える着手（文脈変化）、王駒の升を変えるが文脈は変えない着手（文脈不変の王駒）、およびそれ以外である。
局面は、本測定の対局で開始局面から100手目の直前までに現れた20,880局面（対局局面。手数は初期局面から数える）と、[再生成した教師](../nnue-lr-schedule/nnue-lr-schedule-training.md)の`generated-7100000.bin`（MNSD版2、コミット`31c2a465`のP型のエンジンが2万ノードで生成）の各対局から10局面ごとに選んだ20,000局面（教師局面）である。
教師局面は、2つのネットが学習した版1の教師（削除済み）とは別のエンジンで生成したものである。
表のdHとdPは候補と基準の評価差、単位はセンチポーンであり、「最善の割合」は静的評価の差が最大の手がその種類である局面の割合である。

|---|---|---:|---:|---:|---:|---:|---:|
| 対局 | 文脈変化 | 22,077 | −3.6 | 108.8 | 230 | 3.55% | 1.58% |
| 対局 | 文脈不変の王駒 | 735 | 26.7 | 57.4 | 108 | 0.12% | 0.27% |
| 対局 | その他 | 1,364,248 | 11.1 | 31.9 | 68 | 96.33% | 98.15% |

文脈変化の着手では、2つのネットの評価差のずれがその他の着手の2.5〜3.4倍である。
ずれの平均はほぼ0か負なので、候補が文脈を変える着手を一様に高く評価しているわけではない。
それでも、候補が静的評価で最善とする手が文脈変化である割合は基準の2.2〜3.0倍であり、対局で序盤の王将の着手が約3倍だった傾向と一致する。

3つ目は、教師の5ファイル（`generated-7100000.bin`から`generated-7500000.bin`）の各対局から5局面ごとに選んだ3,357,061局面について、手番側の区分ごとに、両方のネットの静的評価と対局結果との当てはまりを比べたものである。
損失は、評価を共通の尺度1,000センチポーンでロジスティック関数により勝率へ変換し、手番側の得点（勝ち1、引き分け0.5、負け0）との二値交差エントロピーとして計算した。
符号一致率は、引き分けを除く局面で評価の符号と勝敗が一致した割合である。
これらの対局は、どちらのネットの学習にも使われていない。

候補はすべての区分で基準よりわずかに悪い。
損失の差は、最も多い区分5で0.0023、それ以外の区分で0.0035〜0.0062である。
稀な区分で評価が破綻しているわけではない。

3つの診断から言えるのは、文脈を変える着手で候補の評価がばらつき、探索がその手を選びやすいという点にとどまる。
序盤に王将を動かさなかった局でも候補の得点率は24%にとどまり、静的評価の当てはまりの差も小さいので、この2つでは約−200 Eloの差を説明しきれない。
敗因の残りは特定できていない。

## 結論

判定は`H0`であり、設計書のフェーズ5の規則によりP型（`90280a0`）を段階ゲートに出す型として採る。
HalfKP-hm-b8の敗因は特定できておらず、文脈を変える着手で評価がばらつき、探索がその手を選びやすいことは、その一部を説明するにとどまる。

# NNUEの教師に占める決着局面の集計

## 目的

[NNUEの検証損失の頭打ちの切り分け](../plans/nnue-early-best-epoch.md)のフェーズ1として、現行のNNUEの教師を素の探索値の絶対値で6区間に分け、勝敗がほぼ決まった局面（決着局面）が教師に占める割合と、学習前後のネットの損失が教師の確率の下限をどれだけ上回るか（下限からの超過）を区間ごとに記述する。
この集計は判定を伴わず、教師の作り方を直す次の計画への入力とする。

## コマンドライン

集計は、[分割の検査](nnue-validation-split-check.md)の使い捨てのプログラムを拡張した`teacherstat`で行った。
ソースは`data/nnue-early-best-epoch/tools/teacherstat/`、出力は`data/nnue-early-best-epoch/phase1/`（`phase1.json`、`phase1.out`）にあり、リポジトリには含めていない。
移植した学習器の規則（除外の印、検証集合の選び方、先読み教師）は分割の検査と同じであり、教師の確率は学習器の`build_targets_from_arrays`と同じく、単精度の教師値からf64で計算して単精度へ丸めた。

```console
FILES=(data/nnue-lr-schedule-gen/generated-*.bin)
nice -n 19 teacherstat --threads 4 --stride 10 --boot 1000 --boot-seed 1 --bin-teacher la \
  --json phase1.json \
  --net e0=crates/minase/nets/nnue-epoch0.bin \
  --net d0b=data/nnue-hidden-layer-train/d0b/nnue.bin \
  --teacher la=lookahead:0.9:40:1007.4941198261047 \
  --teacher raw=raw:1007.4941198261047 \
  --compare e0:d0b -- "${FILES[@]}"
```

入力は[再生成した教師](nnue-lr-schedule-training.md)の30ファイルである。
ネットは、データを学習していないエポック0のネット（`nnue-epoch0.bin`、PSTの初期値だけを持つ）と、現行の埋め込みネットD0b（SHA-256 `046be0e6…`）である。
区間の教師`la`は、D0bの学習と同じ先読み教師（γ=0.9、40手、教師の勝率尺度1,007.494センチポーン）である。
訓練側は各ファイルの訓練局面を10局面ごとに選んだ7,945,793局面（210,787局）、検証側は全4,153,303局面（11,112局）で集計した。

区間ごとの量は次のとおり定めた。

- 有利側は、素の探索値が0以上なら手番側、負なら相手側とする。「有利側の教師の確率」は、先読み後の教師の確率を有利側から見たものの平均であり、「有利側の負け、引き分け、勝ち」はその局面の対局結果を有利側から見た割合である。
- 下限は、区間の局面の教師の確率の二値エントロピーの平均、超過は、ネットの損失（区間の教師に対する二値交差エントロピー）から下限を引いた平均である。
- 寄与は、区間の超過の合計を全区間の超過の合計で割った値であり、減少の割合は、区間のエポック0からD0bへの超過の合計の減少量を、全区間の減少量の合計で割った値である。
- 符号一致率は、引き分けを除く局面で、ネットの評価値が正なら手番側の勝ち、0以下なら負けの予測とみなし、実際の勝敗と一致した割合である（学習器の`sign_accuracy`と同じ定義）。

## 環境

測定機（Intel Core Ultra 7 265KF、20コア、メモリ30 GB）で、2026年10月17日にnice値19、4スレッドで実行した（経過時間15分25秒、最大常駐メモリ約60 MB）。
同じ機械で、別の計画のSPSA（同時対局数16）、lishogiのBot、およびD0bの再現の学習が動いていた。

## 結果

### 再現の照合

集計した局面数（訓練79,458,082、検証4,153,303）は学習器の記録と一致した。
先読み教師に対する検証損失は、エポック0のネットが0.457074（学習器は0.4570753）、D0bが0.448904（同0.4488929）であり、整数評価による差を除いて一致した。

訓練側の値は検証側と小数第3位までほぼ同じなので、表には割合を除いて検証側の値を示した。
素の探索値の絶対値が2,000センチポーン以上の局面は教師の36%を占め、その区間の有利側の勝率は94%（2,000〜4,000）と99.6%（4,000以上）である。
有利側の教師の確率の平均は、どの区間でも有利側の実際の勝率とほぼ一致しており、区切りは勝敗の決まり具合を正しく表している。
4,000以上の区間は、教師の確率がほぼ1であるため下限が0.023と小さく、1局面あたりの損失への影響も小さい。

D0bの検証での超過の約半分（48.6%）は500〜2,000センチポーンの2区間にあり、2,000センチポーン以上の2区間の寄与は合わせて17.1%である。
エポック0からD0bへの超過の減少は、1,000〜4,000センチポーンの2区間で全体の46.5%を占める。
2,000センチポーン以上の区間では、D0bの超過がエポック0の38%（2,000〜4,000）と23%（4,000以上）まで下がっており、0〜2,000センチポーンの4区間（51%から55%）より学習で大きく縮んでいる。
訓練と検証の超過の差は全区間に現れ、D0bの検証の超過は訓練より10%（4,000以上）から24%（500〜1,000）大きい。

### 結果の目標に対する損失

対局の結果（手番側から勝ち1、引き分け0.5、負け0）を目標とした損失は、エポック0のネットが訓練0.468620、検証0.466801、D0bが訓練0.450530、検証0.450913であった。
検証の損失から訓練の損失を引いた汎化差は、エポック0が−0.00182、D0bが+0.00038である。
対局を単位とする対応のあるブートストラップ（1,000回、シード1）では、汎化差の差（エポック0−D0b）の95%区間は[−0.00353, −0.00102]、検証の結果の損失の差の95%区間は[+0.01464, +0.01703]であった。
同じ区間を1つのネットの汎化差について求めると幅が約0.014あり、対局ごとの結果のばらつきが大きいため、ネットの間の差は対応のある比較でなければ区別できない。

## 結論

現行の教師では、素の探索値が2,000センチポーン以上の決着局面が36%を占める一方、D0bに残る検証の超過への寄与は17%であり、超過の約半分は500〜2,000センチポーンの局面にある。
決着局面の超過が小さいことが、学習に役立たなかったためか既に学び終えたためかは、この集計からは区別できず（設計書の「決着局面の扱い」）、区間の重みを変える学習で確かめる。

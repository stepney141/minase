# ponder-ltc

## 目的

[USI先読み（ponder）](../plans/ponder.md)のフェーズ4として、[STC](ponder-stc.md)を通過した先読みの実装コミット`817963a`が、その直前のコミット`036d3fa`より、先読みを対局条件に含む長時間条件で有意に強いかをGSPRTで判定し、採否を確定する。
測るのは「同じ時計の下で、相手の手番中の計算も使える実装の強さ」であり、同じCPU時間あたりの効率ではない。

## コマンドライン

対局ハーネスは、ハーネスの実装コミット`b201f39`を固定したworktreeでビルドしたバイナリから起動した。
シードは、STCの基本シード38000919からペア数以上離れた未使用の値である。

```console
target/release/match_runner \
  --run-dir /home/stepney141/board-games/minase/data/matches/ponder-ltc --seed 39000919 \
  --candidate commit:817963a --baseline commit:036d3fa \
  --each time=60000+200 --ponder gsprt
```

## エンジン

候補はコミット`817963ab5ecade01638ec587e3902fb5dd2a921d`（バイナリのSHA-256 `bffbcf064f3acc3f2c5f8b66aa5c7dc081af2092784c106dc633d47959829c00`）、基準はコミット`036d3fa4cabc9b310a080aedac824b319fb5f925`（バイナリのSHA-256 `0f6ee02416dc6ab4b8629ac23c4815f06bcd1769e19125cb6eaf8e456cad1e1c`）であり、どちらもSTCと同じバイナリである。
基準は予想手を返さないので、先読みをしない。
規則セットは`L0,P0,R1,E0`（engine-default）である。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ32 GB）であり、候補と基準はいずれも`Threads=1`、`USI_Hash`は各256 MBである。
同時対局数は、`--ponder`の自動計算（物理コア数から1を引き、`Threads`の2倍で割った商）による9である。
手数上限は4,096、応答タイムアウトは120秒、H1は10 Eloで、2026年9月21日に実施した。
測定の前半は、同じ機械でlishogi Botのエンジンが1プロセス動いていた。

## 結論

`H1`であり、エンジン異常、時間切れ、拒否着手、および候補の不合法な予想手がいずれも0件なので、先読みを採用する。
候補は相手の手番中にもCPUを使うので、CPU時間の合計は基準の約2.0倍である。
的中率は[起案時の診断](ponder-hit-rate-diag.md)が長時間条件で見積もった55.9%に近い52.0%だった。

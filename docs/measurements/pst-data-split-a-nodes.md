# データ半分割のA対S0の固定ノード数400ペア

## 目的

[世代3の計画](../plans/pst-gen3.md)のデータ半分割の診断の参考値として、訓練データの一方の半分で学習したPST（A）を、全訓練データで学習した採用PST（S0）と固定ノード数で対局させる。

## コマンドライン

```console
cargo run --release --bin match_runner -- \
  --run-dir data/matches/pst-data-split-a-nodes --seed 99500000 \
  --candidate commit:1c9bf35 --baseline commit:44ae7cb \
  --each nodes=100000 --concurrency 3 elo --pairs 400
```

## エンジン

候補はA（ブランチ`pst-data-split`の`1c9bf35`）、基準はS0（master `44ae7cb`）である。
規則は`L0,P0,R1,E0`、両エンジンとも1手100,000ノードである。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ32 GB）である。
同時3対局、両エンジンとも1スレッド、置換表256 MBで、世代3の生成（同時16対局）と並行して実行した。
固定ノード数の対局なので、並行した負荷は所要時間だけに影響する。
実施は2026年10月2日19時59分から22時34分である。

## 結果

| 項目 | 値 |
|---|---|
| ペア数 | 400（有効376、手数上限で破棄24） |
| ペンタノミアル度数 | [86, 5, 220, 8, 57] |
| Elo | −25.5（95%信頼区間 −47.5〜−3.7） |
| エンジン異常、時間切れ、拒否着手 | 0件 |
| 経過時間 | 9,340秒 |

## 結論

AはS0に対して有意に弱かった。
AはS0と同じ初期値と学習条件で、訓練データを半分にして学習したものであり、更新回数もS0の約半分（7,310回）である。
この差はデータ量と更新回数を合わせた工程全体の差であり、設計書の規定どおり判定には使わない。

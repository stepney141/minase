# データ半分割のB対S0の固定ノード数400ペア

## 目的

[世代3の計画](../plans/pst-gen3.md)のデータ半分割の診断の参考値として、訓練データの他方の半分で学習したPST（B）を、全訓練データで学習した採用PST（S0）と固定ノード数で対局させる。

## コマンドライン

```console
cargo run --release --bin match_runner -- \
  --run-dir data/matches/pst-data-split-b-nodes --seed 99600000 \
  --candidate commit:348bb5c --baseline commit:44ae7cb \
  --each nodes=100000 --concurrency 3 elo --pairs 400
```

## エンジン

候補はB（ブランチ`pst-data-split`の`348bb5c`）、基準はS0（master `44ae7cb`）である。
規則は`L0,P0,R1,E0`、両エンジンとも1手100,000ノードである。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ32 GB）である。
同時3対局、両エンジンとも1スレッド、置換表256 MBで、世代3の生成（同時16対局）と並行して実行した。
固定ノード数の対局なので、並行した負荷は所要時間だけに影響する。
実施は2026年10月2日22時34分から10月3日2時02分である。

## 結果

| 項目 | 値 |
|---|---|
| ペア数 | 400（有効382、手数上限で破棄18） |
| ペンタノミアル度数 | [95, 9, 191, 8, 79] |
| Elo | −15.0（95%信頼区間 −38.9〜+8.7） |
| エンジン異常、時間切れ、拒否着手 | 0件 |
| 経過時間 | 12,508秒 |

## 結論

BのS0に対する点推定は負だが、区間は0を含む。
[A対S0](pst-data-split-a-nodes.md)と合わせると、データ量と更新回数を半分にした工程はS0より弱い方向にある。
この差は判定には使わない参考値である。

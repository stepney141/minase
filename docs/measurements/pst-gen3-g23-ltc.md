# 候補G23とS0の長時間測定

## 目的

[世代3の計画](../plans/pst-gen3.md)の採否測定として、[絞り込み](pst-gen3-g23-vs-g3-stc.md)でLTCへ進めた候補G23（世代2と世代3の10ファイルで学習し直したPST）を、採用構成S0と長時間条件（LTC）のGSPRTで対局させ、採否を判定する。

## コマンドライン

```console
cargo run --release --bin match_runner -- \
  --run-dir data/matches/pst-gen3-g23-ltc --seed 89000921 \
  --candidate commit:26a1469 --baseline commit:44ae7cb \
  --each time=60000+200 gsprt
```

## エンジン

候補はブランチ`pst-gen3-g23`の`26a1469`であり、S0との差は`nets/pst.bin`の差し替えだけである（[学習の記録](pst-gen3-training.md)）。
基準はS0（master `44ae7cb`）である。
規則は`L0,P0,R1,E0`、H1はelo=10、α=β=0.05である。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ32 GB）で、2026年10月3日11時15分から12時57分に実施した。
同時19対局、両エンジンとも1スレッド、置換表256 MB、時間制御は60秒＋1手0.2秒である。

## 結果

| 項目 | 値 |
|---|---|
| ペア数 | 240（有効234、手数上限で破棄6） |
| ペンタノミアル度数 | [30, 1, 118, 3, 82] |
| LLR | +2.974 |
| 判定 | `H1` |
| エンジン異常、時間切れ、拒否着手 | 0件 |
| 経過時間 | 6,150秒 |

候補の得点率は61.3%であり、ロジスティックElo換算では約+80に当たる。この値は採否には使わない。

## 結論

G23はLTCで`H1`となり、エンジン異常、時間切れ、および拒否着手が0件なので、[設計書](../plans/pst-gen3.md)の採用条件を満たす。
G23の重みを採用PSTとする。

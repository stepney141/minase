# 候補G23とG3の短時間測定（LTCへ進める候補の絞り込み）

## 目的

[世代3の計画](../plans/pst-gen3.md)の絞り込み規則に従い、S0に対するSTCでともに`H1`となった候補G23（[記録](pst-gen3-g23-stc.md)）とG3（[記録](pst-gen3-g3-stc.md)）を同じSTCの条件で対局させ、LTCへ進める1候補を決める。
規則は、`H1`、または上限3,000ペアでLLRが0以上ならG23を、それ以外ならG3を選ぶ、である。

## コマンドライン

```console
cargo run --release --bin match_runner -- \
  --run-dir data/matches/pst-gen3-g23-vs-g3-stc --seed 86000921 \
  --candidate commit:26a1469 --baseline commit:ba83fd1 \
  --each time=10000+100 gsprt --max-pairs 3000
```

## エンジン

候補はG23（ブランチ`pst-gen3-g23`の`26a1469`）、基準はG3（ブランチ`pst-gen3-g3`の`ba83fd1`）である。
どちらもmaster `44ae7cb`の`nets/pst.bin`だけを差し替えたコミットであり、重みの学習は[学習の記録](pst-gen3-training.md)にある。
規則は`L0,P0,R1,E0`、H1はelo=10、α=β=0.05である。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ32 GB）で、2026年10月3日7時46分から11時12分に実施した。
同時19対局、両エンジンとも1スレッド、置換表256 MB、時間制御は10秒＋1手0.1秒である。

## 結果

| 項目 | 値 |
|---|---|
| ペア数 | 1,505（有効1,435、手数上限で破棄70） |
| ペンタノミアル度数 | [266, 41, 759, 34, 335] |
| LLR | +2.994 |
| 判定 | `H1` |
| エンジン異常、時間切れ、拒否着手 | 0件 |
| 経過時間 | 12,504秒 |

G23の得点率は52.3%であり、ロジスティックElo換算では約+16に当たる。この値は採否には使わない。

## 結論

G23がG3に対して`H1`となったので、規則に従いG23をLTCへ進める。
G3はこの時点で候補から外れる。

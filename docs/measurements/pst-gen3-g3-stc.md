# 候補G3とS0の短時間測定

## 目的

[世代3の計画](../plans/pst-gen3.md)の採否測定として、世代0から世代3の全16ファイルで学習し直したPST（候補G3）を、採用構成S0と短時間条件（STC）のGSPRTで対局させ、LTCへ進む資格を判定する。

## コマンドライン

```console
cargo run --release --bin match_runner -- \
  --run-dir data/matches/pst-gen3-g3-stc --seed 60000921 \
  --candidate commit:ba83fd1 --baseline commit:44ae7cb \
  --each time=10000+100 gsprt --max-pairs 3000
```

## エンジン

候補はブランチ`pst-gen3-g3`の`ba83fd1`であり、S0との差は`nets/pst.bin`の差し替えだけである（[学習の記録](pst-gen3-training.md)）。
基準はS0（master `44ae7cb`）である。
規則は`L0,P0,R1,E0`、H1はelo=10、α=β=0.05である。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ32 GB）で、2026年10月3日6時31分から7時08分に実施した。
同時19対局、両エンジンとも1スレッド、置換表256 MB、時間制御は10秒＋1手0.1秒である。

## 結果

| 項目 | 値 |
|---|---|
| ペア数 | 232（有効217、手数上限で破棄15） |
| ペンタノミアル度数 | [24, 3, 111, 8, 71] |
| LLR | +2.975 |
| 判定 | `H1` |
| エンジン異常、時間切れ、拒否着手 | 0件 |
| 経過時間 | 2,259秒 |

候補の得点率は61.4%であり、ロジスティックElo換算では約+81に当たる。この値は採否には使わない。

## 結論

G3はSTCで`H1`となり、LTCへ進む資格を得た。
設計書の絞り込み規則に従い、[G23のSTC](pst-gen3-g23-stc.md)の結果と合わせてLTCへ進める1候補を決める。

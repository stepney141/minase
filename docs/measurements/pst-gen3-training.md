# 世代3を加えた候補G3とG23の学習と診断

## 目的

[世代3の計画](../plans/pst-gen3.md)のフェーズ4として、[世代3の教師データ](pst-gen3-generation.md)を加えた候補G3（世代0から世代3の16ファイル）とG23（世代2と世代3の10ファイル）を採用工程の学習条件で学習し、学習後の診断を通す。

## コマンドライン

候補ごとに、ブランチ`pst-gen3`のworktreeで設定ファイル`data/pst-gen3-g3.toml`と`data/pst-gen3-g23.toml`を作り、ワークフローで準備、学習、診断を順に実行した。
設定の`[train]`節は採用工程（先読み教師γ=0.9、n=40、鏡映共有モデル、出力K 1072.6529541015625、学習率0.03、10エポック、バッチ16,384、乱数シード1、駒除去差分の追加損失の係数1000）、`[generate]`節の生成シードは空、基点コミットはmaster `44ae7cb`（初期値はS0の重み）である。
`run.data`は、G3が世代0、世代1の5ファイル、世代2の5ファイル、世代3の5ファイル、G23が世代2と世代3の各5ファイルである。

```console
tools/train/.venv/bin/python tools/train/pst/pst_workflow.py prepare --config data/pst-gen3-<候補>.toml
tools/train/.venv/bin/python tools/train/pst/pst_workflow.py train --run-dir data/pst-gen3-<候補>
tools/train/.venv/bin/python tools/train/pst/pst_workflow.py diagnose --run-dir data/pst-gen3-<候補>
```

## エンジン

学習器と診断器はブランチ`pst-gen3`のコミット`bbb3b3c`の`tools/train/pst/`である（学習器は[再現の記録](pst-gen3-trainer-reproduction.md)の版に半分割オプションを足したもので、オプションは使っていない）。
候補の重みは、master `44ae7cb`の`nets/pst.bin`だけを差し替えたコミットに置いた。
G3はブランチ`pst-gen3-g3`の`ba83fd1`、G23はブランチ`pst-gen3-g23`の`26a1469`である。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ32 GB、GeForce RTX 3060 Ti）で、2026年10月3日5時40分ごろから6時28分に学習と診断を行った。

## 結果

| 項目 | G3 | G23 |
|---|---:|---:|
| 訓練局面数 | 38,266,689 | 27,745,843 |
| 検証局面数 | 2,004,940 | 1,462,975 |
| 総更新回数 | 23,360 | 16,940 |
| 最良エポック | 10 | 10 |
| 検証損失（初期状態→最良） | 0.456697→0.455010 | 0.439711→0.436731 |
| 重みのSHA-256 | `446a4009…` | `e5ba5022…` |

世代3の教師Kは765.95であり、世代0から世代2の値（768.45、1068.21、758.35）は採用工程と同じだった。
G3の最良エポックの世代別の検証損失は、世代0が0.405534、世代1が0.513002、世代2が0.449228、世代3が0.425743である。
世代1の検証損失は初期状態の0.511653から上がり、他の世代は下がった。
検証の分割の構成が候補ごとに異なるので、G3とG23の検証損失は互いに比べない。
両候補とも、10エポック目まで検証損失が下がり続けていた。

学習後の診断は次のとおりである。

| 検査 | G3 | G23 |
|---|---|---|
| Rustと学習器の評価値の一致 | 191,841局面で一致 | 100,000局面で一致 |
| 量子化の前後の平均絶対誤差 | 0.51 cp（最大1.93 cp） | 0.51 cp（最大1.68 cp） |
| 駒除去差分の符号の反転 | 0件（352件を検査） | 0件（341件を検査） |
| 探索用駒価値と出力K | 不変 | 不変 |

S0との浮動小数点の重みの差は、G3が序中盤で平均17.4 cp（最大218.0 cp）、終盤で平均34.2 cp（最大321.6 cp）、G23が序中盤で平均19.5 cp（最大202.9 cp）、終盤で平均33.9 cp（最大284.2 cp）だった。
これは、STCで約−164 Eloとなった[混合比λ=1.0の再学習](teacher-mixing-ratio-100-stc.md)が基点から動いた量（平均11.2 cpと17.4 cp）の約2倍である。

## 結論

G3とG23はどちらも学習後の診断を通過したので、設計書のとおりS0とのSTCで測る。

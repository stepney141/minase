# 探索の見落としの追跡記録

## 目的

[静止探索の出力を学ぶPSTの学習](../plans/qsearch-output-training.md)のフェーズ0として、[相対2駒評価の準備記録](relative-pair-prep.md)の6根で、採用版S0の100,000ノードの探索が教師の読み筋をどこで失うかを追跡し、関与した探索の機構を根ごとに分類する。
棋力測定ではなく、対局の勝敗を使わない。
本記録の結果は、同計画の学習へ進むかどうかの判断には使わない（設計書の「設計判断」の探索の追跡の項）。

## 追跡と分類の事前登録

本節は、追跡の出力と介入の結果を見る前の2026年9月28日に固定した。
結果を見た後に、標本、経路、判定の規則、および閾値を変えない。

### 標本と経路

標本は準備記録の6根であり、根の識別子は202610280-278、202610489-236、202612388-210、202612852-212、202613669-264、および202614203-172である。
根の局面は、準備記録と同じく`data/search-aware-evaluation/`に保存された対局の開始手順と着手列から、USIの`position startpos moves`で履歴ごと再現する。
判定の差mは、探索局面の計画の校正値142.1センチポーンを使う。

各根で、次の2本の経路を追跡する。

- 提案手の経路は、S0の提案手s0と、その子局面を10,000,000ノードで探索した読み筋を連結した手順である。
- 最善手の経路は、教師の最善手a\*と、その子局面を10,000,000ノードで探索した読み筋を連結した手順である。

読み筋は、本ブランチの実行ファイルで子局面を探索し直して得る。
再探索の評価値と読み筋が準備記録の`residual_pv.json`と1つでも一致しなければ、条件の不整合として追跡を止めて原因を調べる。

### 探索条件

S0の提案探索は、1スレッド、探索ごとに新しいプロセスと64 MiBの置換表で、`go nodes 100000`として行われた。
minaseはノード数の上限に達した反復の途中結果を捨て、最後に完了した反復の最善手を返すので、提案手は完了深さd0の反復で決まっている。
したがって追跡と介入は同じ条件の`go depth d0`で行い、機構を無効にしない追跡が、記録された提案手、d0、および評価値を再現することを前提条件とする。
1根でも再現しなければ、追跡を止めて原因を調べる。

### 教師の値

経路のk手目を指した後の局面を$N_k$と書き、根を$N_0$とする。
経路の読み筋の10,000,000ノードの値を根の手番側から見た値を$V$とすると、$N_k$の手番側から見た教師の値を$t_k=(-1)^kV$とする。
$k=1$では、$t_1$が記録された子局面の値と一致することを検査する。
USIの出力が`score mate n`の場合は、探索内部の値と同じく、nが正なら$30000-|n|$、負なら$-(30000-|n|)$として扱う。
読み筋の奥の値は置換表で切り詰められた近似なので、後述の乖離点$D$については、$N_D$を履歴と経路の手順つきで10,000,000ノード探索した値$t'_D$でも乖離を確かめる。

### 乖離の判定

乖離の判定には、d0の反復のうち、根の結果を返した最後の窓の探索を使う。
その中で$N_k$が複数回訪問された場合（null windowの探索、減深した探索、および読み直し）は、親が値を採用した最後の訪問を使う。
すなわち、$N_{k-1}$の最後の訪問の中で行われた$N_k$の訪問のうち、最後に終わったものを使う。
値を採用した最後の探索がLMRで減深されていた場合は、$N_{k+1}$の乖離にかかわらず、$N_k$で停止の理由を「減深」とする。
$N_k$が返した値を$r$とし、その訪問の窓$(\alpha,\beta)$に対して、$r\le\alpha$なら上界、$r\ge\beta$なら下界、それ以外なら正確な値とみなす。
$N_k$が**乖離する**とは、上界なら$t_k\ge r+m$、下界なら$t_k\le r-m$、正確な値なら$|t_k-r|\ge m$であることをいう。

各経路で$k=1$から順に、$N_k$が乖離し、経路のk+1手目が$N_k$で探索され、かつ$N_{k+1}$も乖離する限り、1手ずつ深く進む。
進めなくなった位置を**乖離点**$D$とし、$D$での停止の理由を次のいずれかに分類する。

| 停止の理由 | 条件 |
|---|---|
| 経路上の機構 | $N_D$で、経路の手が次のいずれかによって探索されなかった。主探索の置換表による打ち切り、null moveによる打ち切り、futility pruning、SEEによる捕獲手の枝刈り、静止探索のstand-patによる打ち切り、静止探索の差の見込みによる枝刈り（ノード全体の打ち切りと手ごとの枝刈り）、静止探索のSEEによる枝刈り、および静止探索の置換表による打ち切り。 |
| 減深 | 経路の手がLMRで減深して探索され、全深さで読み直されずに値が確定した。 |
| 兄弟手による打ち切り | 経路の手に届く前に、別の手でβカットが起きた。 |
| 兄弟手の誤り | 経路の手を探索し、$N_{D+1}$は乖離しないが、$N_D$は乖離する。 |
| 地平線 | 経路の手が静止探索で生成されない非捕獲手であるか、手数の上限に達した。 |
| 読み筋の末端 | 読み筋が尽きた時点で、まだ乖離している。 |
| 反復 | 経路の手が反復による引き分けとして扱われた。 |
| 王駒の捕獲 | 経路の手が最後の王駒を取る手として終局値を返した。 |
| 乖離なし | $N_1$が乖離しない。 |

$t'_D$で乖離を確かめられなかった場合は、停止の理由にかかわらず「乖離点の未確認」とする。
根から$N_D$までの経路上で働いた機構、すなわち経路の手へのLMRの減深、経路上のノードでのinternal iterative reduction（IIR）とnull moveの試行、根でのaspiration windowの読み直し、および$N_D$での停止の理由となった機構を、その経路の**追跡で関与した機構**とする。
乖離の判定に使うのは経路上の値だけであり、手の順序付けは機構に含めない。

### 介入

無効にする機構は次の11種類とし、追跡用ビルドだけが持つ診断の手段として実装する。

| 機構 | 無効にしたときの動作 |
|---|---|
| 主探索の置換表による打ち切り | 置換表の読み取りは手の順序付けにだけ使い、値による打ち切りをしない。 |
| IIR | 置換表の手がなくても深さを減らさない。 |
| null move | null moveを試さない。 |
| futility pruning | 静かな手を静的評価で省かない。 |
| SEEによる捕獲手の枝刈り | 主探索で捕獲手をSEEで省かない。 |
| LMR | 減深量を常に0にする。 |
| 静止探索の差の見込みによる枝刈り | ノード全体の打ち切りと手ごとの枝刈りの両方を行わない。 |
| 静止探索のSEEによる枝刈り | 静止探索で捕獲手をSEEで省かない。 |
| 静止探索の置換表による打ち切り | 静止探索で置換表の値による打ち切りをしない。 |
| aspiration window | 各反復を全窓で探索する。 |
| 静的評価の補正（correction history） | 補正値の読み取りを常に0にする。 |

各根で、機構を1種類ずつ無効にして`go depth d0`を実行し、選ばれた手bの損失を$L(b)=v(a^\ast)-v(b)$で求める。
ここで$v$は子局面を10,000,000ノードで探索した値を根の手番側から見た値であり、記録にない手は新たに探索する。
$L(b)<m$（負を含む）なら、その介入は**成功**とする。
成功と失敗にかかわらず、各介入で2本の経路を追跡し、根でのa\*とs0の値と上下界の種類を記録する。

追跡で関与した機構が1種類もない根を除き、両経路の追跡で関与した機構をすべて同時に無効にした介入を1回だけ行い、同じ規則で成否を判定する。

### 分類

各根を次の順に分類する。

| 分類 | 条件 |
|---|---|
| 1機構の特定 | 追跡で関与し、かつ単独の介入が成功した機構がちょうど1種類ある。 |
| 複数機構の疑い | そのような機構が2種類以上ある、または単独の介入はどれも成功せず、同時に無効にした介入が成功した。 |
| 特定できない | 上のいずれでもない。両経路の停止の理由を添えて記録する。 |

単独の介入が成功しても追跡で関与していない機構は、「介入だけで成功」として記録し、分類には数えない。
名目深さの内側に駒の損得の差があるだけの根は、特定できた根に数えない。

機構ごとの件数は、1機構の特定の根ではその機構に1を、複数機構の疑いの根では追跡で関与し単独の介入も成功した各機構に1を数え、同時の介入だけが成功した根は数えない。
同じ機構の件数が3根以上なら、段階12の後続となる探索の計画の候補として記録し、本計画では修正しない。
静止探索の3機構のいずれかが1根以上で数えられた場合は、フェーズ1の末端の取り出しが同じ静止探索を使うことへの注記を残す。

成功した介入については、同じ機構を無効にした`go nodes 100000`の選択と損失も記録する。
これは固定ノードでの影響の記録であり、分類には使わない。

## コマンドライン

追跡用のビルドと、6根の追跡、介入、および分類を次のコマンドで実行した。
スクリプトと出力は `qsearch-output-search-trace/` に保存した。

```console
CARGO_BUILD_JOBS=1 CARGO_TARGET_DIR=target/search-trace nice -n 19 \
  cargo build --release --features search-trace --bin minase
nice -n 19 python3 docs/measurements/qsearch-output-search-trace/trace_roots.py --jobs 1
```

スクリプトは、前提条件の検査、追跡、介入、10,000,000ノードの確認探索、および分類を1回の実行で行い、条件の不一致があれば停止する。
探索はすべて1スレッド、64 MiBの置換表、探索ごとに新しいプロセスで、規則は`engine-default`（`L0,P0,R1,E0`）である。

## 結果

### 前提条件

12の子局面の10,000,000ノードの再探索は、評価値と読み筋が準備記録の`residual_pv.json`とすべて一致した。
6根の提案探索は、`go nodes 100000`と`go depth d0`の両方で、記録された提案手、完了深さ、および評価値を再現した。
したがって、以下の追跡は準備記録と同じ探索を対象にしている。

### 根ごとの分類

次の表は、各根の乖離点、追跡で関与した機構、単独の介入が成功した機構、および分類を示す。
経路のsは提案手の経路、aは最善手の経路であり、乖離しなかった経路は省いた。
全経路の値、窓、上下界、各介入の根での値、および固定100,000ノードの記録は`qsearch-output-search-trace/summary.md`にある。

| 根 | d0 | s0 | a\* | 乖離した経路とD | 停止の理由 | 追跡で関与した機構 | 単独の介入が成功した機構 | 分類 |
|---|---:|---|---|---|---|---|---|---|
| 202610280-278 | 6 | 4j5j | 8j11j | a、D=1 | 経路上の機構（主探索の置換表による打ち切り） | aspiration、tt_cutoff | tt_cutoff、null_move、futility、lmr、qs_delta、qs_see、aspiration、correction | 複数機構の疑い |
| 202610489-236 | 6 | 9i8h | 4k5k | s、D=1 | 減深 | lmr、null_move | tt_cutoff、iir、futility、lmr、qs_delta、qs_see | 1機構の特定（lmr） |

機構名は`TraceDisable`の識別子であり、「介入」の表の機構に対応する。
6根はいずれも、2本の経路のうち一方だけが乖離した。
202612388-210では、読み筋から求めた$t_5=681$は$N_5$の下界835から乖離したが、$N_5$を10,000,000ノードで探索した$t'_5=960$では乖離しなかった。
202613669-264の同時の介入は、第3の手12i11hを選び、損失は123センチポーンだった。

### 集計

分類は、1機構の特定が3根、複数機構の疑いが2根、特定できないが1根だった。
機構ごとの件数は、lmrが2、aspirationが2、tt_cutoffが1であり、その他の8機構は0だった。
3根以上で数えられた機構はなく、静止探索の3機構はいずれも0根だった。

### 解釈上の留意点

単独の介入の成功は、機構の特定性が低い。
6根のうち5根では2から8種類の機構が単独で選択を変え、その多くは追跡で関与しなかった機構だった。
同じ深さで枝刈りや減深を外すと探索木が広がるので、成功は「その機構が誤りを生んだ」ことより、「d0での選択が探索木のわずかな変化で入れ替わる」ことを示している可能性が高い。
したがって、上の件数は事前登録の規則が与える値であり、2根でLMRが原因であることの証拠とは扱わない。

追跡の側では、経路の手の減深が最も多い停止の理由であり、6根のうち3根に現れた（202610489-236と202614203-172の提案手の経路、202613669-264の最善手の経路）。
202613669-264では単独の介入がどれも成功しなかったため、LMRの件数には数えていない。
この観察は件数の規則とは別の記述として記録する。

202610280-278の停止の理由は、$N_1$で置換表の下界655による打ち切りが起きたことである。
追跡が示すのは誤った値が経路へ伝わった位置であり、その値を置換表へ格納した探索の誤りの位置ではない。

202612852-212でaspiration windowが関与したとされるのは、深さd0の反復で根の読み直しがあったためであり、停止の理由は経路外の兄弟手による打ち切りである。
同じ機構を無効にした固定100,000ノードの探索は7g8hを選び、損失は269センチポーンだったので、この介入の成功はノード数の制限の下では再現しない。

損失が負の値になる例（202610489-236でLMRを無効にした固定100,000ノードの6k6l、−42センチポーン）がある。
a\*は記録された候補集合の中での最善手にすぎず、新たに探索した手がそれを上回ることがあるため、損失は真の最善手からの距離ではない。

## 結論

3根以上で特定された機構はなく、静止探索の機構も特定されなかったので、事前登録の規則により、探索の後続計画への引き渡しとフェーズ1への注記はいずれも行わない。
6根の誤りは、深さd0での選択が多くの機構の単独の無効化で入れ替わる不安定な型であり、特定の枝刈りに帰属できるものではなかった。
6根は以後、本計画のどの検証集合にも使わない。

# 静止探索の置換表と置換規則の固定ノード数GSPRT

## 目的

静止探索での置換表の照会・記録、深さを考慮した置換規則、および手なし符号を導入したコミットが、直前コミットより固定ノード数で有意に強いかをGSPRTで判定する。

## コマンドライン

```console
match_runner --seed 20260822 --candidate commit:c817f79 --baseline commit:d68b101 --each nodes=100000 --concurrency 8 gsprt --max-pairs 3000
```

`--run-dir`の記録はなく、実行ディレクトリは残っていない。

## エンジン

候補はコミットc817f79（Lazy SMP第2版フェーズ6）、基準は直前コミットd68b101である。
両者とも`DEFAULT_THREADS`は1である。
規則セットはコマンドラインに指定がなく、コミットc817f79の`match_runner`は省略時にengine-defaultを適用する。

## 環境

CPU型は記録なし。
候補と基準のワーカー数はともに1。
`USI_Hash`は記録なし。
同時対局数8。

## 結果

ペンタノミアル[51, 5, 238, 6, 145]、有効445ペア、破棄1ペア、`engine_failures`全0、LLR 2.958、decision: H1、経過3,087秒。
固定ノード数の測定のため`time_forfeits`は該当しない。
参考として、`Threads=1`のbench署名は候補でdepth 3が645,149、depth 4が1,891,549、depth 5が5,959,065であり、基準では1,190,540、4,573,594、12,764,630であった。
固定深さ5の経過時間は11.1秒から4.2秒へ短縮した。

## 結論

H1に到達したため採用した。

# 順位の教師の生成（フェーズ2）

## 目的

[浅い探索の手の順位を学ぶ損失](../plans/rank-loss-training.md)のフェーズ2として、[小標本](rank-loss-pilot.md)の判定で決めた訓練22,827根と検証1,000根について、候補手の子局面を2予算で探索し、学習に使う安定した組を作る。
棋力測定ではなく、対局の勝敗を使わない。

## コマンドライン

```console
P=data/rank-loss-training
tools/train/.venv/bin/python tools/train/pst/rank_roots.py sample \
  --data $P/data/generated-94000000.bin $P/data/generated-94100000.bin \
  --train 22827 --validation 1000 --seed 20261001 --output $P/phase2/roots-all.jsonl
# roots-all.jsonl を split ごとに roots-train.jsonl と roots-validation.jsonl へ分けた
for S in validation train; do
  $P/bin/eval_teacher-f060e35 rank-evaluate \
    --roots $P/phase2/roots-$S.jsonl --output $P/phase2/results-$S.jsonl --jobs 16
done
```

抽出シード20261001は、小標本のシード20260930と異なる。
小標本の探索結果は学習に使わない。

## エンジン

教師の生成器は小標本と同じ`eval_teacher`（コミット`f060e35`、SHA-256 `34aa4ec6…`）であり、探索と埋め込み採用PSTはmaster `0a0171f`と同一、規則は`L0,P0,R1,E0`である。
探索条件、候補手、および組の判定は、小標本の記録の事前登録のとおりであり、判定の差mは117.7センチポーンである。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ32 GB）で、2026年10月1日1時8分から11時21分に、同時16根として実行した。
経過時間は、検証の1,000根が26分6秒、訓練の22,827根が9時間47分26秒であり、合計は小標本の判定で定めた上限12時間に収まった。

## 結果

抽出した根は、訓練が静かな局面19,485、捕獲局面3,057、成り局面285、検証が静かな局面857、捕獲局面126、成り局面17であり、全根で履歴から記録の局面を復元できた。

| 量 | 訓練 | 検証 |
|---|---:|---:|
| 根 | 22,827 | 1,000 |
| 1根あたりの候補手 | 3.83 | 3.83 |
| 組 | 129,896 | 5,673 |
| 詰みを示す値を含むため除外した組 | 3,430 | 152 |
| 安定した組 | 26,353 | 1,154 |
| 1根あたりの安定した組 | 1.154 | 1.154 |
| 逆順位の組 | 17,566 | 763 |
| 逆順位の割合 | 66.7% | 66.1% |
| $Q^{(1)}$が同値の組 | 540 | 25 |
| 1根の費用の平均（秒） | 24.6 | 24.7 |

詰みを示す値を返した子局面は訓練1,567件、検証69件であり、終局と未完了による除外はなかった。
訓練の安定した組は26,353組であり、小標本の見込み29,425組を下回ったが、第1の判定の基準20,000組を上回った。
1根あたりの安定した組が小標本の訓練128根（1.289）より少なく、1根の費用も小標本（29.0秒）より短かった。

安定した組のうち、他方の手が深さ1の上位3手に由来する組は、訓練で26,353組中25,507組、検証で1,154組中1,111組だった。
訓練で多い組の種類は、深さ1の上位3手どうし（7,083組）、教師の最善手対深さ1の上位3手（5,208組）、および3種類すべてに由来する手対深さ1の上位3手（3,626組）である。
逆順位の組の$Q^{(1)}$の差の中央値は、訓練で−81センチポーン、検証で−71センチポーンだった。

保存物は`data/rank-loss-training/phase2/`にあり、Gitの管理外である。

## 結論

訓練26,353組と検証1,154組の安定した組を得たので、フェーズ3の学習へ進む。

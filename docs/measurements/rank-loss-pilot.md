# 順位の教師の小標本

## 目的

[浅い探索の手の順位を学ぶ損失](../plans/rank-loss-training.md)のフェーズ1として、訓練集合と検証集合の128根ずつで候補手の子局面を2予算で探索し、安定した組の数と生成費用、およびS0の深さ1の値が教師と逆に並べる組の割合を測って、設計書の2つの判定を行う。
棋力測定ではなく、対局の勝敗を使わない。

## 事前登録

本節は、小標本の教師探索を始める前の2026年9月30日に固定した。
結果を見た後に、標本、候補手、組の判定、および判定の計算式を変えない。

### 標本

根は、S0の生成器で新たに生成した15,000局（基本シード94,000,000と94,100,000、[学習データの記録](rank-loss-selfplay-data.md)）の記録から抽出する。
訓練集合と検証集合は、学習器`train_qsearch.py`が使う既存の対局単位の分割をそのまま使う。
根の種類は限定せず、静かな局面、捕獲局面、および成り局面をすべて対象にする。
順位の損失は対局中の手の選択を学ばせるものであり、手を選ぶ局面は種類を問わないからである。
各集合の全記録から、乱数シード20260930で128根ずつを非復元の一様抽出で選ぶ。

各根は、保存した開始手順と着手列から対局を履歴ごと復元し、記録の局面と一致することを確かめてから探索する。

### 探索条件

探索はすべて、S0の探索と埋め込み採用PST、規則`L0,P0,R1,E0`、1スレッド、探索ごとに新しい64 MiBの置換表、ノード上限だけの制限で行う。
これは探索局面の計画の教師診断と同じ条件である。

### 候補手

各根の候補手は、次の3種類の手の和集合から重複を除いたものである。

- 教師の最善手は、根を10,000,000ノードで探索した最善手である。
- S0の提案手は、根を100,000ノードで探索した最善手である。
- 深さ1の上位3手は、全合法手$a$について子局面$s_a$から採用PSTで静止探索した値の符号を反転した$Q^{(1)}(s,a)$の大きい順の3手であり、同値は手のUSI表記の辞書順で先の手を上位とする。

候補手はUSI表記の辞書順に並べ、各手の子局面を1,000,000ノードと10,000,000ノードで独立に探索する。
子局面の探索値の符号を反転した値を、根の手番側から見た手の教師値$V_n(s,a)$とする。

### 組の判定

候補手の2手$a,b$の組は、USI表記の辞書順で$a$を先に置いて向きを固定する。
両手の両予算の教師値がともに通常の評価値である組だけを判定の対象とし、終局、詰みを示す値、または未完了を含む組は除外して件数を記録する。
判定の差mは、S0で測り直した値（[教師の校正](rank-loss-teacher-calibration.md)）を使う。
$D_n=V_n(s,a)-V_n(s,b)$とし、$|D_{1M}|\ge m$、$|D_{10M}|\ge m$、$D_{1M}$と$D_{10M}$が同符号、かつ$|D_{10M}-D_{1M}|\le m$を満たす組を安定した組とする。
安定した組では、$D$が正なら$a$、負なら$b$を教師が支持する手とする。

安定した組のうち、教師が支持する手の$Q^{(1)}$が他方の手の$Q^{(1)}$より厳密に小さい組を逆順位の組とする。
$Q^{(1)}$が等しい組は逆順位に数えず、件数を別に記録する。

### 判定の計算式

1根の費用$c$は、小標本を他の負荷のない測定機で同時16根として実行したときの、その根のすべての探索と$Q^{(1)}$の計算の経過時間の合計（秒）とする。
256根の平均を$\bar c$とし、12時間に同時16で処理できる根の数を$N_{12}=\lfloor 12\times3600\times16/\bar c\rfloor$とする。
訓練に使える根の数は、検証の1,000根を除いた$N_{\mathrm{train}}=N_{12}-1000$とする。
訓練集合の128根での1根あたりの安定した組の数を$r$とし、見込みの訓練の組の数を$N_{\mathrm{train}}\times r$とする。

- 第1の判定は、$N_{\mathrm{train}}\times r\ge20{,}000$であれば満たす。
- 第2の判定は、256根の安定した組全体に占める逆順位の組の割合が10%以上であれば満たす。

2つの判定は独立に適用し、どちらか1つでも満たさなければ見送りとする。
両方を満たした場合、フェーズ2の訓練の根の数は$N_{\mathrm{train}}$とし、12時間の予算を使い切る。
フェーズ2の根は、小標本とは別の乱数シードで抽出し直し、小標本の探索結果は学習に使わない。

### 記録する量

集合ごとに、1根あたりの候補手の数と安定した組の数、組の種類ごとの件数、除外した組の件数と理由、詰みを示す値を返した子の件数、および1根あたりの費用を記録する。
組の種類は、教師が支持する手と他方の手のそれぞれが、上記3種類の候補手のどれに由来するかの組合せで表す。
逆順位の組については、$Q^{(1)}$の差の分布を記録する。
安定した組全体について、尺度$\tau=m$での順位の損失$\log(1+\exp(-\Delta/\tau))$とその勾配の大きさ$\sigma(-\Delta/\tau)/\tau$の分布を記録する。
ここで$\Delta$は、教師が支持する手の$Q^{(1)}$から他方の手の$Q^{(1)}$を引いた値である。

## コマンドライン

```console
P=data/rank-loss-training
tools/train/.venv/bin/python tools/train/pst/rank_roots.py sample \
  --data $P/data/generated-94000000.bin $P/data/generated-94100000.bin \
  --train 128 --validation 128 --seed 20260930 --output $P/phase1/roots.jsonl
$P/bin/eval_teacher-f060e35 rank-evaluate \
  --roots $P/phase1/roots.jsonl --output $P/phase1/results.jsonl --jobs 16
tools/train/.venv/bin/python tools/train/pst/rank_pairs.py pilot \
  --roots $P/phase1/roots.jsonl --results $P/phase1/results.jsonl \
  --m 117.7 --output $P/phase1/pilot.json
```

## エンジン

教師の生成器は、ブランチ`rank-loss-training`のコミット`f060e35`からフィーチャ`qsearch-leaf`付きでビルドした`eval_teacher`（SHA-256 `34aa4ec6…`）である。
探索と埋め込み採用PSTはmaster `0a0171f`と同一であり、規則は`L0,P0,R1,E0`である。
判定の差mは[再校正](rank-loss-teacher-calibration.md)の117.7センチポーンを使った。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ32 GB）で、2026年10月1日0時59分から1時07分に、他の負荷のない状態で同時16根として実行した。
経過時間は7分55秒だった。

## 結果

抽出した根は訓練128根（静かな局面109、捕獲局面18、成り局面1）と検証128根（静かな局面107、捕獲局面19、成り局面2）であり、全根で履歴から記録の局面を復元できた。

| 1根あたりの候補手 | 3.78 | 3.82 | 3.80 |
| 組 | 705 | 725 | 1,430 |
| 詰みを示す値を含むため除外した組 | 23 | 29 | 52 |

詰みを示す値を返した子局面は25件であり、終局と未完了による除外はなかった。

### 判定

| 量 | 値 |
|---|---:|
| 1根の費用の平均$\bar c$ | 29.01秒 |
| 12時間に同時16で処理できる根$N_{12}$ | 23,827 |
| 訓練に使える根$N_{\mathrm{train}}$ | 22,827 |
| 訓練の1根あたりの安定した組$r$ | 1.289 |
| 見込みの訓練の組 | 29,425 |
| 逆順位の割合 | 67.2% |

第1の判定（見込みの訓練の組が20,000以上）と第2の判定（逆順位の割合が10%以上）をともに満たした。

## 結論

2つの判定を満たしたので、フェーズ2で訓練22,827根と検証1,000根の教師を生成する。
S0の深さ1の値は、教師が安定して区別する組の約3分の2で順位を逆にしており、その大半は深さ1の上位3手のうち教師が退ける手を上に置く誤りである。

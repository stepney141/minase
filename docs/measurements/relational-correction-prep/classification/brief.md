# 中将棋の局面資料の分類

ディレクトリ /home/stepney141/board-games/minase/data/relational-correction/phase0/packets/ に、根の局面ごとの資料が62件（`b*.md`、ファイル名が根の識別子）と、分類の指示 `instructions.md` がある。まず instructions.md を読み、その4種類の定義だけに従って、62件のすべてを1件ずつ読んで分類せよ。all.md は62件を連結したものなので読まなくてよい。

資料の前提は次のとおりである。

- 中将棋は12×12の盤の将棋の変種である。升は筋（12から1）と段（aからl）で表す。資料の盤面は「升:駒」の形で、先は先手、後は後手の駒を示す。
- 根の局面で手番を持つ側は、資料の「最初の6手」の1手目で動く駒の所有者である。
- a\*は、根の局面を深く探索（10,000,000ノード）して最善と判定された手である。s0は、浅い探索（100,000ノード）が選んだ手であり、深い探索はs0をa\*より明確に悪いと判定した。
- 分類で問うのは、a\*の子局面とs0の子局面の評価の違いが、指示の4種類のうちどの駒の関係によって説明できるかである。読み筋、駒の損得の推移、追跡の結果は判断の材料であり、読み筋の末端は帰結を確かめる証拠としてだけ使う。

1件ごとに独立に判断し、迷う場合も4種類のいずれか1つを選ぶ。どれにも当てはめられなければ「不明」とする。他の分類者の結果やこのディレクトリの外の文書は参照しない。

回答は、62件について1行1件のJSON（instructions.md の形式、`category` は「近接2駒」「王駒射線」「多駒」「不明」のいずれか）を、指定された出力ファイルへ書く。理由は日本語で1〜3文とする。

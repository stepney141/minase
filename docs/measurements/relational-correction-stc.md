# 局所2駒表とS0のSTC

## 目的

[関係補正項の計画](../plans/relational-correction.md)の利用者の判断による測定のフェーズ4として、倍率1の半径1の局所2駒表を加えた候補と採用版S0を短時間条件STCのGSPRTで比べ、候補をLTCへ進めるかを判定する。

## コマンドライン

```console
cargo run --release --bin match_runner -- \
  --run-dir data/matches/relational-correction-stc --seed 97000000 \
  --candidate commit:d7447b7 --baseline commit:c47106a \
  --each time=10000+100 gsprt --max-pairs 3000
```

## エンジン

候補はブランチ`relational-pair-1`のコミット`d7447b7`（S0の`c47106a`に局所2駒表の推論と差分更新、および倍率1の重み`c207372c…`を加えたもの）、基準はS0の`c47106a`である。
規則は`L0,P0,R1,E0`である。
候補の探索速度は、零の表の構成でS0の0.775倍である（[速度の記録](relational-correction-speed.md)）。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ32 GB）で、2026年10月2日2時38分から3時12分に実施した。
同時19対局、両エンジンとも1スレッド、置換表256 MB、時間制御は`time=10000+100`である。

## 結果

| 項目 | 値 |
|---|---|
| ペア数 | 222（有効207、手数上限で破棄15） |
| ペンタノミアル度数 | [69, 3, 108, 2, 25] |
| 得点率 | 39.3% |
| LLR | −2.947 |
| 判定 | `H0` |
| エンジン異常、時間切れ、拒否着手 | 0件 |
| 経過時間 | 2,031秒 |

得点率39.3%はロジスティックの換算で約−75 Eloに当たる。

## 結論

STCが`H0`となったので、局所2駒表の候補は採用せず、LTCへ進めない。

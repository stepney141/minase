# 局所2駒表の学習

## 目的

[関係補正項の計画](../plans/relational-correction.md)の利用者の判断による測定のフェーズ2として、採用PSTを固定したまま半径1の局所2駒表を採用構成の教師で学習し、候補の重みを作る。
棋力測定ではなく、対局の勝敗を使わない。

## コマンドライン

```console
P=tools/train/.venv/bin/python
C=data/strength-stage9/lookahead-pst.toml
O=data/relational-correction/phase2
$P tools/train/pst/train_pair.py count --config $C --radius 1 --output $O/counts.json
$P tools/train/pst/train_pair.py train --config $C --radius 1 --counts $O/counts.json \
  --base-weights nets/pst.bin --out $O/run --device cuda
for s in 1 0.25; do
  $P tools/train/pst/train_pair.py export --run $O/run --base-weights nets/pst.bin \
    --scale $s --output $O/pair-$s.bin
  $P tools/train/pst/train_pair.py check --weights $O/pair-$s.bin --run $O/run \
    --samples data/relational-correction/prep/samples/quantization.json \
    --probe target/release/pst_probe --output $O/check-$s.json
done
```

作業ディレクトリは本ブランチのworktreeであり、`nets/pst.bin`は採用PSTに半径1の零の表を付けた版3の重みである。

## エンジン

学習器は本ブランチのコミット`c4fa988`の`train_pair.py`、整数評価の照合には同コミットの`pst_probe`を使った。
教師値、教師の分類ごとの尺度、λ、先読み（γ=0.9、n=40）、出力尺度、および訓練と検証の分割は、採用PSTの[学習](lookahead-teacher-pst-training.md)と同じ経路で作った。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ32 GB、GeForce RTX 3060 Ti）で、2026年10月1日22時21分から10月2日2時09分に実施した。
1エポックは約20分から25分だった。

## 結果

### 出現局面数と表の形式

訓練分割23,879,611局面で数えると、半径1の代表要素22,137個のうち、出現した要素は12,892個、出現局面数200未満で0に固定する要素は14,152個（63.9%）だった。
半数以上が0に固定されるので、[設計書](../plans/relational-correction.md)の局所2駒表の形の規則により、ランク16の低ランク分解で学習した。

### 学習

教師の分類ごとの尺度は768.45、1068.21、758.35であり、同記録と一致した。

### 書き出しと整合性

最良エポックの表を代表要素へ展開し、倍率1と1/4で量子化した。
どちらも量子化後の表は0ではなく、i16の範囲に収まった。

|---|---:|---:|
| RustとPythonの整数評価の一致（10,000局面） | 10,000 | 10,000 |
| 量子化誤差の平均（センチポーン） | 0.606 | 0.604 |
| 量子化誤差の最大（センチポーン） | 2.76 | 2.76 |

量子化誤差は2センチポーン以下である。
倍率1の重みのSHA-256は`c207372c9557f82177830429c10447005cc352efb80a497c73c71b4d0ed4ed53`、倍率1/4は`6221677781069e7a06c9353b08100e18a2aa6ff403b113775d5d03ded82747c6`、最良エポックの実数の表は`280f3aa36f1fdf438c95a2b855556144d6132292b800cc0a3cfade44ba7b7f11`である。
学習の記録と整合性の結果は`relational-correction-prep/prep/`の`training.json`、`check-1.json`、および`check-0.25.json`に写した。

## 結論

半径1の局所2駒表は検証損失を0.000178下げ、測定へ進む条件（初期状態より厳密に改善し、量子化後の表が0でない）を満たした。

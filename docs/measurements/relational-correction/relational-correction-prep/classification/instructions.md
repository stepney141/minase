# 分類の指示

根ごとに次の4種類から1つを選び、理由を記す。

関与駒は、a\*の読み筋の最初の6手で動く駒と取られる駒である。
2つの子局面は、a\*の子局面とs0の子局面である。
チェビシェフ距離は、2升の筋の差と段の差の絶対値の大きい方である。

- 近接2駒は、少なくとも一方が関与駒で、互いのチェビシェフ距離が2以内の駒の組の配置によって、2つの子局面の違いを説明できる場合である。取る駒と取られる駒の接近、隣の駒による支え、および隣の駒による進路の塞ぎを含む。

- 王駒射線は、違いが、王駒から8方向のいずれかにある最初の駒と、その奥にある王駒へ向かう敵の走り駒の組の配置で説明できる場合である。

- 多駒は、違いが3枚以上の駒の同時の条件によって初めて説明でき、王駒射線に当たらない場合である。

- 不明は、上のいずれでも説明できない場合である。

読み筋の末端の局面は分類の対象にせず、関係の帰結を確かめる証拠として使う。

回答は根ごとに次のJSON形式とする。

```json
{"root_id": "...", "category": "近接2駒|王駒射線|多駒|不明", "reason": "..."}
```

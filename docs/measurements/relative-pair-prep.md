# 相対2駒評価の準備記録

## 目的

[相対位置の局所2駒関係による評価の補正](../plans/relative-pair-eval.md)のフェーズ0として、関係項の着手の根拠となる配置依存の残存誤りを確認し、着手する場合は比較条件を確定する。
棋力測定ではなく、対局の勝敗を使わない。

## 着手判断の事前登録

本節は、判定に使う根の着手、読み筋、および盤面を見る前の2026年9月26日に固定した。
結果を見た後に、標本、分類の規則、および閾値を変えない。

### 標本

[探索局面の計画](../plans/search-aware-evaluation.md)の最終診断（`data/search-aware-evaluation/phase4/final/report.json`）で、教師の判定が安定した203根のうち、S0の候補集合内の選択損失が差m=142.1センチポーン以上の根を標本とする。
同報告によれば該当する根は6根であり、この件数だけを見て、根の内容は見ていない。
判定が不安定な42根は、予算によって教師の判定が変わるので標本に入れない。
採取局面の平均誤差（−667センチポーン）は静止探索中の局面の偏りであり、静かな局面を採点する関係項の根拠には使わない。

前段の教師はS0の重みを使う探索なので、S0の100,000ノードの提案手と教師の最善手の差は、同じ評価関数の探索予算の差から生じる。
したがって本判定が問うのは、深い探索が見つけた差が、根の局面の近傍の駒の組み方として静的に表せる形をしているかどうかである。
学習器の不具合は前段の学習記録（[search-aware-pst-training](search-aware-pst-training.md)）で否定されており、着手の損失は教師自身の探索値の差なので尺度の不一致も生じない。

### 読み筋の取得

各根で、教師の最善手 \(a^\ast\)（候補集合内で10,000,000ノードの値が最大の手）とS0の提案手 \(a_\theta\) を指した子局面を、教師と同じ条件（S0の重み、1スレッド、置換表64 MiB、探索ごとに新しいプロセス、10,000,000ノード）で探索し、読み筋を得る。
根の局面は、前段の対局記録の開始手順と着手列をUSIの `position startpos moves` で与えて履歴ごと再現する。
実行ファイルは本ブランチの基点（master `cb2aa78`）からビルドする。
S0の `5563d75` との差は探索と評価の挙動を変えない再編だけなので、再探索の評価値は最終診断の記録と一致するはずである。
一致しない根が1つでもあれば、条件の不整合として判定を止めて原因を調べる。

### 分類

駒の損得は、盤上の駒の探索用駒価値（`nets/pst.bin` の47個）の和を根の手番側から見た差で測る。
読み筋の \(k\) 手目までを指した後の駒の損得を \(\mu_k\) とし、\(d_0\) をS0の提案探索の完了深さとする。
各根を次の順に分類する。

| 分類 | 条件 |
|---|---|
| S（探索内の見落とし） | 2つの読み筋の \(\mu_{d_0}\) の差がm以上である。S0の読みの深さの内側で駒の損得が決まっているので、枝刈りや延長の問題として扱い、静的評価の根拠に数えない。 |
| H（地平線の先の駒の損得） | Sでなく、読み筋の末端の \(\mu\) の差がm以上である。駒を取らない手が続いた後に損得が決まる型であり、次の局所性の判定へ進む。 |
| P（駒の損得のない局面の差） | 上のいずれでもない。読み筋の末端の配置の違いだけで値が分かれる型であり、次の局所性の判定へ進む。 |

HとPの根は、さらに局所性で分ける。
関与駒を、\(a^\ast\) の読み筋の最初の6手で動く駒と取られる駒とする。
2つの子局面の違いが、関与駒どうし、または関与駒とその近くの駒の、チェビシェフ距離3以内の組の配置（取る駒と取られる駒の接近、隣の駒による支え、隣の駒による進路の塞ぎ）で説明できる場合をR（局所的な配置）とする。
距離4以上の走り駒の筋、3枚以上の駒がそろって初めて成り立つ王の囲いの崩れ、または特定できない理由に依存する場合をL（局所的でない）とする。
半径の上限を3とするのは、設計書が半径1から3を候補にしているためである。

分類は2者が独立に行う。
Claudeと、判定の仮説を知らせずに規則と読み筋だけを渡した別のエージェントがそれぞれ分類し、両者がRとした根だけをRと数える。
不一致の根は両者の理由とともに記録する。

### 判定

R の根が3以上なら、配置に依存する残存誤りの根拠ありとして、比較条件の確定へ進む。
3未満なら、設計書の規定により、必要性の根拠不足として未実装の見送りを記録する。
3は、標本6根の半数であり、大きな誤りの主要な型が局所的な配置であることを求める値である。
Sの根が多い結果は、関係項ではなく探索の枝刈りや延長の問題を示すものとして別に記録する。

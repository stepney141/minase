# 対照Aと候補Bの採否前の診断（探索局面の学習計画）

## 目的

[探索局面を用いた評価関数の学習](../plans/search-aware-evaluation.md)のフェーズ4として、[学習した](search-aware-pst-training.md)AとBの重みを棋力測定へ出せるかを、事前に固定した規則で判定する。
あわせて、最終診断用の根で着手の損失と静的評価の誤差を測り、実戦用ビルドの速度を記録する。
最終診断と速度は機序を調べるための記録であり、採否には使わない。

## コマンドライン

```console
tools/train/.venv/bin/python tools/train/pst/search_aware.py diagnose \
  --export data/search-aware-evaluation/phase3/export.jsonl --s0 nets/pst.bin \
  --training-dir data/search-aware-evaluation/phase4/training \
  --out-dir data/search-aware-evaluation/phase4/diagnostics \
  --probe target/search-aware-play/release/pst_probe --sample-size 256
target/search-aware-final/release/search_aware_diagnostic \
  --data-dir data/search-aware-evaluation/phase3 --out-dir data/search-aware-evaluation/phase4/final \
  --classification data/search-aware-evaluation/classification.json \
  --s0 nets/pst.bin --a data/search-aware-evaluation/phase4/training/A/pst.bin \
  --b data/search-aware-evaluation/phase4/training/B/pst.bin --jobs 16
target/search-aware-play/release/bench --depth 8 --threads 1 --repetitions 7 --pst <S0、A、Bの重み>
```

実行ファイルと学習器は、ブランチ `search-aware-evaluation` の `0a494c0` からビルドした。
`pst_probe` と `bench` は採取機能なしの実戦用ビルド、最終診断器は採取機能付きのビルドである。

## エンジン

S0はmaster `5563d75` の埋め込みPST、AとBは学習記録の重みである。
最終診断は各探索を1スレッド、探索ごとに新しい64 MiBの置換表とし、提案手は100,000ノード、教師はS0の重みで1,000,000ノードと10,000,000ノードである。
教師の判定に使う差mは、フェーズ2で固定した142.1センチポーンである。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ32 GB）で、2026年9月26日に実施した。
lishogi Botの `minase` が約4コアを使っていた。
最終診断は16並列で14分35秒かかった。
速度の計測は他の生成や対局と重ねず、S0、A、Bの順に1本ずつ実行したが、Botの負荷は残っている。

## 結果

### 採否前の診断

モデル選択集合からシード1で抽出した256局面に、初期配置と局面帯ごとの代表局面を加えた262局面で検査した。

| 検査 | S0 | A | B |
|---|---:|---:|---:|
| 量子化の前後の平均絶対誤差（センチポーン） | 0.49 | 0.51 | 0.53 |
| 量子化の前後の最大誤差（センチポーン） | 0.98 | 1.75 | 1.36 |
| RustとPythonの評価と差分の一致 | 一致 | 一致 | 一致 |
| 逆向きの駒除去差分 | 0 | 0 | 0 |
| S0にない逆向きの駒除去差分 | ― | 0 | 0 |
| S0との駒除去差分の符号反転 | ― | 0 | 0 |
| 評価を下げる成り手（368件中） | 1 | 44 | 294 |
| 成り手の差分の中央値（センチポーン） | +477 | +243 | −361 |
| `may_play` | 真 | 真 | 真 |

量子化済みの重みは、A、B、S0のどの2つも一致しなかった。
事前に固定した判定規則（S0にない逆向きの駒除去差分が0件）により、AとBはともに対局へ進める。

成り手の差分は記録だけの項目であるが、Bで大きく変わった。
標本の成り手の多くは、走り駒が敵陣の奥へ入って成る着手であり、差分は成ることの価値と移動先の升の価値の和である。
S0はこうした着手を中央値+477センチポーンと高く評価し、Aはその半分程度、Bは負に評価した。
一方、除去差分から導いた駒価値は、3者とも±4センチポーン以内で一致した。
したがって、Bの変化は駒価値ではなく、敵陣の奥の升の価値の変化による。
静止探索で評価される局面では、敵陣へ入った直後の駒が取り返されることが多く、深い教師はそれを値に含めるので、Bはその局面を学んで敵陣の奥の升を低く評価したと考えられる。

### 最終診断

最終診断の256根のうち、通常評価の教師値を得た248根で実行した。
候補集合のすべての手で両予算の通常評価を得た根は245根で、残る3根は詰みを示す値を含んだ。
候補集合のすべての手の組がm以上の安定した支持か小差に入る根（教師の判定が安定した根）は203根、それ以外は42根であった。

| 候補集合内の選択損失 | S0 | A | B |
|---|---:|---:|---:|
| 安定した203根の平均（センチポーン） | 26.4 | 28.1 | 50.5 |
| 安定した根のうち損失がm以上の根 | 6 | 5 | 14 |
| 不安定な42根の平均（センチポーン） | 194.0 | 204.1 | 282.5 |
| 比較可能な245根の平均（センチポーン） | 55.1 | 58.3 | 90.3 |

静的評価と、各局面を独立に探索した教師値との誤差（静的評価−教師値）は次のとおりである。

| 局面 | 指標 | S0 | A | B |
|---|---|---:|---:|---:|
| 最終診断の根（248局面） | 平均誤差 | −106 | −20 | +251 |
| | 平均絶対誤差 | 229 | 223 | 395 |
| 最終診断の採取局面（235局面） | 平均誤差 | −667 | −577 | −305 |
| | 平均絶対誤差 | 823 | 788 | 778 |

S0は採取局面の値を平均667センチポーン低く見積もっていた。
Bはこの過小評価を半分以下に減らしたが、通常の根では逆に平均251センチポーン高く見積もるようになった。
PSTは局面が戦術的に動いている最中かどうかを表せないので、採取局面の偏りを直す変更が、通常局面の評価にもそのまま及んだと考えられる。

### 速度

深さ8の `bench`（7回の中央値、1スレッド）は次のとおりである。

| 重み | 総ノード数 | 経過時間 | NPS |
|---|---:|---:|---:|
| S0 | 8,606,700 | 4.01秒 | 2,145,898 |
| A | 13,444,334 | 6.13秒 | 2,191,799 |
| B | 101,959,408 | 18.83秒 | 5,415,493 |

Bでは、同じ深さに達するまでの探索ノード数がS0の約12倍に増えた。
NPSが2.5倍に上がっていることから、増えたノードの多くは静止探索の安価な節点と考えられる。
採取機能なしのビルドへS0の重みを読み込ませた `bench` は、master（`0dfab4b`、`5563d75` との差は文書だけ）からビルドした `bench` と、全局面で最善手、評価値、完了深さ、ノード数が一致した。

## 結論

事前に固定した規則により、AとBはともに棋力測定へ進める。
最終診断では、Bの着手の損失と通常局面の評価誤差がS0とAより大きく、同じ深さまでの探索木も約12倍に増えた。
これらは採否の根拠ではなく、B対AとA対S0の棋力測定で判定する。

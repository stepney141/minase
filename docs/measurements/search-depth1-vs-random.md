# 深さ1探索対ランダム着手の固定局数Elo

## 目的

探索部フェーズ2で実装した評価関数v0と探索骨格が、深さ1の探索だけでランダム着手に対して測定可能な強さを持つことを確認する。

## コマンドライン

記録なし（2026年8月11日当時の`selfplay`バイナリで、`--candidate depth=1 --baseline random`相当の固定局数Eloモードを100ペアで実行した。シードの値は設計書に記録がない）。

## エンジン

候補はフェーズ2完了時点の深さ1固定探索（評価関数v0、静止探索なし、置換表なし）である。
コミットハッシュは設計書に記録がない（plans/match-harness.md はフェーズ2完了時点をコミット93b4bd4と記す）。
基準は同一ビルドのランダム着手プレイヤーである。
規則セットは自己対局の既定である標準規則−R0＋R1である。

## 環境

CPU型、物理コア数、論理コア数は記録なし。
ワーカー数は候補と基準とも1である。
`USI_Hash`は該当なし（置換表は未実装）。
同時対局数は記録なし。

## 結果

100ペア200局で候補が全勝し、ペンタノミアル度数は[0, 0, 0, 0, 100]であった。
全勝標本のためロジスティックEloの点推定は無限大となり有限値を推定できない。
200局無敗から1局あたり期待スコアの95%下限は約0.985（rule of three）であり、Elo換算で+725以上に相当する。
破棄ペア数と異常件数は記録なし。
`time_forfeits`は該当なし（深さ固定）。
経過時間は記録なし。
併せて測定したbenchは、depth=3で総ノード数241,231が再実行で完全に一致し、約195万NPSであった。

## 結論

深さ1探索はランダム着手に対して200局無敗であり、この構成を完了基準ゲートの凍結ベースラインとして固定する（凍結の確定は plans/match-harness.md）。

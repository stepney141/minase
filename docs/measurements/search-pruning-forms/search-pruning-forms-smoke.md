# 枝刈りとLMRの関数形を変えた候補の事前対局

## 目的

[探索の枝刈りとLMRの関数形の見直し](../../plans/archived/search-pruning-forms.md)のフェーズ4として、[SPSA](search-pruning-forms.md)の最終値を反映した候補と起点を、STCの条件で32ペア対局させる。
時間切れとエンジン異常が出ないことを確かめ、時間の使い方の変化を記録する。
採否には使わない。

## コマンドライン

[統括計画](../../plans/search-forms.md)の決定により、SPSAを終えた調整機で、持ち時間を換算せずに実行した。

```console
target/release/minase match run \
  --run-dir /workspace/job/matches/search-pruning-forms-smoke --seed 3310000000 \
  --candidate commit:d52aefb3a50732a638d860df903593045d8f37c0 \
  --baseline commit:99ccc6bbeff0360fe48598de54d96b1d4e64621a \
  --each time=10000+100 --concurrency 95 elo --pairs 32
data/spsa/search-pruning-forms-runner/minase match report \
  --run-dir data/matches/search-pruning-forms-smoke
```

実行ディレクトリは、終了後に測定機の`data/matches/search-pruning-forms-smoke`へ取得し、集計は測定機で行った。

## エンジン

候補は、SPSAの最終値を係数の表の既定値へ書き込んだ`d52aefb3a50732a638d860df903593045d8f37c0`であり、調整機でビルドしたバイナリのSHA-256は`40e2cfb7d923776b345a88f5e33e3fca1c37a6ff22e187b46f3bbe3a61571b2a`である。
起点は`99ccc6bbeff0360fe48598de54d96b1d4e64621a`であり、SHA-256は`fd14865d6dbd14e06850cab0171887b6600355d4db74a4741073fe383ca0820d`である。
起点の後にmasterへ入った`crates/`の変更は、対局ハーネスと`minase spsa`の補助ツール（`crates/minase/src/bin/minase/`）だけであり、起点の探索と評価は現在のmasterと同じである。
runnerは、調整機で`388c5244`をビルドした通常のminase（2.4.0）であり、SHA-256は`029a87159c8955a11910e6019cc99b0625aaa630e2afc6d62c9b566f71353483`である。SPSAのセッションと同じ実行ファイルである。
規則セットは`engine-default`（`L0,P0,R1,E0`）である。

## 環境

調整機は、SPSAと同じvast.aiのAMD Ryzen Threadripper PRO 9995WX（インスタンス56409205、物理96コア、論理192スレッド、runnerが記録した論理CPUは184）である。
この機械の1コアは測定機（Intel Core Ultra 7 265KF）より遅く、負荷時の速度の比`f`は1.46である（[試走の記録](../search-forms/vast-spsa-trial.md)）。持ち時間は換算していないので、1手の探索量は測定機の同じ条件より少ない。
候補と起点はいずれも`Threads=1`、`USI_Hash`は各256 MB、同時対局数は95である。
手数上限は4,096手、応答タイムアウトは120秒である。
2026年10月18日17時48分から17時51分に実施した。

## 結果

| 量 | 値 |
|---|---:|
| 有効ペア | 32（破棄0） |
| ペンタノミアル度数 | [8, 0, 18, 2, 4] |
| 正規化した平均得点 | 0.453 |
| Elo | −32.7 |
| 95%信頼区間 | [−110.5, +42.0] |
| エンジン異常 | 不正着手0、クラッシュ0、応答タイムアウト0、時間切れ0、拒否着手0 |
| 経過時間 | 161.4秒（`summary.json`の累計） |
| 1局の最大常駐メモリ | 621,654,016バイト |

値は`minase match report`が保存記録から再計算した集計による。
32ペアの固定局数Eloは信頼区間の幅が約150 Eloあり、強さの判定には使わない。

時間の使い方は次のとおりである。
総思考時間と終局時の残り時間は、`pairs/`に保存された各手の思考時間から計算した。終局時の残り時間は、持ち時間に1手の加算を着手数だけ足し、思考時間の合計を引いた値である。

| 量 | 候補 | 起点 |
|---|---:|---:|
| 総思考時間 | 1,878.9秒 | 1,909.8秒 |
| 着手数 | 13,813 | 13,817 |
| 1手の平均思考時間 | 136.0 ms | 138.2 ms |
| 終局時の残り時間の中央値 | 1,841 ms | 1,523 ms |

候補と起点の総思考時間の比は0.984である。

手数帯ごとの完了深さ（反復深化で読み終えた深さの平均）と思考時間の中央値は、`scripts/clock_profile.py`を`--role candidate`と`--role baseline`で別々に実行して集計した。

| 手数帯 | 候補の完了深さ | 起点の完了深さ | 候補の思考時間の中央値 | 起点の思考時間の中央値 |
|---|---:|---:|---:|---:|
| 0〜49 | 12.91 | 9.27 | 81 ms | 91 ms |
| 50〜99 | 12.20 | 8.78 | 91 ms | 121 ms |
| 100〜149 | 11.70 | 8.40 | 91 ms | 131 ms |
| 150〜199 | 11.45 | 8.29 | 101 ms | 141 ms |
| 200〜299 | 11.03 | 8.19 | 111 ms | 142 ms |
| 300〜399 | 11.31 | 8.92 | 131 ms | 121 ms |
| 400以降 | 11.93 | 10.30 | 101 ms | 91 ms |

探索を止めた理由の内訳は、候補では上限の時間による停止が23手（0.17%）、目安の時間による停止が13,790手、起点では上限の時間による停止が131手（0.95%）、目安の時間による停止が13,686手だった。
完了深さは全体の平均で候補11.65、起点8.83であり、候補は減深と枝刈りが強まった分だけ、同じ時間で深い反復まで読み終えている。
`clock_profile.py`が出す時間予算の比と上限の超過量は、起点の係数の予算式に基づくので、候補の時間の使い方の解釈には使わない。

## 結論

候補は、時間切れとエンジン異常を起こさなかった。
総思考時間は起点とほぼ同じで、終局時の残り時間は候補の方がやや多い。
設計書の手順どおり、同じ調整機でSTCへ進む。

# 反復の勝敗と禁止手の探索内処理のbench照合

## 目的

[探索部の反復負け回避と反復禁止](../plans/search-repetition.md)のフェーズ4からフェーズ6について、`bench`の局面別のノード数で次の3点を確かめる。
第1に、専用の帯と保護（フェーズ4）が探索の結果を変えないこと。
第2に、探索木の中のR1の攻撃側の判定（項目2、フェーズ5）が採否測定に近い深さで発動し、NPSの低下がフェーズ4の最終のコミットの1%以内であること。
第3に、R2とR3の禁止手の処理（項目3、フェーズ6）がR1の探索の結果とNPSを変えないこと。

## コマンドライン

局面別のノード数は、各コミットを`git archive`で展開してビルドした`minase dev bench`で、深さ5、7、9について1回ずつ取った。

```console
<コミットのバイナリ> dev bench --depth <5|7|9>
```

NPSは、教師生成の終了後の静かな測定機で、性能コアに固定した`scripts/bench_compare.py`の交互測定で測った。
基準は段階開始版、親はフェーズ4の最終のコミット、参照はフェーズ5の最終のコミット、候補は作業ツリー（フェーズ6の最終のコミットbb9d412に文書のコミットを重ねたもの）である。

```console
taskset -c 2 python3 scripts/bench_compare.py --reference 50de0f8 --baseline 88655aa --parent 69e1915 \
  --depth 7 --repetitions 3 --rounds 5 --json docs/measurements/search-repetition-bench/bench-compare-depth7.json
```

## エンジン

| 役割 | コミット | 内容 |
|---|---|---|
| 段階開始版（基準） | 88655aa | 着手時のmasterの先頭 |
| フェーズ4 | 69e1915 | 専用の帯と保護 |
| フェーズ5 | 50de0f8 | 探索木の中のR1の攻撃側の判定（項目2） |
| フェーズ6 | bb9d412 | R2とR3の禁止手の処理（項目3） |

`bench`の規則はエンジン既定のL0、P0、R1、E0であり、ワーカー数は1である。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア）、実メモリ30 GBである。
ノード数は決定的であり、負荷に依存しない。
NPSの交互測定は、2026年10月15日15時32分に教師生成が終了した後の、他の重い処理がない状態で、性能コア（CPU 2）へ固定して行った。

## 結果

局面別のノード数は、深さ5、7、9のいずれでも、フェーズ4は段階開始版と全15局面で一致し、フェーズ6はフェーズ5と全15局面で一致した。
フェーズ5は、深さ5では段階開始版と一致し、深さ7と9では`game-4-ply-246`の1局面だけが変わった。

| 深さ | 段階開始版の総ノード数 | フェーズ5の総ノード数 | `game-4-ply-246`のノード数（段階開始版→フェーズ5） | 同局面の評価値 |
|---:|---:|---:|---|---|
| 5 | 205,388 | 205,388 | 変化なし | 変化なし |
| 7 | 1,089,795 | 1,095,555 | 93,086 → 98,846 | −3,189 → −3,143 |
| 9 | 4,202,022 | 4,540,616 | 252,997 → 591,591 | −3,266 → −3,170 |

局面別の値は[このディレクトリ](search-repetition-bench/)の`positions-<コミット>-depth<深さ>.txt`にある。

深さ7の交互測定（各回は3回実行の中央値、5回の中央値）のNPSは次のとおりである。

| 役割 | 総ノード数 | NPS | 5回の幅 |
|---|---:|---:|---:|
| 段階開始版（基準） | 1,089,795 | 1,429,328 | 0.38% |
| 親（フェーズ4） | 1,089,795 | 1,427,191 | 0.53% |
| 参照（フェーズ5） | 1,095,555 | 1,430,258 | 0.18% |
| 候補（フェーズ6） | 1,095,555 | 1,429,318 | 0.38% |

候補のNPSは親比+0.15%、参照比−0.07%、基準比±0.00%であり、いずれも親の5回の幅の内側にある。

## 結論

フェーズ4は探索の結果を変えず、フェーズ5の判定は深さ7以上で発動してNPSを1%以上下げず、フェーズ6はR1の探索の結果とNPSを変えないので、3つのフェーズの完了条件を満たす。

# 静止探索の固定局数Elo（nodes=100000、200ペア）

## 目的

静止探索の導入による強さの積み上がりを、直前コミットとの固定局数Eloとしてフェーズ4の進捗記録に残す。

## コマンドライン

```console
match_runner --seed 20260824 --candidate commit:c12d460 --baseline commit:fa438de --each nodes=100000 --concurrency 8 elo --pairs 200
```

## エンジン

候補はコミットc12d460（静止探索あり）、基準はコミットfa438de（静止探索なし）である。
規則セットは`commit:`指定の既定であるengine-defaultである。

## 環境

CPU型、物理コア数、論理コア数は記録なし。
ワーカー数は候補と基準とも1である（本マイルストーンは単一スレッド設計）。
`USI_Hash`は記録なし（設計上の既定値は256MB）。
同時対局数は8である。

## 結果

ペンタノミアル度数は[1, 0, 27, 2, 169]（有効199ペア）であった。
Eloは+435.5、95%信頼区間は[+379.9, +512.2]である。
破棄ペア数は1、異常件数は0である。
`time_forfeits`は該当なし（ノード数固定）。
経過時間は958秒である。

## 結論

静止探索は同一ノード数で約435 Eloの改善をもたらし、本マイルストーン中で最大の改良である。

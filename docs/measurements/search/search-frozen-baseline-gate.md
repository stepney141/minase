# 探索部の完了基準ゲート（凍結ベースライン対depth=4）

## 目的

探索部マイルストーンの最終コミットが、凍結ベースライン（コミット0045833のバイナリにdepth=1を指定したもの）に統計的に有意に勝ち越すことを判定する。

## コマンドライン

```console
match_runner --seed 20260828 --candidate commit:facd37f --baseline commit:0045833 --baseline-limit depth=1 --each depth=4 --concurrency 8 gsprt
```

## エンジン

候補はコミットfacd37f（探索部マイルストーンの最終コミット、depth=4）、基準はコミット0045833（凍結ベースライン、depth=1）である。
規則セットは`commit:`指定の既定であるengine-defaultである。

## 環境

CPU型、物理コア数、論理コア数は記録なし。
ワーカー数は候補と基準とも1である（本マイルストーンは単一スレッド設計）。
`USI_Hash`は記録なし（設計上の既定値は256MB）。
同時対局数は8である。

## 結果

ペンタノミアル度数は[0, 0, 0, 0, 207]（有効207ペア）で候補が全勝した。
LLRは2.958で判定はH1（候補が有意に強い）である。
破棄ペア数は0、異常件数は0である。
`time_forfeits`は該当なし（深さ固定）。
経過時間は172秒である。

## 結論

凍結ベースラインへの有意な勝ち越しを満たし、探索部マイルストーンの完了条件の第1項を達成した。

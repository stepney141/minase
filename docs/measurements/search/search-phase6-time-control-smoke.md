# 探索部完了時の時間制御つき自己対局

## 目的

探索部マイルストーンの最終コミットが、残り時間、加算時間、秒読みを使う自己対局を時間切れおよび反則なしに完走することを確認する。

## コマンドライン

```console
match_runner --seed 20260829 --candidate commit:facd37f --baseline commit:facd37f --each time=10000+100,byoyomi=200 --concurrency 8 elo --pairs 10
```

## エンジン

候補と基準はともにコミットfacd37f（探索部マイルストーンの最終コミット）である。
規則セットは`commit:`指定の既定であるengine-defaultである。

## 環境

CPU型、物理コア数、論理コア数は記録なし。
ワーカー数は候補と基準とも1である（本マイルストーンは単一スレッド設計）。
`USI_Hash`は記録なし（設計上の既定値は256MB）。
同時対局数は8である。

## 結果

10ペア20局が破棄0件で完走し、`engine_failures`は全0（`time_forfeits`は0）であった。
ペンタノミアル度数は[0, 0, 8, 1, 1]、Eloは+52.5、95%信頼区間は[−16.8, +126.3]である。
異常件数は0である。
経過時間は360秒である。

## 結論

信頼区間が0を含み同一コミット同士の対局と整合し、時間切れがないため、探索部マイルストーンの完了条件の第2項を達成した。

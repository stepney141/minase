# 第2層の探索改良の積み上がりの固定局数Elo（nodes=100000、200ペア）

## 目的

探索部フェーズ6（第2層の逐次採否）の完了時点とフェーズ4（静止探索）の完了時点を対戦させ、第2層の改良全体による強さの積み上がりを進捗記録として残す。

## コマンドライン

```console
match_runner --seed 20260830 --candidate commit:facd37f --baseline commit:c12d460 --each nodes=100000 elo --pairs 200
```

## エンジン

候補はコミットfacd37f（フェーズ6完了時点）、基準はコミットc12d460（フェーズ4完了時点）である。
規則セットは`commit:`指定の既定であるengine-defaultである。

## 環境

CPU型、物理コア数、論理コア数は記録なし。
ワーカー数は候補と基準とも1である（本マイルストーンは単一スレッド設計）。
`USI_Hash`は記録なし（設計上の既定値は256MB）。
同時対局数は記録なしである。

## 結果

ペンタノミアル度数は[4, 0, 57, 3, 133]（有効197ペア）であった。
Eloは+277.0、95%信頼区間は[+236.1, +325.4]である。
破棄ペア数は3、異常件数は0である。
`time_forfeits`は該当なし（ノード数固定）。
経過時間は1708秒である。

## 結論

第2層の4改良（killer手とhistory、null move pruning、late move reductions、delta pruning）は合計で同一ノード数あたり約277 Eloの改善をもたらした。

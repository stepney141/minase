# 置換表の固定局数Elo（nodes=100000、200ペア）

## 目的

置換表の導入による強さの積み上がりを、直前コミットとの固定局数Eloとしてフェーズ3の進捗記録に残す。

## コマンドライン

```console
match_runner --seed 20260813 --candidate commit:090839d --baseline commit:48b89c0 --each nodes=100000 --concurrency 8 elo --pairs 200
```

## エンジン

候補はコミット090839d（置換表あり）、基準はコミット48b89c0（置換表なし）である。
規則セットは`commit:`指定の既定であるengine-defaultである。

## 環境

CPU型、物理コア数、論理コア数は記録なし。
ワーカー数は候補と基準とも1である（本マイルストーンは単一スレッド設計）。
`USI_Hash`は記録なし（設計上の既定値は256MB）。
同時対局数は8である。

## 結果

ペンタノミアル度数は[20, 0, 92, 6, 80]（有効198ペア）であった。
Eloは+114.5、95%信頼区間は[+80.9, +150.3]である。
破棄ペア数は2、異常件数は0である。
`time_forfeits`は該当なし（ノード数固定）。
経過時間は962秒である。

## 結論

置換表は同一ノード数で約115 Eloの改善をもたらす。

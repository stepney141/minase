# ランダム対ランダムの自己対局ハーネス煙試験

## 目的

探索部フェーズ1で実装した自己対局ハーネスとペンタノミアルGSPRTが、真のElo差が0であることが既知のランダム対ランダムで正しく完走し、同一シードで完全に再現することを確認する。

## コマンドライン

記録なし（2026年8月11日当時の`selfplay`バイナリで、50ペア100局のGSPRTモードと20ペアの固定局数Eloモードを実行した。シードの値は設計書に記録がない）。

## エンジン

候補と基準はともに同一ビルドのランダム着手プレイヤーである。
規則セットは自己対局の既定である標準規則−R0＋R1である。

## 環境

CPU型、物理コア数、論理コア数は記録なし。
ワーカー数は、当時のハーネスがin-process実行であったため候補と基準とも1である。
`USI_Hash`は該当なし（置換表は未実装）。
同時対局数は記録なし。

## 結果

GSPRTモードは50ペア100局が打ち切り0件で0.7秒で完走し、ペンタノミアル度数は[9, 0, 24, 0, 17]、LLRは0.212、判定は保留であった。
同一シードの再実行で出力が完全に一致した。
固定局数Eloモードの20ペアでは、Eloの95%信頼区間が0を含んだ（点推定と区間の数値は記録なし）。
破棄ペア数は0、異常件数は0である。
`time_forfeits`は該当なし（深さ固定でなくランダム着手のため時間制御なし）。

## 結論

ハーネスは同一実力の対局で判定保留と0を含む信頼区間を返し、決定的に再現するため、検定器のバグを探索のバグと混同せずに次フェーズへ進める。

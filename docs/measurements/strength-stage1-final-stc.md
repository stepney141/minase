# 棋力向上段階1の最終短時間GSPRT

## 目的

棋力向上段階1の最終候補と段階開始版を比較し、長時間GSPRTへ進めるかを短時間GSPRTで判定する。

## コマンドライン

次のコマンドを実行した。

```sh
cargo run --release --bin match_runner -- \
  --run-dir data/matches/strength-stage1-final-stc \
  --seed 2026200000 \
  --candidate commit:12e5c0b \
  --baseline commit:afeecec \
  --each time=10000+100 \
  gsprt --max-pairs 3000
```

## エンジン

候補はコミット `12e5c0b4e4544f84890e0e772814944e3f76f506`、基準は段階開始時のコミット `afeecec344e3468ad300baa8435a52f3502690f2` である。
候補には捕獲専用生成、評価値の差分更新、および段階的な手選択が含まれる。
規則セットは標準規則 `L0,P0,R1,E0` である。

## 環境

CPU は Intel Core Ultra 7 265KF であり、物理コア数と論理 CPU 数はいずれも 20 である。
候補と基準のワーカー数は各 1、`USI_Hash` は各 256 MB、同時対局数は 19 である。
時間制御は両エンジンとも初期時間 10,000 ms、1 手 100 ms 加算である。

## 結果

253 ペアを実行し、251 ペアを有効、2 ペアを最大 4,096 手到達により破棄した。
ペンタノミアル度数は `[15, 0, 78, 6, 152]`、LLR は 2.9480440307、判定は `H1` であった。
候補の得点率は 77.89% であった。
不正着手、クラッシュ、応答タイムアウト、`time_forfeits`、および拒否着手はすべて0件であった。
累計実行時間は 1,739.012080204 秒であった。

## 結論

短時間GSPRTが`H1`かつ異常0件で終了したため、最終候補を長時間GSPRTへ進める。

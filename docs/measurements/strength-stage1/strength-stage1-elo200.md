# 棋力向上段階1の固定自己対局

## 目的

棋力向上段階1の最終候補と段階開始版を固定深さで比較し、段階全体の進捗指標を得る。

## コマンドライン

次のコマンドを実行した。

```sh
cargo run --release --bin match_runner -- \
  --run-dir data/matches/strength-stage1-elo200 \
  --seed 2026400000 \
  --candidate commit:ecca82a \
  --baseline commit:afeecec \
  --each depth=4 \
  elo --pairs 200
```

## エンジン

候補はコミット `ecca82ace384fb8e8114eb6c64956cd25c38f0c2`、基準は段階開始時のコミット `afeecec344e3468ad300baa8435a52f3502690f2` である。
候補には捕獲専用生成、評価値の差分更新、および段階的な手選択が含まれる。
規則セットは標準規則 `L0,P0,R1,E0` である。

## 環境

CPU は Intel Core Ultra 7 265KF であり、物理コア数と論理 CPU 数はいずれも 20 である。
候補と基準のワーカー数は各 1、`USI_Hash` は各 256 MB、同時対局数は 19 である。
探索条件は両エンジンとも深さ 4 である。

## 結果

200 ペアを実行し、199 ペアを有効、1 ペアを最大 4,096 手到達により破棄した。
ペンタノミアル度数は `[43, 4, 100, 8, 44]`、候補の得点率は 50.75% であった。
Elo 推定値は +5.238、95% 信頼区間は `[-27.274, 37.842]` であった。
不正着手、クラッシュ、応答タイムアウト、`time_forfeits`、および拒否着手はすべて0件であった。
累計実行時間は 586.293864526 秒であった。

## 結論

固定深さ 4 では推定値が正であったが、95% 信頼区間は 0 を含んだ。
この結果は進捗指標として記録し、変更の採否は最終長時間GSPRTの`H1`判定に基づく。

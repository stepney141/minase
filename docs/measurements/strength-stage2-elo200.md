# strength-stage2-elo200

## 目的

棋力向上段階2の採用構成と段階開始版を標準STCで固定200ペア対局させ、段階内の強さの積み上がりを進捗指標として記録する。

## コマンドライン

```console
match_runner --run-dir data/matches/strength-stage2-elo200 --seed 20260923 \
  --candidate commit:ce654d9 --baseline commit:59846ec \
  --each time=10000+100 elo --pairs 200
```

## エンジン

候補は採用構成のコミットce654d9、基準は段階開始版のコミット59846ec、規則セットは`engine-default`である。

## 環境

CPUはIntel Core Ultra 7 265KF（物理20コア、論理20コア）、候補と基準の`Threads`は1、`USI_Hash`は256MB、同時対局数は自動計算の19である。

## 結果

200ペアを実行し、有効ペア199、破棄ペア1（手数上限）であった。
ペンタノミアル度数は[19, 0, 96, 4, 80]、Eloの点推定は+113.9（95%信頼区間+80.8〜+149.1）であった。
不正着手、クラッシュ、応答タイムアウト、`time_forfeits`、および拒否着手はすべて0件、経過時間は1,444秒である。

## 結論

段階2の採用構成は段階開始版に対してSTCで約+114 Eloであり、進捗指標として記録する。この測定は採否には用いない。

# strength-stage3-elo200

## 目的

棋力向上段階3の採用構成と段階開始版を標準STCで固定200ペア対局させ、段階内の強さの積み上がりを進捗指標として記録する。

## コマンドライン

```console
match_runner --run-dir data/matches/strength-stage3-elo200 --seed 20320903 \
  --candidate commit:1894d14 --baseline commit:3a6b038 \
  --each time=10000+100 elo --pairs 200
```

## エンジン

候補は採用構成のコミット1894d14（駒価値の再調整とSEE）、基準は段階開始版のコミット3a6b038、規則セットは`L0,P0,R1,E0`である。

## 環境

CPUはIntel Core Ultra 7 265KF（物理20コア、論理20コア）、候補と基準の`Threads`は1、`USI_Hash`は256MB、同時対局数は自動計算の19である。

## 結果

200ペアを実行し、有効ペア192、破棄ペア8（手数上限）であった。
ペンタノミアル度数は[36, 6, 86, 4, 60]、Eloの点推定は+41.8（95%信頼区間+6.9〜+77.6）であった。
不正着手、クラッシュ、応答タイムアウト、`time_forfeits`、および拒否着手はすべて0件、経過時間は1,767秒である。

## 結論

段階3の採用構成は段階開始版に対してSTCで+41.8 Eloである。この測定は進捗指標であり、変更の採否には用いない。

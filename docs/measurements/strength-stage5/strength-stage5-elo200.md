# strength-stage5-elo200

## 目的

棋力向上段階5の最終構成（順序付けキーの重複計算の除去とLMRの減深量を採用）が段階開始版に対してどれだけ強くなったかを、固定200ペアのEloで進捗指標として記録する。
採否の判定には使わない。

## コマンドライン

```console
match_runner --run-dir data/matches/strength-stage5-elo200 --seed 20520903 \
  --candidate commit:73578d4 --baseline commit:e172efb \
  --each time=10000+100 --concurrency 9 elo --pairs 200
```

## エンジン

候補は段階5の最終構成のコミット73578d4、基準は段階開始版のコミットe172efb（探索コードは段階4完了時の66ab847と同一）、規則セットは`L0,P0,R1,E0`である。

## 環境

CPUはIntel Core Ultra 7 265KF（物理20コア、論理20コア）、候補と基準の`Threads`は1、`USI_Hash`は256MB、同時対局数は明示した9である。
同じ機械でHaChu戦の固定200ペア（同時対局数10）が並行していた。

## 結果

200ペアを実行し、有効ペア196、破棄ペア4（手数上限）であった。
ペンタノミアル度数は[31, 5, 103, 7, 50]、Eloは+35.6、95%信頼区間は[+4.0, +67.8]である。
不正着手、クラッシュ、応答タイムアウト、`time_forfeits`、および拒否着手はすべて0件、経過時間は2,990秒である。

## 結論

段階5の最終構成は段階開始版に対してSTCで+35.6 Eloであり、進捗指標として記録する。

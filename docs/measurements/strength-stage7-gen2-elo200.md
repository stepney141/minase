# 段階7の最終構成と段階開始版の固定200ペア測定

## 目的

[棋力向上段階7](../plans/strength-stage7.md)の最終採用構成を段階開始版と固定200ペアで比較し、棋力差を進捗指標として記録する。

## コマンドライン

2026年9月14日11:03:12.883819に、日本標準時でリポジトリルートから次の測定を起動した。
実際の起動引数は終了記録と一致し、manifestは起動前に保存した期待値と一致した。

```console
data/strength-stage7/match_runner \
  --run-dir data/matches/strength-stage7-gen2-elo200 --seed 20960903 \
  --candidate commit:240fbfd607eb139030d92b5c718d579df62b20f6 \
  --baseline commit:d0d3c52024c5ab4d74cc82588640a55953426aad \
  --rules engine-default --each time=10000+100 \
  --candidate-hash 256 --baseline-hash 256 --concurrency 12 \
  --max-ply 4096 --response-timeout 120 \
  elo --pairs 200
```

両者の持ち時間は10秒、1手ごとの加算は0.1秒で、秒読みは使わない。
同じ開始局面から先後を入れ替えた2局を1ペアとし、200ペアを投入して停止する。
手数上限に達した局を含むペアは破棄し、有効200ペアになるまでの補充は行わない。
Eloと95%信頼区間は、[測定手順](../guides/sprt.md)に従って有効ペアの正規化得点の平均と分散から計算する。

# 段階7の世代2再学習候補の短時間測定

## 目的

[棋力向上段階7](../plans/strength-stage7.md)の世代2再学習候補を採用済みの鏡映共有モデルと短時間条件（STC）で比較し、長時間条件（LTC）の最終測定へ進めるかを判定する。

## コマンドライン

2026年9月14日07:56:55.969070に、日本標準時で次の測定を起動した。
保存した起動引数、標準出力、およびmanifestの条件は一致した。

```console
data/strength-stage7/match_runner \
  --run-dir data/matches/strength-stage7-gen2-stc --seed 20940903 \
  --candidate commit:240fbfd607eb139030d92b5c718d579df62b20f6 \
  --baseline commit:960c56bcbb6088d0f0466d670ceea36dffeda5b7 \
  --rules engine-default --each time=10000+100 \
  --candidate-hash 256 --baseline-hash 256 --concurrency 19 \
  --max-ply 4096 --response-timeout 120 \
  gsprt --max-pairs 3000
```

両者の持ち時間は10秒、1手ごとの加算は0.1秒で、秒読みは使わない。
同じ開始局面から先後を入れ替えた2局を1ペアとし、[測定手順](../guides/sprt.md)の一般化逐次確率比検定で判定する。
帰無仮説H0は0 Elo、対立仮説H1は10 Elo、第一種と第二種の誤り確率はともに0.05である。
対数尤度比（LLR）の境界は約−2.944と+2.944で、上限は3,000ペアとする。

H1ならLTCへ進み、H0なら候補を採用しない。
上限到達による判定保留は、LLRが0以上ならLTCへ進み、負なら進めない。
採用を確定するには、別のLTCでH1となり、エンジン異常、時間切れ、および拒否着手が0件であることを要する。

# 段階7の世代2採用重みからの探索用駒価値の再導出

## 目的

[棋力向上段階7](../plans/strength-stage7.md)のフェーズ5として、[世代2のLTC](strength-stage7-gen2-ltc.md)で採用した最終重みから探索用駒価値を導き、固定値との差を確認する。
到達可能な37状態のいずれかで相対差が厳密に20%を超える場合だけ、駒価値を変更する候補の対局測定へ進む。
[旧採用重みの診断](strength-stage7-values-diag.md)は保持し、今回の判断は世代2の重みから独立に求めた値に基づく。

## 環境

学習用仮想環境のPythonをCPUで実行し、`OMP_NUM_THREADS`、`OPENBLAS_NUM_THREADS`、`MKL_NUM_THREADS`をそれぞれ2とした。
保存済みヒストグラムと採用重みを使い、訓練データの再走査とGPU計算は行っていない。
対局を伴わないため、同時対局数、探索ワーカー数、および置換表容量は非該当である。

到達可能な37状態の最大相対差は、成れる歩兵の状態29の100から108への変化による8%だった。
判定には表示上の丸めを使わず、各到達可能状態について `5 * abs(導出値 − 固定値) > 固定値` を整数で比較し、該当は0件だった。
歩兵値の2倍である`DELTA_MARGIN`の導出値は216となるが、固定値200を維持する。
駒価値だけを差し替える候補は作らず、そのSTCとLTCは実施しなかったため、対局件数、Elo、対数尤度比、および異常件数は非該当である。

## 結論

最終採用重みから再導出した値と固定値との差は最大8%で、更新基準20%を超えなかった。
47個の固定駒価値と`DELTA_MARGIN = 200`を維持し、世代2の採用コミットを段階開始版およびHaChuとの固定200ペア測定に使う。

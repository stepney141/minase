# 段階7の教師生成の手数上限

## 目的

[棋力向上段階7](../plans/strength-stage7.md)のフェーズ0として、開始版で手数上限4,096の500局を生成し、100手刻みの候補のうち探索1局面あたりの記録局面数が最大になる上限を選ぶ。

## コマンドライン

2026年9月12日に開始版を固定した`data/strength-stage7/trial-generator`で実行した。
一時的な計測は対局番号、序盤のランダム着手数、最終手数、終局の有無、探索局面数、記録局面数の標準出力だけを追加し、その差分を`data/strength-stage7/trial-instrumentation.patch`に保存した。

```console
cd data/strength-stage7/trial-generator
target/release/selfplay_gen generate \
  --output ../plycap-trial.bin --games 500 --seed 1100000 \
  --nodes 100000 --concurrency 16 --max-ply 4096 --hash-mb 16 \
  --random-moves 0 --allow-dirty
```

`--allow-dirty`は一時計測の差分を認めるために指定した。
生成の終了コード0、500局の完了サマリ、プロセスの終了を確認した後、リポジトリのルートから集計とファイル検査を実行した。

```console
tools/train/.venv/bin/python data/strength-stage7/analyze_plycap.py
data/strength-stage7/trial-generator/target/release/selfplay_gen inspect \
  data/strength-stage7/plycap-trial.bin
```

生成ログは`data/strength-stage7/plycap-trial.log`、集計は`plycap-analysis.json`、候補の全数表は`plycap-candidates.csv`、100手幅の対局長分布は`plycap-length-histogram.csv`、検査結果は`plycap-inspect.log`に保存した。
試行生成のファイルは学習に使わない。
シード1100000の使用範囲1100001〜1100500に過去の生成と測定との重複がないことは、[シード監査](strength-stage7-seed-audit.md)で確認した。

## 結果

### 試行生成

500局のうち488局が終局し、12局が4,096手で打ち切られた。
終局理由は詰み455局、王駒の捕獲1局、反復規則による勝ち19局、駒枯れによる勝ち1局、反復規則による引き分け12局であった。
先手243勝、後手233勝、引き分け12局となった。

探索289,509局面から203,644局面を記録し、所要時間は951.820秒であった。
探索速度は304.164局面/秒、記録速度は213.952局面/秒、探索ノード数は28,950,900,000である。
重複局面は0件で、全500局の番号が過不足なく揃い、各局と全体の探索局面数と記録局面数も一致した。
解析とファイル検査で異常はなく、ペアを組まない固定ノードの教師生成なので、ペンタノミアル度数、対数尤度比、Elo、破棄ペア数、`time_forfeits`は非該当である。

記録を持つ対局数は487局であった。
終局した488局のうち第105局は序盤のランダム着手16手の後、17手目で終局し、探索した1局面も記録対象外だったためである。
レコードの手番側結果は負け102,457局面、引き分け2,411局面、勝ち98,776局面で、合計203,644局面となった。

### 候補上限の比較

第i局の観測最終手数をTᵢ、序盤のランダム着手数をoᵢ、記録局面数をrᵢとする。
候補上限cで終局まで残せる対局の集合A(c)は、試行で終局し、かつTᵢ≤cを満たす対局である。
探索局面数の分母はD(c)=Σᵢ[min(Tᵢ,c)−oᵢ]、記録局面数の分子はR(c)=Σᵢ∈A(c)rᵢ、比較する比率はR(c)/D(c)とした。
破棄局の探索割合はΣᵢ∉A(c)(c−oᵢ)/D(c)である。

候補は100手から4,000手までの100手刻みの40個であり、全対局のoᵢは100未満だった。
打ち切り局はいずれもTᵢ=4,096で候補上限を超えているので、全候補の分母を観測記録から計算できる。
比率は整数の分数として比較し、同じ最大値なら小さい上限を選ぶが、今回は4,000手が唯一の最大値となった。

選択した4,000手では203,644/288,357=0.706222であり、600手の127,957/208,661=0.613229より比率が15.164%高い。
600手では87局、17.4%を破棄し、その探索は全体の24.522%を占めるため、計画の約19%という見積りをこの試行での実測へ置き換える。
4,000手では破棄は12局、探索割合は16.596%となる。

この比較は同じ500局の着手列から算出した生成効率の推定であり、新しい上限で生成した際の実時間の比を測ったものではない。
最適値の探索範囲は事前に定めた100〜4,000手に限り、4,096手以降の終局分布はこの試行からはわからない。

## 結論

計画で定めた探索1局面あたりの記録局面数が40候補中で最大となったため、教師生成の手数上限は4,000手に確定する。

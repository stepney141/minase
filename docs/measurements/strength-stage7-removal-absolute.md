# 世代2の駒除去差分に対する片側絶対値損失

## 目的

[棋力向上段階7](../plans/strength-stage7.md)で、駒除去差分の片側絶対値ペナルティを実装し、元の訓練集合内の予備比較で本学習の係数を選ぶ。
[二乗型の予備比較](strength-stage7-removal-pilot.md)は反転を668件から7件へ減らしたが、適格な正係数を選べなかった。
次の方式では小さい違反にも修正勾配を保ち、有限の更新幅が境界を超える影響も確認する。
合成例の観察と実学習条件の固定を終え、学習器の実装と検証も完了した。
新しい予備比較は未開始であり、重みの採用や棋力の改善を判定していない。

## エンジン

初期重みは採用済み鏡映共有モデルのコミット`960c56bcbb6088d0f0466d670ceea36dffeda5b7`と同じ整数重みを使う。
SHA-256は`b26e7841b168ed8e9f4bd8fe0094b7e0dbf6f74d76fae4ee95c19c18fa269b5c`であり、各条件でこの重みと新しいAdam状態から始める。
モデルは`mirrored`、保存形式はMNPTバージョン2、規則セットは`L0,P0,R1,E0`とし、探索用駒価値47個は基準の値に固定する。
評価特徴、2端点の補間式、およびRustの整数評価は変更しない。
実装をコミットへ固定してから準備し、学習ソース、比較スクリプト、入力全11ファイル、および保存配列のSHA-256を照合する。

## 環境

合成検査はPython 3.12.14、PyTorch 2.13.0+cu130、CPUの倍精度で行った。
実学習はNVIDIA GeForce RTX 3060 TiのCUDAを必須とし、CPUへ切り替えない。
ホストはIntel Core Ultra 7 265KF、物理20コア、論理20コアであり、`OMP_NUM_THREADS`、`OPENBLAS_NUM_THREADS`、`MKL_NUM_THREADS`は2に固定する。
実行時のPython、NumPy、PyTorch、CUDA、およびGPU名を各終了記録へ保存する。
対局による測定は含まず、時間制御、同時対局数、置換表、およびEloは適用しない。

| 実学習の条件 | 固定値 |
|---|---|
| 係数η | 0、1、10、100、1000の順に比較し、0は対照とする。 |
| 最適化 | Adam、学習率0.03、10エポックとする。 |
| バッチと乱数 | 16,384局面、学習シード1とする。 |

| 範囲射影 | 各更新後に有限性を検査し、−4,096〜4,095.875センチポーンへ射影する。 |

損失は[評価関数の学習](../plans/evaluation.md#教師値と損失)の片側絶対値型とし、各除去の下限不足と、基準自体が逆向きの場合の上限超過の和をKで割る。
局面内の対象除去を等重みで平均し、その後、対象のない局面も含む元局面を等重みで平均する。
各折れ点の劣勾配は0とし、人工的な除去局面に教師値を付けたり、観測件数へ追加したりしない。
η=1は単一差分の違反側の勾配を同じ尺度の交差エントロピーと比較する起点であり、平均と共有パラメータへの複数の勾配の作用を調べるため10倍刻みの集合を固定した。
この有限集合は制約充足を保証する係数の上限から求めたものではなく、二乗型の係数を移したものでもない。

元の訓練集合の対局を、前の予備比較と同じハッシュ規則で学習用のFITと係数比較用のCALIBへ分ける。
FITは21,467,306局面、CALIBは2,412,305局面で、外側の検証集合1,241,072局面は両方から除外する。
1エポックは1,311更新、各係数は13,110更新となる。
分割、教師Kの推定、10,000局面の標本抽出、および選択規則は計画書に固定し、前の予備比較の保存配列とも照合する。
正係数の最良候補が保存検査を満たし、共通標本の整数符号反転が0件のときだけ適格とする。
最良エポックは0を含むCALIB全体の純粋な二値交差エントロピーで選び、適格係数のうち同損失が最小の係数を選ぶ。
完全に同値なら小さい係数を選び、適格係数がなければ選択しない。
CALIBの反転7件と元の検証診断352件は勾配更新に使わない。
前の比較結果を方式の検討に用い、初期重みが既に学習した世代0と世代1も含むので、CALIBを未参照の性能評価とは扱わない。

## 結果

有限更新の観察は、実学習の係数を比較する前に実データを使わずに行った。
合成変数Sは基準符号を掛けた差分を表し、K=1072.6529541015625、下限b=0.25センチポーン、上限a=1センチポーン、初期点S=1センチポーン、係数η=1とした。
下限例の目的関数は`softplus(S/K) + max(0,b−S)/K`、上限例は`softplus(−S/K) + {max(0,b−S)+max(0,S−a)}/K`である。
各例で学習率3、0.3、0.03を比較し、それぞれ新しいAdam状態から13,110回更新した。
次の表は最後の1,311更新後点を対象とし、平均幅には違反しない点の0も含める。

仕様のSHA-256は`6ac2c90fcfcc5348071477b2056b01b00bd90a5275b76cb412d8957bf5ac7f6c`、スクリプトは`6614956fa3a3a77c66b8122ac36d8497376653c4d7109829c234030fc3a73120`である。

解析上の最小点が下限bまたは上限aにあっても、有限回のAdam更新で境界に止まるわけではなく、全6条件で末尾に違反が残った。

実学習の学習率は0.03に固定する。
この合成例の最大違反幅が上下限とも、固定余裕0.25と重み丸めの誤差上限137/720センチポーンとの差43/720より小さかったためである。
この差は約0.059722センチポーンだが、合成例のSは直接更新する1変数であり、共有パラメータの更新から生じる実際の除去差分の幅を保証しない。
損失の形と学習率を両方変えるため、前の二乗型との結果の差を損失型だけの効果とは解釈せず、同じ学習率の係数0を対照にする。
新しい予備比較の損失、反転件数、候補重み、および係数選択の結果はまだない。

前の二乗型の係数10,000の最良候補は、FIT全体でも制約違反が残っていた。
学習器を読み込まない独立監査で全11入力を走査し、全レコードから対局単位の分割を再構成して、保存済みのFIT局面番号と一致することを確認した。
21,467,306局面の1,142,323,505件の非王駒除去を調べ、基準整数差が0の144件を追加損失から除いた。

現行の診断は両者を反転として数えるため、集計から後者を除いていない。
2段階平均の二乗損失Rは`5.171066881346786e-10`で、下限不足の最大幅は45.621725センチポーンだった。

全11入力のSHA-256、保存重みの量子化と鏡映対称性、固定駒価値47個も一致し、代表6件は実際の盤面除去と有理数評価で照合した。
監査仕様のSHA-256は`1f2b19f2d1c703ffeb4dfe43c04634de38865e3c520aa58466c440a70a2962d3`、スクリプト`data/strength-stage7/removal-fit-audit.py`は`e7a03a5821b9b77011506715ad0931d083adbb2770c63a98bb2144d29a0f6d2d`である。
結果`data/strength-stage7/removal-fit-audit.json`のSHA-256は`5871e3a7ed435ea733556ae324de988d41b4e4c00de8c3704f5ef1284952cae3`である。
この結果から違反がCALIBだけの問題ではないことは分かるが、有限ペナルティの最適点での違反と最適化の未収束は区別できない。
更新中の勾配履歴と他エポックの重みは調べておらず、この監査で候補の更新は行っていない。

片側絶対値型の実装は、独立した有理数の期待値を先に更新して二乗型での失敗を確認した後に変更し、対象21テストと全Python 72テストを通した。
上下の違反側での勾配が違反量によらず±1/Kであり、各境界の劣勾配が0になることを確認した。
二乗への置換、Kの2乗による除算、上限項の削除、および境界の非零勾配という4種類の誤実装をすべて検出した。
検証結果は`data/strength-stage7/removal-absolute-implementation-verification.json`に保存し、学習ソースのSHA-256は`e5475945e0eb921cd258f605e508d7beafeb5d67397847ce0cc4cb7fe0f6f9a5`である。
GPUでも採用済み基準を使った2つの合成盤面で追加損失と全重みの勾配が0であることを確認し、最適化更新は行わなかった。
Rustの543テストが通り、1件を無視し、clippyとfmtも終了コード0だった。
比較スクリプトは分割ハッシュ909例、合成盤面4条件、および係数選択11条件を独立した期待値と照合した。

## 結論

有限更新の合成観察を根拠に学習率0.03を固定し、片側絶対値型の係数0、1、10、100、1000を同じ条件で比較する。
学習器の検証を終え、固定した実装と入力を確認してから予備比較を開始する。
既存の整数診断と採否基準は維持する。

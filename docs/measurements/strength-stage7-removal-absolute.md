# 世代2の駒除去差分に対する片側絶対値損失

## 目的

[棋力向上段階7](../plans/strength-stage7.md)で、駒除去差分の片側絶対値ペナルティの5係数を元の訓練集合内で比較し、本学習に使う係数を判定した。
符号反転0件と保存可能性を満たしたη1000を選び、採用済み基準からの本再学習を準備している。

損失は[評価関数の学習](../plans/evaluation.md#教師値と損失)の片側絶対値型とし、各除去の下限不足と、基準自体が逆向きの場合の上限超過の和をKで割る。
局面内の対象除去を等重みで平均し、その後、対象のない局面も含む元局面を等重みで平均する。
各折れ点の劣勾配は0とし、人工的な除去局面に教師値を付けたり、観測件数へ追加したりしない。
η=1は単一差分の違反側の勾配を同じ尺度の交差エントロピーと比較する起点であり、平均と共有パラメータへの複数の勾配の作用を調べるため10倍刻みの集合を固定した。
この有限集合は制約充足を保証する係数の上限から求めたものではなく、二乗型の係数を移したものでもない。

元の訓練集合の対局を、前の予備比較と同じハッシュ規則で学習用のFITと係数比較用のCALIBへ分けた。
FITは21,467,306局面、CALIBは2,412,305局面で、外側の検証集合1,241,072局面は両方から除外する。
1エポックは1,311更新、各係数は13,110更新となる。
分割にはUTF-8文字列`stage7-removal-calibration-v1`と終端0バイト、生成ネットの検査和32バイト、生成シードのu64、および対局番号のu32を連結したSHA-256を使った。
整数はリトルエンディアンとし、先頭8バイトを同じ向きの整数として10で割った余りが0ならCALIB、それ以外ならFITとした。
対局単位の3集合の交差は0であり、分割、教師K、および標本の保存配列は前の予備比較と一致した。
教師KはFITだけから求め、世代別の件数とともに次の値へ固定した。

除去診断の標本は、昇順のCALIB局面番号からNumPyのPCG64とシード20260915で重複なく10,000局面を選び、再び番号順に並べた。
この共通標本に含まれる全528,740件の非王駒除去を評価し、外側の検証局面や既知の駒の升を標本選びへ渡していない。
正係数の最良候補が保存検査を満たし、共通標本の整数符号反転が0件のときだけ適格とする。
量子化の保存検査は標本での平均絶対誤差が2センチポーン以下であることを求め、最大誤差にも同じ上限を課す基準ではない。

完全に同値なら小さい係数を選び、適格係数がなければ選択しない。
前の二乗型で残ったCALIBの反転7件と元の検証診断352件は勾配更新に使わない。
前の比較結果を方式の検討に用い、初期重みが既に学習した世代0と世代1も含むので、CALIBを未参照の性能評価とは扱わない。

全エポックの重みを保持していないため、最適化更新から保存された最良重みへの対応を独立に再実行した監査ではない。

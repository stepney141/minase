# 世代2の駒除去差分を用いる学習方法の検討

## 目的

世代2の再学習で生じた駒除去差分の符号反転を、評価形式と診断基準を維持した学習方法で抑えられるかを検討する。
検討の対象は追加する学習損失であり、新しい重みの採用や棋力の改善を示す測定ではない。

## コマンドライン

既知の反転は、保存済みの2局面を固定したRust評価器へ渡して再現できる。

```sh
data/strength-stage7/gen2-projected/probe/target/release/pst_probe \
  --pst data/strength-stage7/gen2-projected/pst-base.bin \
  --positions data/strength-stage7/gen2-projected/removal-sign-fixture.bin
data/strength-stage7/gen2-projected/probe/target/release/pst_probe \
  --pst data/strength-stage7/gen2-projected/training/pst.bin \
  --positions data/strength-stage7/gen2-projected/removal-sign-fixture.bin
```

訓練標本の抽出と集計は次のコマンドで実行した。

```sh
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 MKL_NUM_THREADS=2 \
  tools/train/.venv/bin/python \
  data/strength-stage7/removal-learning-study/study_removals.py \
  --run-dir data/strength-stage7/gen2-projected \
  --base-float data/strength-stage7/mirror-training/training/pst-float.npz \
  --seed 20260914 --samples 10000 \
  --output-dir data/strength-stage7/removal-learning-study
```

結果は`data/strength-stage7/removal-learning-study/study.json`、抽出した局面と全除去差分は同ディレクトリの`training-sample.npz`と`removal-deltas.npz`に保存した。
採用済み基準の量子化前重みは丸めの比較資料にだけ使い、提案損失の基準には採用済みの整数重みを用いた。

同符号の増悪を抑える項は、同じ標本の保存済み差分から追加集計した。

```sh
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 MKL_NUM_THREADS=2 \
  tools/train/.venv/bin/python \
  data/strength-stage7/removal-learning-study/compare_hinges.py \
  --study-dir data/strength-stage7/removal-learning-study \
  --output data/strength-stage7/removal-learning-study/hinge-upper-bound-comparison.json
```

## 結果

### 補間係数の変化が反転を生む

既知の局面では、自歩兵を除くと候補の整数評価が142から144センチポーンへ上がる。
量子化前の重みでも差は+2.4336684756808813センチポーンであり、丸めだけで生じた現象ではない。
独立計算と固定したRust評価器による再現は、[世代2の学習記録](strength-stage7-gen2-training.md)と`data/strength-stage7/gen2-projected/removal-sign-audit.json`に残している。

除去前の序中盤と終盤の重み総和をそれぞれ\(M,G\)、除く駒の重みを\(m,g\)、除去前後の補間係数を\(\phi,\phi'\)とする。
丸め前の評価差\(\Delta=E_{\mathrm{after}}-E_{\mathrm{before}}\)は、次のように分解できる。

\[
\Delta=-\{\phi m+(1-\phi)g\}
       +(\phi'-\phi)\{(M-m)-(G-g)\}.
\]

第1項は補間係数を固定した駒の除去、第2項は残った盤面の補間係数の変化を表す。
候補の量子化前重みでは第1項が−12.88063227335612センチポーン、第2項が+15.314300749037センチポーンとなり、後者が前者の損失を上回った。
したがって、除く駒の重みだけを制約しても原因全体を扱えない。

両端点で自駒の重みを正にするだけでも、符号反転は防げない。
たとえば王駒2枚と自歩兵1枚の合成例で、歩兵を両端点とも+1センチポーン、残る王駒の総和を序中盤−180センチポーン、終盤+180センチポーンとすると、除去前177から除去後180へ評価が上がる。
これは実測した候補ではなく、補間式の反例であり、`data/strength-stage7/removal-learning-algebra-check.json`に有理数計算を保存した。

### 訓練標本でも基準と候補を比べる

既存の検証集合から得た352件は、原因の再現と最終診断に使う。
追加損失の係数をこの352件に合わせて選ぶことを避けるため、頻度の調査には元の分割で訓練用となる局面だけを別に抽出する。
全11ファイルを連結した通算局面番号から、シード20260914の乱数で重複なく抽出し、既存の対局単位の分割で訓練用となる最初の10,000局面を受理した。
抽出候補10,526件のうち重複2件と検証用524件を除いたもので、訓練用の各局面は等確率で選ばれる。
世代0、1、2の局面数は360、3,996、5,644であり、9,041組の入力ファイルと対局番号を含む。
標本の分割、全特徴の写像、および局面帯は、独立実装と現行の関数で一致した。

全非王駒を1枚ずつ除いた531,474件では、期待する方向に反する整数評価差が基準で1件、候補で1,102件あった。
基準から候補への厳密な符号反転は1,101件、除去全体の0.207160%であり、すべて成れる歩兵の状態29だった。
そのうち自歩兵が599件、相手歩兵が502件で、期待する方向から逆方向への反転だけが生じた。
新たな反転の大きさは最大56センチポーンであり、既知の代表局面1件に限った問題ではなかった。

| 除去前の補間係数の帯 | 標本局面数 | 非王駒除去数 | 新たな厳密符号反転数 |
|---|---:|---:|---:|
| 0以上0.2未満 | 1,154 | 10,944 | 6 |
| 0.2以上0.4未満 | 1,683 | 45,601 | 113 |
| 0.4以上0.6未満 | 2,004 | 89,539 | 201 |
| 0.6以上0.8未満 | 2,016 | 126,010 | 166 |
| 0.8以上1以下 | 3,143 | 259,380 | 615 |

候補の量子化前重みでも逆向きの除去差分が1,175件あり、整数評価で逆向きだった1,102件はすべてこの中に含まれた。
候補の整数差分が0となる除去は151件あったが、量子化前後で厳密な逆符号となった除去は0件である。
この標本でも、検出した反転を量子化だけの問題とは扱えない。

基準の逆向き評価1件は相手の酔象を除く場合であり、整数評価差が基準の−61から候補の−311センチポーンへ悪化していた。
これは同じ負符号なので、現行の符号反転の診断や、同じ符号だけを促す損失では捉えられない。
この実測に基づき、基準が逆向きである除去については、同じ符号のまま悪化する量も追加損失へ含める案とする。

以上は固定した訓練標本の記述であり、全訓練集合の頻度や棋力への影響の推定ではない。
同じ対局の複数局面が含まれるため、各除去を独立とした信頼区間も付けない。
大容量入力の全体検査和は既存の検証済み記録を参照し、本調査では実際のヘッダーとファイル長を確認して抽出局面を読んだ。

### 基準の符号を保つ損失を第一候補にする

推奨する方式は、各訓練局面から非王駒を1枚ずつ除いた評価差に、基準と同じ符号を促し、基準自体が逆向きの場合には増悪も抑える二乗ペナルティを加えることである。
今回の適用対象は、採用済みの2端点の鏡映共有モデルに限る。
基準と同じ大きさの駒価値を再現させず、期待する方向の基準には符号を保つ余裕を、逆向きの基準にはその余裕と悪化量の上限を求める。
除去後の補間係数も計算し直すため、残った盤面の評価変化を損失に含められる。

基準は、実際に採用している整数重みを1/8センチポーン単位から復元したものに固定する。
基準の量子化前の別ファイルを使うと、採用済み評価との差が入り、初期重みが制約を満たすことを保証できなくなる。
基準の整数評価は前後をそれぞれ0方向へ切り捨てて制限値へ収め、その差の符号を\(s_0\)とする。
\(s_0=0\)の除去は、現行診断で厳密な符号反転が生じないため追加損失の対象から外す。

基準と候補の未丸め差分を\(\Delta_0,\Delta_\theta\)とし、余裕を\(b=\min(|\Delta_0|,0.25)\)センチポーンとする。
基準の整数評価が自駒の除去で上がるか、相手駒の除去で下がる場合は\(v_0=1\)、その他は\(v_0=0\)とする。
1回の除去に対する追加損失は次式とする。

\[
r=\frac{
\max(0,b-s_0\Delta_\theta)^2
+v_0\max(0,s_0\Delta_\theta-|\Delta_0|)^2
}{K^2}.
\]

\(K=1072.6529541015625\)は既存の出力尺度である。
局面内では対象となる除去を等重みで平均し、その後で局面を等重みで平均した値を\(R\)とする。
対象がない局面の\(R\)への寄与は0とし、全局面が交差エントロピーには寄与する。
学習目的は既存の平均二値交差エントロピーに\(\rho R\)を加えたものとし、追加係数\(\rho\)は有限の非負値に限り、既存の教師混合係数\(\lambda=0.75\)と区別する。

採用済み重みを候補にも使えば、\(s_0\Delta_0=|\Delta_0|\ge b\)となり、追加損失は0になる。
一方、候補が逆符号へ進むと損失が増え、その勾配は当該差分を基準の符号へ戻す方向に働く。
基準が逆向きの場合は、\(s_0\Delta_\theta\)が区間\([b,|\Delta_0|]\)を外れると損失が増えるため、同符号の増悪も抑えられる。
他の局面や交差エントロピーの勾配も同時に作用するので、有限の係数で学習しただけでは全制約を満たす保証はなく、既存の整数診断は引き続き必要である。

現行の診断は、基準の符号が望ましくない場合に、候補が望ましい方向へ改善した反転も拒否する。
この追加損失もその反転を抑えるが、同じ符号を保って差分を0へ近づける改善は許し、基準と同じ悪化量を再現することまでは求めない。
増悪に対する項は未丸め差分を扱うため、量子化後の悪化量が厳密に0となる保証や、新たな採否基準を導入するものではない。
自駒の除去は常に評価を下げるという絶対的な条件へ変更する場合は、学習方法と併せて診断基準も見直す別の判断となる。

標本上では、符号を促す項だけが正となる除去が1,229件、1,080局面あり、局面平均の\(R\)は\(4.0151862133294074\times10^{-7}\)だった。
逆向きの基準からの増悪を抑える項を加えると、正となる除去は1,230件、1,081局面となり、\(R=3.128073342387544\times10^{-6}\)となった。
酔象の1件に対する追加の増悪量は250.4847787221273センチポーンであり、採用済み重みを候補にも使う対照では両項とも0となった。
これは保存した重みに対する損失の計算結果であり、その損失を用いて学習した効果ではない。

### 量子化の余裕を差分から導く

各重みを1/8センチポーンへ最近接丸めする誤差は、絶対値で1/16センチポーン以下である。
除去前の盤上駒数を\(N\)、先獅子特徴の有無を\(L\in\{0,1\}\)、補間の分子\(q=90\phi,q'=90\phi'\)の減少を\(d=q-q'\)とすると、共通する特徴の相殺により除去差分の誤差は次の値以下になる。

\[
\frac{1+2d(N+L-1)/90}{16}\ \text{センチポーン}.
\]

\(q=\operatorname{clamp}(N-2,0,90)\)の境界を含めて計算すると、上限は\(137/720\)、約0.190278センチポーンである。
今回の\(N=53,L=0\)では\(97/720\)、約0.134722センチポーンとなる。
前後に適用する整数への切り捨てと評価値の制限はともに単調なので、量子化後の未丸め差分が同じ符号なら、最終整数値の差が逆符号になることもない。

0.25センチポーンはこの量子化誤差上限を超えるが、これは実数の厳密計算についての境界であり、浮動小数点の加算誤差は別に点検する。
符号保存の十分条件は、学習後の\(s_0\Delta_\theta\)が局面ごとの量子化誤差上限以上となることである。
追加損失が0でも、\(b\)がこの上限未満なら、その十分条件を満たすとは限らない。
そのため、0.25という値を理由に既存の整数診断を省略したり、許容する反転幅を広げたりしない。

### 代案との比較

| 方法 | 判断 |
|---|---|
| 除去差分へ直接ペナルティを加える。 | 補間係数の変化、基準の符号、および基準が逆向きの場合の増悪を直接扱えるため、第一候補とする。係数の予備比較と再学習後の診断が必要である。 |
| 序中盤と終盤の重みの差へ二乗ペナルティを加える。 | 補間による変化を抑えられるが、必要な局面依存性にも作用し、除去差分の符号を直接制約しない。 |
| 各駒の両端点を期待する符号へ射影する。 | 残った盤面の補間変化を制約できず、上の合成例でも反転が残るため採らない。 |
| 除去差分の半空間と保存範囲の共通部分へ毎回射影する。 | 固定した訓練局面については凸制約になるが、多数の制約を保持して同時に満たす解法が必要であり、未観測局面の保証にはならない。単純な範囲射影と同じ処理としては追加しない。 |
| 学習率だけを下げる。 | 更新幅は変わるが、現行の学習目的に除去差分の制約が入らないため、原因に対応する第一候補にはしない。 |
| 診断を通った別エポックへ差し替える。 | 検証損失が最小のエポックを選ぶ現行契約を変えるため、この修正には含めない。 |

### 再学習前に係数と検証を固定する

追加係数は、元の訓練集合の中を対局単位で学習用と係数比較用に分け、有限個の候補を予備比較して決める。
予備比較では更新回数を事前に確認し、各候補の交差エントロピー、符号反転数、追加損失、および処理時間を同じ標本で記録する。
予備比較の教師Kは内部の学習用集合だけから求め、エポック選択にも内部の係数比較用集合の交差エントロピーだけを使う。
現行の学習コマンドを係数ごとにそのまま反復すると、元の検証集合でエポックを選ぶため、この予備比較の分割にはならない。
既存の検証集合、既知の352件、または自己対局の勝敗を係数選択には使わず、予備比較の値を見てから候補集合や選択規則を追加しない。
本検討では係数の数値とその比較結果をまだ確定していない。

本学習は採用済み重みから始め、生成済みの全11ファイル、外側の検証分割、固定した\(K\)、教師混合係数、鏡映共有、および各更新後の保存範囲への射影を維持する。
最良エポックは初期状態を含む既存の検証集合の交差エントロピーで選び、追加損失を検証損失へ混ぜない。
失敗した実行を上書きせず、新しい設定とソースを固定した実行ディレクトリに、追加係数と各損失を別々に記録する。
本学習後の診断が再び失敗した場合は採否測定へ進まず、既知の352件に合わせて係数、余裕、対象局面、または別エポックを選び直すこともせず、原因調査と次の変更判断へ戻る。
今回の診断を見て学習方法を考案した事実は残るので、調整に使わないことをもって既存の検証集合を完全に未参照の評価資料とは扱わない。

実装時には、2端点の鏡映共有モデルについて、除去後の盤面を実際に再評価した差と追加損失で使う式が一致することを検査する。
検査には両陣営、王駒の除外、先獅子特徴の保持、鏡映、パディング、および補間係数の上下端を含める。
さらに、基準で損失0となること、逆符号と同符号の増悪の合成例で正の損失と是正方向の勾配が得られること、基準の整数差0を対象外にすること、および非有限値を拒否することを確認する。
既知の検証局面は式の再現検査には使えるが、そこで得た勾配を新しい候補の学習へ使わない。

## 結論

推奨は、採用済み重みの符号を保ち、基準自体が逆向きの場合は増悪も抑える駒除去差分の二乗ペナルティである。
補間による残りの盤面の変化を損失へ含め、推論形式と既存の診断基準を維持できる。
現時点で示したのは式の妥当性と検討手順であり、追加係数の決定、恒久実装、再学習、および棋力測定は未実施である。

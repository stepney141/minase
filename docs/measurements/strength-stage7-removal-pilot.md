# 世代2の駒除去差分に対する追加損失の係数比較

## 目的

[棋力向上段階7](../plans/strength-stage7.md)で事前に定めた追加損失の5係数を元の訓練集合内で比較し、全訓練集合による再学習へ進める係数を選ぶ。
全5条件は正常終了したが、正の係数のいずれも符号反転0件の基準を満たさず、係数は選択しなかった。
追加損失の根拠は[学習方法の検討](strength-stage7-removal-learning.md)に記録し、この予備比較では棋力の改善や重みの採用を判定しない。

## コマンドライン

リポジトリのルートで、次のコマンドにより準備した。

```sh
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 MKL_NUM_THREADS=2 \
  tools/train/.venv/bin/python -u \
  data/strength-stage7/removal_pilot.py prepare \
  --directory data/strength-stage7/removal-pilot \
  --inputs data/strength-stage7/gen2-projected/training/inputs.json \
  --base data/strength-stage7/gen2-projected/pst-base.bin \
  > data/strength-stage7/removal-pilot-prepare.log 2>&1
```

準備後の照合を終え、次の起動スクリプトで予備比較を開始した。

```sh
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 MKL_NUM_THREADS=2 \
  tools/train/.venv/bin/python -u \
  data/strength-stage7/removal_pilot_execute.py
```

起動スクリプトは係数`0, 10, 100, 1000, 10000`の順で、`removal_pilot.py run --directory data/strength-stage7/removal-pilot --coefficient <係数>`を1件ずつ実行する。
子コマンドではPython、スクリプト、および実行ディレクトリを絶対パスで指定し、その実際の引数を`rho-<係数>-process.json`と`rho-<係数>-exit.json`へ保存する。
各子プロセスの標準出力と標準エラーは`rho-<係数>.log`へ保存し、失敗した場合はそこで後続を止める。
全5条件が正常終了した場合だけ、同じスクリプトの`select --directory data/strength-stage7/removal-pilot`を実行する。
係数のディレクトリ名と記録名では整数を5桁で0埋めし、係数0は`rho-00000`と表す。

生成データは再利用し、新たな自己対局生成は行わない。
入力は`data/gen0.bin`、基本シード100000〜500000の10万刻みの`data/gen1-s<seed>.bin`全5件、および基本シード600000〜1000000の10万刻みの`data/strength-stage7/gen2/generated-<seed>.bin`全5件である。
全11入力のパスとSHA-256、使用する局面番号、初期重み、およびソースの固定情報は`data/strength-stage7/removal-pilot/prepared.json`に保存した。

各係数の最良エポックは、エポック0を含むCALIB全体の純粋な二値交差エントロピーで選び、同じ損失なら先のエポックを保つ。
追加損失はFITの全非王駒の除去差分へ適用し、基準の整数差0を除外して局面内の対象を等重みで平均した後、対象のない局面も含む元局面を等重みで平均する。
除去後の補間係数を再計算し、基準の符号を保つ項に加え、基準自体が逆向きの場合だけ同符号の増悪を抑える項を使う。
係数0は追加損失を計算しない対照であり、選択対象にはしない。

除去の比較標本は、昇順のCALIB局面番号からNumPyのPCG64とシード20260915で重複なく選んだ10,000局面を全条件で共有する。
最良エポックの量子化誤差の平均が2センチポーン以下で、標本上の整数除去差分の厳密な符号反転が0件となる正の係数だけを適格とする。
適格な係数のうちCALIB全体の二値交差エントロピーが最小の値を選び、完全に同値なら小さい係数を選ぶ。
該当する係数がなければ選択せず、係数範囲や余裕を後から拡張して続行しない。
CALIBには初期重みが以前学習した世代0と世代1の局面も含まれるため、この比較を未参照データによる性能評価とは扱わない。

次の方法として検討するのは、同じ除去差分の下限と上限に対する片側絶対値ペナルティである。
候補と基準の未丸め除去差分を\(\Delta_\theta,\Delta_0\)、基準の整数差の符号を\(s_0\)とし、\(S=s_0\Delta_\theta\)、\(a=|\Delta_0|\)、余裕\(b=\min(a,0.25\ \mathrm{cp})\)と定める。
基準が物理的に逆向きであることの指示変数を\(v_0\)とし、基準の整数差が0の除去は従来どおり対象外とする。
\(x_+=\max(x,0)\)と書けば、現行の二乗項と次の候補はそれぞれ

\[
r_2=\frac{(b-S)_+^2+v_0(S-a)_+^2}{K^2},\qquad
r_1=\frac{(b-S)_++v_0(S-a)_+}{K}
\]

となる。
対象と2段階の平均を保ち、交差エントロピーに加える係数を新たに\(\eta\)とする。
下限への違反\(u=b-S>0\)があるときの\(S\)に対する修正勾配の大きさは、二乗項では\(2u/K^2\)で境界へ近づくと0になるが、絶対値項では境界へ達するまで\(1/K\)である。
基準自身の損失0も保たれるため、既存の差分計算を維持しつつ、この性質を変える候補となる。

有限係数での違いは1変数の例でも示せる。
\(c>0\)を除去項の集計重み、\(\sigma(z)=1/(1+e^{-z})\)とし、交差エントロピーを\(\log(1+e^{S/K})\)と置く。
二乗項を加えた最小点\(S_*\)は任意の有限\(\rho>0\)で\(b-S_*=K\sigma(S_*/K)/(2\rho c)>0\)を満たす一方、絶対値項なら\(\eta c\ge\sigma(b/K)\)で最小点が\(b\)に一致する。
これは余裕違反が最適点にも残り得ることを示す解析例であり、CALIBの7件の原因を確定する式ではない。
また、絶対値項でも小さい係数では違反が残り、有限回のAdam更新による境界の往復や学習外の局面の反転を排除できない。
係数\(\eta\)は\(K\)による正規化が異なるので、今回の\(\rho\)の値をそのまま移さず、まず解析解と合成例を照合した。

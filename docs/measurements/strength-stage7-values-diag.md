# 段階7の採用重みからの探索用駒価値の再導出

## 目的

[棋力向上段階7](../plans/strength-stage7.md)のフェーズ5として、現時点で採用している鏡映共有モデルの重みから探索用駒価値を導き、現在の固定値との差を確認する。
盤上に到達可能な37状態のいずれかで相対差が20%を超えた場合だけ、駒価値を変更する候補を作って対局測定へ進む。
[世代2の再学習候補](strength-stage7-gen2-training.md)は駒を除いた際の評価差の符号反転により診断基準を満たさず、その後の処理方針を確認している。
本計算は現採用重みに対する結果であり、追加学習で採用重みが変わる場合は再導出が必要となる。

## コマンドライン

```console
tools/train/.venv/bin/python data/strength-stage7/derive-final-values.py \
  960c56bcbb6088d0f0466d670ceea36dffeda5b7
```

2026年9月14日に終了コード0で完了した。
結果は`data/strength-stage7/values/values-diag.json`、採用コミットから取り出した重みは同ディレクトリの`final-adopted.bin`に保存した。
診断JSONのSHA-256は`3603fd9ce629a116447f35bfa26346ff5b23b168c108aedc6b8e36ec7f1fb908`である。
スクリプトは既存の出力ディレクトリの再利用を拒否する。

## エンジン

対象は鏡映共有モデルの採用コミット`960c56bcbb6088d0f0466d670ceea36dffeda5b7`に含まれる`nets/pst.bin`である。
ファイル全体のSHA-256は`b26e7841b168ed8e9f4bd8fe0094b7e0dbf6f74d76fae4ee95c19c18fa269b5c`、本体の検査和は`3000ae5c53f68742a7dad0ce48aab02dc3c6a8416cbbb8265e9aa0087713dc4a`である。
MNPTバージョン2の両端点各13,680個の重みと47個の固定駒価値を読み、出力Kは1072.6529541015625とした。

補間係数の平均には、[世代2追加後の識別性診断](strength-stage7-gen2-identifiability.md)が保存した世代0〜2の全訓練23,879,611局面の駒数ヒストグラムを使った。
入力は世代0の1ファイル、世代1の5ファイル、および世代2の5ファイルであり、パスと検査和の集合が再学習用に固定した全11入力と一致することを確認した。
検証集合を含めず、各訓練局面へ等しい重みを付けて平均する。
参照した`data/strength-stage7/gen2/identifiability/report.json`のSHA-256は`31f566749e38279f84814cd07568c62f19ba45e62c897a2cc6767268e12481cc`である。

## 環境

Python 3.12.14、NumPy 2.5.2を備えた学習用仮想環境でCPU上の計算を行った。
保存済みのヒストグラムと採用重みだけを読み、訓練データの再走査やGPU計算は行わなかった。
対局を行わないため、同時対局数、探索ワーカー数、および置換表容量は非該当である。

## 結果

盤上駒数を \(N\) とすると、補間係数は \(\varphi=\min(90,\max(0,N-2))/90\) である。
全訓練局面の平均は、保存したヒストグラムから次の有理数として求めた。

\[
\bar\varphi=\frac{P}{Q}
=\frac{1{,}270{,}160{,}139}{2{,}149{,}164{,}990}
\approx 0.5910016889861955,
\qquad Q=90\times23{,}879{,}611.
\]

状態 \(s\) と端点 \(e\) について、1/8センチポーン単位の保存重みの自駒側と相手駒側の差を144升で合計し、\(\Delta_e(s)\) とする。
各端点を \(\bar\varphi\) で合成してから升平均と陣営差の換算を行うため、丸め前の駒価値は次式となる。

\[
\Delta_e(s)=\sum_{x=0}^{143}
\bigl(w_e(\mathrm{own},s,x)-w_e(\mathrm{enemy},s,x)\bigr),
\qquad
\frac{T_s}{D}
=\frac{P\Delta_{\mathrm{mg}}(s)+(Q-P)\Delta_{\mathrm{eg}}(s)}{Q\times144\times16}.
\]

分母の16は、自駒側と相手駒側の差を2で割る換算と、1/8単位をセンチポーンへ戻す換算による。
整数化では0.5を0から遠ざける方向へ丸め、整数の演算だけで次式を計算した。

\[
R_s=\operatorname{sgn}(T_s)
\left\lfloor\frac{2|T_s|+D}{2D}\right\rfloor.
\]

王将と玉将の状態11、および太子の状態21は、到達可能な非王駒35状態の導出値の最大値に、成っていない歩兵の導出値を加えて定めた。
それ以外の状態は \(v_s=R_s\) とした。
この整数の有理式による独立計算と`pst_diagnostics.derived_piece_values`の出力は全47値で一致した。

到達可能な37状態で、固定値との相対差の絶対値が最大だったのは、成れない飛車の状態7であった。
固定値848に対して導出値872となり、差は+24センチポーン、相対差は \(24/848=3/106\approx2.830189\%\) である。
20%超の判定は丸めた百分率を使わず、各到達可能状態について \(5|v_s-f_s|>f_s\) を整数で比較し、該当する状態は0個だった。

成っていない歩兵の状態29は固定値100に対して導出値101、到達可能な非王駒の最大値は獅子の状態20の2,547となった。
このため王将と玉将、および太子の導出値は \(2{,}547+101=2{,}648\) であり、現在の固定値2,622との差は+26センチポーンである。
静止探索の余裕値`DELTA_MARGIN`は歩兵の2倍なので、導出値では202となるが、現在の値200を維持する。

閾値を超える状態がなかったため、駒価値を差し替えた候補ファイルは作成せず、短時間制御と長時間制御の逐次対局測定は実施しなかった。
対局件数、ペンタノミアル度数、対数尤度比、Elo、破棄ペア、および`time_forfeits`は非該当である。

## 結論

到達可能な37状態で固定値との相対差は最大2.830189%にとどまり、20%超の閾値を満たさなかった。
この採用重みを用いる限り、計画上は47個の固定駒価値と`DELTA_MARGIN = 200`を維持し、駒価値だけを変える候補の対局測定は行わない。
世代2の処理方針が未確定のため、段階最終値としての判断は保留する。

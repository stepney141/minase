# 棋力向上段階8（前向き枝刈りの第3層）の起案時の発動率診断（bench深さ5と6）

## 目的

前向き枝刈りの第3層の候補項目について、[棋力向上の段階計画](../plans/strength-stages.md)の規則（実装前に`bench`深さ6で発動率が5%以上であること）に照らして着手の可否を決めるため、各項目が発動し得るノードと手の件数を数える。

## コマンドライン

診断は本番の経路へ入れず、[診断差分](strength-stage8-activation-diag/diagnostic.patch)を第2期高速化の最終の採用版へ当てた別ターゲットディレクトリのビルドで数えた。経過時間は使わない。

```console
git apply docs/measurements/strength-stage8-activation-diag/diagnostic.patch
CARGO_TARGET_DIR=target/diag cargo build --release --bin bench
target/diag/release/bench --depth 6 --threads 1 --repetitions 1
```

合計は[totals.json](strength-stage8-activation-diag/totals.json)にある（深さ5と深さ6）。

## エンジン

第2期高速化の最終の採用版であるコミット`24ddf4f`である。`bench`は規則セット`engine-default`を固定で使い、総ノード数は深さ5で1,201,518、深さ6で2,932,173である。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア）、rustc 1.98.0であり、2026年9月17日に1スレッドで測った。件数は決定的である。

## 結果

深さ6の値を示す。「浅い非PVノード」は残り深さ3以下で探索窓の幅が1のノードであり、現行のfutility pruningの対象ノードと同じである。

### ノードの分類

| 項目 | 件数 | 割合 |
|---|---:|---:|
| 通常探索のノード（置換表の打ち切りを除く） | 282,040 | |
| うち非PVノード | 280,949 | 99.6% |
| うち浅い非PVノード（futilityの対象） | 277,458 | 98.4% |
| 2手前より静的評価が上がったノード（improving） | 196,985 | 71.4%（2手前がある276,070ノードに対して） |
| 2手前より静的評価が上がらないノード | 79,085 | 28.6% |
| 手番側の王駒に相手の利きが届くノード | 5,462 | 1.9% |
| ProbCutの対象になり得るノード（残り深さ5以上の非PV、null moveの直後を除く） | 1,122 | 0.4% |
| うち静的評価が`β − 2p`以上 | 763 | 0.3% |

### 浅い非PVノードで検査した手

| 項目 | 件数 | 割合 |
|---|---:|---:|
| futility pruningで展開しなかった非捕獲手 | 2,182,763 | |
| 検査した手 | 1,230,085 | |
| うち捕獲手（置換表の手を除く） | 608,108 | |
| うちSEEが負で規則に依存しない捕獲手 | 242,052 | 39.8%（深さ1で38.2%、深さ2で52.0%、深さ3で40.7%） |
| うち非捕獲手（置換表の手と殺し手を除く） | 339,461 | |
| うち履歴値が0 | 306,534 | 90.3% |
| うち履歴値が32未満 | 327,204 | 96.4% |
| うち手番号が8以上 | 322,608 | 95.0% |
| うち手番号が8以上かつ履歴値が0 | 300,386 | 88.5% |
| うち履歴値が負 | 0 | 0%（malusが不採用なので履歴値は非負） |
| 検査した非捕獲手のうち獅子の手（全深さ） | 74,835 | 13.5%（555,199手に対して） |
| うちじっと | 4,416 | 0.8% |

非捕獲の残り深さ別の内訳は深さ1が199,608手、深さ2が105,649手、深さ3が34,204手である。
獅子の2段階の非捕獲移動は着手の正準表現で直接の跳びと同一視されるので、じっと以外は1段階の手と区別できない。

### 静的評価と探索値のずれ

置換表へ正確な値（`Exact`）を保存したノードは571件で、探索値と静的評価の差の絶対値の平均は273（歩兵の駒価値100に対して2.7倍）、差が歩兵の半分を超えるものが428件（75.0%）である。

## 結論

SEEが負の捕獲手の枝刈りは浅い非PVノードで検査する捕獲手の39.8%に発動し、履歴と手番号による非捕獲手の枝刈りは検査する非捕獲手の88.5%を対象にし得る。improvingフラグは28.6%のノードで「上がらない」側になる。王手延長（1.9%）とProbCut（0.4%）は発動率が5%に届かず、獅子の2段階の非捕獲移動は正準表現で区別できないので、いずれも見送る。静的評価の補正は、正確な値の保存が全ノードの0.2%と少ないが、差の平均が歩兵の2.7倍と大きいので、補正の鍵を診断で選んだうえで扱う。

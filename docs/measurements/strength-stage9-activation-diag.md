# 棋力向上段階9の着手時の発火率診断

## 目的

[棋力向上段階9](../plans/strength-stage9.md)のフェーズ0として、項目1から項目3の追加特徴68列について、教師データでの発火率、端点の識別性、王駒が2枚の側を含む局面の割合、特徴どうしの相関、および学習PSTの残差との相関を測り、特徴の除外、端点の共有、王駒が2枚の側の方式を確定する。

## コマンドライン

特徴値は、診断用のブランチのリリースビルドで、教師データの11ファイルのそれぞれについて次のコマンドで書き出した。

```console
target/release/pst_probe --pst nets/pst.bin \
  --positions data/<入力>.bin \
  --king-features data/strength-stage9/features/<入力>.mnkf
```

診断は次のコマンドで実行した。

```console
tools/train/.venv/bin/python tools/train/pst/king_features_diag.py \
  --data data/gen0.bin \
    data/gen1-s100000.bin data/gen1-s200000.bin data/gen1-s300000.bin \
    data/gen1-s400000.bin data/gen1-s500000.bin \
    data/strength-stage7/gen2/generated-600000.bin \
    data/strength-stage7/gen2/generated-700000.bin \
    data/strength-stage7/gen2/generated-800000.bin \
    data/strength-stage7/gen2/generated-900000.bin \
    data/strength-stage7/gen2/generated-1000000.bin \
  --king-features <上と同じ順のMNKFファイル11個> \
  --pst nets/pst.bin --output-k 1072.6529541015625 --batch 65536 \
  --output data/strength-stage9/activation-diag.json
```

## エンジン

特徴の計算と診断器は、ブランチ `strength-stage9-diag` のコミット `327bfe0` である。
基準の重みは段階開始版（masterの `1633f53`）の `nets/pst.bin` であり、保存された出力Kは1072.6529541015625である。
特徴の定義の識別値は1、列数は68である。
評価値と探索は変更していない。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ32 GB）である。
特徴値の書き出しは1プロセスの逐次実行で、11ファイル25,120,683局面に107.4秒を要した。
2026年9月21日に実施した。

## 結果

対象は世代0から世代2の訓練の分割23,879,611局面である。
世代別の教師Kの推定値は804.0、1099.7、777.6、教師値の混合はλ=0.75である。

### 除外と端点の共有の判定

発火率の最小値は0.181%であり、0.1%を下回る列はなかった。
識別性の指標（特徴値の二乗を重みとした補間係数φの偏差平方和）の最小値は1009であり、100を下回る列はなかった。

## 結論

68列のすべてを除外せずに残し、全列が2端点の重みを持つ。
王駒が2枚の側を含む局面は訓練の分割の0.81%であり、起案の目安の5%を下回るので、王駒が2枚の側の特徴値を0とする方式を確定する。

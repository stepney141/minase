# 棋力向上段階9の項目1（王の遮蔽と開いた筋）の学習と診断

## 目的

[棋力向上段階9](../plans/strength-stage9.md)の項目1の候補について、学習PST、探索用駒価値、出力Kを固定したまま追加特徴24個の重みを学習し、採否測定の前の診断を通す。

## コマンドライン

候補のworktreeで、設定ファイル `data/strength-stage9/shelter.toml` を使い、次の順に実行した。

```console
tools/train/.venv/bin/python tools/train/pst/pst_workflow.py prepare --config <設定ファイル>
tools/train/.venv/bin/python tools/train/pst/pst_workflow.py generate --run-dir data/shelter-training
tools/train/.venv/bin/python tools/train/pst/pst_workflow.py train --run-dir data/shelter-training
tools/train/.venv/bin/python tools/train/pst/pst_workflow.py diagnose --run-dir data/shelter-training
```

設定は、モデル `mirrored`、出力K 1072.6529541015625、学習率3.0、10エポック、バッチ16,384、乱数シード1、λ=0.75、駒除去差分の損失の係数0、`freeze_pst = true`、`extra_columns = "0:24"`、`train_extra = "0:24"` である。
教師データは世代0から世代2の11ファイルで、生成のシードは空であり、新しい生成は行っていない。
特徴値は[発火率の診断](strength-stage9-activation-diag.md)で書き出した68列のファイルから列0から列23を選んだ。

## エンジン

基準の重みと診断用の `pst_probe` は、ブランチ `strength-stage9-shelter` のコミット `001b551`（項目1の24列、追加特徴の重み0）である。
学習した重みを埋め込んだ候補はコミット `ba5f792` である。

## 環境

測定機はIntel Core Ultra 7 265KF（実メモリ32 GB）とNVIDIA GeForce RTX 3060 Ti（8 GB）である。
学習は12分54秒、診断は45秒を要した。
2026年9月21日に実施した。

## 結論

候補は採否測定の前の診断をすべて通過した。
学習した重みは終盤の端点でだけ大きく、敗局の中盤の局面では追加特徴の寄与が−28センチポーン以内にとどまるので、現行の教師では中盤の王の危険を学習できていない。

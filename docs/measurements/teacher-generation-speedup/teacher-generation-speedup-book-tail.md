# 生成機の本の末尾で使われない計算資源の測定

## 目的

[教師生成の高速化](../../plans/archived/teacher-generation-speedup.md)のために、生成機で本（教師の1ファイル、7,500局）の末尾に使われない計算資源の量を測る。

## コマンドライン

生成機へSSHで接続し、20秒ごとに生成プロセスのスレッド数、累積CPU時間、および常駐メモリを読み取って記録した。
生成プロセスには手を加えていない。
スクリプトは[付属資料](teacher-generation-speedup-book-tail/gen-sampler.sh)にあり、接続先は伏せた。

```console
MP=$(pgrep -x minase | head -1)
ls /proc/$MP/task | wc -l
cut -d" " -f14,15 /proc/$MP/stat
grep VmRSS /proc/$MP/status
```

## エンジン

対象は[世代反復](../../plans/nnue-generation-reset.md)の第1世代の生成であり、生成器は第0世代のネットを埋め込んだコミット`6f874692`のビルド、規則セットは`L0,P0,R1,E0`である。
生成の条件は7,500局、1手2万ノード、同時384局、手数の上限4,000手、置換表16 MiBである。

## 環境

vast.aiの出品48544090（AMD EPYC 9654の2基構成、物理192コア、384スレッド、NUMAノード2、メモリ125 GB）で、2026年11月4日に測った。
全スレッドが動いている間のCPU使用量は368.7 CPU相当であり、cgroupのCPU上限368.64に一致する。

## 結果

1本の全期間1,915秒のうち、スレッド数が384のまま続いた時間は1,664秒である。
それ以後は下表のとおり急に減り、最後の約190秒は25スレッド以下である。

| 本の開始からの秒数 | スレッド数 |
|---:|---:|
| 1,664 | 381 |
| 1,686 | 270 |
| 1,708 | 96 |
| 1,729 | 25 |
| 1,751 | 18 |
| 1,795 | 10 |
| 1,838 | 7 |
| 1,881 | 2 |

使われない割合の分母は、本の全期間の計算資源である。
全期間を368.7 CPU相当で動かせば706,057 CPU秒になるのに対し、実際に使ったのは627,435 CPU秒なので、78,622 CPU秒（全資源の11.1%）が使われていない。
これをすべて回収できれば、時間あたりの生成量は1.125倍になる。
同じ本の常駐メモリは全スレッドが動く間は約85 GBで、スレッド数が96まで減ると23 GBになる。

カーネル時間は全期間で0.7〜2.6 CPU相当（全体の1%未満）で、生成プロセスの常駐メモリのうちTransparent Huge Pagesの割合は測定時点で93%だった。

## 結論

本の末尾で全計算資源の11.1%が使われておらず、残りが100スレッド以下（約23 GB）になった時点で次の本（約85 GB）を始めれば、メモリの合計が約108 GBで搭載量125 GBに収まるので、この大部分を回収できる見込みである。

# 混合比λ=1.0で再学習した学習PSTの短時間測定（STC）

## 目的

[教師の混合比λ=1.0](../plans/teacher-mixing-ratio.md)の候補（基点の学習PSTを、λ=1.0の先読み教師で学習し直した重み）を、基点と対等条件の短時間GSPRTで測り、長時間測定へ進めるかを振り分ける。

## コマンドライン

```console
data/worktrees/teacher-mixing-ratio-runner/target/release/match_runner \
  --run-dir data/matches/teacher-mixing-ratio-100-stc --seed 54000921 \
  --candidate commit:16a2257351daaa2f46ed789e03ccca84f88d3dd0 \
  --baseline commit:622a879f9e0cf0bfdcf7aad3585e93a9acbe1226 \
  --each time=10000+100 --concurrency 16 gsprt --max-pairs 3000
```

## エンジン

候補はブランチ `teacher-mixing-ratio-100-candidate` の `16a2257` である。このコミットは、基点 `622a879` に `nets/pst.bin` の差し替えだけを加えたものであり、重みの学習は[混合比λ=1.0での再学習](teacher-mixing-ratio-training.md)による。
基準は基点 `622a879` である。
規則セットは `engine-default`（L0、P0、R1、E0）、両エンジンとも `Threads=1`、`USI_Hash` 256 MBである。
runnerは `622a879` の `match_runner`（SHA-256 `06fe7121…`）で、H1はelo=10、α=β=0.05である。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ32 GB）、同時対局数は16、他の負荷はない。
2026年9月26日3時46分から4時5分に実施した。

## 結果

| 量 | 値 |
|---|---:|
| 有効ペア | 123（破棄2、手数上限） |
| ペンタノミアル度数 | [59, 3, 54, 1, 6] |
| LLR | −2.956 |
| 判定 | H0 |
| エンジン異常 | 不正着手0、クラッシュ0、応答タイムアウト0、時間切れ0、拒否着手0 |
| 経過時間 | 1,135秒 |

候補の得点率は28.0%（ペア得点の標準誤差は約2.6%）であり、ロジスティックElo換算で約−164に当たる。この値は採否には使わない。

負けの幅が、学習損失の小さな差から予想される幅を大きく超えていた。
そのため、設計書の「後続へ引き継ぐ条件」が求める共通する不具合の有無を、次の3点で確かめた。

1. 候補コミットの `nets/pst.bin` のSHA-256は学習の出力と一致し、測定で使った候補のバイナリは深さ1の初期局面で22（基準は17）を返した。候補は学習した重みを埋め込んでいる。
2. 基点の学習PSTからの重みの変化量は、序中盤と終盤の平均絶対値で89と139であり、STCとLTCで採用された[先読み教師での再学習](lookahead-teacher-pst-training.md)の81と157と同程度だった。探索用駒価値は変わっていない。
3. 学習後の診断で、Rustと学習器の評価値は141,841局面すべてで一致した。

重みの入出力、符号、埋め込みに不具合は見つからなかった。
変化量が同程度の2つの再学習で棋力の向きが逆になった原因は、本測定だけでは特定できない。

## 結論

候補は短時間測定でH0となり、振分け規則に従い不採用とする。長時間測定 `teacher-mixing-ratio-100-ltc` へは進めない。
後続の計画には、従来の採用PST（`622a879` の `nets/pst.bin`）を引き継ぐ。

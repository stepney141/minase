# 混合比λ=1.0での学習PSTの再学習と診断

## 目的

[教師の混合比λ=1.0](../plans/teacher-mixing-ratio.md)のフェーズ2として、基点の採用PSTを、自己対局の分類のλを1.0へ上書きした先読み教師で学習し直し、学習後の診断を通して採否測定の候補を作る。

## コマンドライン

```console
tools/train/.venv/bin/python tools/train/pst/pst_workflow.py prepare --config data/teacher-mixing-ratio/lambda100.toml
tools/train/.venv/bin/python tools/train/pst/pst_workflow.py train --run-dir data/teacher-mixing-ratio/lambda100-training
tools/train/.venv/bin/python tools/train/pst/pst_workflow.py diagnose --run-dir data/teacher-mixing-ratio/lambda100-training
```

3つのコマンドは、いずれもブランチ `teacher-mixing-ratio-100` の作業ツリーで実行した。
設定は、基点を `622a879`（SPSAの2回目の22係数を採用したmaster）、入力を基本の教師の11ファイル、モデルを `mirrored`、出力K 1072.6529541015625、学習率0.03、駒除去差分の追加損失の係数1000、10エポック、バッチ16,384、乱数シード1、`lambda_override = 1.0`、`lookahead = { gamma = 0.9, plies = 40 }` とした。
この設定は、[先読み教師での再学習](lookahead-teacher-pst-training.md)の設定と比べて、基点と `lambda_override` だけが異なる。

## エンジン

候補の重みは、ブランチ `teacher-mixing-ratio-100` の `16a2257`（`622a879` に `nets/pst.bin` の差し替えだけを加えたコミット）に置いた。
重みのSHA-256は `c6d6ef46a78d9a00547d1235da79b19ed686e9ea6af92cdec8bb5dc794683abc` である。
重みに依存する2件の単体テスト（初期局面の評価値、深さ5の窓外れ）は、候補コミットでは失敗する。
[先読み教師値](../plans/lookahead-teacher.md)の前例に従い、候補コミットの差分を重みファイルだけに保つため、これらのテストは採用時に更新する。

## 環境

測定機はIntel Core Ultra 7 265KF（物理20コア、論理20コア、実メモリ32 GB、GeForce RTX 3060 Ti）で、2026年9月26日に実施した。学習は約20分で終わった。

## 結果

教師Kは世代0から順に768.5、1068.2、758.4であり、設計書の予測どおり先読み教師での再学習と同じ値になった。
教師の分類は3つとも自己対局であり、記録上の実効λはすべて1.0である。
λ=1.0の教師に対する検証損失は、初期状態（基点の重み）の0.472950から、最良のエポック10で0.471485へ下がった。
損失は10エポック目まで単調に下がり続けており、収束には達していない。

学習後の診断は次のとおりである。

| 検査 | 結果 |
|---|---|
| Rustと学習器の評価値の一致 | 141,841局面で一致 |
| 量子化の前後の平均絶対誤差 | 0.53センチポーン（最大1.81） |
| 駒除去差分の符号の反転 | 0件（352件を検査） |
| 成りの評価差の一致 | 一致 |
| 出力Kと探索用駒価値 | 不変 |

設計書の共通の診断（採否には使わない記録）は次のとおりである。対象は検証の分割の1,241,072局面（3,676局）である。

| 指標 | 基点 | 候補 |
|---|---|---|
| 対局結果の二値交差エントロピー（局面の平均） | 0.47478 | 0.48091 |
| 対局結果の二値交差エントロピー（対局ごとの平均の平均） | 0.49057 | 0.49661 |
| 符号の一致率 | 74.31%（除外17,508件） | 73.77%（除外17,342件） |

候補は対局結果を教師から外したので、対局結果の予測はわずかに悪くなった。
世代と局面帯ごとの15区分では、λ=1.0の教師に対する検証損失が全区分で基点より小さい。
教師の参照値との平均絶対誤差は、出力Kと教師Kの比で換算した値では13区分で候補が小さく、生の値では5区分で候補が小さい。
除去差分から導いた序中盤の駒価値は、歩兵103、仲人117、香車371、反車380、横行508、竪行596、角行673、飛車850、龍馬992、龍王1152である。固定の探索用駒価値との差は、この10駒では最大で4%である。

## 結論

候補は学習後の診断を通過した。
基点との差が重みファイルだけの候補 `16a2257` を、STC（`teacher-mixing-ratio-100-stc`）で測る。

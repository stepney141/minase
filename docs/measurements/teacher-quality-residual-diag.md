# 教師値の成分ごとの残差と王の安全度の特徴の相関

## 目的

教師データの改善の起案時の診断として、[棋力向上段階9](../plans/strength-stage9.md)の追加特徴68列と学習PSTの残差の相関を、教師値を探索値だけにした場合、既定の混合にした場合、対局結果だけにした場合で比べ、王の危険の信号が教師値のどの成分にあるかを調べる。

## コマンドライン

```console
tools/train/.venv/bin/python tools/train/pst/king_features_diag.py \
  --data <世代0から世代2の11ファイル> --king-features <対応するMNKFの11ファイル> \
  --pst data/strength-stage9/pst-1633f53.bin --lambda <1.0、0.75、0.0> \
  --output-k 1072.6529541015625 --batch 65536 --output <出力>
```

入力と特徴値のファイルは[段階9の発火率の診断](strength-stage9-activation-diag.md)と同じである。

## エンジン

診断器はブランチ `strength-stage9-diag` のコミット `f280587`、学習PSTは段階9の段階開始版（masterの `1633f53`）の `nets/pst.bin` である。

## 環境

測定機はIntel Core Ultra 7 265KF（実メモリ32 GB）であり、1回の実行は約3分である。
2026年9月21日に実施した。

## 結論

対局結果の残差は、項目1の全列で期待どおりの負の符号を持つが、絶対値は0.008未満である。
探索値の残差は、項目1の距離1と距離2の列で符号が正へ反転し、探索の教師が「歩のない筋と走り駒」を危険と見ていないことを示す。
項目2の列は、探索値でも対局結果でも負の相関を持ち、絶対値は探索値の側が大きい。
どの成分でも相関は0.04未満であり、自己対局の教師データでは、教師値の混合の比を変えるだけで王の危険の信号を大きくすることはできない。

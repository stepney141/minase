# 持ち時間の伸縮の開始値の事前対局

## 目的

[探索の不安定さに応じた持ち時間の伸縮の設計書](../../plans/archived/time-instability-scaling.md)のフェーズ2として、新しい12係数をStockfishの換算値の開始値に置いた形の変更と起点を、STCの条件で16ペア対局させ、時間切れとエンジン異常がないことを確かめ、開始値での時間の使い方の変化を記録する。
採否や係数の選び直しには使わない。

## コマンドライン

調整機を借りる前に、測定機で実行した。

```console
data/spsa/time-instability-scaling-runner/minase match run \
  --run-dir data/matches/time-instability-scaling-start --seed 5025000000 \
  --candidate commit:68d3a4d4 --baseline commit:370f7077 \
  --each time=10000+100 --concurrency 16 elo --pairs 16
```

集計は、`minase match report`と、手数帯ごとの時計を再構成する次のコマンドで行った。

```console
data/spsa/time-instability-scaling-runner/minase match report \
  --run-dir data/matches/time-instability-scaling-start
scripts/clock_profile.py data/matches/time-instability-scaling-start \
  --budget quadruple-soft --role candidate
scripts/clock_profile.py data/matches/time-instability-scaling-start \
  --budget quadruple-soft --role baseline
```

`clock_profile.py`の予算に対する比の欄は古い係数を固定しているので使わず、手数帯ごとの実測値の集計だけを使った（[起点の時計の記録](time-instability-scaling-baseline.md)と同じ扱い）。

## エンジン

候補は、形の変更の最後のコミット`68d3a4d491c94dee29f979b8de70025fca902565`であり、新しい12係数はStockfishの換算値の開始値、既存の係数は起点の値のままである。
起点は、設計書を始めた時点のmaster`370f707780548b0fa65d3e1303881a9fd609c05b`である。
runnerは、`68d3a4d4`をビルドした通常のminase（版2.4.0、SHA-256`dfb6bbe6…`）である。
規則は`engine-default`（`L0,P0,R1,E0`）である。

## 環境

測定機はIntel Core Ultra 7 265KF（性能コア8個と高効率コア12個、物理20コア、20スレッド）である。
両エンジンの`Threads`は1、`USI_Hash`は既定の256 MB、同時対局数は16である。
ほかの対局測定、SPSA、教師生成、および学習は動いていなかった。lishogiのBotは止めておらず、対局の間に2局を指していた。

## 結果

| 量 | 値 |
|---|---:|
| 有効ペア | 16（破棄0） |
| ペンタノミアル度数 | [2, 1, 9, 1, 3] |
| 正規化した平均得点 | 0.531 |
| Elo | +21.7 |
| 95%信頼区間 | [−78.9, +126.2] |
| エンジン異常 | 不正着手0、クラッシュ0、応答タイムアウト0、時間切れ0、拒否着手0 |
| 経過時間 | 146.3秒（`summary.json`の累計） |
| 1局の最大常駐メモリ | 1,006,764,032バイト |

16ペアの固定局数Eloは信頼区間の幅が約200 Eloあり、強さの判定には使わない。

時間の使い方は次のとおりである。
32局の手数は平均427手、中央値440手だった。

| 量 | 候補 | 起点 |
|---|---:|---:|
| 32局の総思考時間 | 916.3秒 | 923.7秒 |
| 着手数 | 6,679 | 6,677 |
| 1手の平均思考時間 | 137.2 ms | 138.3 ms |
| 終局時の残り時間の中央値 | 1,853 ms | 1,472 ms |
| 反復の境界での停止（soft） | 6,656 | 6,667 |
| 探索途中のhardによる中断 | 23 | 10 |

候補の総思考時間は起点の0.992倍であり、[教訓](../../lessons/compare-total-time-usage-before-sprt.md)の90%以上110%以下の範囲に入った。

手数帯ごとの平均完了深さと思考時間の中央値は次のとおりである。

| 手数帯 | 手数（候補） | 完了深さ（候補） | 完了深さ（起点） | 思考時間の中央値（候補、ms） | 思考時間の中央値（起点、ms） |
|---|---:|---:|---:|---:|---:|
| 0〜49 | 653 | 16.19 | 16.11 | 92 | 103 |
| 50〜99 | 784 | 16.01 | 16.10 | 93 | 111 |
| 100〜149 | 775 | 15.49 | 15.72 | 91 | 111 |
| 150〜199 | 775 | 15.38 | 15.35 | 101 | 121 |
| 200〜299 | 1,536 | 14.73 | 14.89 | 102 | 122 |
| 300〜399 | 1,268 | 14.56 | 15.19 | 91 | 132 |
| 400〜 | 888 | 14.41 | 15.02 | 81 | 101 |

候補の完了深さは、0〜49手と150〜199手の帯では起点を上回り、残りの5つの帯では下回った。差が最も大きいのは300〜399手の帯（0.63）である。
候補の思考時間の中央値はどの帯でも起点より短く、総思考時間はほぼ同じなので、候補は思考時間の分布の裾で長く考えている。
T7で窓を浅く読んだ反復も反復の番号で数えるので、候補の完了深さは実際に読んだ深さより深く数えられている。

## 結論

開始値の形の変更は、時間切れとエンジン異常を起こさず、1局の総思考時間を起点とほぼ同じに保った。手数帯ごとの完了深さは7つのうち5つの帯で起点を下回ったが、設計書の規則により、この条件は合否ではなく記録とし、SPSAへ進む。

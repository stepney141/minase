# 先読み教師値（将来の探索値の幾何加重平均による教師値）の設計書

## 先に読む要約

本書は、評価関数の学習に使う教師値（学習の目標にする値）を、記録した局面そのものの探索値から、同じ対局でその後に現れた局面の探索値を混ぜた値へ変える方式を定め、王の安全度の特徴がその教師で意味のある重みを得るかを事前に固定した基準で判定し、基準を満たした候補だけを自己対局で測る。
現行の教師値は、局面ごとに10万ノードの探索値（深さ約6）を勝率へ変換し、対局結果と3:1で混ぜた値である。
[棋力向上段階9](strength-stage9.md)の3つの診断では、指定した標本、特徴、判定基準の下で、深い探索による付け直し、人間の対局結果、人間の配置から始めた自己対局のどれも、教師への追加を採用する根拠を得られなかった。
一方で、[lishogiの敗局](../research/lishogi-game-yO464dzl-loss-analysis.md)と[HaChuとの対局の分析](../research/hachu-minase-playing-style-analysis.md)は、minaseが自身を有利とする評価を保ったまま、十数手の後に評価が急落して負ける型を示している。
そこで本書は、局面tの教師値に、同じ対局のt+1手からt+n手までに記録された探索値を、手数が離れるほど小さくなる幾何級数の重みで平均した値（先読み値）を使う仮説を検証する。
この形はKnightCapのTD(λ)（時間差分学習）の目標値に着想を得たものであり、追加の探索を要せず、既存の教師データの対局番号と手数だけから計算できる。
進め方は、先読み値と現在の探索値の差の分布を記録し、項目1（王の遮蔽と開いた筋、24列）の重みを先読み教師で学習して、事前に固定した露出局面の集合に対する項目1の寄与が基準を満たすかを判定し、満たした候補だけを短時間と長時間の時間制御GSPRT（[docs/guides/sprt.md](../guides/sprt.md)）で測る。
完了条件は、差の分布の記録、基準に対する判定、候補の採否または見送りが測定記録とともに残り、採用した場合は学習PSTごと先読み教師で学習し直した第2の候補の採否も記録されていることである。

## 目的

現行の学習は、局面の静的評価をその局面の探索値へ近づける。
探索値は深さ約6の読みの範囲でしか局面を見ないので、駒を取らない手が7手から9手続く攻めの準備を数値に含まない。
段階9の診断では、この盲点を教師の側から埋める3つの方法のどれも、指定した標本と特徴では採用の根拠を得られなかった。
本書は、探索を深くする代わりに、対局が実際に進んだ先の探索値を使う仮説を立てる。
仮説は、攻めの準備が整った局面ではその後の十数手で探索値が下がるので、先読み値はその局面を現在の探索値より低く評価し、静的評価がこの値へ近づけば評価関数は準備が整った配置を静的に減点する、というものである。
仮説の成否は、事前の判定と自己対局の測定で確かめる。

## 適用範囲

対象は、`tools/train/pst/` の学習器（教師値の計算と教師の分類）、診断器、および段階9の項目1の候補である。
評価関数の特徴、探索、教師データの形式（MNSD）、生成器は変えない。
本書の用語は段階9の設計書に従い、次の語を加える。
混合の比は[評価関数](evaluation.md)と同じくλで表し、先読みの減衰率は別の記号γで表す。

- **探索値** `v_t` は、記録した局面tの手番側から見た探索値（センチポーン、整数）を指す。
- **先読み値** `v̂_t` は、同じ対局のt+1手からt+n手までに記録された局面の探索値を、局面tの手番側の視点へそろえ、手数の差kに重み `γ^(k−1)` を掛けて平均した実数値を指す。記録されていない手数は平均に含めず、重みは含めた手数だけで正規化する。t+1手からt+n手までに記録された局面がなければ `v̂_t = v_t` とする（退避）。
- **先読み教師値**は、現行の教師値の探索値を先読み値に置き換えた値 `λ · sigmoid(v̂_t / K) + (1 − λ) · result`（λ=0.75）を指す。教師Kは先読み値から教師の分類ごとに推定する。
- **急落局面**は、`v̂_t − v_t` が−300センチポーン以下の局面を指す。−300は、王手を伴わない大駒1枚分の損失に当たる値として本書が置く目安であり、記録にだけ使う。
- **露出局面の集合**は、[診断A](../measurements/strength-stage9-depth-sensitivity.md)の予備標本の露出局面1,000局面（`data/strength-stage9/diag-a/pilot/sample.json`）を指し、事前の判定に使う。この集合は本書の着手前に固定されている。
- **項目1の寄与**は、ある局面について、手番側の視点の項目1の24列の特徴値と重みの積の和を補間係数φで補間した値（センチポーン）を指す。

本書の第2の候補は世代3を生成せず、基本の教師の11ファイルだけを使う。

## 設計判断

| 項目 | 決定 |
|---|---|
| 先読み値の形 | 幾何級数の重みによる平均とし、将来の最小値は採らない。最小値は探索値の揺れによって系統的に低い側へ偏り、両陣営で同じ偏りが生じると1つの局面に矛盾する目標を与えるためである。幾何加重平均はこの下方への偏りを避けるが、不偏ではない。将来の値は実際に指された着手列に依存し、生成時の除外（詰みの帯、捕獲または成りの最善手、再出現）も値と無関係ではないので、先読み教師は生成方策と除外条件に依存する教師である。 |
| TD(λ)との関係 | KnightCapのTD(λ)は、主変化の末端の評価について、終局の報酬を終端項に含む時間差分の和で更新する。本書の式は記録した局面の探索値を使い、終端項を持たず、有限の窓の中の記録だけで正規化するので、TD(λ)の目標値と同一ではない。名称は「将来の探索値の幾何加重平均」とし、TD(λ)は着想の出所として引く。 |
| 減衰率γと手数の上限n | γ=0.9、n=40手（先後合計）とし、結果を見て変えない。欠けた手数がない場合の試算では、γ=0.9で12手目の重みが3.19%、20手以内の合計が89.2%、12手目から40手目までの合計が30.4%、40手で打ち切る無限級数の重みが1.48%である。敗局では174手目の局面から急落まで約12手から16手あるので、12手目以降の累積30%が急落を伝える。KnightCapのγ=0.7では12手目の重みが0.59%であり採らない。γ=0.7と0.95の値は差の分布の診断で記録だけを行い、候補には使わない。 |
| 記録されていない手数の扱い | 生成時の除外で記録されない手数は平均から除き、重みを正規化する。除外された局面の探索値は保存されていないためである。窓の中に記録が1件だけなら、先読み値はその値になる。診断では、窓の中の記録数、最初の記録までの手数、退避した局面の割合を記録する。 |
| 対局結果との混合 | λ=0.75の混合は変えない。先読み値は探索値の置き換えであり、対局結果の項の役割（対局全体の帰結）は変わらない。 |
| 教師の分類と設定の照合 | 先読みは学習時の変換であり、生成時の来歴とは区別する。先読みを使う教師は、γとnを教師の分類の属性に加えた別の分類とし、教師Kを先読み値から推定し直す。学習の設定 `train.lookahead`（γとn）は準備、学習、診断の記録に固定し、再開時に照合する。同一の学習実行の中で、同じMNSDファイルを先読みありと先読みなしの両方で入力することはしない。 |
| 付け直しファイルとの併用 | 先読みと付け直しファイルの併用は拒否する。付け直した記録と元の記録では探索の条件が異なり、将来の値の探索条件が混在すると分類がγとnだけでは表せないためである。本書は基本の教師の11ファイルだけを使う。 |
| 実数の先読み値の受け渡し | MNSDの探索値の欄は16ビット整数なので、先読み値はこの欄へ書き戻さず、記録と同じ行番号で対応する実数の配列として学習器の中に持つ。教師Kの推定、訓練、検証、および残差の診断は同じ配列を参照する。 |
| 教師Kの再推定の記録 | 探索値が下がっても教師Kが下がれば勝率へ変換した教師値は上がり得る（段階9の「検証」の指摘と同じ）。そこで、訓練の分割から推定した現行の教師のKと先読み教師のKを記録し、露出局面と対照局面（診断Aの予備標本）について、現行の教師値と先読み教師値の勝率の差を記録する。 |
| 事前の判定 | 候補を自己対局で測るかどうかは、先読み教師で学習した項目1の重みによる、露出局面の集合1,000局面に対する項目1の寄与の平均が−30センチポーン以下であるかで決める。手番側の王駒が露出しているので、寄与は手番側の評価を下げる負の値が期待される。−30は診断Aが置いた運用上の最小の差と同じ値である。比較のために、基本の教師で学習した項目1の重み（`data/strength-stage9/shelter2-basic-training`）による同じ集合の寄与の平均も記録する。基準を満たさなければ候補を作らず、見送りを記録する。 |
| 静止探索の末端で合わせる方式との関係 | 将棋の学習器が採る「静止探索の末端の局面の静的評価を深い探索値に合わせる」方式は、本書の対象外とする。本書は目標値の側だけを変え、入力の局面は変えない。両方を同時に変えると効果を切り分けられない。 |
| 候補の範囲 | 最初の候補は、段階開始版の学習PSTを固定し、項目1の24列だけを先読み教師で学習したものとする。採用された場合に限り、最初の候補を直前の採用版として、学習PSTと項目1を先読み教師で同時に学習した第2の候補を測る。第2の候補の結論は「先読み教師での同時学習の効果」と表現し、最初の候補との比較で判定する。 |
| 診断の記録 | 先読み値と探索値の差の分布（駒数の帯ごと）、急落局面の割合、窓の統計、および118列の特徴と先読み教師の残差との相関を記録する。これらは記録であり、事前の判定には使わない。 |

## 先読み値の計算

学習器は、各MNSDファイルを読むときに、対局番号ごとの記録について次の式で先読み値を計算する。

```text
u_s = v_s            （s − t が偶数のとき。局面sの手番が局面tの手番と同じ）
u_s = −v_s           （s − t が奇数のとき）
v̂_t = Σ_{s} γ^(s−t−1) u_s / Σ_{s} γ^(s−t−1)   （sは同じ対局で t < s ≤ t+n の記録された手数）
```

記録された手数がなければ `v̂_t = v_t` とする。
手番は着手のたびに交代し、じっとと獅子の2段階移動も全体で1手なので、手数の差の偶奇が手番の一致を決める。
計算は決定的であり、同じファイルとパラメータから同じ値が得られる。
学習器は、MNSDファイルの記録が対局番号の非減少順、同じ対局の中では手数の厳密な増加順に並んでいることを検査し、崩れているファイルは並べ替えずに拒否する。
γは0より大きく1未満、nは1以上4,096以下を受理する。

## 実装フェーズ

### フェーズ1　学習器の先読み値

学習器と診断器に、設定 `train.lookahead`（γとn）と対応するコマンドライン引数を加え、先読み値の計算、実数の配列の受け渡し、教師の分類の属性、教師Kの推定、付け直しファイルとの併用の拒否、および記録（`inputs.json`、`training.json`）への反映を実装する。
完了条件は、次のことがテストで固定されていることである。

- 手数の欠けた列、視点の反転、上限nでの打ち切り、窓に記録がない場合の退避が、小数になる手計算の例で定義どおりに計算され、教師Kの推定、訓練、検証、残差の診断の全経路で実数のまま使われる。
- 同じ入力とパラメータから同じ先読み値が得られる。
- 対局の順序が崩れた入力、γとnの範囲外、および付け直しファイルとの併用が拒否される。
- 先読み値を使う分類の教師Kが、現行の教師と別に推定され、γとnが分類と記録に入る。

### フェーズ2　差の分布の記録と項目1の学習

基本の教師の11ファイルについて、γ=0.9（候補）と0.7、0.95（記録のみ）の先読み値と探索値の差の分布、急落局面の割合、窓の統計、118列との残差相関、教師Kの比較、および露出局面と対照局面の教師値の勝率の差を記録し、測定記録 `lookahead-teacher-diag` に残す。
続けて、段階開始版の学習PSTを固定して項目1の24列をγ=0.9の先読み教師で学習し、学習後の診断（段階7と段階9の基準）を通したうえで、露出局面の集合に対する項目1の寄与で事前の判定を行う。
学習した重み、寄与、および判定は測定記録 `lookahead-teacher-shelter-training` に残す。

### フェーズ3　採否測定

判定を通過した場合、候補のコミット（特徴数の定数と重みファイルをそろえたもの）を作り、STC（`lookahead-teacher-shelter-stc`、基本シード42000921）とLTC（`lookahead-teacher-shelter-ltc`、基本シード45000921）で測る。
採用した場合は、学習PSTと項目1を先読み教師で同時に学習した第2の候補を、最初の候補を基準に `lookahead-teacher-joint-stc` と `lookahead-teacher-joint-ltc`（基本シード48000921と51000921）で測る。

## 検証

- 先読み値の計算は、手で計算した小さな対局列（記録の欠け、対局の境界、上限n、小数になる平均を含む）で固定する。
- 最初の候補の学習後の診断は段階9の「検証」の基準に従う。固定した学習PST、探索用駒価値、出力Kが1ビットも変わらないこと、量子化の前後の平均絶対誤差が2センチポーン以下であること、Rustと学習器の評価値が一致することを確かめる。
- 第2の候補では学習PSTが変わるので、固定の検査の代わりに段階7の駒除去差分の損失と符号の検査を学習PSTの部分に適用し、探索用駒価値と出力Kが変わらないことを確かめる。
- 敗局の174手目から182手目の局面について、項目1の寄与を記録する。この敗局は特徴の選定に使ったので、参考の診断であり、採否の基準にしない。
- 採否測定は[SPRTの手引き](../guides/sprt.md)の標準コマンドに従い、エンジン異常、時間切れ、拒否着手が0件であることを採用の条件にする。
- すべてのコミットで `cargo test`、`cargo clippy -- -D warnings`、`cargo fmt --check`、および学習器の単体テストが通ることを確かめる。

## 完了条件

- 差の分布、急落局面の割合、窓の統計、残差相関、教師Kの比較が測定記録に残っている。
- 項目1の先読み教師での重み、露出局面の集合に対する寄与、および事前の判定の結果が測定記録に残っている。
- 判定を通過した場合は、候補のSTCとLTCの結果と採否が記録され、採用した場合は第2の候補の採否も記録されている。
- 段階9の設計書の状態に、項目1の採否または見送りが本書の記録とともに反映され、[評価関数](evaluation.md)の「教師値と損失」と[PSTの学習手順](../guides/pst-training.md)に先読み値の定義と設定が反映され、ROADMAPの状態表が本書の結論と一致している。

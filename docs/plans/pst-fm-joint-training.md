# PSTとFMの同時学習の設計書

## 先に読む要約

本書は、評価関数の2つの部分であるPSTとFMを、1つの損失で同時に学び直す（joint training）。
PST（piece-square table）は駒の種類と升ごとの点数を足し合わせる線形の評価表であり、FM（Factorization Machine）は2駒の組の係数を各特徴に持たせた長さ32のベクトルの内積で表す補正項である（[FMの設計書](factorization-machine.md)）。
現行の評価関数は、先に学んだPSTを固定してFMの補正だけを学び、その補正を1/4に縮めたものなので、PSTの学習にはFMの補正が含まれていない。
同時学習では、2駒関係をFMが、駒と升の独立な寄与をPSTが受け持つように役割を分け直せ、PSTを学び直すたびにFMも学び直すという順序の依存も1回の学習で解消できる。
学習の教師は、探索値と対局結果を混合比λで混ぜた値であり、λ=0.75とλ=1.0の2つの候補をそれぞれ単一のλで学び、両方を対局で測る。
評価関数はa·PST＋b·FMの線形モデルとみなし、a=b=1に正規化して係数をPSTとFMの重みに吸収させるので、FMの補正の大きさは手で決めた係数ではなく損失と正則化で決まる（2026年10月7日の利用者の決定）。
現行の補正1/4は他の縮小率と比べて選んだ値ではないので、学習の初期値にも制約にも使わない。
学習は候補LのPSTと縮小前のFaのFMから始め、上限200エポックの早期終了で止める。
採否は、着手時のmasterに対する短時間条件STCと長時間条件LTCの段階ゲート（自己対局の勝敗から強さの差を逐次判定する検定、[SPRTの手引き](../guides/sprt.md)）で決める。
完了条件は、2つの候補の採否が測定記録とともに確定することである。

## 目的

現行の評価値は、採用PSTの候補L（[エポック数の延長](pst-longer-training.md)）に、候補Faの補正1/4のFM（[FMの再学習](fm-quarter-current-pst.md)）を加えたものである。
候補LはFMなしで学ばれ、FaはLを固定して学ばれたので、PSTは、FMが表す2駒関係の分まで駒と升の点数で近似したまま残っている。
両方を同時に学べば、2駒関係はFMが、駒と升の独立な寄与はPSTが受け持つように役割を分け直せる。
また、[ROADMAP](../ROADMAP.md)の次の候補の節が記すとおり、現行の方式ではPSTを学び直すとその上でFMも学び直す必要があり、評価関数の更新が2段の学習と2回の段階ゲートになる。
本書は、同時学習した評価関数が現行のmasterより強くなるかを対局で確かめる。

オセロ（リバーシ）の評価関数についての岡下と首藤の研究（参考資料）は、線形モデルとFMの相互作用項を同時に学習している。
線形部分だけを進行度で切り替えて潜在ベクトルを共通にする構造は、minaseのFMと同じである。
ただし同研究では、線形モデル単独が強豪のオセロエンジンEdaxと同じ特徴を使いながらEdaxに負け越しており、著者も学習不足を認めている。
したがって同研究が示したのは、学習不足の線形モデルに対するFMの優位であり、十分に学習した線形モデルに補正を加える方式に対する同時学習の優位ではない。
本書は同研究を構造の傍証として扱い、同時学習の効果の根拠とはしない。

## 適用範囲

本書の用語と記号を次のように定める。

- **M**は、着手時のmasterの先頭のコミットである。本書の起案時点では、その評価関数は候補LのPSTと候補Faの補正1/4のFMからなる。
- **J75**と**J100**は、それぞれλ=0.75とλ=1.0の教師で同時学習した重みを持つ候補のコミットである。
- **混合比λ**は、教師値の中の探索値の重みである。教師値は、探索値を勝率に換算した値にλを、対局結果（勝ち1、引き分け0.5、負け0）に1−λを掛けて足したものである。探索値は、同じ対局の後続の局面の探索値を減衰率γ=0.9で最大40手先まで平均した先読み教師（[PSTの学習手順](../guides/pst-training.md)）を使う。
- **ロジット**は、勝率pに対するlog(p/(1−p))であり、評価値（センチポーン）を出力K（Mの重みファイルの値1072.65）で割った値として扱う。FMの補正Φはこの単位で学ぶ。
- **出力係数a_f**は、FMの潜在次元f（1から32）ごとに置く符号付きの実数であり、Φ=Σ_f a_f Σ_{i<j} v_{if} v_{jf} x_i x_j の形で補正の大きさと符号を決める。v_iは特徴iのベクトル、x_iは特徴iが局面で成り立つかを表す0か1の値である。
- **補正の大きさ**は、検証集合から乱数シード1で選んだ1万局面でのΦの標準偏差をセンチポーンで表した値をいい、[FMの再学習の学習記録](../measurements/fm-quarter-current-pst-training.md)と同じ方法で測る。同記録では、Faの補正の大きさは補正1/4の前が273センチポーン、後が68センチポーンである。
- **2端点**は、PSTが持つ序中盤用と終盤用の2組の点数表であり、盤上の総駒数に応じた比率で混ぜて評価に使う（[PSTの序中盤と終盤の補間](tapered-pst.md)）。
- **MNPT**は、PSTとFMの重みを保存するminaseの重みファイル形式であり、バージョン3がFMを含む。

対象は次のとおりである。

- PSTとFMを同時に学ぶ学習器を `tools/train/src/minase_train/` に実装し、MNPTバージョン3で出力する。
- 2つの候補を学習し、正しさの検査を通過させ、段階ゲートで採否を決める。

次の事項は対象外とする。

- Rustの評価関数と重み形式の変更は行わない。同時学習で変わるのはMNPTバージョン3のPSTとFMの部分の値だけであり、推論と差分更新はMのまま使う。
- 補正なしのPSTを軽い評価として探索で使う仕組み（lazy evaluation）は、2026年10月7日の利用者の決定により、本書の後に別の設計書で扱う。そのために、候補LのPSTの重み `data/pst-longer-training/training/pst.bin`（MNPTバージョン2）と浮動小数点の重み `pst-float.npz` を変更せずに残す。
- 探索係数、探索用駒価値、および出力Kは変更しない。

## 依存関係

特徴、教師、検証の分割、および早期終了の定義は、[PSTの学習手順](../guides/pst-training.md)と[FMの再学習](fm-quarter-current-pst.md)に従う。
特徴番号は、PSTとFMの学習器が共有する `data/features.py` の13,680特徴（47駒状態×2陣営×144升と、先獅子の対象升144個）である。
学習の入力は、候補LとFaを学んだのと同じ自己対局データ、すなわち世代2の5ファイル（[棋力向上段階7](strength-stage7.md)で生成）と世代3の5ファイル（[世代3の再学習](pst-gen3.md)で生成）とする。訓練は27,745,843局面、検証は対局の識別子のハッシュで約5%を分けた1,462,975局面である。
GPU学習はGPUを利用できるホストで行う。codexのサンドボックスからはGPUを使えないので、学習の実行はcodexへ委任しない（[教訓](../lessons/run-gpu-training-outside-codex-sandbox.md)）。

## 設計判断

| 項目 | 決定 |
|---|---|
| 学習の方式 | PSTとFMを1つのモデルとして、1つの損失で同時に学ぶ（joint training）。モデルのロジットは、浮動小数点の2端点PSTを補間した評価値を出力Kで割り、FMの補正Φを足したものとする。FMの学習器は整数に切り捨てたPSTの評価を定数として足していたが、同時学習ではPSTにも勾配が要るので浮動小数点のPSTを使う。 |
| 教師の勾配を分ける案 | 採らない。PSTの重みをλ=0.75の教師、FMの重みをλ=1.0の教師で更新する案は、1つの出力に2つの目的を課す。PSTとFMが共通に表せる評価の方向では、2つの教師がその出力を別々の値へ引くので、互いの寄与を打ち消し合い、両者の重みの分け方が正則化や止めたエポックに左右され得る。FMは、各陣営に王駒が1枚の局面では、駒と王駒の全位置との組に係数を置くことでPSTの線形項と定数項を表せるので、共通の方向は実在する。チェス、将棋、オセロのエンジンの学習コードにも、1つの出力の部分ごとに教師を変える先例は見つからなかった（参考資料）。 |
| 教師の混合比 | 単一のλで学び、λ=0.75の候補J75とλ=1.0の候補J100の2つを作る（2026年10月7日の利用者の決定）。採用PSTはλ=0.75で学ばれた一方、PSTをλ=1.0で学び直すと約150 Elo負けた記録がある（[共適応の検証](eval-search-coadaptation.md)）。FMはλ=0.75で過学習した記録がある（[FMの設計書](factorization-machine.md)）。どちらの値にも反対の記録があるので、事前に1つへ絞らない。教師はどちらも先読み教師とし、探索値を勝率に換算する教師Kは、教師の分類ごとに訓練集合だけから推定する。 |
| 初期値 | PSTは候補Lの浮動小数点の重み `data/pst-longer-training/training/pst-float.npz`、FMは候補Faの浮動小数点の重み `data/fm-quarter-current-pst-fa/fm-float.npz` をそのまま使い、出力係数を1/4にしない。この初期値を既存の手順で量子化すると、PSTの両端点はMの重みファイルと一致し、FMの部分は補正1/4を施す前のFaの重みファイル `data/fm-quarter-current-pst-fa/fm.bin` と一致する。初期値は、PSTとFMを順に学んだときにそれぞれの損失を最小にした重みの組であり、手で選んだ値を含まない。したがってエポック0の評価はMではなく、対局で一度も測っていない組合せである。学習中に一度も現れない特徴の埋め込みを0に固定するマスクは、Faと同じく訓練集合とその鏡映から数え直す。 |
| 補正の大きさ | 評価関数をa·PST＋b·FMとみなし、a=b=1に正規化する（2026年10月7日の利用者の決定）。PSTの評価は重みについて線形であり、Φは出力係数a_fについて線形なので、aとbを別の学習変数として置いても、PSTの重み全体とa_f全体を定数倍すれば同じ評価を表せる。このため係数は重みに吸収させ、補正の大きさは損失と正則化項だけで決める。補正の大きさに上限を置かず、推論時の倍率も学習後の縮小も行わない。これは、FMの補正の強さを推論時に変える係数を設けず、大きさを学習時の正則化で決めるとした[FMの設計書](factorization-machine.md)の「現行PSTを固定し、FMを補正項として学習する」の節の方針に戻すものである。補正1/4は、重みファイルの指数を1増やすという最小の操作で得られる縮小率であり、これを定めたブランチ `fm-eval` の `docs/plans/fm-quarter.md` は他の縮小率を探索していない。 |
| 補正の大きさの代案 | 補正を1/4の水準以下に縮め戻す制約（projected rescaling）、学習後に補正を縮める変換、および補正の大きさが目標値に合うようにλresを選ぶ案は、いずれも根拠のない縮小率を前提にするので採らない。縮小率を複数作ってSTCで選ぶ案も、学習から決まる値ではないので採らない。初期値をMの重み、すなわちFaの出力係数を1/4にしたものとする案も採らない。早期終了は初期値の近くで止まり得るので、初期値に置いた1/4が学習の結果へ持ち込まれるからである。 |
| 補正の大きさの危険 | 損失を最小にする大きさのFMを対局で測った記録は、当時のPSTに対するSTCの約−240 Elo（[FMの設計書](factorization-machine.md)）だけであり、現行のPSTの上で学んだFaを縮めずに使った評価は対局で測っていない。同書の診断では、合法手ごとの着手前後の評価差のうちFMの補正分が平均で歩兵価値の0.9倍、最大で4倍に達し、探索の枝刈りの余裕値と同程度だった。同時学習ではPSTが補正の一部を受け持ち得るが、補正が小さくなるとは限らない。本書はこの危険を学習の制約で避けず、段階ゲートで判定する。補正が大きすぎて候補が棄却された場合の費用は、候補ごとに1本のSTC（約1〜8時間）である。棄却の原因を後から追えるように、「検証」の節で補正の大きさと着手前後の評価差を記録する。 |
| 鏡映 | 各局面を確率0.5で左右鏡映するデータ拡張を、モデル全体の入力に適用する。PSTは鏡映で対応する特徴の重みを共有するので鏡映の影響を受けず、FMは鏡映で対応する特徴の埋め込みを共有しないので拡張を要する。 |
| 駒除去差分の補助損失 | 駒除去差分は、盤上の王駒以外の駒を1枚取り除いたときの評価値の変化であり、自分の駒を除けば評価が下がり、相手の駒を除けば上がるべきである。候補Lの学習と同じく、除去差分の符号を参照の評価に合わせる補助損失（`tools/train/src/minase_train/pst/removal.py`）を係数1000で加える。同時学習では、対局で使うのはPSTとFMを合わせた評価なので、補助損失もその評価の除去差分に課す。参照は、駒得評価v0（`crates/minase/src/eval/handcrafted.rs`）とする（2026年10月8日の利用者の決定）。参照の表は、世代0のPSTの初期化に使った既存の関数 `initial_weights`（`tools/train/src/minase_train/data/mnpt.py`）の表、すなわちv0の駒の価値を全升へ、序中盤と終盤の両端点に同じ値で置いた表とする。v0の位置の加点はすべて0以上で除去差分の向きを変えないので、表に含めない。この表では、各駒の寄与は駒の価値（100センチポーン以上）だけであり、駒どうしの相互作用も補間の影響もないので、自駒を除けば評価は下がり、相手の駒を除けば上がり、向きが逆になることはない。例外は、除去の前後の評価が上限±28,999センチポーンに切り詰められる場合であり、差分は100センチポーンより小さくなるか、0になって補助損失の対象外になる。ただし、Lの訓練局面では、この表の評価が切り詰められる局面は0件だった。したがって、対象となる除去では下限幅はつねに0.25センチポーンとなり、参照の向きが逆の場合に限る上限の罰則は働かず、補助損失は「自駒を除けば少なくとも0.25センチポーン下がり、相手の駒を除けば少なくとも0.25センチポーン上がる」ことを求める単調性の制約になる。従来の学習は直前の採用PSTを初期値と参照の両方に使ってきたので、参照の除去差分に含まれる不自然な向き（自駒を除くと評価が上がる、または相手の駒を除くと下がる）を、符号の罰則によって世代をまたいで維持してきた。[採用PSTの過学習の診断](../measurements/pst-overfitting-diagnosis.md)では、Lの学習の参照（Pc）は、Lの訓練局面の全除去のうち5,691件で駒の持ち主から決まる向きと逆の符号を持ち、2,804件で整数差分が0のため補助損失の対象外だった。参照をv0へ替えると補助損失の定義が変わる局面は5,826局面で、訓練局面の0.021%に当たる。これらの逆向きが誤りであるとは確かめていないが、学習が教師のデータに基づいて直す余地を持たない点を改める。Mの評価を参照にしないのは、補正1/4が参照を通じて学習に持ち込まれるからでもある。初期値のLはPcの参照の符号を保つように学ばれたので、これらの逆向きを含んでいる見込みであり、その場合はエポック0の補助損失が0にならない。補助損失の形は現行の `removal_loss` をそのまま引き継ぐ。すなわち、参照の整数差分が0の除去は対象外とし、候補の差分には参照と同じ符号を、参照の差分の絶対値と0.25センチポーンの小さい方の下限幅で求め、参照の符号が駒の陣営から期待される方向と逆の除去に限って、差分の絶対値が参照を超えることにも罰則を課し、局面ごとに対象の除去で平均してから局面で平均する。この形は除去差分の符号を保たせるものであり、FMの補正の大きさそのものに上限を課さない。現行の関数はPSTの特徴重みだけを受け取るので、候補の差分を、駒数の変化による補間率の変更を含むPSTの差分と、出力Kを掛けてセンチポーンに直したFMの差分の和として受け取る形に改め、PSTとFMの両方に勾配が流れるようにする。FMの除去差分は、潜在次元ごとの埋め込みの和S_f=Σ_j v_{jf} x_jを使えば、特徴iの除去について −Σ_f a_f v_{if}(S_f − v_{if}) として全駒分をまとめて計算できるので、除去した局面ごとに評価を計算し直す必要はない。 |
| 最適化 | 1つのAdamWに2つのパラメータ群を置き、各部分の学習条件を候補LとFaの学習からそのまま引き継ぐ。PSTの群は学習率0.03、重み減衰0とし（Adamと同じ更新になる）、更新後に重みを[−4096, 4095.875]へ制限する。FMの群は学習率10⁻³、重み減衰10⁻⁴とし、補正を小さく保つ正則化項として、補正の二乗平均に係数λres=10⁻⁴を掛けて損失に加える。λres=10⁻⁴は、[FMの設計書](factorization-machine.md)が10⁻³、10⁻⁴、10⁻²を検証損失で比較して選んだ値である。ただし10⁻³との検証損失の差0.000003は乱数シードによるばらつき0.000011の内側であり、両者は区別できなかった（[学習記録](../measurements/fm-phase1-training.md)）。この比較はPSTを固定した当時の条件によるものであり、補正の標準偏差は0.218と0.227で異なった。PSTも更新する同時学習では、λresが予測をPSTとFMへ配分する比にも影響し得るが、その影響は測っていない。本書は、学習の本数を増やさないために、同時学習の条件でλresを選び直さない（2026年10月7日の利用者の決定）。過学習は主に早期終了で抑える。FMの重み減衰10⁻⁴は、AdamWが1更新ごとに各重みへ(1−学習率×重み減衰)=(1−10⁻⁷)を掛ける。減衰だけを取り出すと、上限の200エポック（338,800更新）で各重みは約3.3%縮み、補正は出力係数について1次、埋め込みについて2次なので補正全体では約9.7%縮む。実際の学習では勾配による更新が加わるので、この値は減衰の直接の効果の目安にとどまる。バッチは、評価の大部分を担うPSTの学習と同じ16,384とする。FMはすでに学習済みのFaから始めるので、Faの学習（バッチ4,096）より1エポックあたりの更新回数が約4分の1になることは許容する。乱数シードは1とする。 |
| 出力K、探索用駒価値 | Mの重みファイルの値をそのまま使い、学習しない。探索の枝刈りの余裕値と手の並べ替えは探索用駒価値から作られるので、候補の探索はMと評価値を通じてだけ異なる。 |
| 早期終了 | 一般的な早期終了の定義に従う。各エポックの後に検証損失を測り、最良値を厳密に下回れば最良の重みを更新し、最後に最良を更新したエポックから5エポック続けて更新がなければ止め、学習したエポックの中で最良の重みを返す。上限は200エポックとする。待つエポック数5は、評価の大部分を担うPSTの直近の学習（候補L）の値に合わせる。エポック0（学習前、すなわち候補LのPSTに縮小前のFaの補正を足した評価）の検証損失は記録だけにし、最良の候補に含めない。学習したエポックの最良の検証損失がエポック0を下回らなくても見送らない。 |
| 効果の切り分けの限界 | 候補Lの学習は上限の200エポックでも検証損失が下がり続けており、PSTにはまだ学べる余地がある。J75は、PSTをLと同じλでさらに学ぶことも含むので、J75が強くなっても、その向上が同時学習によるのか、PSTの追加学習によるのかを分けられない。測定の費用を抑えるため、PSTだけを追加学習する対照は置かない。J75を採用した場合は、ROADMAPの次の候補「さらに長い学習」の効果もJ75に含まれたものとみなし、その候補を別に測らない。また、両候補とMとの差には、補正の大きさの変化と、補助損失の参照をv0へ替えた効果も含まれる。 |
| 過学習を疑う兆候 | λ=0.75では、当時のFMの学習で、訓練損失が下がる一方で1エポック目から検証損失が上がった記録がある。同じ対局の局面は対局結果を共有するので、FMが動かない駒の組から対局を識別してその結果を記憶したことが原因と考えられた。今回は学習済みの初期値とPSTの同時更新があるので、同じ現象が起きるとは限らないが、補正の大きさに上限を置かないので、上限による抑えもない。訓練損失と検証損失を両方記録し、両者が逆向きに動いた場合は過学習を疑う兆候として記録するが、原因を断定はしない。この場合も、規則どおり最良エポックの重みを対局で測る。 |
| 採否 | J75とJ100をそれぞれMに対して標準のSTCとLTCで測り、LTCで`H1`（候補が有意に強い）かつエンジン異常、時間切れ、拒否着手が0件の候補を採用の対象とする。2つの候補をLTCまで測ることは、[SPRTの手引き](../guides/sprt.md)の「パラメータ違いはSTCまでに1つへ絞る」の例外であり、2026年10月7日の利用者の決定による。採用の対象が1つならそれを採用する。2つとも採用の対象になった場合は、[FMの再学習](fm-quarter-current-pst.md)と同じく、J75を候補側、J100を基準側として、対称な仮説（H0 elo=−5、H1 elo=+5）のGSPRTで直接対局させる。時間制御はSTC、上限は3,000ペアとし、`H1`ならJ75、`H0`ならJ100を採る。上限で判定が保留になった場合は、停止時点の点推定のEloが正ならJ75、0以下ならJ100を採る。この直接対局は、両者がMより強いことを段階ゲートで示した後に、どちらを載せるかを決めるためだけに使う。 |
| 代理指標の扱い | 検証損失と探索速度は記録するが、採否の条件にしない。 |

## 学習器

学習器は、PSTの学習器のモデル（鏡映共有の2端点PST）とFMの学習器のモデルを部品として再利用し、新しいコマンド `train-joint` として実装する。
入力は、Mの重みファイル（出力K、探索用駒価値、および規則セットの読み出し用）、候補LとFaの浮動小数点の重み、学習データ、λ、および先読みの設定である。
1バッチの処理は次のとおりである。

1. 局面の特徴を作り、確率0.5で鏡映する。
2. PSTの補間値を出力Kで割った値にΦを足して、ロジットとする。
3. 先読み教師とλから教師値を作る。
4. 二値交差エントロピーに、Φの二乗平均（係数λres）と、PSTとFMを合わせた評価の駒除去差分の補助損失（係数1000、参照はv0）を加えて、損失とする。
5. 更新し、PSTの重みを範囲に制限し、一度も現れない特徴の埋め込みを0に戻す。

出力は、PSTの部分を8倍して丸めたi16（PSTの学習器と同じ1/8センチポーン単位）、FMの部分を既存の `quantize` で量子化した値とし、MNPTバージョン3で書く。
補正1/4の変換は行わない。
FMの学習器の `validate_fixed_base` はPSTの不変を検査するので、同時学習では探索用駒価値と出力Kの不変を検査する形に置き換える。
学習の記録には、各エポックの訓練損失、検証損失、および補正の大きさを残す。

## 所要時間の見積り

時間は、同時対局数16の測定機での見積りである。
学習の1エポックの時間は、PSTだけの学習とFMだけの学習がそれぞれ約2分だったことから約3〜4分と見込むが、同時学習では駒除去差分のFMの計算が加わるので、フェーズ2の最初に試走して見積りを改める。
対局の時間は、[FMの再学習](fm-quarter-current-pst.md)の見積りと実績に基づく。

| 段階 | 内容 | 見積り |
|---|---|---|
| 準備 | 学習器の実装と検査 | codexへの委任で数時間 |
| 1 | J75とJ100の学習（GPUで同時に） | 早期終了で数十エポックなら数時間、上限の200エポックなら約1日 |
| 2 | J75とJ100のそれぞれのSTC | 1本あたり約1〜8時間（判定までのペア数は強さの差で変わる） |
| 3 | 通過した候補のLTC | 1本あたり約5〜30時間 |
| 4（条件付き） | J75とJ100の直接対局 | 約1〜8時間 |

全体では、両候補が早く学習を止めてSTCで棄却される場合の約半日から、両候補が上限まで学習してLTCまで進み、直接対局も行う場合の約5日までとなる。

## 実装フェーズ

### フェーズ1　学習器

「学習器」の節のとおり `train-joint` を実装する。
次の4つのテストを加える。
1つ目は、初期値をそのまま量子化した重みファイルのPSTの部分がMの重みファイルと、FMの部分が `data/fm-quarter-current-pst-fa/fm.bin` と、それぞれバイト単位で一致することである。
2つ目は、初期値の浮動小数点の評価と、量子化した整数の評価の差が、平均絶対誤差2センチポーン以下であることである。
3つ目は、補助損失のためにまとめて計算した駒除去差分が、駒を実際に1枚ずつ除いて評価し直した差分と一致することである。
4つ目は、補助損失の勾配がPSTの重み、FMの埋め込み、および出力係数のすべてに流れることである。
完了条件は、学習ツールの単体テストの通過と、実装のコミットである。

### フェーズ2　学習と候補の作成

最初に、J75とJ100を同じGPUで同時に数百更新だけ試走し、1エポックあたりの時間と最大メモリを測って、所要時間の見積りを改める。
J75とJ100を学習し、最良エポックの重みを `crates/minase/nets/pst.bin` へ書き込み、重みに依存するテスト（初期局面の評価値など）を更新して、それぞれコミットする。
候補ごとに、「検証」の節の正しさの検査を行い、benchの探索速度をMと比べて記録する。
benchは、[FMの再学習の学習記録](../measurements/fm-quarter-current-pst-training.md)と同じくtasksetで性能コアに固定して測る。
結果は測定記録 `pst-fm-joint-training-training` に2つの候補をまとめて残す。
完了条件は、候補ごとの検査の通過とコミットである。

### フェーズ3　採否測定

測定機で `minase match run` と `match_runner` が他に動いていないことを実行ファイル名で確かめてから、J75とJ100をそれぞれMに対してSTCで測り、[SPRTの手引き](../guides/sprt.md)のSTCの振り分け規則に従ってLTCへ進める。
2つの候補の測定は同時に走らせず、順に行う。
runnerはMでビルドした `minase` を専用の場所へ複製して固定する。

```console
<固定したminase> match run \
  --run-dir data/matches/pst-fm-joint-training-j75-stc --seed 26000000 \
  --candidate commit:<J75> --baseline commit:<M> \
  --each time=10000+100 --concurrency 16 gsprt --max-pairs 3000
```

J75のLTCは測定名の接尾辞を `-ltc`、基本シードを27000000、時間制御を `time=60000+200` とし、`--max-pairs` を付けない。
J100はSTCの基本シードを28000000、LTCを29000000とし、測定名の `j75` を `j100` に替える。
直接対局は、測定名 `pst-fm-joint-training-j75-vs-j100-stc`、基本シード47000000で、`gsprt --elo0 -5 --elo1 5 --max-pairs 3000` とする。
採否を記録し、採用した場合は[評価関数](evaluation.md)の現行設計と[PSTの学習手順](../guides/pst-training.md)を改める。

## 検証

- 量子化の前後の評価（FMを含む）の平均絶対誤差が2センチポーン以下であること。
- `fm-diagnostics` を同時学習用に改めた検査で、10万局面のRustの評価と学習器の整数評価が完全に一致すること。
- 各候補の重みファイルの探索用駒価値と出力Kが、Mの重みファイルとバイト単位で一致すること。
- FMを含む評価での駒除去差分が、駒の持ち主から決まる向きと逆になる件数と、差分が0になる件数を、訓練局面の全除去で数え、Mの件数と並べて記録すること。この件数は採否の条件にしない。
- 各候補の補正の大きさを、Faの補正1/4の前後の値（273センチポーンと68センチポーン）と並べて記録すること。合法手ごとの着手前後の評価差のうちFMの補正分の平均と最大を、[FMの設計書](factorization-machine.md)の「不採用の結果の解釈」と同じ方法で測り、Mの値と並べて記録すること。いずれも採否の条件にしない。
- 各候補とMの間で、`crates/` の差が重みファイルと重みに依存するテストだけであること。`tools/train/` の学習器と診断器の変更はエンジンの挙動に影響しないので、この条件から除く。
- `cargo test`、`cargo clippy -- -D warnings`、`cargo fmt --check`、および学習ツールの単体テストが通過すること。
- 採否の測定でエンジン異常、時間切れ、および拒否着手が0件であること。段階ゲートで開始する最初の測定で1件でも出た場合は、測定を止めて原因を調べる。

## 完了条件

- 2つの候補の学習の記録、正しさの検査、探索速度、および採否または見送りが測定記録に残っている。
- 採用した場合は、[評価関数](evaluation.md)の現行設計と[PSTの学習手順](../guides/pst-training.md)に同時学習の手順が反映され、[FMの設計書](factorization-machine.md)と[FMの再学習](fm-quarter-current-pst.md)から本書へリンクされている。
- 不採用の場合は、学習器をmasterへ統合せず、結論と測定記録だけをmasterへ残す。
- ROADMAPの状態表が本書の結論と一致している。

# 残存誤りに対応する関係補正項の設計書

## 先に読む要約

本書は、評価関数PSTでは表せない駒どうしの関係による誤りが残っているかを、過去の診断に使っていない新しい自己対局の局面群で調べ、残っていればその関係を表す補正項を1つだけPSTに加えて、棋力が上がるかを確かめる。
PSTは駒の種類と升ごとの点数を足す現行の評価方式であり、同じ升の駒の価値を周囲の駒によって変えられない。
候補の補正項は、近くの2駒の種類と間隔を採点する局所2駒表、王駒から見た遮蔽物とその奥の敵の走り駒を採点する射線表、および3駒以上の同時条件を表せる小型の差分更新ニューラルネットNNUEの3種類である。
まず、深い探索が安定して判定した根のうち、浅い探索が大きく誤った根を集め、実際に読んだ深さと評価値を追跡して、探索の変更で誤りが解消するかを確かめる。
解消を確認できなかった根は原因未確定として残し、配置の違いを説明する駒の関係を事前に固定した規則で分類する。
同じ種類の関係で配置の違いを説明できる根が基準の件数に達した場合だけ、その関係に対応する補正項を1つ選んで実装し、どれも達しなければ実装せずに見送る。
補正項は0で初期化し、PST、学習データ、教師値、および学習方式を採用構成に固定して補正項だけを学習するので、学習前の評価は採用版と一致し、変化を補正項に帰属できる。
採否は、補正を加えた版を着手時のmasterにある採用版S0と、逐次確率比検定GSPRTによる短時間条件STCと長時間条件LTCの自己対局で比べて決める（[手引き](../guides/sprt.md)）。
完了条件は、分類による見送り、候補の不採用、または候補の採用のいずれかが測定記録とともに確定することである。

## 状態

完了（見送り）。2026年10月1日に、フェーズ0の分類による見送りで完了した。
新しい自己対局2,048局から採った1,974根のうち、教師の判定が安定した大きな誤りは92根で、探索の変更で解消を確認できなかった根は62根だった。
2者の分類が一致した根は近接2駒の15根が最多で、着手の基準であるNの3分の1（21根）に届かなかったので、補正項は実装していない（[準備記録](../measurements/relational-correction-prep.md)）。
探索の変更で解消した30根では、null move、aspiration window、およびLMRの単独の介入がそれぞれ12〜14根の誤りを解消したが、1根で複数の機構が選択を変えることが多く、機構を誤りの原因とは特定していない。
利用者の確認を待っていた追跡時間の上限は、2026年10月1日に利用者が本計画の遂行を指示したことにより、本書の案のまま採用した。
自己選択の閾値を引き継ぐ前提は、補正項を選ばなかったので使っていない。

## 目的

本書は、「独立した局面群で確認した配置に依存する誤りに対応する関係を補正項として加えると、同じ持ち時間で棋力が上がる」という仮説を検証する。
[相対2駒評価の計画](relative-pair-eval.md)は、6根の分類で配置に依存する誤りを1つも確認できず、2026年9月26日に未実装で見送った（[準備記録](../measurements/relative-pair-prep.md)）。
ただし6根は、教師が安定して判定した203根から損失の大きい順に選んだ小さな標本であり、関係の種類も局所的な2駒の組だけを判定した。
本書は、標本を独立に取り直して大きくし、局所的な2駒の組に加えて王駒の射線と3駒以上の条件も分類の対象にする。

本書が問うのは、分類で選んだ1つの補正項がS0を改善するかどうかであり、3種類の補正項の優劣は比べない。
探索の変更で解消を確認した根は探索の後続計画へ引き渡し、残る根の数と関係の分類が着手の基準を満たした場合だけ補正項を実装する。

## 適用範囲

本書の用語を次のように定める。
S0は、着手時のmasterにある採用PSTと探索のコミットを指す。
**王駒**は王将、玉将、および太子を指す。
**大きな誤り**は、教師の判定が安定した根で、S0の100,000ノードの提案手の選択損失が判定の差m以上である根を指す。
mと安定した根の定義は[探索局面の計画](search-aware-evaluation.md)に従い、mはS0が変わった場合に同計画の校正の手順で測り直す。

本書で実装するものは次のとおりである。

- 探索局面の計画のブランチから、履歴つきの自己対局の生成器と診断器を移し、1局から1根を抽出してその根だけを診断器へ渡す処理を加える。
- 分類で選んだ補正項1つについて、推論、差分更新、重み形式、学習器、および診断を実装する。
- 分類で一致した根の2つの子局面をS0の訓練予算（100,000ノード）で探索し、訓練教師の探索値の部分が配置差を識別するかを代理診断として記録する処理を診断器に加える。

次の事項は本書に含めない。

- 補正項を2種類以上同時に実装したり、比べたりしない。
- 利きの特徴を対局中に計算する構成は扱わない。全盤の利き表は、段階9で定めた1秒あたりの探索ノード数（NPS）の下限である基準の0.90倍に対し0.816倍にとどまった（[利き表の測定](../measurements/strength-stage9-table-bench.md)）。
- 探索、学習目標、および教師値の作り方は、着手時の採用構成から変えない。
- 規則は`engine-default`、すなわち`L0,P0,R1,E0`に固定する。

## 依存関係

補正項の数式、容量、および差分更新は[評価表現の構成案](../research/evaluation-architecture-candidates.md)を正とする。
局所2駒表の学習の契約、出現の少ない要素の扱い、自己選択の診断、および倍率の決め方は、[相対2駒評価の計画](relative-pair-eval.md)の設計判断を引き継ぎ、射線表と小型NNUEにも同じ契約を当てる。
教師値については本書の比較条件を優先し、着手時の採用構成と同じ定義、混合比、および尺度を使う。
小型NNUEの初期化は[第1層の飽和の教訓](../lessons/nnue-first-layer-init-saturation.md)に従う。
棋力の採否は[SPRTの手引き](../guides/sprt.md)に従う。

フェーズ0には、着手の履歴を保存する自己対局の生成器と、根を履歴ごと復元して候補手の子局面を独立に探索する診断器が必要である。
どちらも探索局面の計画のブランチ`search-aware-evaluation`にある。
これらは実験専用の道具として同ブランチから本書のブランチへ移して使い、補正項の採否にかかわらずmasterへは統合しない。
同計画の生成器は1局から16根を採る条件を検査し、診断器は同計画の分割と教師の応答の形式を入力に要求するので、1局1根の抽出と、その根だけを診断器へ渡す処理を本書で加える。

診断用の対局の生成と教師の探索、学習、および段階ゲートは測定機を使うので、他の計画の生成や測定と重ねずに予定する。

## 設計判断

| 項目 | 決定と理由 |
|---|---|
| 診断の標本 | S0の自己対局を新しく生成し、1局から1根を無作為に採る。過去の診断に使った根を含まないことで、6根や250根で見た結果に合わせて規則を選ぶことを防ぐ。1局1根とするのは、同じ対局の根が独立でないためである。根は1,024根ずつ追加し、各回の追跡を終えた時点で、探索の変更による解消を確認できなかった大きな誤りが30根以上になるか、合計4,096根に達したら採取を止める（「誤りを分類する」の節）。 |
| 誤りの型 | [相対2駒評価の準備記録](../measurements/relative-pair-prep.md)と同じ規則で、S0の名目深さの内側で駒の損得が決まる型S、その先で決まる型H、駒の損得のない型Pを記録する。この分類は読み筋の暫定的な記述であり、原因の判定には使わない。型Sも追跡の対象とし、名目深さだけで関係の分類から除外しない。 |
| 探索の関与 | [静止探索の計画](qsearch-output-training.md)の追跡手順を新しい根にも適用する。実際の到達深さ、値の種類、および評価した末端を記録し、機構を1つずつ変える。固定深さでの変化と、100,000ノードで選択損失がm未満に下がることの両方を確認できた根だけを、探索の変更で解消した根として扱う。それ以外は原因未確定として残す。 |
| 関係の種類 | 探索の変更による解消を確認できなかった根を、型S、H、Pを問わず、近接2駒、王駒射線、多駒、不明の4種類に分ける（定義は「誤りを分類する」の節）。分類は補正項の仮説を選ぶために使い、表現力の不足が原因だと確定するものではない。 |
| 分類の独立性 | 2つの独立したエージェントへ、同じ規則、読み筋、および追跡結果を渡す。期待する補正項と相手の分類結果を知らせずにそれぞれ分類させ、両者が一致した根だけを種類ごとの件数に数える。不一致の根も、着手の基準の分母からは除かない。 |
| 着手の基準 | 採取を止めた時点で、探索の変更による解消を確認できなかった大きな誤りの総数をNとする。Nが30未満なら標本不足として見送る。Nが30以上なら、一致した根が最も多い種類について、その件数がNの3分の1以上（30根なら10根以上）であれば、その種類の補正項を実装する。不明と分類不一致もNに含める。同数の場合は、係数の少ない順に王駒射線、近接2駒、多駒を選ぶ。どの種類も基準に届かなければ見送る。30根は、ある種類の真の割合が2分の1のとき、3分の1以上を観測する確率が二項分布で約98%となる標本数であり、3分の1は選んだ関係が残る誤りの主要な型であることを求める値である。 |
| PSTの固定 | 着手時の採用PST、探索用駒価値、および出力の尺度を固定し、補正項だけを学習する。改善または悪化を補正項に帰属させるためであり、相対2駒評価の計画と同じ扱いである。 |
| 初期化 | 補正項の出力は0から始める。局所2駒表と射線表は表を0で初期化し、小型NNUEは最終層だけを0にして、それ以前の層には飽和しない非零の初期値を与える。 |
| 教師値 | 着手時の採用構成と同じ教師値を使い、探索値と対局結果の混合比λ、および教師の尺度も変えない。表現の追加と教師値の変更を分離するためである。対局結果を含む場合は、[対局結果の記憶を防ぐ教訓](../lessons/game-constant-target-memorization.md)が認める監視つきの条件を適用し、対局単位の検証損失を最初の区間から記録する。訓練損失が下がる一方で検証損失が上がる場合は、保存済みの区間を比較して過学習の有無を判定し、λを変更して本実験を続けない。混合比の変更が必要なら、同じモデルとデータで教師値だけを変える別の比較を起案する。この訓練教師は、フェーズ0で候補手を識別する両予算の診断教師とは別物である。訓練教師は先読みの平均と対局結果の混合であり、指されなかった子局面には作れないので、診断教師が識別した配置差を訓練教師が識別するかは直接には確かめられない。「誤りを分類する」の節の代理診断と「補正項を実装して学習する」の節の学習後の確認で記録し、どちらも見送りや不採用の条件にはしない。 |
| 学習目標 | 着手時の採用構成の学習方式を、補正を加えた評価全体に当てる。静止探索の出力の回帰や順位の損失が採用されていれば、それも含める。 |
| 出現の少ない特徴 | 相対2駒評価の計画は、学習局面での出現が200局面未満の表要素を0に固定する。射線表も同じ規則を表の要素ごとに当てる。小型NNUEでは、入力特徴（第1層の行）の出現を数え、200局面未満の入力特徴の行を0に固定して学習しない。隠れ層には規則を当てない。 |
| 局所2駒表の形 | 相対2駒評価の計画の直接表を基本とし、同計画の規則で半径を決める。出現の少ない要素を0に固定する規則で、選んだ半径の要素の半数以上が0になる場合は、ランク16の低ランク分解で学習して推論前に表へ展開する方式に替える。少ない標本で係数を推定するための選択であり、どちらか1つだけを実装する。 |
| 倍率 | 相対2駒評価の計画の自己選択の診断で、倍率1か1/4の一方を決める。Factorization Machineの補正は倍率1/4だけが採否測定を通過しており、補正の振幅が採否を分けたためである。この診断の閾値$G^\ast$はFactorization Machineの補正1/4で校正された値であり、別のモデルへ移せることを保証する尺度の理論はない。本書は、Gが補正項の種類にかかわらず、凍結したPSTの出力へ加える補正のセンチポーン単位の偏りを、候補自身が指した局面の同じ抽出方法で測る量であることを根拠に、$G^\ast$を3種類の補正項へそのまま適用する前提を置く。この前提と、適用しない場合の代案を採らない判断は、フェーズ0で補正項を選んだ直後、フェーズ1の実装を始める前に測定記録へ固定し、待機や先送りを設けない。学習済みの候補のGは、相対2駒評価の計画と同じくフェーズ3で測り、倍率1、次いで1/4の順に$G\le G^\ast$を判定し、どちらも満たさなければ見送る。倍率を決めた後の重みで、他の採否前の診断を行う。 |
| 小型NNUEの幅 | 構成案のとおり、隠れ層の幅を64とする。構成案は幅64から始め、64で関係の誤りが残る場合に128を比べる順序を定めており、本書は1つの補正項だけを試すので最初の幅に固定する。 |
| 速度 | 評価単体、着手時の更新、および探索全体の時間を分けてbenchで記録するが、採否の条件にはしない。局所2駒表の半径だけは、相対2駒評価の計画の速度の規則で決める。最終判断は同じ持ち時間の対局で行う。 |
| 採否 | PST、学習データ、教師値、および学習方式を固定し、補正を加えた版をS0と直接比べる。PSTだけを学習し直した対照は、PSTが変わらないので設けない。 |

## 誤りを分類する

フェーズ0では、S0で自己対局を1,024局ずつ生成し、各局から1根を無作為に採る。
各根で、S0の100,000ノードの提案手と教師の両予算の提案手を候補集合とし、各子局面を1,000,000ノードと10,000,000ノードで独立に探索して、安定した根と大きな誤りを判定する。
大きな誤りの各根で、教師の最善手とS0の提案手の子局面を10,000,000ノードで探索して読み筋を得て、[準備記録](../measurements/relative-pair-prep.md)の規則で型S、H、Pに分ける。
この型は読み筋で駒の損得が現れる位置を記述するだけであり、名目深さが各枝で実際に読んだ深さを保証しないため、型Sを探索の見落としと断定できない。

次に、すべての大きな誤りで[静止探索の計画](qsearch-output-training.md)の追跡を行う。
教師の読み筋に沿って手の探索の有無、削減後の残り深さ、枝刈りの理由、返り値が正確な値か上界か下界か、および静止探索で評価した末端を記録する。
評価値と読み筋の違いに関わる機構を1つずつ変え、まずS0と同じ完了深さで変化を調べ、その後100,000ノードで根の選択損失を測る。
介入後の提案手も教師の両予算で独立に評価し、元の候補集合での教師最善手に対する損失を求める。
その比較が安定した支持にも小差にも当たらない場合は、解消を確認できなかった根として残す。
この診断では評価関数と教師の条件を変えず、固定深さでの変化と、固定ノードで選択損失がm未満に下がることの両方を確認した根だけを、探索の変更で解消した根として記録する。
その根は探索の後続計画へ引き渡し、関係の分類から除くが、評価関数が誤りに関与していなかったとは結論しない。
解消を確認できない根は、型S、H、Pを問わず残し、追跡が不十分な根や複数の機構が関わる根も原因未確定として数える。

各回の1,024根の追跡を終え、残る大きな誤りが30根以上になるか、合計4,096根に達した時点で採取を止める。
採取の停止は関係の分類を見る前に判定し、最後の回で30根を超えた場合も、残ったすべての根を分母Nに含める。
過去の診断では安定した根の約3%が大きな誤りだったので、1,024根あたり25根前後の大きな誤りを見込むが、そのうち探索の変更で解消する割合は分からない。

追跡の費用には、根の数とは別に時間の上限を置く。
1根の追跡は、[静止探索の計画](qsearch-output-training.md)のフェーズ0で測った6根の追跡時間の中央値の3倍を上限とし、上限に達した根は原因未確定として残してNに含める。
1回の1,024根で追跡に使う合計時間は実時間4時間を上限とし、上限に達した回は残る大きな誤りを追跡せずに採取を止め、フェーズ0を診断未完了として記録して見送る。
1根の追跡時間には、追跡用ビルドによる探索、機構ごとの再探索、および介入後の提案手の教師評価を含め、測定機で同時16の並列度、S0の探索版で測る。
3倍と4時間は費用配分のための選択であり、追跡が十分であることを保証する統計的な上限ではない。
この見送りは費用による中断であり、関係補正が不要だったという結論には置き換えない。

残る根は、準備記録と同じく、浅い探索の提案手と教師の最善手の2つの子局面と、教師の最善手の読み筋の最初の6手に関与する駒を対象に、関係の種類を判定する。
関与駒は、その6手で動く駒と取られる駒である。
読み筋の末端では関与駒がすでに取られていることがあるので、末端の局面は分類の対象にせず、関係の帰結を確かめる証拠として使う。
2つの子局面の違いを、次の4種類に分ける。
チェビシェフ距離は、2升の筋の差と段の差の絶対値の大きい方である。

- 近接2駒は、少なくとも一方が関与駒で、互いのチェビシェフ距離が2以内の駒の組の配置によって違いを説明できる場合である。取る駒と取られる駒の接近、隣の駒による支え、および隣の駒による進路の塞ぎを含む。
- 王駒射線は、違いが、王駒から8方向のいずれかにある最初の駒と、その奥にある王駒へ向かう敵の走り駒の組の配置で説明できる場合である。
- 多駒は、違いが3枚以上の駒の同時の条件によって初めて説明でき、王駒射線に当たらない場合である。
- 不明は、上のいずれでも説明できない場合である。

近接2駒は局所2駒表、王駒射線は射線表、多駒は幅64の小型NNUEに対応する。
これらの分類は、配置の違いを表す候補を選ぶための仮説であり、分類だけでは誤りの原因を表現力の不足と確定しない。
この4種類の定義、探索の変更で解消したと判定する条件、採取の停止規則、追跡時間の上限、および着手の基準は、根の内容を見る前に測定記録`relational-correction-prep`へ固定する。
記録には型S、H、Pごとの全件数、探索の変更で解消した件数、残る件数、関係の種類が一致した件数、不明、分類不一致、および時間の上限で中断した根と回を残し、分母Nを再計算できるようにする。

補正項の種類を選んだ後、フェーズ1へ進む前に、選んだ種類で一致した各根について、教師の最善手とS0の提案手の2つの子局面をS0の重みで100,000ノード探索し、根の手番側へ符号をそろえた差を求めて記録する。
この予算は採用構成の学習データを生成した探索の予算であり、訓練教師のうち探索値の部分に当たるが、訓練教師そのものではない。
訓練教師は先読みの平均と対局結果の混合であり、順位の損失が採用されていれば教師の順位も含むので、指されなかった子局面には同じ教師値を作れない。
そのためこの比較は代理診断であり、差がm以上で診断教師と同じ手を支持する根の割合を記録するだけで、実装へ進むかどうかの条件にはしない。
実際の訓練ラベルによる識別の確認は本書では行わないまま進み、学習後には「補正項を実装して学習する」の節のとおり、同じ根での着手の改善だけを記録する。
いずれの確認も、教師とS0が同じPSTに由来する盲点を除くものではない。

## 補正項を実装して学習する

フェーズ1からフェーズ3は、分類で選んだ補正項1つについてだけ行う。
補正項の数式、特徴、および差分更新は、構成案の該当する節のとおりに実装する。
実装後、補正を0にした状態の評価と探索が、固定の局面集を固定の深さで探索する速度計測コマンド`bench`で、S0と総ノード数と最善手まで一致することを確かめる。

学習データは、着手時の採用構成を学習したものと同じ局面と教師値を使い、訓練集合と検証集合の対局単位の分割も引き継ぐ。
教師値の混合比と尺度、および静的回帰、静止探索出力の回帰、順位損失のいずれを使うかは採用構成に合わせて固定し、区間ごとに訓練損失と対局単位の検証損失を記録する。
採用構成が対局結果を教師に含む場合も混合比を変えず、最初の区間から対局結果の記憶による過学習を監視する。
訓練損失と検証損失の乖離を判定する区間と規則はフェーズ2の開始前に固定し、記録する。
過学習を確認した候補は採否前の診断へ進めず不採用とし、教師値の変更は別の比較で扱う。
小型NNUEでは、駒の多い局面、疎な局面、および王駒2枚の局面で、第1層の上下の飽和率を最初の区間の前後で記録する。
いずれかの局面群で第1層の過半の成分が常に飽和している場合は、[教訓](../lessons/nnue-first-layer-init-saturation.md)の初期化の不具合として学習を止め、初期化を直してから学習し直す。

学習後、分類で一致した根は学習データに含まれないので、補正を加えた評価による100,000ノードの提案手をこれらの根で求める。
提案手が元の候補集合にない場合は、「誤りを分類する」の節の介入後の提案手と同じく、その子局面を両予算で独立に評価して安定性を判定し、安定した支持にも小差にも当たらない根は比較不能として件数を記録し、割合の分母から除く。
比較できた根のうち選択損失がm未満に下がった根の割合を記録する。
この割合は学習後の着手の改善の記録であり、教師、表現、最適化、および探索を合わせた結果なので、訓練教師の識別能力を単独で示すものではなく、採否の条件にもしない。

## 採否前の診断

最初に、フェーズ1の前に固定した閾値$G^\ast$を使い、相対2駒評価の計画の自己選択の診断で倍率を1か1/4に決め、どちらも基準を満たさなければ見送る。
以後の診断と対局は、この倍率を掛けた重みで行う。
次に整合性の検査として、RustとPythonの評価と差分更新の一致、量子化の誤差、および駒除去差分の符号を調べる。
最後に、[静止探索の計画](qsearch-output-training.md)と同じ250根で着手と評価を診断し、同計画の規則でS0より有意に悪化した候補は対局へ出さずに不採用とする。
この規則は、総論が挙げる「候補手順位と過大評価が改善したモデルだけを対局へ進める」条件を、対局前の必須条件にはしない。
約200根の標本では小さな改善を識別できないため、有意な悪化を検出した候補だけを除き、診断の通過を改善や非劣性の証明とは扱わない。

## 棋力の採否

候補の重みと推論のコードをS0に加えたコミットを作り、S0とのSTCとLTCを標準の段階ゲートで行う（`relational-correction-stc`、`relational-correction-ltc`）。
LTCが`H1`で、エンジン異常、時間切れ、および拒否着手が0件の場合だけ採用する。
STCで先へ進めなかった場合は、S0に対する10 Eloの改善を示せなかったと記録して不採用で完了する。

## 停止と後続の判断

分類で見送った場合は、原因が未確定の根を含む分類の件数と、探索の変更で解消した根の引き渡しを記録して完了する。
この結論は、その標本と規則の下で関係を表す補正項を着手する根拠がなかったことに限られ、関係を表す評価方式全般を否定しない。
不採用の場合は、選んだ補正項と倍率が本書の条件で棋力を上げなかったと記録し、他の種類の補正項を続けて試すことはしない。
他の種類を試すには、改めて独立した標本で分類をやり直す計画を起案する。

採用した場合は、[評価関数の設計書](evaluation.md)、重み形式の説明、および[学習の手引き](../guides/pst-training.md)を更新する。

## 所要時間の見積り

| フェーズ | 主な計算 | 見積り |
|---|---|---|
| 0 | 1,024局ずつの生成と、根の候補手と根の探索、大きな誤りの読み筋の探索、および機構ごとの追跡 | 生成と教師探索は1,024根あたり約1時間、上限の4,096根で約4時間。追跡は1回あたり4時間を上限とし、最大4回で16時間。 |
| 1〜3 | 実装、学習、および250根の診断 | 学習はフェーズ1で実測して見積もる、診断は約15分 |
| 4 | STC 1本とLTC 1本 | STCは約1時間から8時間、LTCは約4時間から21時間 |

フェーズ0の生成は、1局約400手を100,000ノードで指す過去の生成の速度から約30分と見積もる。
教師の探索は、1根あたり最大3つの子局面と根の局面をそれぞれ約7.4秒（10,000,000ノードの約6.7秒と1,000,000ノードの約0.7秒）で探索し、1,024根で同時16約30分である。
追跡は固定深さで機構を1つずつ変えるため、探索木の大きさによって費用が変わる。
静止探索の計画で使う6根の追跡時間から1根あたりの費用を求め、1,024根あたり約25根の大きな誤りを追跡する見積りをフェーズ0の開始前に記録し、最初の1,024根の実測で更新する。
1根あたりと1回あたりの追跡時間の上限は「誤りを分類する」の節に定め、上限で中断した場合の費用は上限の値そのものとする。
学習時間は補正項の種類によって桁が異なるので、補正項を選んだ後、その1区間をフェーズ1で実測して見積もる。
STCとLTCの幅は、静止探索の計画の見積りと同じ根拠による。

## 実装フェーズ

### フェーズ0　誤りの分類

定義と基準を固定してから診断用の対局を生成し、大きな誤りを追跡する。
探索の変更で解消した根を分けた後、残る根の関係を独立に分類する。
結果は測定記録`relational-correction-prep`へ残し、補正項の種類を1つ選ぶか見送る。
種類を選んだ場合は、訓練教師の代理診断と、自己選択の閾値を引き継ぐ前提の記録を同じ記録へ残してからフェーズ1へ進む。

### フェーズ1　推論と差分更新

選んだ補正項の推論、差分更新、および重み形式を実装し、補正0でのS0との一致と速度を記録する。

### フェーズ2　学習

学習器を実装して補正項を学習し、学習曲線と対局単位の検証損失を測定記録`relational-correction-training`へ残す。

### フェーズ3　診断

採否前の3つの診断を行い、倍率を決めて測定記録`relational-correction-diagnostics`へ残す。

### フェーズ4　採否

段階ゲートを行い、測定ごとに記録を残す。

### フェーズ5　現行設計の更新

採用した場合は「停止と後続の判断」の節に従って関係する文書を更新し、本書の状態を完了へ書き換える。

## 検証

完了の前に、次の確認を行う。

- 補正項の差分更新は、捕獲、2枚捕獲、居喰い、成り、王駒の移動と捕獲、太子の出現、および先獅子の変化を含む着手列で、全再計算と整数で一致する。
- 補正0の評価は、全局面でS0の評価と一致する。
- 左右鏡映と手番の視点の扱いが構成案の定義どおりであることを、鏡映した局面の組で確かめる。
- 学習器の評価値は、Rustの評価値と一致する。
- 型S、H、Pだけで根を除外せず、探索の変更による解消の判定と、関係の分類の分母を記録から再現できる。
- 追跡時間の上限で中断した根と回が、原因未確定と診断未完了として記録から区別できる。
- 訓練教師の代理診断に使った子局面の探索値、診断教師の支持の向き、および学習後の同じ根での選択損失が、根ごとに記録から再現できる。
- 学習局面、対局単位の分割、教師値の定義、混合比、および尺度が、着手時の採用構成と一致する。

## 完了条件

次のいずれかが測定記録とともに確定した時点で、状態を完了にする。

- フェーズ0の採取の停止規則、追跡時間の上限、または分類で見送った。
- 学習中の過学習、採否前の診断、またはSTCで不採用とした。
- LTCで採否が確定した。

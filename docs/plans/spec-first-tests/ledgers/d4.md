## 保留・注記

- **D4-024-04の反復規則合成**: R1（d込み）とR2/R3（a〜cのみ）の判定差そのものは反復裁定層（repetition/adjudication、D4の対象ファイル外）の挙動である。D4側は「盤面キー(a〜c)と権利キー(d)の分離」という局面表現上の境界性質として固定し、規則ごとのキー利用は当該領域のテストに委ねる。
- **D4-IMP-01の「空升の除去の拒否」**: `remove_piece` は非公開でdebug_assertによる防御のみであり、公開APIとして観測可能な拒否（Result）は存在しない。公開経路（ビルダー・着手適用）では空升除去に到達しないため、観測可能な境界（二重配置・EMPTY/WALL配置の拒否）だけをテストした。受理挙動の変更が必要になった場合はSPEC_UNCLEARへ差し戻す。
- **マトリクスD4-IMP-06の「17対」表記**: 本文の対応表は18対を列挙しており（成れない駒種は王将・玉将/獅子/奔王の3種、21−3=18）、「17」は誤記と判断して表の内容(18対)を期待値とした。

## マトリクス78挙動のカバレッジ集計

- テスト化: 75/78。USI 34/34、CECP 29/31、ENG 6/7（ENG-07はテスト実装方針のメタ契約であり、本再構築が方針として遵守）、CLI 6/6（CLI-01はtry_parse_from単体レベル、プロセス終了コードは未検証。CLI-05はminase・usi_randomの接続確認のみで、match_runner・random_playはD6の編集対象外）。
- 保留（テスト不能・部分）:
  - D6-CECP-10（部分）: 2レグ手・じっとのエンジン送信形式。決定的台本で多レグ手を強制するには探索の着手選択（評価依存）の固定が必要であり、「具体的な着手を固定しない」規律と両立しない。受信側のレグ形式（D6-CECP-07）と単レグ送信＋レグ連結往復は検証済み。
  - D6-CECP-20（部分）: time/otimのセンチ秒→ミリ秒スケーリングの数値は、privateフィールドを読まずにwireから観測できない（時間予算の実測はD7領域）。受理の外形とlevel/stの正規化純関数は検証済み。
  - D6-CECP-30: エンジン着手拒否時のtellusererror＋force退避。正常系では到達不能な防御的契約であり、マトリクス自身が「通常台本では検証不能（変異検証フェーズ4の対象）」と明記。
  - D6-CECP-09（部分）: `@@@@`の代表選択（移動元の内部密番号最小）は全候補が同一の後続局面を生むためwire観測不能。受理・拒否の外形のみ検証（マトリクスの分担指示どおり）。
  - SU-01/02/03（文書補修待ち・明文なし）: go depthの上限境界、movetime併用優先順位、同一引数重複はテスト化しない。

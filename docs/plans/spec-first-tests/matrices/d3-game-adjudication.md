# D3 対局進行と裁定　挙動マトリクス

本書は、spec-first再構築マイルストーン（docs/plans/spec-first-tests.md）のフェーズ2成果物として、領域D3「対局進行と裁定」の期待挙動を規範文書だけから導出したものである。期待値の根拠は RULES.md 第12版（特に第20〜27条・第31〜32条・第24〜25条）、docs/plans/game-referee.md の設計確定事項、および docs/plans/adjudication-refactor.md の設計確定事項に限り、実装コードは一切参照していない。条文から確定できない挙動は末尾のSPEC_UNCLEAR登録簿へ記録し、期待値を捏造していない。

期待観測は、対局結果（勝敗・引き分け・継続）、勝敗理由、合法手集合の変化、着手の受理・拒否として記述する。実装APIの名前は使わない。「対局合法手」は局面合法手からR2・R3の禁止手を除いた集合をいう（adjudication-refactor.md「合法手の用語」）。

## 記法と共有フィクスチャ

**座標**: 升を（列, 段）で表す。列は第5条初期配置図の左から1〜12、段は図の上（後手側一段目）を1、先手側最下段を12とする。先手の「前」は段の減少方向である。敵陣は先手にとって段1〜4、後手にとって段9〜12。最奥段は先手の歩兵・香車にとって段1、後手にとって段12である。

**F1（反復12手列）**: 初期局面から次の4手を1周期として繰り返す。①先手仲人(4,8)→(4,7)、②後手仲人(9,5)→(9,6)、③先手仲人(4,7)→(4,8)、④後手仲人(9,6)→(9,5)。④の完了時に初期局面（先手番）が2回目として出現し、⑧完了時に3回目、⑫完了時に4回目が出現する。全12手は非捕獲・非王手であり、動かした仲人の到達升からの利き（前後1升）はいずれも空升に向くため、第31条R1の定義ですべて非攻撃的着手である。対局開始局面は履歴上の第1回として数える（adjudication-refactor.md「任意局面と履歴」）。

**F2（駒枯れ基本形）**: 先手は王将1枚、後手は玉将＋飛車1枚。直前の後手の着手（飛車が先手の最後の非王駒を捕獲）で第22条1項の条件が成立し、手番は先手（裸側）。行ごとに飛車の位置（先手王将の利き内か否か）を指定する。

**F3（合法手なし形）**: 先手王将(1,1)、先手歩兵(2,1)（先手最奥段で不成のまま第19条2項により移動不能）、先手香車(1,2)および(2,2)（前方の(1,1)・(2,1)が自駒で閉塞し、香車は前方以外へ動けない）。後手玉将ほかの後手駒は遠方に置く。手番先手。先手の王将の隣接3升(1,2)(2,1)(2,2)はすべて自駒であり、歩・香は移動不能のため、王駒の安全性を考慮せずとも先手の着手が1つも存在しない。

**F4（二王駒形）**: 先手は王将＋太子（醉象が第20条2項により成ったもの）＋補助駒、後手は玉将＋攻撃駒。

**F5（獅子二王駒取り形）**: 先手獅子(6,6)、後手玉将(6,5)、後手太子(6,4)。手番先手。獅子の2段階移動の第1段階で(6,5)の玉将を取り、第2段階で(6,4)の太子を取れる配置。

**F6（E3裸玉形）**: E3採用下で、先手は王将のみ（裸玉側）、後手は玉将＋価値ある駒（構成と配置は行ごとに指定）。裁定は各着手の完了時に行う。

## SPEC_UNCLEAR登録簿

以下は規範文書から期待挙動を確定できなかった事項である。assertを書かず、必要なら文書補修（spec-first-tests.md「SPEC_UNCLEARの扱い」）へ回す。

1. **投了・合意引き分けの手続き的細目**（第21条6・7項）。表明できる時点（手番中か随時か）、非手番側の投了の可否、終局済み対局への投了・合意の入力に対する応答は条文にない。第27条2〜3項は不合法入力の処理を運用規定へ委ねるが、投了・合意は着手ではないためその規定の対象かも不明である。
2. **第21条3項cの外延**。「直ちに自分の勝利を成立させる着手」に、R1の継続攻撃側敗北を成立させる着手が含まれることはadjudication-refactor.mdで確定している（D3-021-05）。しかし駒枯れ勝利を成立させる着手（歩兵の金成りなど）やE3裁定を成立させる着手を同号に数えるかは明文がない。
3. **第24条1項dの発生源と符号化**。実装が選択できるローカルルールのうちdに該当する一時的権利（P1・P2の成り権回復待機が候補）を、R1の同一局面判定へどう反映するかの細目はRULES.mdにない。第31条はR2・R3でのd除外だけを定める。P1・P2採用時のR1対局が構成可能になるまで、D3-024-04の到達手段は保留する。
4. **先獅子の未解決3論点が第24条1項cへ与える影響**（adjudication-refactor.md「既知の規則上の曖昧さ」）。1手で獅子2枚を取る場合のトリガー升、取った側に獅子が複数残る場合の禁止対象、先獅子中の隣接取り返しは文献上未解決であり、現行解釈の維持が確定している。D3では現行解釈を所与とし、その内容の当否をテストしない（当否の所有はD2領域）。

6. **R1の区間の端点**。「最初の同一局面から4回目までの間、自分のすべての着手」について、最初の出現を生じさせた着手自身を区間に含むか（両端の開閉）は条文から一義に読めない。

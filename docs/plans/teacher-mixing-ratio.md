# 教師の混合比λ=1.0（探索値だけの教師）の設計書

## 先に読む要約

本書は、評価関数の学習に使う教師値（学習の目標にする値）のうち、探索値と対局結果を混ぜる比率λを現行の0.75から1.0（探索値だけ）に変えた候補を学習し、直前の採用版に対する採否を自己対局で確かめる。
現行の教師値は `t = λ · sigmoid(v / K) + (1 − λ) · result` であり、λ=0.75は[評価関数](evaluation.md)が初期値として置き、世代0で比較して固定すると定めた値だが、その比較の測定記録は残っていない。
[チェス評価関数の教師と混合比の調査](../research/chess-evaluation-targets.md)によれば、先行するチェスエンジンには対局結果だけ、探索値だけ、および両者を混ぜる方式があり、75:25を普遍的な最適値とする根拠はない。
利用者の判断により、比較する比率は1.0の1つに固定する。自己対局は平均640手と長く対局結果の雑音が大きいので、探索値だけを教師にする方が学習の目標の分散が小さいという見込みによる。
候補は、直前の採用版の学習PSTを初期値に、段階7の採用設定と同じ入力で学習し、直前の採用版との差は重みファイルだけとする。
λ=0.75で同じ追加学習をした対照は作らないので、本書の結論は「λ=1.0での再学習の工程全体の効果」であり、混合比だけの効果ではない。
教師値が異なる候補は学習損失では比べられないので、対局結果の予測誤差など共通の指標を診断として記録したうえで、採否は短時間と長時間の時間制御GSPRT（[docs/guides/sprt.md](../guides/sprt.md)）だけで決める。
完了条件は、候補の学習と診断、短時間および長時間の測定の結果と採否（または見送り）が測定記録とともに残り、採用した場合は評価関数の設計書のλの値が更新され、採否にかかわらずROADMAPの状態表が本書の結論と一致していることである。

## 状態

起案。2026年9月22日に起案し、同日にレビューと利用者の判断（比率を1.0に固定）を反映した。
着手は、進行中の[先読み教師値](lookahead-teacher.md)の候補の採否が確定した後とする。その結果によって、本書の候補の基点（直前の採用版とその教師の作り方）が決まるためである。
次の一手は、学習器への比率の上書きの実装である。

## 目的

教師値の混合比は、探索値の信頼性と対局結果の雑音の釣り合いで決まる量であり、エンジンごとに異なる。
minaseの探索値は10万ノード（深さ約6）の浅い探索の値であり、対局結果は着手列の偶然に強く依存する。
対局結果を混ぜれば浅い探索の盲点を補える可能性があるが、[棋力向上段階9](strength-stage9.md)の診断では、対局結果が持ち込む信号は王の安全度の特徴について検出できなかった。
一方で、対局結果の雑音が学習の目標を乱している可能性は残る。
本書は、対局結果を教師から外した候補を対局で測ることで、この可能性を確かめる。

## 適用範囲

対象は `tools/train/pst/` の学習器（教師値の計算と教師の分類）と、学習した重みファイルだけを差し替えた候補である。
評価関数の特徴、探索、教師データの形式、生成器は変えない。
本書の用語は[評価関数](evaluation.md)、[棋力向上段階9](strength-stage9.md)、および[先読み教師値](lookahead-teacher.md)に従い、次の語を加える。

- **混合比λ**は、教師値に占める探索値（または先読み値）の割合を指す。λ=1は探索値だけ、λ=0は対局結果だけの教師である。
- **基点**は、本書の着手時点の直前の採用版を指す。基点の学習PSTを初期値とし、基点の教師の作り方（現行の探索値か先読み値か、γとn）を引き継ぐ。基点と教師の設定は、着手時に準備の記録へ固定する。
- **比率の上書き**は、来歴ファイルが持つ自己対局の分類のλを、学習時の設定で一括して置き換えることを指す。来歴ファイルは変えない。
- **教師の参照値**は、基点の教師の設定で各局面に与えられる探索側の値（現行の探索値、または先読み値）を指す。

## 依存関係

教師の分類、来歴ファイル、および学習時の変換の記録は、[棋力向上段階9](strength-stage9.md)のフェーズ4と[先読み教師値](lookahead-teacher.md)の基盤を使う。
ブランチは、これらの基盤がmasterへ入っていないため、`lookahead-teacher` から分岐した `teacher-mixing-ratio` とする。
基点は、[先読み教師値](lookahead-teacher.md)の候補が採用されればその候補（先読み教師、γ=0.9、n=40）、採用されなければ段階開始版（現行の教師）である。
測定の基本シードは、段階9と先読み教師値が割り当てた範囲（41000921から51000921）の続きから取る。

## 設計判断

| 項目 | 決定 |
|---|---|
| 比率 | λ=1.0の1つとし、結果を見て値を足さない。利用者の判断による。当初の案の0.25と0.5は測らない。λ=0（対局結果だけ）は、探索値を捨てると学習の目標の分散が大きくなり、段階9の診断でも対局結果の信号は検出できなかったので候補にしない。 |
| 対照 | λ=0.75で同じ追加学習をした対照は作らない。対照を作ると測定が2倍になるためである。したがって候補の比較相手は基点そのものであり、結論は「λ=1.0での再学習の工程全体の効果」と表現し、混合比だけの効果とは言わない。 |
| 候補の構成 | 基点の学習PSTを初期値に、段階7の採用設定（鏡映共有、学習率0.03、駒除去差分の追加損失の係数1000、10エポック、バッチ16,384、乱数シード1、出力K固定）で、基本の教師の11ファイルから学習する。追加特徴は含めない。基点と候補の差は重みファイルだけとする。 |
| 比率の上書きの実装 | 学習の設定 `train.lambda_override` で、自己対局の分類（`result_origin` が `selfplay`）のλを一括して置き換える。実戦棋譜の分類（λ=0）には適用しない。未指定と明示的な値を区別し、指定がなければ来歴のλを使う。上書きしたλは教師の分類の属性として教師Kの推定と `inputs.json`、`training.json` に記録し、準備の記録に固定して、学習と診断と再開時に照合する。先読みと併用する場合も、教師の分類は先読みの属性と上書きしたλの両方を持ち、教師値の計算は同じ実効λを使う。 |
| 教師Kの扱い | 教師Kは候補の学習で訓練の分割から推定し直す。λ=1でも対局結果からKを推定して探索値の勝率への換算に使う。「探索値だけ」は混合式に対局結果を直接加えないという意味であり、Kの校正に対局結果を使わないという意味ではない。同じ入力、分割、先読みの設定なら、Kは基点と同じ値になる。 |
| 共通の診断 | 候補と基点の教師値は異なるので、学習損失で比べない。検証の分割について次を記録する。(1) 対局結果の二値交差エントロピー: 評価値を固定の出力Kで勝率へ換算し、対局結果（負け0、引き分け0.5、勝ち1）との二値交差エントロピーを、局面の平均と対局ごとの平均の平均の2つで出す。(2) 教師の参照値との平均絶対誤差: 段階7の診断と同じく、世代と局面帯ごとの標本について、生の値と `出力K / 教師K` で換算した値の両方をセンチポーンで出す。(3) 符号の一致率: 引き分けの局面と評価値が0の局面を除き、評価値の符号と対局結果の勝敗が一致する割合を、除いた件数とともに出す。(4) 除去差分から導いた駒価値。これらは記録であり、採否には使わない。 |
| 採否 | STCとLTCの標準手順に従い、候補は基点に対して測る。 |
| 診断に失敗した候補 | 学習後の診断（量子化の平均絶対誤差が2センチポーン以下、Rustと学習器の評価値の一致、駒除去差分の符号の反転なし、探索用駒価値と出力Kの不変）に失敗した場合は測定へ進まず、原因を調べる。原因が学習器の不具合なら修正して同じ設定で学習し直す。λや学習の設定を変えて通す再学習は行わない。原因を除けない場合は見送りとして記録する。この扱いは測定の前に固定する。 |
| 先読み教師値との関係 | 本書は比率だけを変え、先読みの有無は基点に従う。先読みと比率の交互作用は評価しない。 |
| 学習中に比率を変える方式 | Stockfishが採る、学習の途中でλを変える方式は採らない。固定の比率の結果が分かってから検討する。 |

## 実装フェーズ

### フェーズ1　比率の上書き

学習器と診断器に `train.lambda_override` と対応するコマンドライン引数を加え、自己対局の分類のλを置き換え、教師の分類の属性、教師Kの推定、記録、準備の記録への固定、および再開時の照合に反映する。
完了条件は、次のことがテストで固定されていることである。

- 上書きが自己対局の分類にだけ適用され、実戦棋譜の分類のλ=0は変わらない。
- 上書きしたλで教師値と教師Kが計算され、分類の記録に上書きの値が入る。未指定と明示的な値が区別される。
- 範囲外の値（0未満、1超、非有限）が拒否される。
- 準備の記録に固定した上書きの値と、学習および診断の設定が一致しない場合に拒否される。

### フェーズ2　候補の学習と診断

基点の設定に `train.lambda_override = 1.0` を加えた設定で学習し、学習後の診断と本書の共通の診断を通す。
結果は測定記録 `teacher-mixing-ratio-training` に残す。

### フェーズ3　採否測定

候補を `teacher-mixing-ratio-100-stc`（基本シード54000921）で測り、[SPRTの手引き](../guides/sprt.md)の振分け規則に従って `teacher-mixing-ratio-100-ltc`（基本シード57000921）へ進める。

## 検証

- 候補の学習は基点と同じ入力、初期値、設定、乱数シードで行い、設定の差が `train.lambda_override` だけであることを準備の記録で確かめる。
- 学習後の診断は段階7と段階9の基準に従う。量子化の前後の平均絶対誤差が2センチポーン以下であること、Rustと学習器の評価値が一致すること、駒除去差分の符号の反転がないこと、探索用駒価値と出力Kが変わらないことを確かめる。
- 採否測定は[SPRTの手引き](../guides/sprt.md)の標準コマンドに従い、エンジン異常、時間切れ、拒否着手が0件であることを採用の条件にする。
- すべてのコミットで `cargo test`、`cargo clippy -- -D warnings`、`cargo fmt --check`、および学習器の単体テストが通ることを確かめる。

## 完了条件

- 候補の学習、共通の診断、STCとLTCの結果と採否、または診断の失敗による見送りが測定記録に残っている。
- 採用した場合は[評価関数](evaluation.md)の「教師値と損失」のλの値と、[PSTの学習手順](../guides/pst-training.md)の設定が更新されている。
- 採否にかかわらず、ROADMAPの状態表が本書の結論と一致している。

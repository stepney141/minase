# 手作り評価項目の係数を自己対局から学ぶ先行研究

「人間がヒューリスティックな評価項目を定義し、その係数を自己対局から学ぶ」という方式には、直接対応する先行研究と実装がある。
多数の戦略的な評価項目を持つ実装ではTexelが、駒価値と駒の位置に対する重みを扱う学術研究ではBealとSmithの1999年の論文が該当する。
以下は2026年9月22日に確認した一次資料に基づく。
探索値と対局結果の混合比は、別の[教師に関する調査](chess-evaluation-targets.md)で扱う。

## 対象となる学習

線形の評価関数なら、局面を \(x\)、人間が定義した特徴を \(\phi_j\)、学習する係数を \(w_j\) として、基本形を次のように書ける。

\[
E_w(x)=\sum_j w_j\phi_j(x).
\]

例えば、人間が「孤立ポーンの個数」を数える処理を作り、その1個あたりの減点を学習する。
学習が決めるのは、その項目を設けるかどうかではなく、定義済みの項目が評価へ及ぼす強さである。
実際の評価関数には非線形項や局面の進行に応じた補間もあるため、すべてが上の単純な線形式に収まるわけではない。

## Texel

Texelは、駒価値、ポーン構造、可動性、王の安全性などを人間が実装し、係数を自己対局データから調整した直接の先例である。
1.03のソースには、二重ポーンや孤立ポーンへの減点、ビショップ対や開いた筋のルークへの加点、王の安全性の重み、および駒の可動性に対応する表がある。
特徴の計算式と調整対象の定数をコード上で区別できる。[係数と表の定義](https://github.com/peterosterlund2/texel/blob/ed426c529eeab401c19ead47e15221d1cbfc634c/texellib/src/parameters.hpp#L458-L525)、[可動性の計算例](https://github.com/peterosterlund2/texel/blob/ed426c529eeab401c19ead47e15221d1cbfc634c/texellib/src/evaluate.cpp#L646-L674)

Peter Österlundの2014年1月31日の説明では、現行版や過去版のTexelが指した64,000局から、約880万局面を学習用に抽出する。
各局面の教師は、その対局の白勝ち1、引き分け0.5、黒勝ち0である。
外部の強いエンジンによる評価値を必須とせず、自分で指した対局の結果から係数を求めている。[作者の原説明](https://www.talkchess.com/forum/viewtopic.php?start=26&t=50823)

学習する評価関数を用いた静止探索の出力を \(Q_w(x)\)、シグモイド変換を \(\sigma\)、対局結果を \(z_i\) とすると、最小化する誤差は次の形になる。

\[
L(w)=\frac{1}{N}\sum_{i=1}^{N}\left[\sigma(Q_w(x_i))-z_i\right]^2.
\]

静止探索は、駒の取り合いなどが続く局面をそのまま評価しないために行う探索である。
ここで探索値は学習対象の予測側にあり、固定した探索値を教師へ混ぜるわけではない。
引き分けを0.5とするので、予測対象は厳密には勝率ではなく、勝率に引き分け率の半分を加えた得点期待値となる。[作者の目的関数](https://www.talkchess.com/forum/viewtopic.php?start=26&t=50823)、[静止探索と誤差計算](https://github.com/peterosterlund2/texel/blob/ed426c529eeab401c19ead47e15221d1cbfc634c/texelutil/src/chesstool.cpp#L628-L668)

作者は当時、整数係数を1つずつ増減する局所探索で約400個の係数を調整した。
公開コードも、係数を変えるたびに静止探索を再実行し、誤差が減れば変更を保持する。
コードでは平均二乗誤差の平方根を比較するが、この単調変換は最小化の解を変えない。[作者の調整手順](https://www.talkchess.com/forum/viewtopic.php?start=26&t=50823)、[局所探索の実装](https://github.com/peterosterlund2/texel/blob/ed426c529eeab401c19ead47e15221d1cbfc634c/texelutil/src/chesstool.cpp#L210-L267)

作者は7段階の改善量を合計して99.6 Eloと報告している。
各段階は1秒＋1手0.08秒の条件で32,000局を指して測定され、途中には評価項目の追加や学習データの変更も含まれる。
この値は、固定した特徴とデータに対する1回の係数学習の効果でも、開始版と最終版の直接対局による測定値でもない。[作者の結果報告](https://www.talkchess.com/forum/viewtopic.php?start=26&t=50823)

## BealとSmithの学術研究

D. F. BealとM. C. Smithの「Learning Piece-square Values using Temporal Differences」は、1999年のICCA Journal、22巻4号、223〜235頁に掲載された研究である。
人間が用意した駒価値と駒種ごとの位置評価という表現について、重みをゼロから自己対局だけで学習する。
出版社の要旨は、自己対局だけを使ったことと、駒価値だけの場合を位置評価も加えた場合と比較したことを明記している。[出版社の要旨と書誌情報](https://journals.sagepub.com/doi/abs/10.3233/ICG-1999-22404)

学習には時間差分学習を使い、得られた位置評価にはチェスの初歩的な知識と対応する傾向が現れたと報告している。
人間が「駒の種類と位置を評価へ反映する」という形式を選び、各組合せの値を対局から求める点で、質問の方式に該当する。
ただし、王の安全性や孤立ポーンなどの多様な項目を同時に調整する実例としては、Texelのほうが近い。[出版社の要旨](https://journals.sagepub.com/doi/abs/10.3233/ICG-1999-22404)

この論文について今回確認できたのは出版社が公開する要旨と書誌情報であり、本文の実験条件や棋力の改善量は未確認である。
したがって、自己対局による係数学習の先例として引用し、学習局数や棋力向上の数値は示さない。

## Ethereal

Etherealの公開された手作り評価関数用チューナーも、駒価値、可動性、ポーン構造、王の安全性などの重みを学習する。
対局結果を勝ち1、引き分け0.5、負け0として、静的評価のシグモイド変換との平均二乗誤差を減らす。
更新には、過去の勾配に応じて更新幅を調整するAdaGradを使う。[評価項目](https://github.com/AndyGrant/Ethereal/blob/0e47e9b67f345c75eb965d9fb3e2493b6a11d09a/src/tuner.c#L46-L118)、[対局結果の読込み](https://github.com/AndyGrant/Ethereal/blob/0e47e9b67f345c75eb965d9fb3e2493b6a11d09a/src/tuner.c#L206-L226)、[損失](https://github.com/AndyGrant/Ethereal/blob/0e47e9b67f345c75eb965d9fb3e2493b6a11d09a/src/tuner.c#L343-L358)、[更新](https://github.com/AndyGrant/Ethereal/blob/0e47e9b67f345c75eb965d9fb3e2493b6a11d09a/src/tuner.c#L147-L158)

Andrew Grantの解説§2.2には、100万局を単位とする自己対局群から局面を取り出す方法が記されている。
各局面を深く探索し、最善とされた手順の終端局面へ変換してから、元の対局結果を教師として学習する。
作者は、変換後の局面に元の対局結果を付けることで対応が弱まり得る点も認めている。[作者の解説§2.2](https://github.com/AndyGrant/Ethereal/blob/0e47e9b67f345c75eb965d9fb3e2493b6a11d09a/Tuning.pdf)

Etherealの2017年の改善報告は、外部で公開された局面データを使った初期の実験であり、後年の自己対局データによる方式とは区別する必要がある。
その24 Eloと48 Eloの改善を、自己対局だけで得た効果として引用することはできない。[2017年の作者報告](https://www.talkchess.com/forum/viewtopic.php?t=65538#p736294)

## minaseとの関係

以上から、人間が評価項目を設計し、自己対局からその係数を求める構想そのものには、学術研究と公開実装の両方に先例がある。
多数のヒューリスティックな項目を持つminaseの設計に対しては、Texelの方式とEtherealの実装が直接の比較対象になる。
ただし、この対応は方式の先例を示すものであり、中将棋での棋力向上や、探索値75%と対局結果25%という教師の混合比を保証しない。
特にTexel原法とEtherealの公開チューナーは対局結果だけを教師にしているため、特徴をどう設計するかと、教師をどう作るかは別に判断する必要がある。
調査済みの10項目と現在の学習器への具体的な適用は、[評価項目の自己対局による係数学習](evaluation-terms-selfplay-feasibility.md)にまとめた。

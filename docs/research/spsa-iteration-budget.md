# SPSAの反復予算の決め方

SPSAの反復数は、調整に使える対局予算から開始時に決め、完了後の独立した棋力測定で次回の規模を見直す。
所定の反復数への到達は最適値への収束を意味しない。
Spallの解説は、許容する最大反復数への到達または連続する反復の小さな変化を実用上の停止条件として挙げる一方、漸近的な収束率が有限回の実行を代表するとは限らないと説明している。[Spallの解説、pp. 484, 490](https://www.jhuapl.edu/spsa/pdf-spsa/spall_an_overview.pdf)
公開セッションの規模は[既存の調査](chess-engine-spsa-session-sizes.md)にまとめてあり、必要数の下限としては扱わない。

## 時間から反復数へ換算する

調整に使う時間をT時間、実測した処理量をqペア/時間、1反復のペア数をbとすると、反復予算の目安は `N = floor(qT / b)` になる。
1ペアは同じ開始局面で先後を入れ替える2局なので、予定局数は `2Nb` である。
Tには採否を判定する別対局の時間を含めず、棋力検証の予算を別に確保する。

minaseの[現行設計](../plans/spsa.md#調整セッションの規模と所要時間)は、約380ペア/時間という過去の実測に基づき、1,500反復×8ペア＝12,000ペアを約32時間の初回予算としている。
同設計の概算では、有利な摂動の効果が一定の5 Eloなら係数の期待移動量は探索範囲の約5.1%であり、無勾配で引き分けのない独立局を仮定した偶然の移動量の標準偏差は約2.4%である。
これらは仮定に依存する規模の見積もりであり、22係数の収束を保証しない。

反復数を比較するときは、1反復のペア数も揃えて読む必要がある。
Fishtestは1反復を2局と数えるが、OpenBenchは調整点の評価数を反復数とし、1点あたりのペア数を別に指定する。[Fishtestの公式手引き](https://github.com/official-stockfish/fishtest/wiki/Creating-my-first-test#spsa-algorithm-in-fishtest)、[OpenBenchの公式手引き](https://github.com/AndyGrant/OpenBench/wiki/SPSA-Tuning-Workloads#spsa-hyperparameters)
同じ総ペア数でも、1方向を測るペア数を増やすと摂動方向を引き直す回数が減るため、反復の配分を変えた実行が同じ結果を出すとは限らない。

## 停止後に原因と採否を分ける

係数が動かない場合は、最適値への到達を結論する前に、摂動幅と学習率、整数への丸め、および係数が対局中に使われる頻度を確認する。
Fishtestの手引きは、数千局後にもほとんど動かない調整を止めるよう勧め、摂動幅が小さすぎて効果を捉えられない場合を理由として挙げている。[Fishtestの公式手引き](https://github.com/official-stockfish/fishtest/wiki/Creating-my-first-test#spsa-tests)
minaseでも学習率と摂動幅を反復とともに減らすため、終盤の変化が小さいことだけでは収束を判定できない。[minaseの更新則](../plans/spsa.md#更新則)

完了した候補の採否は、調整値を固定したコミットと調整前コミットの新しい対局で、逐次確率比検定（SPRT）により判定する。[minaseの採否手順](../guides/spsa.md)
予定した反復を終えたか、調整値が動いたか、棋力が改善したかは別の問いなので、採用できなかった場合も反復不足と即断せず、係数の履歴と調整条件から次の実行を設計する。

総反復数の変更は、新しいセッションとして行う。
minaseでは総反復数が学習率と摂動幅の式に入り、[手引き](../guides/spsa.md)が途中変更を禁じている。
Fishtestも開始時の総局数からハイパーパラメーターを決めるため総局数を変更できないとしており、単純な延長を通常の運用として扱っていない。[Fishtestの公式手引き](https://github.com/official-stockfish/fishtest/wiki/Creating-my-first-test#spsa-tests)

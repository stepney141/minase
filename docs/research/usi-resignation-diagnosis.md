# 保存済み対局記録による投了閾値の診断

## 結論

保存済みの自己対局記録104,224局へ、着手した側の評価値が閾値以下なら投了する仮想条件を当てた結果、どの閾値でも誤投了（投了した側が実際の対局では勝つか引き分けた局）は0件にならなかった。
詰み帯（`mated_in`の報告）だけを条件にしても、31局（発火した局の0.03%）で報告した側が勝っている。
したがって、投了の閾値は誤投了0件では決められず、誤投了で放棄する得点の割合と、投了によって省ける思考時間との比較で決める。
放棄する得点の割合と削減時間は閾値に対して単調であり、全記録と現行構成群（2026年9月8日以降のコミット同士の時間制御の測定）で同じ形をとる。

| 閾値 (cp) | 放棄する得点の割合（現行構成群） | 削減時間 |
|---|---|---|
| 3,000 | 0.88% | 13.4% |
| 3,500 | 0.40% | 9.8% |
| 4,000 | 0.19% | 7.2% |
| 5,000 | 0.06% | 4.0% |
| 詰み帯のみ | 0.03% | 0.7% |

放棄する得点の割合は、対象局のうち仮想的な投了で失う得点（勝ち1、引き分け0.5）の合計を局数で割った値であり、過去の実装が投了条件の成立後に取り戻した得点の割合である。
既定値の選定は、この表を根拠にした過去標本に基づく運用上の判断であり、[USI投了の設計書](../plans/usi-resignation.md)が利用者の決定として確定する。
選んだ閾値を未参照の対局で検証してはいないので、この表は公開対局での逆転率を保証しない。

## 入力と方法

入力は、2026年9月23日時点で`data/matches/`配下にあった116実行ディレクトリの`pairs/`にある局ごとの記録（[棋力測定ハーネス基盤の効率化](../plans/match-harness-efficiency.md)の保存形式）である。
各着手の記録は、評価値、視点、深さ、上下界の種別、思考時間、および応答を持つ。
除外前の105,760局から、時間切れと異常（`forfeit`、286局）および手数上限の打ち切り（`cutoff`、1,250局）を除き、審判裁定、投了、および引き分けで終わった104,224局を対象にした。
集計中に別の測定が進行していたので、同じ手順でも局数は数十局の幅で変わり得る。

仮想条件は次のとおりである。
着手した側の視点へ換算した評価値が閾値以下（`mated_in`は常に以下、`mate_in`は常に超過）、深さが1以上、上下界の種別が`exact`の着手を発火とし、時系列で最初の発火でその局を仮想的に終える。
閾値の候補は1,500から8,000 cpまでの9段階と、負の詰み帯全体（`ResignValue` 29,744に相当）であり、29,744を超える値は診断していない。
誤投了は、発火した側が実際の対局で勝った局（相手の投了による勝ちを含む）と引き分けた局を数える。
削減時間は、発火した着手より後の両者の思考時間の合計を、対象局の思考時間の合計で割った値である。
連続手数は数えない。3,000 cpの誤投了は連続1手で942局、連続2手で820局、連続3手で770局であり、連続を要求しても1〜2割しか減らないので、状態を持つ費用に見合わない。

現行構成群は、候補と基準の両方が2026年9月8日（序中盤と終盤を補間するPSTの採用日）以降のコミットで、思考制限が時間制御、規則が`engine-default`の55実行ディレクトリ（除外前54,928局、除外後53,779局）である。
この群には、Factorization Machineによる評価、段階7の再学習、先読み教師による再学習など、出力の目盛りは同じでも重みが異なる評価モデルの対局が混在しており、評価モデルごとに分けた集計は行っていない。
評価尺度が異なる過去の評価関数、固定深さの測定、および外部エンジンとの対局を含む全記録の表を併記した。

再現手順は次のとおりである（リポジトリ直下で実行する）。

```console
python3 scripts/resign_diagnosis.py table --boundary 2026-09-08
python3 scripts/resign_diagnosis.py detail mate
```

## 詰み帯の誤投了の内訳

詰み帯の31局の終局理由は、詰み21局、駒枯れ（RULES.md第22条）6局、反復の裁定4局である。

駒枯れの6局では、王駒だけになる直前の数手で、余分な駒を持つ側が`mated_in`、王駒だけの側が`mate_in`を報告したまま、審判層が余分な駒を持つ側の勝ちを裁定した。
探索は駒枯れを知らないので、王駒を取られる読みと駒枯れの裁定が食い違う。

残る25局では、`mated_in`の報告が消えた後に、数十手から数百手をかけて逆転し詰ますか、反復の裁定で勝っている。
`mated_in`を報告した自分の着手の数は、22局で1手、3局で2手である。
報告と同じ時点の相手の評価値は、17局で数百から数千cpの優勢、8局で0以下であり、相手が`mate_in`を報告した局はない。
この型の`mated_in`が探索の見落とし（相手の詰み手順を過大に読む）なのか、相手の見落とし（実在する詰みを相手が読めなかった）なのかは、本診断では確定していない。
同じ条件の自己対局で片側だけが詰みを報告する頻度は発火した局の0.03%であり、投了の費用としては小さいが、探索部の調査対象として記録しておく。

## 数値の解釈

放棄する得点の割合は、双方のうち先に発火した側が放棄する得点を局単位で数えた値であり、片側だけが投了を導入したときの得点差ではない。
同じ開始局面から先後を入れ替えた2局の相関も補正していないので、標本誤差の区間は示さない。
閾値の順序づけは、隣り合う閾値の間で誤投了の件数が2倍前後変わることに基づく。

誤投了の頻度は自己対局での逆転率に基づく。
lishogiの公開対局の相手は人間であり、優勢な人間が勝ち切れない頻度は自己対局の相手より高い可能性があるので、公開対局での逆転率は表の値より大きい側に見積もる必要がある。

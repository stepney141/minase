# 標準レシピv3でのA型のNNUEの世代反復の系列

## 系列の説明

本書は、中将棋エンジンminaseの評価関数NNUE（着手ごとに差分で更新できる小さなニューラルネット）の世代反復のうち、標準レシピv3で手書きの評価関数v0からやり直した系列のページである。
世代反復では、前の世代のネットによる自己対局の局面に探索値を付けた教師を生成し、その教師だけから次の世代のネットを学ぶ。
この系列は、王の位置を使わない入力A型（駒と升の組をそのまま入力にする形）のネットを、第N世代に約N億局面の教師を使って、最大第5世代まで作る計画だった（[世代反復の設計書](../../plans/archived/nnue-generation-iteration.md)）。
教師の生成と学習の条件は、[学習の手引きの標準レシピ](../../guides/nnue-training.md#標準レシピ)が定める。

世代のネットはgitに入れず、ネットワーク接続の記憶装置（NAS）の`/mnt/synology_nas/minase/nnue/nets/`に、ファイル全体のSHA-256の16進数を名前にして置く。
世代ごとの教師、学習の出力、および世代の記録`gen-<N>/generation.json`は、手元の計算機（以下、作業機）の`data/nnue-generation-iteration/`にある。
世代の記録は、生成、学習、および判定に使ったコミット、ネットのパスとSHA-256、および教師の勝率尺度（教師の探索値を勝率へ換算する尺度）を持つ。

## 状態

2026年11月20日に着手し、2026年11月24日に第3世代を終えた。
2026年11月25日に、利用者の決定で第3世代で中断し、この系列を凍結した。以後、本書は書き換えない。
第1世代は、手書きの評価関数v0のネット（第0世代）が生成した教師ファイル（以下、本）43本から学び、第0世代との判定で`H1`を取った。
第2世代は、第1世代のネットが生成した86本から学び、第1世代との判定で`H1`を取った。
第3世代は、第2世代のネットが生成した129本から学び、第2世代との判定で`H1`を取って、暫定最良世代（以後の世代の対照）になった。
1億局面に相当する本数は、第1世代の最初の4本の記録局面数の平均2,325,829から43と決まり、第N世代の教師は43N本とする（2026年11月20日の利用者の決定）。
同じ4本から較正した教師の勝率尺度は733.12 cp（cpはセンチポーンで、歩兵1枚の100分の1）であり、全世代で同じ値を使う。
第1世代と第2世代は標準レシピv3で学び、第3世代は、学習器の不具合を直したコミットと標準レシピv4で学んだ（[端数バッチと学習率の設計書](../../plans/archived/nnue-decay-to-end.md)）。
第3世代のネットは、masterのエンジンにそれまでの標準のネット（SHA-256は`37054c9e…`）を渡した対照との比較でも`H1`を取った（[比較の記録](../../measurements/nnue-generation-iteration/nnue-generation-iteration-gen3-master-stc.md)）。
2026年11月24日に利用者が、第3世代のネットを探索の測定に使う標準のネットにすると決めた（[NNUEの評価関数の手引き](../../guides/evaluation-nnue.md)）。
第3世代のネットは、利用者の決定でHugging Face Hubのモデルリポジトリ`stepney141/minase-nets`に`nnue/p/minase-nnue-p-lishogi-20261124-cbbccf6f.nnue`として公開した。
第4世代の教師は生成していない。設計書の採否の測定（旧基準との配置の距離、STC、およびLTC）も行っていない。

## 進捗

世代は最大5つであり、5点以下の推移は表で読めるので、進捗図は作らない。
世代ごとの判定は、持ち時間10秒、1手0.1秒加算の対局で行う逐次検定であり、候補が対照より有意に強いという判定を`H1`と呼ぶ（[測定の手引き](../../guides/sprt.md)）。
対照は、その時点で最後に`H1`を取った世代であり、判定を始める前は第0世代のv0である。

学習と配置の値は次のとおりである。

第3世代は、決まった長さを最後まで学んだ最後の重みであり、最後の検証損失は学習中の最小値と同じだった。
配置の距離Mは、判定の対局での候補の側の駒の配置が、人間の上位者などの配置からどれだけ離れているかを1つにまとめた値であり、偏りの目安として記録する。

## 読み取れること

第1世代は、v0の対局の探索値を1.5エポック学んだだけで、v0に対して得点率0.887（+358 Elo）となり、第2世代は第1世代に対して得点率0.880（+346 Elo）、第3世代は第2世代に対して得点率0.855（+308 Elo）となった。
3世代続けて、前の世代との差は300 Eloを超えている。差は世代ごとに小さくなっているが、95%信頼区間は互いに重なっている。
第3世代は、masterのエンジンにそれまでの標準のネットを渡した対照にも、規則セット`lishogi`の同じ条件で得点率0.899（+380 Elo、95%信頼区間+312〜+479）となった。それまでの標準のネットは別の規則セット`JCSA`で学んだものなので、`lishogi`での強さの比較として読む。
第1世代と第2世代の標準レシピv3の学習では、検証損失は1.5エポックで最小になり、学習は2.5エポックで止まった。第3世代の標準レシピv4の学習では、検証損失は4エポックの最後まで下がり続けた。学習器と学習率の予定が違うので、この違いが教師の量によるものかは分からない。
検証損失の値は、世代ごとに教師が違うので、世代のあいだで比べられない。
書き出しの量子化誤差の絶対値の平均は8.24 cp、14.02 cp、13.18 cpであり、第3世代では増えなかった。
駒を1枚除いたときの評価の変化の符号がv0の駒割と逆になる割合は、0.046%、0.104%、0.270%と世代ごとに2倍以上に増えている。
配置の距離Mは0.265、0.272、0.283と世代ごとに約0.01ずつ大きくなっているが、偏りが問題になった過去のネットの0.46前後より小さい。20〜99手で奔王が1〜2段にいる割合は3.9%、5.7%、7.5%と増えている。
1局の平均手数は、教師の対局で413手、445手、455手と世代ごとに延びている。
学習の最大常駐メモリは1本あたり約0.27〜0.28 GiB（第3世代で35.55 GiB）で、設計書の見込みの約0.36 GBより少なかった。
教師の生成では、入札で借りる中断可能インスタンスがたびたび止められ、合う出品がなくなる状態も起きたので、第1世代の途中からオンデマンドの機械も使っている。
第2世代と第3世代は、1本の生成に約20分かかる機械を使ったので、1本あたりの費用が第1世代の0.30米ドルから約0.40米ドルに上がった。
第3世代では、129本のうち9本を手元の別の機械で生成した。

## 測定の条件

この系列では、全世代の教師の生成と判定の対局に、同じ1つのコミット（設計書の「反復のコミット」）`f2eb705febe317229addc561ff8a0838c545e2eb`のエンジンと生成器を使う。
学習器は、第1世代と第2世代では反復のコミットのものを、第3世代では不具合を直したコミット（設計書の「学習器のコミット」）`afdc36fb9695908762de36215248cccac816b0c3`のものを使った。
世代の判定は、候補と対照の両方に反復のコミットのエンジンを使い、ネットだけを、エンジンの通信規約USIのオプション`EvalFile`で替えて、規則セット`lishogi`で行う。

## 費用
